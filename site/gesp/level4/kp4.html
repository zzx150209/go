引用与参数传递

04
GESP 4级知识字典 · 知识点 04

区分值传递与引用传递，掌握数组作为参数的行为。

检索词：值传递引用参数

参数传递方式决定函数得到的是数据副本，还是能够直接访问调用处的对象。设计修改、交换或只读函数时，要先确定是否需要改变原变量，再选择值、引用或指针。

本课先记住

核心结论

值传递改副本，引用传递改原对象，指针传递通过地址改对象；数组传参还必须单独给出长度。

常用语法

void byValue(int value); // 值参数接收一个新副本
void byReference(int& value); // 引用参数成为实参的别名
void byPointer(int* pointer); // 指针参数接收实参地址

最小示例

void addOne(int& value) { // value 直接代表调用处的整数对象
    value = value + 1; // 修改引用也就修改了原对象
} // 函数结束后，修改结果保留在实参中

关键易错点

  • 想修改实参却使用值传递
  • 指针参数未判空就解引用
  • 在函数内用 sizeof 推算数组参数长度

这节课要会什么

本课建立三个核心：用同一组数据对照值、引用和指针传递；追踪调用前、函数内、返回后的对象变化；为数组和只读大对象选择边界清楚的接口。

从这个场景开始

值传递像把资料复印件交给别人，引用像允许对方直接在原件上修改，指针像把原件的存放地址交出去。三种方式都能传信息，但修改结果完全不同。

知识范围与官方定位

四级需要比较值传递、引用传递和指针传递，理解数组作为参数时的特点，并根据是否需要修改实参选择方式。

01 值传递

值参数得到实参当前值的副本。调用 addOne(number) 时，先创建新的形参 value，再把 number 的值复制进去；两者数值可能相同，但属于不同对象。

函数内修改 value 只改变副本。返回后副本销毁，number 保持原值。它适合 int 等较小数据的只读计算，或本来就只想在副本上处理的任务。

void addOne(int value) { // 创建形参副本并接收实参当前值
    value = value + 1; // 只修改函数内部的副本
} // 副本销毁，调用处原变量不变

02 引用传递

引用参数不是新副本，而是调用处对象的另一个名字。`int& value` 中的 & 表示引用类型；调用时直接写 addOne(number)，不写 &number。

函数内给 value 赋值就是给 number 赋值，所以接口应让读者一眼看出它可能修改实参。引用必须绑定有效对象，不能用 nullptr 表示“没有对象”。

void addOne(int& value) { // 让 value 成为调用处整数对象的别名
    value = value + 1; // 通过别名直接修改原对象
} // 引用结束，但原对象的新值仍然保留

03 指针传递

指针参数自身仍是值传递：函数得到一份地址副本。虽然修改这个指针副本的指向不会自动改调用处指针，但解引用它可以访问地址对应的原对象。

调用时用 &number 取得地址，函数内先检查 pointer 是否为 nullptr，再用 *pointer 读写。指针适合接口确实需要表示“可能没有对象”的情况。

void addOne(int* pointer) { // 接收一个 int 对象的地址副本
    if (pointer != nullptr) { // 解引用前确认地址不是空指针
        *pointer = *pointer + 1; // 沿地址读取、加一并写回原对象
    } // 结束非空指针处理分支
} // 结束指针参数函数

04 数组作为参数

一维数组作为实参时，函数参数接收首元素地址，原数组不会被整体复制；因此修改 values[i] 会修改调用处对应元素。

首地址本身不带元素个数。`const int values[]` 与 `const int* values` 在函数参数位置表达同类接口，`sizeof(values)` 只反映参数本身，不是原数组总字节数。

长度必须单独传入，并让循环严格满足 0≤i<length。const 表示本函数只读取元素，既保护数据，也清楚表达职责。

int sumArray(const int values[], int length) { // 接收只读首地址和明确长度
    int sum = 0; // 初始化累计和
    for (int i = 0; i < length; i++) { // 只遍历下标 0 到 length-1
        sum = sum + values[i]; // 把当前合法元素加入累计和
    } // 结束数组遍历
    return sum; // 返回全部元素之和
} // 结束数组求和函数
关键提醒：数组长度必须由参数明确传入，不能在函数里用 sizeof 推回原长度。

05 const 引用与方式选择

较长的 string 或结构体只需读取时，可以使用 const 引用：引用避免复制整份对象，const 禁止函数通过这个形参修改原对象。

例如 printText(message) 的形参写成 `const string& text`。调用语法仍直接传对象，不写地址符号；函数内可以读取 text，却不能给 text 赋新值。

选择时先问“要不要改原对象”，再问“有没有可能不存在”，最后考虑复制是否明显：只读小数据用值；必须修改用引用；可能为空用指针；只读较大对象用 const 引用。

  • const 不可省略，否则接口允许修改原字符串
  • & 可以省略成值传递，但会复制整个 string
  • 调用处直接写 printText(message)，不写 &message
void printText(const string& text) { // 以只读引用接收原字符串
    cout << text << '\n'; // 读取并输出，但不能修改 text
} // 结束后原字符串保持不变

printText(message); // 调用处直接传对象，不写 &message

典型例题

比较三种方式交换变量

程序使用固定整数 3 和 5，让三个函数分别尝试交换，观察调用处变量是否改变。

完成程序

#include <bits/stdc++.h> // 引入本程序需要的标准库
using namespace std; // 允许直接使用 cin、cout、string 等标准库名称

void swapByValue(int left, int right) { // 使用值参数尝试交换两个副本
    int temporary = left; // 暂存左侧副本的原值
    left = right; // 把右侧副本的值赋给左侧副本
    right = temporary; // 把暂存值赋给右侧副本
} // 结束值传递函数，副本销毁且不会写回实参

void swapByReference(int& left, int& right) { // 使用引用参数直接操作两个实参
    int temporary = left; // 暂存第一个实参的原值
    left = right; // 把第二个实参的值写入第一个实参
    right = temporary; // 把暂存值写入第二个实参
} // 结束引用传递函数，交换结果保留在原变量中

void swapByPointer(int* left, int* right) { // 接收两个整数对象的地址
    if (left != nullptr && right != nullptr) { // 确认两个指针都能安全解引用
        int temporary = *left; // 沿 left 地址读出并暂存第一个对象的原值
        *left = *right; // 沿两个地址读写，把第二个对象的值写给第一个
        *right = temporary; // 把暂存值写入第二个对象
    } // 结束非空指针处理分支
} // 结束指针传递函数

int main() { // 主函数是程序的入口
    int left = 3; // 定义第一个待交换变量
    int right = 5; // 定义第二个待交换变量

    swapByValue(left, right); // 只交换副本，main 中两个变量保持不变
    cout << left << ' ' << right << '\n'; // 输出 3 5，验证值传递没有写回

    swapByReference(left, right); // 通过引用交换 main 中的两个变量
    cout << left << ' ' << right << '\n'; // 输出 5 3，验证引用修改了实参

    swapByPointer(&left, &right); // 传入地址，再次交换两个原变量
    cout << left << ' ' << right << '\n'; // 输出 3 5，验证指针也能修改实参
    return 0; // 返回 0，表示程序正常结束
} // 结束 main 函数

解题与执行过程

  1. 值传递复制出 left = 3、right = 5，函数只交换副本，main 中仍是 3 和 5。
  2. 引用形参是 main 中两个变量的别名，交换后原变量变为 5 和 3。
  3. 指针形参分别接收两个原变量的地址，通过 *left 和 *right 完成交换。
  4. 三次输出依次说明：值传递不能写回，引用和有效指针都能修改原变量。

常见错误

期望值参数修改实参

错误写法：用 void swap(int left, int right) 交换后期待原变量改变。原因：left 和 right 只是副本。正确写法：需要写回时使用引用或有效指针。

引用声明位置错误

错误写法：把调用写成 swap(&left, &right)，却让函数接收 int&。原因：引用调用直接传变量，不传地址。正确写法：引用函数调用 swap(left, right)。

数组参数缺少长度

错误写法：函数只接收 int values[]，却假设能自动知道元素个数。原因：数组参数只保留首元素地址。正确写法：把合法长度作为独立参数传入。

指针参数忘记解引用或检查

错误写法：直接给 pointer 赋整数，或不检查 nullptr 就访问 *pointer。原因：pointer 保存地址。正确写法：先确认指针有效，再通过 *pointer 修改对象。
