函数基础

01
GESP 4级知识字典 · 知识点 01

掌握函数声明与定义、调用与返回值，把重复任务拆分成函数。

检索词：声明定义返回值

函数把一项有明确输入、处理和输出的任务命名。它既能避免重复代码，也能把长程序拆成容易检查的小部分。真正掌握函数，不是只会背格式，而是能说清声明、定义、调用和返回各在什么时候发生。

本课先记住

核心结论

声明让编译器先认识接口，定义给出任务做法，调用才开始一次真实执行；return 交回结果并立即结束本次调用。

常用语法

int larger(int left, int right); // 声明：说明返回类型、函数名和参数类型
int larger(int left, int right) { // 定义：给出相同接口和函数体
    return left; // 返回一个 int 结果并结束本次调用
} // 结束 larger 函数定义

最小示例

int square(int value) { // 接收一个整数副本并计算平方
    return value * value; // 把平方结果返回调用处
} // 结束 square 函数定义

关键易错点

  • 把“写出函数定义”误认为函数已经执行
  • 声明与定义的返回类型、函数名或参数列表不一致
  • 有返回值的函数存在走到末尾却没有 return 的路径
  • 把返回值当成自动输出，忘记在调用处接收或输出

这节课要会什么

本课建立三个核心：看懂一个函数接口的每个组成部分；追踪“调用—进入—返回—继续”的执行路线；把一项重复任务拆成职责清楚的函数。

从这个场景开始

班级系统要多次比较两名同学的分数。若每次都重新写一段 if，代码会重复；若把“接收两个整数并返回较大值”命名为 larger，main 只需把数据交给它并接回结果。全页都用这台“比较机器”理解函数。

知识范围与官方定位

四级需要掌握函数的作用、声明、定义、调用、参数列表、返回值、void 函数和嵌套调用。函数重载只作识别性补充：能根据参数列表判断调用哪个版本即可，不把复杂重载规则扩大为本级核心。

01 声明与定义

先拆开 `int larger(int left, int right)`：最前面的 `int` 是返回类型，说明调用完成后交回一个整数；`larger` 是函数名；圆括号里的两个 `int` 是形参类型，left、right 是函数体内使用的形参名。函数接口回答“接收什么、返回什么”，函数体回答“具体怎么做”。

函数声明只写接口并以分号结束，例如 `int larger(int, int);`。形参名在声明中可以省略，因为编译器此时只需要知道类型和数量；初学阶段保留 left、right 更容易阅读。声明没有函数体，也不会进行比较。

函数定义写出相同接口和一对大括号。若定义放在 main 前面，main 调用时编译器已经见过它，可以不另写声明；若定义放在 main 后面，就要先声明。C++ 编译器按源码顺序处理，调用前至少要看见声明或完整定义。

声明和定义描述的是同一个函数时，返回类型、函数名、参数个数、参数顺序和参数类型必须对应。只改一个位置，会让编译器把它们当成不同接口或报告错误。

先声明接口，再把定义放到 main 后面

int larger(int left, int right); // 先声明稍后会出现的两整数比较函数
int main() { // 主函数可以在只见到声明时调用 larger
    cout << larger(3, 5) << '\n'; // 传入两个实参并输出返回结果 5
    return 0; // 返回 0 表示主程序正常结束
} // 结束 main 函数
int larger(int left, int right) { // 按声明给出完全一致的函数定义
    if (left > right) { // 左边分数更大时选择左边结果
        return left; // 返回 left 并立即结束本次 larger 调用
    } // 结束左边更大的返回分支
    return right; // 前一条件不成立时返回 right
} // 结束 larger 函数定义
关键提醒：声明末尾有分号，定义末尾没有额外分号；声明和定义任一接口成分不一致，都不能当作“差不多”。

02 调用、返回值与 void 函数

调用表达式由函数名和实参列表组成。执行 `larger(3, 5)` 时，先计算两个实参，再按位置创建 left=3、right=5；程序暂时离开 main，进入 larger 的函数体。形参名与调用处变量名可以不同，对应关系看位置和类型。

执行到 `return 表达式;` 时，先计算表达式，再把值交回调用点，并立即结束本次调用。return 后面属于同一路径的语句不会再执行。调用表达式可以出现在赋值右侧、输出语句或另一个函数的实参中。

返回类型是 `void` 时，函数完成的是动作而不是提供一个值，例如输出一条分隔线。`return;` 可以提前结束 void 函数，但不能写 `int result = printLine();`，因为它没有可接收的结果。

函数还可以嵌套调用：`largestOfThree(3, 8, 5)` 先调用 `larger(3, 8)` 得到 8，再调用 `larger(8, 5)` 得到 8。这里是一个函数调用另一个已经定义的函数，不允许在函数体内部再定义新函数。

  • 调用 larger(3, 5) 前先计算实参 3 和 5
  • 进入函数后，本次调用拥有 left=3、right=5 两个形参
  • return right 先取到 5，再把 5 交回调用点并结束本次调用
  • 调用点拿到 5 后，才继续执行外层赋值或输出
int largestOfThree(int first, int second, int third) { // 定义求三个整数最大值的函数
    int firstResult = larger(first, second); // 先用嵌套调用求前两个数的较大值
    return larger(firstResult, third); // 再与第三个数比较并返回最终结果
} // 结束 largestOfThree 函数定义
void printLine() { // 定义只完成输出动作的无返回值函数
    cout << "-----\n"; // 输出一条分隔线但不产生可接收的返回值
} // 结束 printLine 函数定义
关键提醒：非 void 函数的每一条可能路径都要返回合适类型的值；“某个示例刚好走到 return”不能证明其他分支也安全。

03 任务拆分与函数设计

设计函数先写三句话：输入是什么、任务是什么、返回或修改什么。`larger` 的输入是两个整数，任务是比较，输出是较大整数。只有写清这三项，才能选择返回类型和参数列表。

一个函数最好只完成一个主要任务。“求较大值”和“输出提示”分开后，larger 既能用于屏幕输出，也能用于求三个数最大值；若把 cin、比较和固定文字全塞进去，函数就很难复用。

函数名要能读出意图，参数只传完成任务需要的数据。有明确计算结果时优先返回值；只完成输出等动作时才使用 void。全局变量不是省参数的捷径，它会让数据来源和修改位置更难追踪。

把长程序拆成函数不等于越碎越好。只有当一段代码有独立任务、会重复使用或值得单独验证时再拆分；一行简单赋值通常不需要额外函数。

  • 先写清输入、任务、输出，再决定返回类型和参数列表
  • 让一个函数只承担一个主要职责，并使用能表达职责的名字
  • 重复计算或需要单独测试的步骤优先提取为函数
  • 调用者负责准备数据和使用结果，被调用函数负责完成约定任务

04 补充识别：函数重载

同一作用域内可以定义同名但参数列表不同的函数，这叫函数重载。参数数量不同，或对应位置的参数类型不同，都可以帮助编译器根据实参选择版本。

调用 `larger(3, 5)` 时两个实参是 int，因此选择 int 版本；调用 `larger(2.5, 1.8)` 时两个实参是 double，因此选择 double 版本。初学阶段让差别明显，避免依赖复杂的自动类型转换。

只有返回类型不同不能形成重载。调用代码在选择函数时主要看到函数名和实参，不能只靠“准备把结果存到 int 还是 double”区分两个完全相同的参数列表。

  • 函数名相同，但参数类型不同，所以两个版本可以共存
  • 调用 larger(3, 5) 时，两个实参都是 int，选择 int 版本
  • 若只把返回类型改成 double、参数仍完全相同，编译器无法区分，不能构成重载
int larger(int left, int right) { // 定义接收两个 int 的整数版本
    if (left > right) { // 两个 int 中左值更大时选择 left
        return left; // 返回整数版本的左值结果
    } else { // 左值不大于右值时选择 right
        return right; // 返回整数版本的右值结果
    } // 结束 int 版本的条件分支
} // 结束 int 版本的 larger 函数

double larger(double left, double right) { // 定义接收两个 double 的小数版本
    if (left > right) { // 两个 double 中左值更大时选择 left
        return left; // 返回小数版本的左值结果
    } else { // 左值不大于右值时选择 right
        return right; // 返回小数版本的右值结果
    } // 结束 double 版本的条件分支
} // 结束 double 版本的 larger 函数
int integerAnswer = larger(3, 5); // 两个 int 实参选择整数版本并得到 5
double decimalAnswer = larger(2.5, 1.8); // 两个 double 实参选择小数版本并得到 2.5
关键提醒：四级主程序优先使用名称清楚、接口简单的函数；不要为了炫技设计难以区分的重载。

典型例题

用函数求两个整数的较大值

输入两个 int 范围内的整数并求较大值。程序先声明 larger，让 main 可以调用；函数定义放在 main 后面，完整展示“声明—调用—定义”和返回路线。

完成程序

#include <bits/stdc++.h> // 引入本程序需要的标准库
using namespace std; // 允许直接使用 cin、cout、string 等标准库名称

int larger(int left, int right); // 前置声明比较函数的完整接口

int main() { // 主函数是程序的入口
    int left, right; // 定义两个整数保存输入数据
    cin >> left >> right; // 读入需要比较的两个整数
    cout << larger(left, right) << '\n'; // 调用 larger 并输出返回的较大值
    return 0; // 返回 0，表示程序正常结束
} // 结束 main 函数

int larger(int left, int right) { // 定义与前置声明完全一致的比较函数
    if (left > right) { // 左边整数更大时执行左值返回分支
        return left; // 把 left 交回调用点并结束本次调用
    } else { // 左边不大于右边时执行右值返回分支
        return right; // 把 right 交回调用点并结束本次调用
    } // 结束两种大小关系的选择结构
} // 结束 larger 函数定义
示例输入
3 5
示例输出
5

解题与执行过程

  1. 编译阶段先读到声明，确认 larger 接收两个 int 并返回 int；因此 main 中的调用合法。
  2. 运行到 larger(3, 5) 时，程序暂时离开 main，本次调用创建形参 left = 3、right = 5。
  3. 条件 left>right 即 3>5 不成立，程序进入 else 并执行 return right。
  4. return 先取到 5，再把 5 返回调用处；main 中的调用表达式得到 5，cout 输出 5。
  5. 函数定义写在 main 后面不影响运行顺序；源码位置与调用时的控制流程是两件事。

常见错误

声明和定义不一致

错误写法：声明 int larger(int, int)，定义却写 long larger(int, int)。原因：同一函数的接口不一致。正确写法：让返回类型、函数名和参数列表逐项一致。

有返回值的路径忘记 return

错误写法：int larger(...) 的某个分支执行到函数末尾仍未返回。原因：调用处得不到确定结果。正确写法：保证每条可能路径都返回一个 int 值。

调用时参数数量错误

错误写法：larger(3)。原因：声明要求两个实参。正确写法：按接口提供两个参数，例如 larger(3, 5)。

把所有操作塞进一个函数

错误写法：一个函数同时读入、计算多项无关结果并负责全部输出。原因：任务难复用、难检查。正确写法：按任务拆分，并为每个函数明确输入和输出。
