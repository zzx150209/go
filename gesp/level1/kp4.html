输入输出语句

04
GESP 1级知识字典 · 知识点 04

使用 cin、cout、scanf、printf，并按题目要求控制输出格式。

检索词：cin-coutscanf-printf

本课先记住

  • 核心结论： 输入按题目顺序把数据交给变量，输出按代码顺序形成最终文本；OJ 比较的是实际输出，空格、换行和小数格式都属于答案。
  • 常用语法： C++ 流使用 cin >>、cout <<；C 风格输入输出使用 scanf、printf，格式符必须与变量类型匹配。
  • 最小示例： cin >> a >> b; cout << a + b << '\n'; 会读入两个数并只输出它们的和与一个换行。
  • 关键易错点： 程序不会自动补空格，scanf 读普通变量通常要写地址符 &，保留小数位数只改变显示形式，不会提高变量精度。

知识范围与官方定位

程序有了基本结构以后，还需要让题目给出的数据进入程序，再把处理结果按照指定格式送出去。这个过程分成两端：

一端 要解决的问题 一级常用工具
标准输入 数据从哪里来，依次保存到什么位置 cin、scanf
标准输出 哪些内容以什么顺序组成最终答案 cout、printf

例如，输入依次给出学号和成绩：

101 87

题目要求先输出成绩，再输出学号：

87 101

这不只是“把两个数显示出来”。程序还要读对数据的数量和顺序，知道每个数据保存在哪里，再按照题目要求改变输出顺序，准确放入空格和换行。

本页集中解决三个核心问题：

  1. cin、cout 怎样从左到右处理数据；
  2. scanf、printf 的格式符怎样与数据逐项对应；
  3. 怎样让最终输出的字符和题目要求完全一致。

本页先把 studentId、score 看作已经准备好的保存位置。变量怎样定义、数据类型怎样选择、表达式怎样计算，会在后面的课程中分别讲解。

01 cin 标准输入

cin 的职责是从标准输入中读取数据，并把读到的内容保存到变量中。同一份程序因此可以处理不同的输入，而不需要把样例数字写死在代码里。

输入一个数据与多个数据

输入一个数据的基本写法是：

cin >> studentId; // 读取一个数据，保存到 studentId

需要连续读取多个数据时，继续按照题目给出的顺序写 >>：

cin >> studentId >> score; // 依次读取学号和成绩

这条语句可以按三个部分理解：

组成部分 职责
cin 指明数据来自标准输入
>> 取出下一个符合要求的数据
右侧变量 保存本次读到的数据

一处 >> 对应一个保存位置。需要两个数据，就要准备两个位置并写出两次读取，不能用逗号代替后面的 >>。

cin 从左到右怎样读取

假设代码是：

cin >> studentId >> score;

输入为：

101 87

读取过程如下：

步骤 当前执行部分 读到的数据 保存结果
1 >> studentId 101 studentId = 101
2 >> score 87 score = 87

变量名不会让 cin 自动寻找“像学号的数据”。真正决定对应关系的是代码中的位置：第一个数据给第一个变量，第二个数据给第二个变量，依次类推。

空格、换行和制表符怎样分隔数据

对于本页使用的普通数字输入，cin >> 会先跳过数据前面的空格、制表符和换行，再读取下一个数据。因此下面三种输入都能得到相同结果：

101 87
10187
101     87

所以 cin >> a >> b; 表示“依次读取两个数据”，不表示“每一行只能读取一个数据”。以后学习整行文字输入时，换行会有不同作用，本页暂不展开。

什么时候不能按预期读完

检查 cin 时要同时看四件事：数据数量、先后顺序、目标类型和保存位置。

  • **数据不足：**程序还没有拿到后面的数据。在控制台中通常会继续等待；如果输入文件已经结束，后续读取会失败。
  • **顺序写反：**程序可能仍能读完，但数据进入了错误的变量。
  • **类型不匹配：**需要整数的位置遇到 * 之类不能读成整数的内容时，读取会失败，不能把该变量当作有效输入，也不能假定它一定自动变成 0。
  • **数据多余：**当前语句只读取需要的数量，后面的数据会留给后续读取语句。

例如输入 1 * 时，两个整数位置不能全部读取成功；若第二个位置是字符，* 才可以作为一个字符读入。这里先认识“类型会影响读取规则”，各种类型会在“基本数据类型”一页系统学习。

02 cout 标准输出

cout 的职责是把内容送到标准输出。它不会替我们猜测应该输出哪些文字、空格或标点，代码写了什么，最终文本才会出现什么。

cout 可以连接哪些内容

例如：

cout << "score=" << score;

这条语句包含两类内容：

写法 输出的是什么
"score=" 双引号中的固定文字 score=
score 变量当前保存的值

如果 score = 91，最终形成的文本是 score=91。变量名 score 本身不会出现在屏幕上，除非把它写进双引号。

cout 从左到右怎样形成文本

继续输出学号：

cout << "score=" << score << ", id=" << studentId;

当 score = 91、studentId = 205 时：

顺序 本次加入的内容 当前文本
1 固定文字 score= score=
2 score 的值 91 score=91
3 固定文字 , id= score=91, id=
4 studentId 的值 205 score=91, id=205

每一处 << 都把右侧内容接到当前文本末尾。判断输出时，应沿代码从左到右拼接，不能只看最后一个变量。

03 空格、换行与输出格式

输出格式决定最终答案“长什么样”。数值相同，但空格、换行、标点或顺序不同，仍然是不同的输出。

程序不会自动补空格

假设 score = 91、studentId = 205：

写法 实际输出 区别
cout << score << studentId; 91205 中间没有空格
cout << score << " " << studentId; 91 205 中间恰好一个空格
cout << score << " " << studentId; 91 205 中间有两个空格

空格也属于双引号中的固定内容。题目要求几个空格，就要写出几个；cout 不会因为两个变量相邻而自动加空格。

endl 与换行符

下面两种写法都能在一级常见输出题中结束当前行：

cout << score << endl; // 输出成绩后换行cout << studentId << "\n"; // 输出学号后换行

endl 是换行写法；"\n" 中的 \n 是转义序列，也表示换行。双引号中的普通文字、空格和标点按写法输出，\n 这样的转义序列则按特殊含义执行，不会在屏幕上显示反斜杠和字母 n。

换行放在哪里，下一段内容就从哪里开始：

cout << score << " " << studentId << "\n"; // 同一行输出两个值cout << score << "\n" << studentId << "\n"; // 两个值分成两行

OJ 会检查最终文本

OJ 通常只接收题目要求的结果。题目没有要求时，不要擅自输出 请输入数据、答案是 等提示文字。

提交前逐项检查：

  1. 输出的数据数量和顺序是否正确；
  2. 固定文字、标点和大小写是否完全一致；
  3. 数据之间需要几个空格；
  4. 每一行在哪里结束；
  5. 是否要求固定的小数位数；
  6. 是否混入题目没有要求的内容。

04 scanf 与 printf

scanf、printf 是另一套常见输入输出方式。它们把数据的格式写进第一个双引号中，再让后面的输入位置或输出数据与格式符一一对应。

scanf 怎样按照格式读取

读取两个 int 数据可以写成：

scanf("%d%d", &studentId, &score);
组成部分 职责
scanf 按格式从标准输入读取数据
"%d%d" 两个 %d 依次要求两个 int 数据
&studentId 第一个数据写入 studentId
&score 第二个数据写入 score

scanf 要把数据写进变量，因此普通输入位置前要写 &。一级阶段先把它记作必要写法，不在本页展开地址和指针。

printf 怎样按照格式输出

输出成绩和学号可以写成：

printf("%d %d\n", score, studentId);

格式串从左到右决定最终文本：

格式串中的部分 实际作用
第一个 %d 输出 score 的值
中间空格 输出一个普通空格
第二个 %d 输出 studentId 的值
\n 换行

printf 只读取变量的值用于显示，所以输出数据前不写 &。

格式符必须与类型配对

数据类型 scanf 读取 printf 输出
int %d %d
long long %lld %lld
float %f %f
double %lf %f
char %c %c

最容易混淆的是 double：scanf 读取时使用 %lf，printf 输出时使用 %f。格式符数量、顺序或类型不对应，都可能让程序无法按预期工作。

普通 %c 会直接读取下一个字符，空格和换行也可能被读入。如果题目要求下一个非空白字符，常见写法是在 %c 前放一个空格：

scanf(" %c", &grade); // 先跳过空白，再读取一个字符

若题目本来就要读取空格字符，则不能这样跳过空白。

格式串中的固定字符也要匹配

例如：

scanf("%d,%d", &studentId, &score);

这条语句对应的输入是：

205,91

英文逗号是格式串中的固定字符，输入中也必须在对应位置出现。类似地，scanf("%d:%d:%d", ...) 会要求三个整数之间出现冒号。固定字符只负责匹配，不会被保存到变量中。

一级阶段选择 cin／cout 或 scanf／printf 中的一套写对、写一致即可。本页不展开底层缓冲、性能基准或输入失败后的恢复操作。

05 格式化输出与保留小数

格式化输出只决定结果怎样显示。它不会改变变量原来保存的值，也不能修复此前已经发生的错误计算。

固定显示小数位数

数值 3.5 按要求显示两位小数时，应输出 3.50。

使用 cout：

cout << fixed << setprecision(2) << 3.5 << "\n";

使用 printf：

printf("%.2f\n", 3.5);

两种写法都输出：

3.50

fixed 让 setprecision(2) 表示小数点后两位；%.2f 中的 .2 也表示小数点后两位。若后面还有更多数字，显示时会按规则舍入。例如 3.456 显示两位小数时得到 3.46。

先确认数值，再检查显示

判断格式化输出时按两步走：

  1. 先确认变量中保存的值是否正确；
  2. 再根据 fixed、setprecision 或 printf 格式检查显示结果。

把 3.5 显示成 3.50，变量并没有永久变成“只能保存两位小数”。反过来，若前面的计算已经得到错误数值，再漂亮的输出格式也不能把它改正确。

输入输出的统一检查顺序

面对一段输入输出代码，可以按下面的顺序检查：

阶段 先问什么 具体做法
输入数量 题目给几个数据，代码读几个 给输入数据和读取位置分别编号
输入对应 每个数据按什么顺序、什么类型保存 沿 cin 或 scanf 从左到右连线
输出内容 要输出变量值还是固定文字 把每一处 << 或格式串拆成片段
输出格式 空格、标点、换行和小数位数怎样要求 手工拼出最终文本
实际验证 代码是否只对样例碰巧正确 运行样例，再换一组顺序敏感的数据

可以把它压缩成一句话：先给输入和保存位置连线，再把输出逐段拼起来，最后逐字符核对。

典型例题

输入依次给出一名学生的学号和成绩。程序需要交换它们的输出顺序：先输出成绩，再输出学号，中间恰好一个空格，末尾换行。

题目与输入输出

输入两个整数：

studentId score

输出一行：

成绩 学号

输入样例：

101 87

输出样例：

87 101

先手工确定数据去向

输入顺序 数据 保存位置
1 101 studentId
2 87 score

输出时先取 score 的值 87，再加入一个字面量空格，接着取 studentId 的值 101，最后换行。输入顺序和输出顺序不同，正好可以检查程序有没有把两个保存位置写反。

逐步写出关键语句

先准备两个保存位置并按题目顺序读取：

int studentId; // 保存学号int score; // 保存当前成绩cin >> studentId >> score; // 依次读取学号和成绩

再按要求组成一行输出：

cout << score << " " << studentId << "\n";

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int studentId; // 保存输入中的学号    int score; // 保存输入中的当前成绩    cin >> studentId >> score; // 按题目顺序读取两个数据
    cout << score << " " << studentId << "\n"; // 先输出成绩，再输出学号    return 0;}

执行过程

输入 101 87 时：

步骤 正在执行的部分 保存位置 当前输出
1 cin >> studentId studentId = 101 无
2 >> score score = 87 无
3 输出 score 两个变量都不改变 87
4 输出字面量空格 " " 两个变量都不改变 87
5 输出 studentId 两个变量都不改变 87 101
6 输出 "\n" 两个变量都不改变 当前行结束

这张表严格沿程序从左到右展开：输入阶段依次改变两个保存位置，输出阶段依次追加成绩、空格、学号和换行，不会改动两个变量。

用多组数据验证

输入 正确输出 主要检查
101 87 87 101，然后换行 正式样例与交换顺序
205 91 91 205，然后换行 更换数据后仍按保存位置输出
第一行 7，第二行 100 100 7，然后换行 换行也能分隔两个普通整数

若程序只在第一组样例中正确，换一组学号和成绩后就输出反了，说明代码没有真正按保存位置和题目顺序组织输出。

引导练习（不记录进度）

补全“读入两个整数并输出一行和”的关键语句。输入 3 4 时，先把 3、4 分别交给两个变量，再计算和；输出不得带提示文字，只保留结果和换行。

成功标准： 实际输出必须逐字等于 7 后接一个换行，不能多空格或说明文字。完成后不看提示独立完成页末“整页综合测试”；提交后逐题核对格式符、变量地址、空格、换行和小数位数。

常见错误

  1. 把输入输出符号写反。 cin 使用 >>，cout 使用 <<；方向写反会导致编译或语义错误。
  2. 写成 cin >> a, b;。 逗号不会代替第二个 >>，这条语句只让 cin 读取 a；多个变量要写成 cin >> a >> b;。
  3. 输入数量、顺序或类型不匹配。 给数据和保存位置编号，再逐项连线；读取失败后不要继续把变量当作有效输入。
  4. 输出漏空格或换行位置错误。 把预期结果按字符写出来，再沿 cout 或格式串逐段拼接。
  5. 擅自输出提示文字。 OJ 没有要求的 答案是、请输入 都可能让结果错误。
  6. scanf 漏写 & 或格式符配错。 从第一个格式符开始，与后面的每个输入位置和类型一一对应。
  7. 只写 setprecision(2)，没有配合 fixed。 此时不一定表示小数点后固定两位。
  8. 认为格式化会改变原值。 格式控制发生在输出阶段，只改变显示文本。
