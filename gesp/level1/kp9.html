分支结构

09
GESP 1级知识字典 · 知识点 09

使用 if、if-else、else-if、switch 和三元运算处理不同情况。

检索词：if-elseswitch-case

本章先记住

  • 核心结论： 分支结构先根据当前数据完成判断，再选择本次要走的路线；没有被选中的互斥路线不会执行。
  • 常用结构： 范围、大小和复合条件用 if；一个整数或字符匹配多个固定值时可以用 switch-case。
  • 最小示例： score = 72 → score >= 60 为 true → 进入“及格”路线。
  • 关键易错点： 写完条件还要检查边界、判断顺序和路线是否遗漏；只测一个普通数据，通常发现不了这些问题。

前一章的顺序结构始终沿同一条路线向下执行。真实题目常常要求程序看数据办事：温度低于 0 才提示结冰，成绩落在哪个区间就输出哪个等级，菜单编号不同则完成不同操作。分支结构就是程序中的选择点。

两个子课分别讲清 if 和 switch-case 的语法与真实执行。先按顺序学完它们，再用本章的选择与验证方法把知识连起来：看懂题目的判断方式，选对结构，用测试数据确认每条路线都正确。

从顺序执行到选择路线

分支不会取消顺序执行。程序到达选择点以前，普通语句仍按顺序完成；得到判断结果以后，只执行本次选中的路线；离开分支后，又从后续语句继续向下执行。

前面的顺序语句        ↓读取变量当前值，完成条件判断或固定值匹配        ↓   选择本次路线    ↙         ↘ 路线 A      路线 B    ↘         ↙   回到共同的后续语句

读一段分支时，可以按五步追踪：

  1. 记录到达分支前各变量的当前值；
  2. 把当前值代入条件，或取得 switch 表达式的值；
  3. 找到本次真正进入的路线；
  4. 标出没有执行的互斥路线；
  5. 确认分支结束后从哪条语句继续。

这里的“一次只走一条”指同一条 if-else-if-else 链或设计成独立结果的 switch。多个彼此独立的 if 会各自判断，一次可能进入多个代码块。

两个子课怎样衔接

建议按下面的顺序学习，再回到本页做综合测试：

顺序 子课 学完后的可观察结果
1 if 条件分支 给出一组实际数据，能算出条件真假，指出单分支、双分支或多分支会走哪条路线，并检查范围边界
2 switch-case 分支 给出一个整数或字符，能找到匹配入口，追踪 break、default 和贯穿带来的实际输出
3 回到本页 能从题目规则选择结构，列出全部结果路线，并设计覆盖边界与非法输入的测试数据

本章只处理一级常见的单层选择。if 子课会说明大括号范围和 else 的归属，但不把多层嵌套分支当作一级主任务；switch 的嵌套也留到后续等级。简单三目运算符已经在基本运算中用于认识二选一，一级主程序仍优先写更容易追踪的完整 if-else。

判断方式决定写法

先问“题目怎样区分情况”，再决定语法。不要因为刚学过某种结构，就把所有题都改成同一种写法。

题目的判断方式 推荐结构 一次可能执行几条路线 例子
条件成立时才额外做一件事，条件不成立时不用替代处理 单分支 if 0 或 1 条 温度低于 0 时提示结冰
条件真假分别对应一种结果 if-else 恰好 1 条 整数是偶数还是奇数
三个及以上互斥范围，要按顺序选择第一条成立路线 if-else if-else 最多 1 条；有末尾 else 时恰好 1 条 按成绩区间输出等级
多个条件可以同时成立，每个条件都要单独处理 多个独立 if 0、1 或多条 同时标记“及格”和“优秀”
一个整数或字符与多个离散固定值比较 switch-case 从一个入口开始执行 菜单编号、星期编号

switch 适合列出 1、2、3 或 'A'、'D' 这样的固定值，不直接处理“至少 60 分”或“0 到 100 之间”的范围。范围、取余和多个逻辑条件交给 if 更直接。

先把题目整理成决策表

代码只是把规则写给计算机。规则本身如果有重叠、缺口或顺序错误，语法正确也会得到错误结果。

以“90 分及以上输出 A，60 分及以上输出 B，否则输出 C”为例。假设题目保证成绩在 0 到 100 之间，先写出每条路线真正负责的范围：

判断顺序 写出的条件 实际负责范围 命中后的结果
1 score >= 90 90 到 100 A
2 score >= 60 60 到 89，因为 90 以上已被第一条取走 B
3 else 0 到 59 C

第二条虽然只写了下界，实际不会接到 90 分，因为程序找到第一条成立路线后就停止检查本链后面的条件。若把 score >= 60 放在前面，90 分会先进入 B 路线，A 路线就失去入口。

这张表也暴露了一个前提：输入范围由题目保证。如果题目还要求处理小于 0 或大于 100 的成绩，就要先增加“成绩非法”的路线，不能让非法值落入普通等级。

综合应用：闰年与月份天数

月份天数把复合条件、互斥路线和非法输入放在同一个问题中，适合用来检查整章是否真正学会。先判断月份是否合法，再处理 2 月、30 天月份和剩余合法月份。

2 月需要使用闰年规则：年份能被 400 整除，或者能被 4 整除但不能被 100 整除。写成条件是 year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)。

年份 能被 400 整除 能被 4 整除且不能被 100 整除 年份结果
2000 true false 闰年
1900 false false 平年
2024 false true 闰年

完整月份决策可以整理成四条互斥路线：

判断顺序 要检查的问题 成立时的最终结果 不成立时继续
1 `month < 1 month > 12`
2 month == 2 闰年 29 天，平年 28 天 检查 30 天月份
3 `month == 4 month == 6
4 已排除非法月份、2 月和 30 天月份 31 天 判断结束

用实际输入走一遍，可以确认每条路线的含义：

输入 year month 选择过程 最终结果
2024 2 月份合法 → 2 月 → 2024 是闰年 29 天
1900 2 月份合法 → 2 月 → 1900 是平年 28 天
2024 4 月份合法 → 不是 2 月 → 30 天月份 30 天
2024 12 月份合法 → 不是 2 月 → 不是 30 天月份 31 天
2024 13 第一条就判定月份非法 非法，不能继续归入 31 天

这道题适合使用 if，因为它包含范围、取余和复合逻辑条件。即使月份编号看起来像固定整数，也不能只用一个简单 switch 解决闰年 2 月的判断。

怎样验证分支路径

分支程序不能只用一个“看起来正常”的数据。可靠的测试要同时检查三件事：

  1. 路线覆盖： 每一种最终结果至少实际运行一次；
  2. 边界覆盖： 对 >、>=、<、<= 使用边界值和相邻值；
  3. 互斥与完整： 需要唯一结果时，每组输入只能得到一个结果，同时不能留下没有结果的合法输入。

成绩分级至少测试 59、60、89、90：59 和 60 检查及格边界两侧，89 和 90 检查优秀边界两侧。月份天数至少覆盖非法月份、平年 2 月、闰年 2 月、30 天月份和 31 天月份。switch 任务则要覆盖每组固定值、共享处理的入口以及 default。

运行自己的程序时，可以用同一张记录表对照预期：

输入 条件或匹配的实际结果 选中的路线 明确跳过的路线 预期结果 实际结果
一组具体数据 逐项写出 true、false 或匹配值 写路线名称 写未执行路线 手算得到 运行后填写

若预期与实际不一致，先看第一个不同点：条件算错通常是运算或边界问题；选中路线不对通常是判断顺序问题；一次出现多个互斥结果，通常是把一条 else-if 链写成了多个独立 if，或 switch 路线漏写了应有的 break。

常见错误

  1. 还没有划分路线就直接写代码，结果条件互相重叠或漏掉一类输入。
  2. 互斥分类使用多个独立 if，一次输出了两个本应互斥的结果。
  3. 多分支先写宽范围，后写严格范围，后面的路线永远无法到达。
  4. 用 switch 硬写范围或复杂条件，没有先看题目的判断方式。
  5. 只测试区间中间的普通数据，没有检查边界值、相邻值和非法输入。
  6. 只确认“选中了什么”，没有确认其他互斥路线确实被跳过、分支结束后从哪里继续。

具体语法错误、条件形成过程和代码块范围在 if 子课中检查；case、break、default 与贯穿问题在 switch-case 子课中检查。父页不重复两套语法，只把选择与验证方法合在一起。

关联学习

顺序结构提供分支前后仍要遵守的逐句执行规则。学完本章后，循环结构会让一段语句在条件控制下重复执行；循环的“是否继续”同样要把变量当前值代入条件，但本章不提前展开循环过程。

整章综合测试

6 题

第 1 题若 x = 2、y = 4、z = 6，哪个表达式的值为真？

答案：D
官方真题少见写法。先按一级能理解的步骤看：x < y 先比较，原题中的 !(x < z) 把括号内比较结果取反，最后 || 只要一侧为真整体就为真。容易误读 ! 的作用范围，或者把它和不等号混淆。日常代码推荐写成 x < y || x >= z，条件含义更直接。
对应知识点：02 if 与逻辑条件

第 2 题a = 3、b = 5 时，表达式 (a > b) ? a : b 选择哪个值？

答案：B
对应本页 05 三目运算符。先判断 a > b，3 > 5 为假，所以跳过问号后的 a，选择冒号后的 b，最终结果为 5。
对应知识点：05 三目运算符

第 3 题关于 if 和 else，哪项说法正确？

答案：A
else 是可选分支，只写 if 也符合语法；else 不能脱离对应的 if 单独使用。
对应知识点：01 单分支 if

第 4 题程序根据年份 y 和月份 m 输出天数。m 等于 2 时，下面哪条规则正确？

答案：B
闰年二月有 29 天，平年二月有 28 天；闰年要求能被 400 整除，或能被 4 整除但不能被 100 整除。
对应知识点：06 典型应用

第 5 题程序按“90 分及以上输出 A，60 分及以上输出 B，否则输出 C”的顺序判断。成绩依次为 59、60、90 时，输出分别是什么？

答案：A
对应本页 03 多分支 else-if。59 不满足前两个条件，输出 C；60 不满足 >= 90 但满足 >= 60，输出 B；90 第一个条件就成立，输出 A。多分支会执行从上到下第一个成立的分支。
对应知识点：03 多分支 else-if

第 6 题switch 的某个 case 末尾漏写 break，通常会发生什么？

答案：A
没有 break 时会继续执行后续 case，直到遇到 break 或 switch 结束。
对应知识点：04 switch-case
