01 官方核心未复习

计算机存储与网络

了解存储单位换算，认识网络协议与常见网络概念。

存储与单位网络与协议
核心要点
  • 存储单位：1 Byte = 8 bit，1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB。
  • 内存是临时存储（断电丢失），硬盘/SSD 是永久存储（断电保留）。
  • 网络中数据通过协议传输，常见协议 HTTP/HTTPS 用于网页，TCP 用于可靠传输。
  • IP 地址标识网络中的设备，域名便于记忆，DNS 将域名解析为 IP。
注意事项
  • 换算时注意 1024 而不是 1000，存储容量厂商常用 1000。
  • bit 是最小单位（0或1），Byte 是基本寻址单位。
02 官方核心未复习

程序设计语言

区分机器语言、汇编语言与高级语言，了解编译与运行过程。

语言分类编译过程
核心要点
  • 机器语言由 0 和 1 组成，CPU 直接执行，但人很难读写。
  • 汇编语言用助记符表示指令，需要汇编器翻译为机器码。
  • 高级语言（C++、Python）接近自然语言，需要编译器或解释器翻译。
  • 编译型语言（C++）先整体翻译为可执行文件再运行；解释型语言（Python）逐行翻译执行。
注意事项
  • C++ 是编译型语言，运行前需要编译，编译后运行速度快。
  • 编译器报错信息中的行号对应源文件，不是翻译后的机器码。
03 官方核心未复习

流程图

识别流程图符号，追踪流程走向，并在流程图与代码之间互相翻译。

符号辨认流程追踪
核心要点
  • 流程图用标准符号表示算法步骤：椭圆表示开始/结束，矩形表示处理，菱形表示判断，平行四边形表示输入输出。
  • 箭头表示执行方向，从开始符号出发，沿箭头执行直到结束符号。
  • 流程图与代码可以互相翻译：顺序对应顺序结构，菱形对应 if 判断，回箭头对应循环。
注意事项
  • 判断框有两个出口（是/否），不要漏掉任何一条路径。
  • 循环体在流程图中表现为从判断框回到上方的箭头。
04 官方核心未复习

数据类型转换

掌握隐式转换与强制转换，注意整数除法与精度丢失。

隐式转换强制转换
核心要点
  • 隐式转换：小类型自动转大类型，如 int 转 double，不丢失精度。
  • 强制转换：(double)a 把 a 当 double 处理，(int)3.14 得到 3（截断小数）。
  • 整数除法问题：7/2=3，要得到 3.5 需要写成 7.0/2 或 (double)7/2。
  • 字符与整数互转：char 本质是 ASCII 码，'A'+1 得到 'B'。
int a = 7, b = 2;
double c = (double)a / b;  // 3.5（先转a再除）
int x = (int)3.99;         // 3（截断，不是四舍五入）
char ch = 'A' + 1;          // 'B'
注意事项
  • 强制转换是截断不是四舍五入，3.99 转 int 是 3 不是 4。
  • 混合运算时 int 和 double 一起计算，int 自动提升为 double。

多分支判断

处理分支嵌套与条件边界，避免遗漏情况。

分支嵌套条件边界
核心要点
  • if-else if-else 链从上到下判断，满足第一个就执行对应块并跳出。
  • 分支嵌套：if 里面再写 if，注意 else 与最近的未配对 if 结合。
  • 处理区间判断时要注意边界，分数 60 分及格不能写成 score>60。
  • 多分支用 switch 时表达式必须是整数或字符类型。
int x;
cin >> x;
if (x > 0) {
    if (x >= 100) cout << "大数" << endl;
    else cout << "正数" << endl;
} else if (x == 0) {
    cout << "零" << endl;
} else {
    cout << "负数" << endl;
}
注意事项
  • 嵌套 if 的 else 属于最近的 if，加括号明确逻辑更安全。
  • 区间判断用 >= 和 <= 时注意不要漏掉边界值。
06 官方核心未复习

循环嵌套

用双重循环处理行列、图形与枚举问题，控制内层跳转。

行列问题内层跳转
核心要点
  • 双重循环：外层循环控制行，内层循环控制列，常用于输出图形和枚举。
  • 外层每执行一次，内层完整执行一遍。
  • 内层循环的 break 只跳出内层，不影响外层。
  • 注意循环变量不要同名，避免互相覆盖。
// 输出九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        cout << j << "*" << i << "=" << i*j << "\t";
    }
    cout << endl;
}
注意事项
  • 双重循环总次数是外层次数乘以内层次数，数据量大时会很慢。
  • 输出图形时注意每行末尾要换行。
07 官方核心未复习

常用数学函数

使用绝对值、平方根、最大最小值与随机数，注意取值范围。

绝对值平方根最大最小值
核心要点
  • abs(x) 求整数绝对值，fabs(x) 求浮点数绝对值，需要 #include <cmath>。
  • sqrt(x) 求平方根，pow(a,b) 求 a 的 b 次方。
  • max(a,b) 和 min(a,b) 求最大最小值，C++11 起支持。
  • rand() 生成伪随机数，需要 srand(time(0)) 设置种子。
#include <cmath>
double a = -3.14;
cout << fabs(a) << endl;    // 3.14
cout << sqrt(16) << endl;   // 4
cout << pow(2, 10) << endl; // 1024
int r = rand() % 100;       // 0到99的随机数
注意事项
  • sqrt 参数必须非负，负数会返回 NaN。
  • rand() 范围是 0 到 RAND_MAX，%n 得到 0 到 n-1。

程序调试

根据编译信息与运行结果定位错误，学会输出中间变量。

编译信息中间输出
核心要点
  • 编译错误：语法不对，编译器给出行号和原因，逐条修改。
  • 运行时错误：程序崩溃，常见原因是数组越界、除零、死递归。
  • 逻辑错误：程序能运行但结果不对，需要输出中间变量排查。
  • 常用调试方法：在关键位置插入 cout 输出变量值，对比预期结果。
// 调试：输出中间值
int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;
    cout << "i=" << i << " sum=" << sum << endl;  // 追踪
}
注意事项
  • 先修第一个编译错误，后面的错误可能是它引起的连锁反应。
  • 运行超时通常是死循环或算法复杂度太高。
