链表

06
GESP 5级知识字典 · 知识点 06

掌握单向与双向链表的插入、删除与反转，会用数组模拟。

检索词：链表操作数组模拟

位置 1、3、2 并不连续，却可以按 10、30、20 的顺序访问：链表用链接指出下一项。本页先用同一个小链表看懂共同模型、三种形态和实现选择，再进入子页学习完整操作。

本课先记住

核心结论

链表的先后顺序由链接决定，不由结点所在的地址或数组下标决定；改链接前要先保存仍需访问的位置。

常用语法

从 head 出发，沿当前结点的 next 前进；普通链遇到各自的空标记停止，循环链再次回到 head 停止。

current = current->next;
current = nextIndex[current];
最小示例

head=1，位置链 1→3→2→0，对应数据顺序 10→30→20；这里的 0 只是数组模拟约定的空下标。

head = 1;
nextIndex[1] = 3;
nextIndex[3] = 2;
nextIndex[2] = 0;
关键易错点
  • 把下标加一当遍历、循环链仍等待空标记、双向只改一侧，或先覆盖旧后继，都会导致漏结点、无法停止或断链。

知识范围与官方定位

五级需要认识结点的数据域、链接域、head 与 tail，理解单向、双向、循环链表以及数组下标模拟，并能在子页完成创建、遍历、插入和删除。父页只建立共同模型、识别方法和选择路线；完整 C++ 写法、逐轮操作和容量管理留在两个子页。

本页先建立共同基础并比较各方法；完整过程、C++ 写法与复杂度请进入对应子知识点学习。

共同基础

  • K1｜一个结点由数据域和链接域组成：数据域保存内容，链接域保存下一结点的位置。head 是进入链表的入口，不是额外的数据结点；tail 表示尾部位置。
  • K1｜统一状态 S1：head=1；位置 1 保存 10、next=3，位置 3 保存 30、next=2，位置 2 保存 20、next=0。位置虽然不连续，链接给出的逻辑顺序仍是 10→30→20。
  • K1｜普通数组模拟链的观察过程：current=1，非空，访问 10 后到 3；current=3，访问 30 后到 2；current=2，访问 20 后到 0；current=0 是条件第一次不成立的停止行，不访问 value[0]。
  • K1｜空标记随实现而变：指针链表常用 nullptr，数组模拟可约定 0。0 不是所有链表通用的空值；空链必须先判断 head，不能先访问结点。
  • K2｜单向链只有 next，适合从头向后走，普通链遇空标记停止；双向链再有 prev，适合前后移动；循环链让尾部 next 回到 head，适合轮转。三者都从入口沿链接访问。
  • K2｜在 S1 上识读双向链，只需补上 prev[1]=0、prev[3]=1、prev[2]=3，反向应得到 2→3→1→0；识读循环链，只把 next[2] 从 0 改为 head(1)，访问 1、3、2 后再次到 1 时停止。
  • K2｜只需从头向后访问时选单向；需要从当前位置回到前一个结点时选双向；需要尾部之后自动回到开头时选循环。循环链应先处理空表，再以“再次到 head”为一整轮的结束。
  • K3｜修改链接前先保存仍要使用的位置。例如从 1→2→0 形成 S1：先保存 oldNext=2，再令位置 3 的 next 指向 oldNext，最后才让位置 1 的 next 指向 3；每一步都不能让位置 2 从 head 不可达。
  • K3｜双向链把 x 放在 a、b 之间时，必须让 x 的 prev/next 记住两侧，也让 a 的 next 与 b 的 prev 接回 x。中间状态还不是完成状态，最后要从前后两个方向检查相邻关系。
  • K3｜边界检查：空链的 head、tail 都为空；单结点的 head=tail；头部没有前驱，尾部没有后继；删掉唯一结点后两者都要为空。普通链尾部指向空标记，循环链尾部指回 head。
  • 选择演示｜题目给出“最多 100 个结点、结点用整数编号、nextIndex 保存后继、0 是空下标”，因此应选数组模拟。对 S1 从 head=1 沿链接复核得到 1→3→2→0，而不是用 current++；只有题目要求动态结点、地址链接和释放时，才转到指针实现。
  • 空间口径｜两种实现都使用 O(n) 总存储。若 value、nextIndex、previousIndex 都是 int，槽位为 0..N，且常见环境中 int=4 字节，三个数组约为 12(N+1) 字节；平台不同时以 sizeof(int) 为准。指针结点大小受指针宽度和对齐影响，只能以 sizeof(Node) 为准。
  • 引导练习｜从 S1 写出 current 的变化并指出何时不再访问数据。答案：1→3→2→0，在 current=0 的首次失败判断停止。成功标准：只访问 1、3、2，且没有漏掉停止行。
  • 独立练习｜在 S1 的位置 3 后插入位置 4。答案：先保存 oldNext=next[3]=2，再令 next[4]=2，最后令 next[3]=4，结果为 1→3→4→2→0。成功标准：从 head 到达四个位置各一次，尾部仍到 0。
  • 迁移练习｜值班名单要从最后一人回到第一人。答案：选循环链，把 next[2] 改为 head(1)；空表先停，非空表访问 1、3、2 后在下一位置再次等于 head 时停。成功标准：一轮中每个结点恰访问一次。

方法对比

指针实现链表

主要用途：题目需要动态创建结点，并用真实地址表示链接。

使用提醒：进入指针子页学习 Node、nullptr、创建、遍历、插删、反转与释放；结点大小以 sizeof(Node) 为准。

数组模拟链表

主要用途：题目给出固定上限和整数编号，适合用 value、nextIndex、previousIndex 表示数据与链接。

使用提醒：进入数组子页学习容量和下标管理；本章约定 0 为空下标，有效结点从 1 开始。

纠错：把链表当连续数组

主要用途：现象：在 S1 中写 current++ 会访问 1、2，漏掉位置 3 且顺序错误；原因：编号不表示后继关系。

使用提醒：修正为读取当前结点的 next 或 nextIndex；复验应恰好得到 1→3→2，并在 0 的首次失败判断停止。

纠错：循环链等待空标记

主要用途：现象：访问 1、3、2 后又回到 1，一直重复；原因：尾链接回 head，链中不会出现 nullptr 或 0。

使用提醒：先判断空表；非空表完整走一圈后，在 current 再次等于 head 时停止。复验一轮只访问 1、3、2 各一次。

纠错：双向链只改一侧

主要用途：现象：正向 1→3→2 看似正确，反向却不能从 2 回到 3；原因：next 与 prev 没有同步。

使用提醒：让新结点记住前后两侧，并让两侧接回新结点；复验时分别正向、反向检查相邻结点是否互相指回。

纠错：覆盖旧后继

主要用途：现象：接入位置 3 后，位置 2 从 head 再也到不了；原因：把 next[1] 改成 3 前没有保存原来的 2。

使用提醒：先保存 oldNext，再连接新结点，最后改前驱链接；复验从 head 应到达 1、3、2 各一次，并满足当前链表的终止规则。
