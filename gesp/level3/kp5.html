一维数组

05
GESP 3级知识字典 · 知识点 05

按位置编号访问元素，完成统计、查找和最值更新，并检查下标范围。

检索词：下标访问范围检查

本课先记住

  • 核心结论： 数组最多能放多少个元素，叫作容量；这次实际用了多少个，叫作元素个数。元素在数组中的位置编号，叫作下标。数组的开头、末尾以及允许访问的最小和最大下标，都是需要检查的边界。
  • 常用语法： 用 int a[100] = {}; 声明定长数组；0-based 的前 n 项是 a[0] 到 a[n - 1]，遍历写成 for (int i = 0; i < n; i++)。
  • 最小示例： int score[5] = {72, 80}; 会把前两项设为 72、80，其余三项自动设为 0；本次若只使用两项，循环仍只走 i < 2。
  • 关键易错点： a[n] 已越过本次有效元素；只有 n 等于容量时，a[n] 才越过数组本身。写程序时既要检查 n 不超过容量，也要按本次实际元素个数控制访问。

知识范围与使用边界

先看一个具体问题：要保存 30 名同学的成绩，若分别声明 30 个变量，输入、统计和查找都会写成大量重复语句。一维数组把一组同类型、有顺序的数据放在连续的位置中，再用编号访问其中一项，循环就能按同一规则处理全部数据。

本课只解决三个核心问题：怎样声明数组并安全访问有效位置；怎样在遍历中维护计数、查找和最值状态；怎样根据访问式和值域反推相邻、移动、标记和计数的合法范围。七个稳定知识区继续完整保留，但都服务于这三个核心。

本课使用编译时已经确定长度的原生一维数组，输入数据最多 100 项。输入输出、变量、分支和循环沿用已经学过的写法，不重新展开。

核心概念

核心一：安全存取。 先分清固定容量、实际元素个数 n 和合法位置，再读写数组。

核心二：遍历维护状态。 i 决定本轮访问哪一项，计数器、查找位置或最值变量保存已经处理部分的结果。

核心三：从访问式和值域反推限制。 看见 a[i - 1]、a[i + 1] 或 cnt[value]，要先证明这些位置不会超出可用范围。

01 数组声明、容量与下标

数组声明与容量

声明 5 个整数位置的语法如下：

int score[5]; // 声明数组 score，预留 5 个同类型元素位置

int 是每个元素的类型，score 是数组名，5 是容量。有效下标从 0 开始，因此五个位置依次是 score[0]、score[1]、score[2]、score[3]、score[4]。

如果希望所有位置一开始都是 0，可以写：

int score[5] = {}; // 声明数组 score，预留 5 个元素位置并全部初始化为 0

也可以在声明时直接给出元素：

int score[] = {72, 80, 91, 65}; // 声明数组 score，并按初始化列表依次写入各元素

这里初始化列表中有 4 个数，所以编译器确定数组容量为 4，有效下标是 0 到 3。

初始化时也可以只给前几项赋值：

int a[5] = {1, 2}; // 声明数组 a，并按初始化列表依次写入各元素

这时 a[0] 是 1，a[1] 是 2，没有写出的后三项会自动初始化为 0。它和只写 int a[5]; 不同：后者没有为这五项指定初值，不能直接把其中的值当作 0 使用。

题目通常还会给出实际元素个数 n。容量表示“最多能放多少项”，n 表示“本次真正用了多少项”，两者不能混为一谈。

const int CAPACITY = 100; // 定义只读常量 CAPACITY，值为 100，统一控制容量或规则边界int a[CAPACITY] = {}; // 声明数组 a，预留 CAPACITY 个元素位置并全部初始化为 0

CAPACITY 是不会改变的容量。程序必须保证 n <= CAPACITY，并且只能处理本次输入的前 n 项。

下标       0        1        2        3        4元素     a[0]     a[1]     a[2]     a[3]     a[4]存储     [ int ][ int ][ int ][ int ][ int ]

数组元素类型一旦确定，每个位置都按同一种类型解释；数组长度也必须在编译时确定。本课使用的原生数组是固定长度，不能在运行中把 int a[5] 自动扩展成 int a[6]，所以要先根据题目数据范围预留足够容量。

数组占用的总字节数按“容量 × 每个元素的字节数”计算。在常见 GCC/OJ 环境中，一个 int 通常占 4 字节，因此 int a[5] 通常占 5 × 4 = 20 字节，int a[100] 通常占 100 × 4 = 400 字节。int 的准确大小由编译器和平台决定，所以程序应使用 sizeof 核对，不能把 4 当作所有环境永远不变的语言规则。

实际元素个数 n 不会改变数组已经分配的容量。即使 int a[100] 本次只读入 n = 7 个数，这个数组仍为 100 个 int 位置预留空间；循环只应访问 a[0] 到 a[6]。因此“分配多少空间”看容量，“本次处理多少数据”看 n，两项要分别检查。

对在当前作用域中声明的原生数组，可以用 sizeof 计算容量：

int a[5] = {3, 1, 4, 1, 5}; // 声明数组 a，并按初始化列表依次写入各元素int length = sizeof(a) / sizeof(a[0]); // 用数组总字节数除以单个元素字节数，计算数组容量cout << length;  // 输出 5

sizeof(a) 得到整个数组占用的字节数，sizeof(a[0]) 得到一个元素占用的字节数，二者相除就是元素个数。这个公式只适用于当前作用域中完整的原生数组，不要把它当成适用于任何变量的通用求长度公式。

代入常见的 4 字节 int 可以完整算一遍：sizeof(a) 通常是 20，sizeof(a[0]) 通常是 4，所以 20 / 4 = 5。这里相除后得到的是元素容量 5，不是最后一个下标；最后一个有效下标仍是 5 - 1 = 4。

原生数组不能整体赋值。

两个普通变量可以写 a = b;，但两个原生数组不能直接写成 destination = source;。要复制数组，必须逐项赋值：

int source[5] = {2, 4, 6, 8, 10}; // 声明数组 source，并按初始化列表依次写入各元素int destination[5] = {}; // 声明数组 destination，预留 5 个元素位置并全部初始化为 0
for (int i = 0; i < 5; i++) { // 从本循环起点开始，只在 i < 5 成立时访问元素，每轮再执行 i++    destination[i] = source[i]; // 把源数组下标 i 的值复制到目标数组同一位置} // 下标 i 的元素复制完成，i++ 后继续复制下一个位置

循环第 i 轮只复制下标为 i 的一个元素。这样既能看清复制过程，也能根据实际元素个数 n 控制需要复制的范围。

02 数组输入与遍历

数组输入与遍历

数组声明后，需要通过下标访问具体元素。下面的片段读入前 n 项，再按原顺序输出：

// 从下标 0 到 n - 1 依次读入本次真正使用的每个位置。for (int i = 0; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    cin >> a[i]; // 把第 i + 1 个输入值存入数组下标 i} // 当前元素已写入 a[i]，i++ 后读取下一个位置
// 按同样的有效下标范围依次输出数组元素。for (int i = 0; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    cout << a[i] << " "; // 输出当前数组元素，并为下一项保留一个分隔空格} // a[i] 已输出，i++ 后继续输出下一个有效元素

循环变量 i 表示当前位置，a[i] 表示这个位置保存的数值。每轮结束后 i++，也就是让下标增加 1。

第一次循环访问 a[0]。当 i = n - 1 时访问最后一个有效元素；下一次 i 变成 n，条件 i < n 不成立，循环结束，因此不会访问 a[n]。

03 数组统计与计数

数组计数

遍历数组时，可以让一个变量保存已经处理过的结果。求和时，sum 从 0 开始，每轮把当前元素加入总和：

数组求和过程：5、3、8。sum 从 0 开始，依次变成 5、8、16，也就是 0 → 5 → 8 → 16；每一步都能用“原来的总和 + 当前元素”复算。

int sum = 0; // 用 sum 记录已经遍历过的元素总和；从 0 开始表示尚未累计任何结果
// 从左到右处理全部 n 个元素，每轮把当前值加入总和。for (int i = 0; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    sum = sum + a[i]; // 把当前数组元素加入总和，保留到下一轮继续累计} // a[i] 已加入 sum，i++ 后继续累计下一个元素

计数器也从 0 开始。每当当前元素满足条件，就让计数器增加 1：

int positiveCount = 0; // 用 positiveCount 记录已经发现的正数个数；从 0 开始表示尚未累计任何结果
// 依次检查每个数组元素是否为正数。for (int i = 0; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    if (a[i] > 0) {  // 当前元素大于 0，说明找到一个正数，正数个数加 1        positiveCount++; // 当前元素是正数，已发现的正数个数增加 1    } // 当前元素是否贡献一次正数计数已经确定} // 当前元素是否为正数已经判断完，i++ 后检查下一项

这里判断的是元素 a[i] 是否为正数，不是判断下标 i。

求平均值要先得到总和，再除以实际元素个数 n。平均值只在 n > 0 时有意义；若先做两个整数的除法，小数部分会被舍去，所以要让其中一个运算数成为浮点数：

long long sum = 0; // 用 long long 保存总和，给多个 int 相加留下更大范围for (int i = 0; i < n; i++) { // 只累计本次输入的前 n 个有效元素    sum = sum + a[i]; // 把当前元素加入已处理部分的总和} // 结束求和循环，此时 sum 已包含全部 n 个元素double average = 1.0 * sum / n; // n 大于 0 时计算小数平均值，1.0 避免整数除法截断

例如数组 2、3、5 的总和是 10，平均值是 10.0 / 3 ≈ 3.333；若写成 10 / 3，两个运算数都是整数，只会先得到 3。题目若允许 n = 0，必须先单独处理空数组，不能除以 0。

04 顺序查找

数组查找

查找目标值时，可以用 bool found = false; 表示开始时还没有找到，用 position = -1 表示没有合法下标。

bool found = false; // 开始查找前还没有答案，用 false 记录这一状态int position = -1; // -1 不是合法下标，用它表示目前尚未找到
// 从第一个元素开始寻找目标值，最晚检查到下标 n - 1。for (int i = 0; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    if (a[i] == target) {  // 当前元素等于目标值，记录第一次出现的位置并停止查找        found = true; // 当前元素等于 target，记录已经找到目标        position = i; // 保存目标第一次出现的下标 i，供循环外输出        break; // 条件“a[i] == target”已经成立，立即停止当前循环，保留第一个答案    } // 一旦进入此分支，前一行 break 会直接跳出外层 for 循环} // 未找到时才执行 i++ 检查下一项；找到时从这里跳到循环后

题目要求第一次出现的位置，因此找到后立刻 break，不再检查后面的元素。position 保存 C++ 下标；如果题目问“第几个元素”，输出时再使用 position + 1。

05 最大值与最小值

数组最大值和最小值

只要题目保证 n >= 1，就可以用第一个真实元素初始化最大值：

int maximum = a[0]; // 用第一个真实元素初始化最大值，兼容全为负数的输入int minimum = a[0]; // 用第一个真实元素初始化最小值，避免使用范围外的假值
// a[0] 已作为初值，因此从下标 1 开始检查剩余元素。for (int i = 1; i < n; i++) { // 从本循环起点开始，只在 i < n 成立时访问元素，每轮再执行 i++    if (a[i] > maximum) {  // 当前元素比已记录的最大值更大，需要更新最大值        maximum = a[i]; // 用更大的当前元素更新已处理部分的最大值    } // maximum 已保存前 i + 1 个元素中的最大值，下面继续检查最小值
    if (a[i] < minimum) {  // 当前元素比已记录的最小值更小，需要更新最小值        minimum = a[i]; // 用更小的当前元素更新已处理部分的最小值    } // minimum 已保存前 i + 1 个元素中的最小值，本轮比较完成} // a[i] 与当前最大值、最小值均已比较，i++ 后处理下一项

循环从下标 1 开始，因为 a[0] 已经作为初值。不能习惯性把最大值设为 0；当数组全部是负数时，0 可能根本不在输入中。

06 数组处理与状态变化

数组遍历与状态变化

数组处理不只读取数据，也会在合法位置内改变数据。交换两个元素时，先用临时变量保存左边旧值，再覆盖左边，最后把旧值写到右边。反向排列就是让 left 从 0 向右、right 从 n - 1 向左，反复交换，直到两者相遇。输入 1、2、3、4、5 时，两次交换后得到 5、4、3、2、1；中间的 3 不需要和自己交换。

在固定容量数组中插入或删除时，核心是先移动，再改变实际元素个数：

for (int i = n; i > position; i--) { // 从末尾向前腾出 position 位置，保证旧元素不被覆盖    a[i] = a[i - 1]; // 把前一个元素向右移动一格} // 右侧元素全部移动后，position 已经空出a[position] = value; // 把新值写入指定插入位置n++; // 插入成功后，实际元素个数增加 1
for (int i = position; i + 1 < n; i++) { // 从删除位置向后处理到原最后一项之前    a[i] = a[i + 1]; // 用右侧元素覆盖当前空位，相当于整体左移} // 原最后一项已经不再属于有效数据n--; // 删除成功后，实际元素个数减少 1

去除重复值时，也可以用两层循环做直白检查：uniqueCount 表示数组前部已经保留了多少个不同值；每读到一项，就只和前 uniqueCount 项比较，没有出现过才写到保留区末尾。输入 3、1、3、2、1 时，保留区依次变为 3、3 1、3 1、3 1 2、3 1 2，最终 uniqueCount = 3。这一段只帮助理解“外层选当前项、内层查已保留项”的状态，不作为本页第二条完整程序主线。

数组遍历与状态变化

用数组 4、-2、7、7、1 同时观察正数计数、最大值和最大值第一次出现的位置。a[0] 已经作为最值初值，所以比较循环从 i = 1 开始；严格使用 >，遇到第二个 7 时不会覆盖第一次出现的位置 2。

bool appeared[101] = {}; // 下标 0 到 100 分别代表对应数值，false 表示尚未出现int cnt[101] = {}; // 下标 0 到 100 分别保存对应数值的出现次数，初始均为 0
for (int i = 0; i < n; i++) { // 循环 n 次，每轮读取并统计一个输入值    int value; // 暂存本轮输入，随后直接把它当作 appeared 和 cnt 的下标    cin >> value; // 读入第 i + 1 个待统计数值    appeared[value] = true; // 把 value 对应的标记设为 true，表示这个值至少出现过一次    cnt[value]++; // 当前又读到一个 value，把它的出现次数增加 1} // 本轮输入值的标记和次数均已更新，i++ 后读取下一个数

appeared[value] 是标记数组：只回答这个数是否出现。cnt[value] 是计数数组：记录这个数出现了多少次。数组长度写成 101，是因为要使用下标 0 到 100。只有题目保证数值范围时才能这样做；若 value 为负数或大于 100，就会越界。

if (!appeared[x]) { // 目标值从未出现时，输出对应的缺失提示    cout << x << " 没有出现"; // 标记为 false，说明 x 在输入中一次也没有出现} // appeared[x] 的缺失判断结束，下面再用次数区分缺失和重复
if (cnt[x] == 0) { // 出现次数为 0 时，说明目标值在输入中缺失    cout << x << " 缺失"; // 出现次数为 0，输出 x 缺失} else if (cnt[x] >= 2) { // 上一情况不成立时，继续检查另一种边界情况    cout << x << " 重复出现"; // 出现次数超过 1，输出 x 重复} // cnt[x] 为 0 或至少为 2 的两种情况已经判断完毕

!appeared[x] 和 cnt[x] == 0 都能判断缺失；cnt[x] >= 2 表示至少出现两次，可以判断重复。访问这些位置前仍要保证 x 在 0 到 100 内。

输入 2、5、2 时，cnt[2] 依次变为 1、1、2，cnt[5] 依次变为 0、1、1。完整统计程序仍然只是“读一个值、先检查 0 到 100、再执行 cnt[value]++”的重复；本页保留这个可复算结果，不再复制第二份带 main 的程序。

典型例题

反向输出不改变数组内容，只把访问顺序改为 n - 1、n - 2、…、0。例如 {4, 7, 2} 依次访问下标 2、1、0，输出 2 7 4；这是遍历方向的变化，不再另设完整程序。

相邻元素

相邻元素题每轮要访问一对元素。使用 a[i - 1] 和 a[i] 时，i 必须从 1 开始：

int largestDifference = 0;// i 从 1 开始，保证 a[i - 1] 是合法下标。for (int i = 1; i < n; i++) {    int difference = a[i] - a[i - 1];    if (difference < 0) {        difference = -difference;    }    if (difference > largestDifference) {        largestDifference = difference;    }}

第 1 轮访问 a[0] 和 a[1]，最后一轮访问 a[n - 2] 和 a[n - 1]。这段代码要求 n >= 2。

为避免两个很大的 int 相减溢出，本课完整示例约定每个输入整数在 -10000 到 10000 之间，因此差值一定能放进 int。

下面的唯一完整程序只完成一项可迁移任务：读入 n 个整数，输出最大值和它第一次出现的 0-based 位置。输入约定为 1 <= n <= 100，每个数都在 C++ int 可表示范围内；程序只比较整数，不做可能溢出的算术。

完整程序：数组综合练习

#include <bits/stdc++.h>using namespace std;
int main() {    const int CAPACITY = 100;    int a[CAPACITY] = {};
    int n;    cin >> n;
    // 元素个数必须为正，并且不能超过固定容量，否则后续访问会越界。    if (n < 1 || n > CAPACITY) {        cout << "Invalid" << '\n';        return 0;    }
    for (int i = 0; i < n; i++) {        cin >> a[i];    }
    // 用第一个真实元素初始化，全部为负数时也不会凭空得到 0。    int maximum = a[0];    int position = 0;
    // a[0] 已经作为初值，所以从下标 1 开始比较。    for (int i = 1; i < n; i++) {        // 只在严格更大时更新，相等时保留最大值第一次出现的位置。        if (a[i] > maximum) {            maximum = a[i];            position = i;        }    }
    cout << maximum << ' ' << position << '\n';
    return 0;}

完成这道典型例题的成功标准是：合法输入只输出“最大值 空格 第一次出现位置”；非法元素个数输出 Invalid；重复最大值不覆盖第一次位置；输出末尾换行。

数组综合程序测试案例必须覆盖下面八类真值，并且全部成立：

  1. 5\n4 -2 7 7 1\n 输出 7 2。
  2. 1\n-5\n 输出 -5 0。
  3. 4\n3 3 3 3\n 输出 3 0。
  4. 3\n-8 -3 -5\n 输出 -3 1。
  5. 5\n1 2 3 4 9\n 输出 9 4。
  6. 5\n9 1 8 2 7\n 输出 9 0。
  7. 0\n 输出 Invalid。
  8. n = 100 且依次输入 1 到 100 时，输出 100 99。

把循环写到 i <= n 会多访问一项

× 错误写法有 n 个元素时使用 for (int i = 0; i <= n; i++) 访问 a[i]
✓ 正确写法0-based 遍历写为 i = 0 到 i < n；需要前一项的相邻扫描写为 i = 1 到 i < n。

原因：最后一次 i 等于 n，而有效的最后一项是 a[n - 1]；a[n] 已越过有效数据。

检查方法：先写出最后一次循环要访问的下标，再反推循环条件。

常见错误

  1. 把容量当成元素个数。 现象：声明 int a[100] 后总是处理 100 项。原因：100 只是最多可放的位置数，本次有效数据由 n 决定。修正：输入前检查 n，遍历只走 i < n。复验：n = 3 时只访问 a[0] 到 a[2]。
  2. 混用两套编号。 现象：输入写进 a[0] 到 a[n - 1]，输出却从 a[1] 开始。原因：0-based 与 1-based 混在同一段代码里。修正：一段程序只采用一套约定。复验：逐项写出第一个和最后一个实际访问的位置。
  3. 循环写成 i <= n。 现象：最后一轮访问 a[n]。原因：最后一个有效位置是 n - 1。修正：0-based 遍历使用 i < n。复验：代入 n = 5，最后一次循环应为 i = 4。
  4. 输入前不检查 n。 现象：n = 101 时仍向容量 100 的数组写入。原因：循环开始前没有验证实际元素个数。修正：先判断 n < 1 || n > CAPACITY。复验：n = 0 和 n = 101 都输出 Invalid。
  5. 空数据仍读取首项。 现象：n = 0 时执行 maximum = a[0]。原因：首项并不是本次有效数据。修正：在初始化最值前排除空数据。复验：只有 1 <= n <= CAPACITY 才进入读数和最值循环。
  6. 相邻扫描从 0 开始。 现象：第一轮尝试访问 a[-1]。原因：表达式含 a[i - 1]，却没有反推 i 的最小值。修正：从 i = 1 开始。复验：第一对是 a[0] 与 a[1]，最后一对是 a[n - 2] 与 a[n - 1]。
  7. 最大值初始化为 0。 现象：全负数输入得到不存在的最大值 0。原因：初值不是任何真实候选。修正：使用 a[0] 初始化。复验：-8 -3 -5 必须得到 -3。
  8. 相等时覆盖第一次位置。 现象：4 -2 7 7 1 得到位置 3。原因：更新条件写成了 >=。修正：只在 a[i] > maximum 时更新。复验：两个 7 中保留下标 2。
  9. 直接整体赋值。 现象：写出 destination = source;。原因：原生数组不能用普通赋值语句整体复制。修正：按相同合法位置逐项赋值。复验：逐轮核对 destination[i] = source[i]。
  10. 把任意数值当位置。 现象：负数或大于 100 的值直接用于 appeared[value]。原因：没有证明值域落在 0 到 100。修正：只在题目保证或程序检查值域后访问。复验：分别检查最小值 0、最大值 100 和两个范围外反例。

本课收束为三个动作：先用容量、n 和合法位置保证安全存取；再在遍历中维护真实状态；最后根据访问式和值域反推限制。计数、查找、最值、相邻、移动和按值记录都只是这三个动作的不同应用。
