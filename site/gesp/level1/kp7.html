检索词：运算符优先级

本课先记住

  • 核心结论： 运算符按优先级和结合方向组成表达式；先得到右侧结果，再由赋值把结果写回变量，关系与逻辑运算得到真假值。

  • 关键易错点： = 不是 ==，两个整数相除仍是整数结果；混合表达式不确定时应加括号并逐步记录中间值。

知识范围与官方定位

变量保存数据，运算符则告诉程序怎样处理这些数据。看见一个表达式时，不能只认出其中的符号，还要回答三个问题：

  1. 这个表达式会得到数值、真假，还是从两个结果中选一个？
  2. 它只产生结果，还是会把新值写回变量？
  3. 有多个运算符时，程序先算哪一部分？

例如下面四个表达式都使用了变量 a、b，作用却不同：

表达式 得到的结果 是否修改原变量
a + b 两数之和 否
a > b true 或 false 否
a += b 更新后的 a 是，修改 a
a++ 完成一次自增 是，修改 a

本页覆盖一级大纲中的算术、关系、赋值、自增自减、逻辑和条件运算，以及常用优先级和结合方向。位运算、复杂类型转换、嵌套三目运算和复杂表达式求值规则不在本页范围内。

01 算术运算

运算符旁边参与运算的数据叫作操作数。在 a + b 中，a、b 是操作数，+ 决定对它们做加法。

五种基本算术运算

运算 运算符 示例 结果
加法 + 12 + 5 17
减法 - 12 - 5 7
乘法 * 12 * 5 60
除法 / 12 / 5 2
取余 % 12 % 5 2

C++ 中的乘法必须写成 *，不能写数学中的 ×，也不能省略乘号：

int area = length * width; // 正确：用 * 计算长方形面积

2x 不是 C++ 的乘法写法，必须写成 2 * x。

加号、减号也能表示正负

当 + 或 - 只作用于一个操作数时，它们表示正号或负号：

int a = 5;int positive = +a; // positive 得到 5，a 不变int negative = -a; // negative 得到 -5，a 仍然不变

-a 只是计算出 a 的相反数。若要修改 a，必须把结果重新写回：

a = -a; // 先求 -a，再把结果保存回 a

所以判断表达式是否改变变量时，要找有没有赋值、复合赋值、自增或自减，不能看到一次计算就认为原变量已经变化。

02 关系运算

关系运算比较两个数据，结果只有 true 或 false。

运算符 含义 当 a = 3、b = 5 时 结果
> 大于 a > b false
>= 大于等于 b >= 5 true
< 小于 a < b true
<= 小于等于 a <= 3 true
== 等于 a == b false
!= 不等于 a != b true

关系运算只负责比较，不会修改参与比较的变量。普通 cout 输出真假值时，true 通常显示为 1，false 通常显示为 0。

赋值等号和相等比较不是一回事

a = b;  // 赋值：把 b 的值保存到 a，会修改 aa == b; // 比较：判断 a 与 b 是否相等，不修改变量

读到等号时，先看是一个 = 还是两个 ==。一个表示“保存”，两个表示“是否相等”。

C++ 不能照写数学中的链式比较

数学中可以写 1 ≤ x ≤ 10。C++ 中不要写成：

1 <= x <= 10 // 不能按“x 在 1 到 10 之间”理解

C++ 会先计算 1 <= x，结果只能是 false 或 true；参与后面的数值比较时，它们分别相当于 0 或 1。于是第二次比较实际是 0 <= 10 或 1 <= 10，结果都会为真，当然不能正确检查范围。

正确写法是把两个关系分别写清，再用逻辑与连接：

(x >= 1) && (x <= 10) // 下界和上界都满足，x 才在范围内

03 整数除法与取余

上一页已经看到 7 / 2 和 7 % 2。本节把整数除法的“商”和“余数”放在一起讲清楚。

两个整数相除得到整数商

对于本页使用的正整数，/ 会保留完整商，舍去不能整除的部分，不做四舍五入：

表达式 完整商 结果
17 / 5 3 3
3 / 5 0 0
10 / 5 2 2

若要得到小数结果，必须让浮点数在除法发生前参与运算。例如 7.0 / 2.0 得到 3.5。整数与小数混合运算的完整类型转换规则会在后续等级继续学习。

取余得到没有分完的部分

% 计算整数相除后的余数：

17 / 5 = 317 % 5 = 2

可以用下面的关系反向核对：

被除数 = 商 × 除数 + 余数17 = 3 × 5 + 2

对于正整数，余数满足 0 <= 余数 < 除数。如果算出的余数等于或大于除数，就说明商或余数算错了。

除法和取余的使用条件

  • / 和 % 的除数都不能为 0；
  • % 两侧必须是整数；
  • 本页主教学只处理非负整数。负数整数除法和负数取余的完整规则不在本课展开。

取余常用于：

n % 2  // 检查非负整数 n 除以 2 的余数n % 10 // 取得非负整数 n 的个位数字n % k  // 计算每组 k 个时剩余多少个

这里的 % 表示取余，不是数学中的百分号。

04 赋值与复合赋值

赋值的执行顺序是：先计算右侧，再把结果保存到左侧变量。

int a = 10;a = a + 3; // 右侧先用旧值 10 算出 13，再把 13 写回 a

执行后 a 从 10 变成 13。左侧必须是可以修改的变量，不能写 3 = a。

复合赋值把计算和写回合在一起

复合赋值 等价的完整写法 执行后发生什么
a += b a = a + b a 增加 b
a -= b a = a - b a 减少 b
a *= b a = a * b a 变为原来的 b 倍
a /= b a = a / b 商写回 a
a %= b a = a % b 余数写回 a

例如：

int score = 20;score += 5; // score = score + 5，score 变成 25score *= 2; // score = score * 2，score 变成 50score -= 8; // score = score - 8，score 变成 42score /= 5; // 整数除法 42 / 5 得 8，score 变成 8score %= 3; // 8 % 3 得 2，score 变成 2

这五条语句必须从上到下执行。后一条看到的是前一条已经写回的新值，不能每次都从 20 重新计算。

连续赋值从右向左执行

int a;int b;a = b = 3;

执行过程是：

  1. 先执行 b = 3，此时 b 得到 3；
  2. 再执行 a = b，此时 a 也得到 3。

等价的直白写法是：

b = 3;a = b;

int a = b = 3; 中的 b 必须提前定义，否则程序找不到要赋值的变量。一级主代码优先使用分步写法，连续赋值只要求能按从右到左读懂。

还要注意：

a += 3; // a 在原值上增加 3a =+ 3; // 相当于 a = +3，直接把正数 3 赋给 a

符号顺序不同，含义完全不同。

05 自增与自减

单独计算 i + 1 不会修改 i：

int i = 5;i + 1; // 只产生结果 6，没有写回，i 仍为 5

要让 i 增加 1，可以写：

i = i + 1; // 完整写法i += 1;    // 复合赋值i++;       // 自增

相应地，i-- 让 i 减少 1。循环变量每轮只增加 1 时可以优先写 i++；普通累计量或增加量不是 1 时，仍用完整赋值或复合赋值表达清楚。

单独使用时，前置和后置结果相同

++a; // a 先增加 1b++; // b 也增加 1--c; // c 减少 1d--; // d 也减少 1

当它们各自单独占一条语句时，前置和后置的最终效果相同。

放进表达式时，取得的值不同

int a = 5;int x = a++; // x 先取得旧值 5，然后 a 变成 6
int b = 5;int y = ++b; // b 先变成 6，然后 y 取得新值 6
语句 表达式先取得什么 原变量最后是多少 接收变量是多少
x = a++ a 的旧值 5 a = 6 x = 5
y = ++b b 增加后的新值 6 b = 6 y = 6

自减遵循相同规则。一级实际编程仍优先把 i++、i-- 单独写成更新语句，不在一条复杂表达式中多次修改同一个变量。

06 逻辑运算

逻辑运算组合或改变真假条件，结果仍然是 true 或 false。

运算符 含义 整体为真的条件
&& 并且 左右两个条件都为真
|| 或者 至少一个条件为真
! 取反 原条件为假

真假表

条件 A 条件 B A && B A || B
false false false false
false true false true
true false false true
true true true true

!true 的结果是 false，!false 的结果是 true。

范围判断需要同时满足上下界，因此使用 &&：

bool inRange = (x >= 1) && (x <= 10);

当 x = 7 时，左右条件都为真，inRange 得到 true；当 x = 12 时，右侧条件为假，整体得到 false。

短路决定右侧是否执行

C++ 先计算左侧条件。如果只看左侧就能确定整体结果，右侧不会继续计算。

表达式 左侧结果 是否计算右侧 整体结果
A && B false 不计算 false
A && B true 继续计算 由 B 决定
A || B true 不计算 true
A || B false 继续计算 由 B 决定

短路还会决定右侧运算是否真的发生。假设 a = 10、b = 0：

bool safe = (b != 0) && (a / b > 2);

执行过程：

步骤 当前部分 结果 下一步
1 b != 0 false && 的整体结果已经确定为假
2 a / b > 2 不执行 不会发生除以 0
3 保存结果 safe = false 表达式结束

如果把左右两部分交换，程序就可能先执行 a / b，失去保护。因此短路表达式的顺序必须符合实际目的。

07 条件运算符

条件运算符也叫三目运算符。它根据一个条件，从两个结果中选择一个：

条件 ? 条件为真时的结果 : 条件为假时的结果

例如：

int maximum = (a > b) ? a : b;

当 a = 3、b = 5 时：

  1. 先计算条件 a > b，结果为 false；
  2. 条件为假，选择冒号后的 b；
  3. b 的值是 5，所以 maximum 得到 5；
  4. 没被选中的 a 不作为这次表达式的结果。

一级只要求看懂这种简单二选一。需要执行多条语句时，后面的分支结构会使用更清楚的 if-else；本页不学习嵌套三目运算。

08 优先级与结合方向

一个表达式中出现多个运算符时，优先级决定哪一类先算；优先级相同时，结合方向决定从哪边开始。

一级常用优先级

从高到低 运算符 说明
1 () 括号内先计算
2 后置 ++、-- 表达式取得旧值后再更新
3 前置 ++、--、!、单目 +、- 只作用于紧邻的一个对象或条件
4 *、/、% 乘、除、取余
5 +、- 加、减
6 <、<=、>、>= 大小关系
7 ==、!= 相等与不等
8 && 逻辑与
9 || 逻辑或
10 ? : 简单二选一
11 =、+=、-=、*=、/=、%= 赋值与复合赋值

不要把整张表当成死记任务。做题时先找括号，再按“算术 → 关系 → 逻辑 → 赋值”分层；拿不准就补括号或拆成多条语句。

同级算术运算通常从左到右

20 / 5 * 2 = 4 * 2 = 810 - 3 - 2 = 7 - 2 = 5

赋值则从右向左结合，所以 a = b = 3 先修改 b，再修改 a。

一步一步计算混合表达式

计算：

3 + 2 * 4 > 10 && !false
步骤 本步运算 得到的结果 结果类型
1 2 * 4 8 整数
2 3 + 8 11 整数
3 11 > 10 true bool
4 !false true bool
5 true && true true bool

普通输出最终结果时会看到 1。

比较先算，赋值最后发生

假设 b = 5：

int a;a = b > 3;  // 等价于 a = (b > 3)，比较为 true，a 得到 1a = b == 3; // 等价于 a = (b == 3)，比较为 false，a 得到 0

关系运算和相等比较都高于赋值，所以先得到 true 或 false，再把真假值转换成普通整数 1 或 0 写入 a。更容易阅读的写法是直接保存为 bool：

bool greaterThanThree = (b > 3);bool equalToThree = (b == 3);

括号和准确的变量名能直接写出含义，也能减少把 = 与 == 看错的机会。

做运算题的统一检查顺序

面对一个表达式，可以按下面的顺序检查：

  1. 圈出操作数，确认它们是整数、小数还是真假值。
  2. 找出会写回变量的运算：赋值、复合赋值、自增、自减。
  3. 先算括号，再按优先级分层计算。
  4. 每完成一步，就写下当前结果和结果类型。
  5. 遇到 /、% 检查除数；遇到 &&、|| 检查右侧是否真的执行。

典型例题

学校有 n 名学生参加活动，每个完整小组安排 k 人，场地最多允许 limit 个小组。程序需要计算：

  • 能组成多少个完整小组，还剩多少人；
  • 场地最多提供多少个座位；
  • 容量是否足够、是否恰好分完，以及这两个条件是否同时成立。

输入保证 n、k、limit 都是 int 范围内的正整数，k 不为 0，且 k * limit 不超过常见 int 上限。

对于输入 23 5 5，先手算：

完整小组数 = 23 / 5 = 4剩余人数 = 23 % 5 = 3总座位数 = 5 * 5 = 25容量足够：23 <= 25，为 true恰好分完：3 == 0，为 false两个条件同时成立：true && false，为 false

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int n;    int k; // 题目保证 k 是正整数，可以作为除数    int limit;    cin >> n >> k >> limit;
    int fullGroups = n / k; // 整数除法得到完整小组数    int remaining = n % k; // 取余得到未进入完整小组的人数    int totalSeats = k * limit; // 计算场地最多提供的座位数
    bool capacityEnough = (n <= totalSeats);    bool dividedExactly = (remaining == 0);    bool canArrange = capacityEnough && dividedExactly;
    cout << fullGroups << " " << remaining << endl;    cout << totalSeats << endl;    cout << capacityEnough << " " << dividedExactly << " " << canArrange << endl;    return 0;}

输入：

23 5 5

输出：

4 3251 0 0

执行过程：

步骤 新完成的运算 结果 当前关键状态
1 读入三个数 无计算结果 n = 23、k = 5、limit = 5
2 n / k 完整商为 4 fullGroups = 4
3 n % k 余数 3 remaining = 3
4 k * limit 25 totalSeats = 25
5 n <= totalSeats true capacityEnough = true
6 remaining == 0 false dividedExactly = false
7 true && false false canArrange = false
8 依次输出 4 3、25、1 0 0 程序结束

可以用 23 = 4 × 5 + 3 核对：完整商是 4，余数是 3。这个等式也能帮助我们发现把商和余数写反的错误。

还可以检查三个边界：

输入 完整组／剩余 座位数 三个真假结果 检查目的
23 5 5 4 3 25 1 0 0 有余数但容量足够
20 5 3 4 0 15 0 1 0 恰好分组但容量不足
20 5 4 4 0 20 1 1 1 两个条件都成立

引导练习（不记录进度）

取 a = 17、b = 5，分别求 a / b 和 a % b。先判断两侧都是整数，再写出完整商 3 和余数 2，最后用 17 = 3 × 5 + 2 反向核对。

成功标准： 商、余数和反向等式必须同时成立，并确认除数不是 0。完成后不看提示独立完成页末“整页综合测试”；提交后逐题按括号、优先级、结合方向和写回顺序复演错题。

常见错误

  1. 认为整数除法会自动得到小数。 7 / 2 得 3。自查时先看除法发生前两侧的数据类型。
  2. 用 0 作除数。 / 和 % 的右侧都不能为 0；看到这两个符号先检查除数范围。
  3. 对浮点数使用 %。 % 两侧必须是整数，它不是小数运算符，也不是百分号。
  4. 把 = 与 == 混淆。 先问这一步要“保存新值”还是“判断相等”，再决定写一个或两个等号。
  5. 把 += 错写成 =+。 复合赋值的算术符号写在等号前；a =+ 3 只是把正数 3 赋给 a。
  6. 认为 i + 1 会更新 i。 检查计算结果有没有写回，或者是否使用了 +=、++。
  7. 照写数学中的 1 <= x <= 10。 在 C++ 中应把上下界分别比较，再用 && 连接。
  8. 把逻辑运算符写少一个符号。 并且写 &&，或者写 ||；单个 &、| 属于本页不讲的位运算。
  9. 短路保护顺序写反。 要先检查除数不为 0，再把除法放到 && 右侧。
  10. 凭直觉猜混合表达式。 先找括号，再分算术、关系、逻辑和赋值；仍不确定就主动补括号或拆行。

整页综合测试

8 题

第 1 题表达式 4 * (11 + 12) / 4 的值是多少？

答案：C
先算括号得 23，再按从左到右计算乘法和除法，结果仍为 23。
对应知识点：08 优先级与结合方向

第 2 题int a = 6; 执行 a %= 4; 后，a 的值是多少？

答案：B
a %= 4 等价于 a = a % 4，6 除以 4 的余数是 2。
对应知识点：04 复合赋值

第 3 题当 x = 12 时，表达式 x >= 1 && x <= 10 的结果是什么？

答案：B
对应本页 06 逻辑运算。x >= 1 为真，x <= 10 为假；&& 要求两边都为真，因此整体为假。两个关系表达式都只进行比较，不会修改 x。
对应知识点：06 逻辑运算

第 4 题整数表达式 37 / 4 的结果是多少？

答案：A
两个整数相除执行整数除法，小数部分被舍去，结果为 9。
对应知识点：03 整数除法与取余

第 5 题int a = 5; 单独执行 a++; 后，a 的值是多少？

答案：C
a++ 单独使用时让 a 增加 1，所以 a 从 5 变为 6。
对应知识点：05 自增与自减

第 6 题a = 3、b = 5 时，表达式 (a + b) * 2 的结果是多少？

答案：C
对应本页 01 算术运算。先算括号中的 3 + 5 = 8，再乘 2 得 16。
对应知识点：01 算术运算

第 7 题a = 3、b = 5 时，下面哪个关系表达式的结果为假？

答案：C
对应本页 02 关系运算。3 不等于 5，所以 a == b 为假；比较只得到真假结果，不会修改变量。
对应知识点：02 关系运算

第 8 题a = 3、b = 5 时，int maximum = (a > b) ? a : b; 会把哪个值保存到 maximum？

答案：B
对应本页 07 条件运算符。条件 a > b 为假，所以选择冒号后的 b，maximum 最终保存 5。
对应知识点：07 条件运算符
