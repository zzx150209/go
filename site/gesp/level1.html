01 官方核心未复习

计算机基础知识

认识计算机的发展、组成、软硬件、操作系统与文件目录。

计算机组成软硬件
核心要点
  • 硬件是计算机的实体部分，包括 CPU、内存、硬盘、主板、输入输出设备等，看得见摸得着。
  • 软件是指挥硬件工作的程序和数据，分为系统软件（操作系统）和应用软件（浏览器、编辑器等）。
  • CPU 负责运算和控制，内存临时保存正在运行的程序和数据，硬盘长期保存文件。
  • 输入设备把外部信息送入计算机（键盘、鼠标、麦克风），输出设备把结果呈现出来（显示器、打印机、扬声器）。
  • 计算机内部用二进制（0 和 1）表示所有信息，因为电子元件只有通电和断电两种稳定状态。
注意事项
  • 触摸屏既是输入设备也是输出设备，判断时看信息流向。
  • 改文件扩展名不会改变文件内容，.cpp 源文件必须编译后才能运行。
02 官方核心未复习

集成开发环境

完成编辑、编译、运行和调试，判断常见程序错误。

IDE编译调试
核心要点
  • IDE（集成开发环境）把编辑、编译、运行、调试四个功能整合在一个软件中。
  • 写代码用编辑器，保存后编译器把 .cpp 源文件翻译成可执行程序（.exe），再由运行环境执行。
  • 常见错误有：语法错误（编译时报错）、链接错误（找不到函数）、运行时错误（程序崩溃）、逻辑错误（结果不对）。
  • 调试时可以在关键位置打断点，逐行执行并查看变量值，定位逻辑问题。
注意事项
  • 编译错误看行号和提示，先改第一个错误，后面的可能是连锁反应。
  • 程序运行结果不对时，用 cout 输出中间变量值来追踪。
03 官方核心未复习

程序基本结构

理解头文件、命名空间、main 函数、语句、代码块和注释。

main函数程序框架
核心要点
  • 一个最简单的 C++ 程序包含：头文件包含（#include）、命名空间声明（using namespace std）、main 函数。
  • main 函数是程序的入口，程序从 main 的第一条语句开始执行，到 return 0 结束。
  • 每条语句以分号结尾，大括号 { } 表示一个代码块。
  • 注释有两种：// 单行注释 和 /* 多行注释 */，编译器忽略注释内容。
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
注意事项
  • return 0 表示程序正常结束，main 函数必须有返回值类型 int。
  • cout 输出时需要换行用 endl 或 '\n'。

输入输出语句

使用 cin、cout、scanf、printf，并按题目要求控制输出格式。

cin-coutscanf-printf
核心要点
  • cin 用于从键盘读取数据，cout 用于向屏幕输出数据，都需要 #include <iostream>。
  • cin >> 变量 会跳过空格和换行，依次读取多个值。
  • cout << 内容 可以连续输出，用 endl 换行。
  • scanf/printf 是 C 风格输入输出，格式化输出用 %d（整数）、%f（小数）、%c（字符）、%s（字符串）。
int a, b;
cin >> a >> b;              // 输入两个整数
cout << a + b << endl;      // 输出和

printf("%d %d\n", a, b);   // C 风格输出
注意事项
  • cin 和 cin 不要混用 scanf/printf，避免不同步问题。
  • 输出格式要严格按题目要求，包括空格、换行和小数位数。
05 官方核心未复习

程序基本概念

掌握标识符、关键字、常量、变量、赋值与表达式。

变量常量标识符表达式
核心要点
  • 标识符是程序员自己起的名字（变量名、函数名），只能由字母、数字、下划线组成，不能以数字开头。
  • 关键字是 C++ 保留的单词（int、if、for 等），不能用作标识符。
  • 常量是程序运行中不改变的值（如 3.14、'hello'），变量是内存中可以改变的数据。
  • 赋值语句 x = 5; 把右边的值存入左边的变量，等号是赋值不是数学等式。
int a = 10;      // 定义变量a并赋初值
int b = a + 5;   // b = 15
a = a + 1;       // a = 11（自增）
const double PI = 3.14159;  // 常量
注意事项
  • 变量必须先定义再使用，未初始化的变量值是随机的。
  • C++ 区分大小写，Age 和 age 是两个不同的变量。
06 官方核心未复习

基本数据类型

认识整型、浮点、字符和布尔类型的范围与选择方法。

int-doublechar-bool
核心要点
  • int 存储整数（约 -21 亿到 21 亿），double 存储小数（约 15 位有效数字）。
  • char 存储单个字符（如 'A'），bool 存储真（true）或假（false）。
  • 整数除法会截断小数部分：7 / 2 = 3 而不是 3.5。
  • 选择数据类型时看数值范围：小数用 double，超大整数用 long long。
int a = 7, b = 2;
double c = 7.0 / 2.0;   // c = 3.5
double d = a / b;        // d = 3.0（整数除法先执行）
char ch = 'A';           // 字符用单引号
bool ok = true;          // 布尔值
注意事项
  • 整数除以整数结果还是整数，要得到小数至少有一个操作数是小数。
  • char 本质是整数，'A' 的 ASCII 值是 65。
07 官方核心未复习

基本运算

掌握算术、关系、逻辑、赋值、自增自减及优先级规则。

运算符优先级
核心要点
  • 算术运算符：+、-、*、/、%（取余），注意整数除法和取余只对整数有效。
  • 关系运算符：>、<、>=、<=、==（等于）、!=（不等于），结果为 true 或 false。
  • 逻辑运算符：&&（并且）、||（或者）、!（非），优先级 ! > && > ||。
  • 赋值运算符：=、+=、-=、*=、/=，自增 ++ 和自减 --。
int a = 10, b = 3;
a + b   // 13
a / b   // 3（整数除法）
a % b   // 1（10除以3余1）
(a > 5) && (b < 5)  // true
a++     // a变成11，先使用再加1
++a     // a先加1再使用
注意事项
  • == 是判断相等，= 是赋值，不要混淆。
  • 负数取余的结果符号跟被除数有关，C++ 中 -7 % 3 = -1。
08 官方核心未复习

顺序结构

按顺序完成输入、计算和输出，并通过变量变化检查。

顺序执行变量追踪
核心要点
  • 程序默认按语句书写顺序从上到下依次执行。
  • 解题时通常三步：输入数据 → 计算处理 → 输出结果。
  • 通过输出中间变量值可以追踪每一步发生了什么，帮助找错。
  • 变量的最终值取决于最后一次赋值，之前的值会被覆盖。
// 计算长方形面积和周长
int length, width;
cin >> length >> width;
int area = length * width;       // 计算面积
int peri = 2 * (length + width); // 计算周长
cout << area << " " << peri << endl;
注意事项
  • 调试时在关键步骤加 cout 输出，确认变量值是否符合预期。
  • 语句顺序很重要，先计算再输出，不要搞反。

分支结构

使用 if、if-else、else-if、switch 和三元运算处理不同情况。

if-elseswitch-case
核心要点
  • if (条件) { ... } 条件为真时执行大括号内的语句。
  • if-else 二选一：条件为真执行 if 块，否则执行 else 块。
  • else if 可以串联多个条件，从上到下依次判断，满足一个就执行。
  • switch 适合单值多分支判断，每个 case 后记得 break。
int score;
cin >> score;
if (score >= 90) cout << "A" << endl;
else if (score >= 80) cout << "B" << endl;
else if (score >= 60) cout << "C" << endl;
else cout << "D" << endl;
注意事项
  • if 后不要加分号，否则大括号内容不再受条件控制。
  • switch 中 case 不写 break 会继续执行后面的 case（穿透）。

循环结构

掌握三种循环与循环控制，解决累加、最值、位数、数列和枚举问题。

for-while循环控制
核心要点
  • for 循环适合已知次数：for(初始化; 条件; 更新) { ... }。
  • while 循环适合未知次数：while(条件) { ... }，条件为真时反复执行。
  • do-while 先执行一次再判断条件，至少执行一次。
  • break 跳出当前循环，continue 跳过本次循环直接进入下一次。
// 计算 1 到 100 的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
cout << sum << endl;  // 5050

// 累加输入直到输入0
int x, total = 0;
while (cin >> x && x != 0) {
    total += x;
}
注意事项
  • for 循环中循环变量建议在初始化处定义（for(int i=...）。
  • 死循环：while(true) 需要用 break 退出，注意不要忘记出口。
