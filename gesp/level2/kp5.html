多分支判断

05
GESP 2级知识字典 · 知识点 05

处理分支嵌套与条件边界，避免遗漏情况。

检索词：分支嵌套条件边界

本课先记住

  • 核心结论： 隐式转换由表达式规则触发，显式转换由程序员写出；转换发生在除法前才会改变除法类型，浮点数转整数按向零方向截断。
  • 常用语法： 需要浮点除法时写 double result = double(a) / b;，浮点数转整数写 int whole = int(value);；还要能识别 (double)(a) 和 (int)(value)。
  • 最小示例： 5 / 2 得到 2，double(5) / 2 和 (double)(5) / 2 都得到 2.5，int(-2.9) 和 (int)(-2.9) 都得到 -2。
  • 关键易错点： double(a / b) 或 (double)(a / b) 都转换得太晚，丢失的小数不能恢复；向零截断不是四舍五入。

知识范围与官方定位

本页对应二级大纲中的数据类型转换：理解系统自动进行的隐式转换，能够进行显式转换，并正确处理整数除法、浮点数转整数和混合类型表达式。

先看一个会直接影响答案的现象：int a=5, b=2; double result=a/b; 中，result 保存的不是 2.5，而是 2.0。右侧的两个操作数都是 int，所以程序先完成整数除法得到 2，最后才把 2 保存为 double。要保留小数，必须在除法发生前先转换一个操作数。

类型转换决定一个值用哪种形式参与运算。最常见的错误不是“不会转换”，而是转换发生得太晚，整数除法已经丢掉了小数部分。

本页区分系统自动完成的隐式转换和程序员明确写出的显式转换；重点比较“除法前转换”与“除法后转换”，并用正数、负数和接近 0 的数确认浮点数转整数采用向 0 截断而不是四舍五入。

数据类型规定一段数据怎样解释、能参与哪些运算以及通常怎样存储；类型转换是把一个值按另一种类型产生新结果。转换可能改变表示范围、计算规则或输出形式，但不会自动把原变量的声明类型永久改掉。例如把 int 值 5 转成 double 会得到 5.0 参与本次运算，原来的整数变量仍是 int。

01 隐式类型转换

不同类型共同运算时，C++ 会按规则自动转换。例如 int 与 double 相加时，整数先转成 double，结果通常也是 double。

隐式转换常出现在三个位置：赋值时，右边值要适应左边变量；混合运算时，参与运算的值会按规则调整到可以共同计算的类型，例如 int 与 double 相加时把整数值转为 double；函数调用时，实参要适应形参类型。二级重点分析前两种。每次都问两句：“转换发生在运算前还是运算后？”“最终结果保存进什么类型？”

字符参与算术时也会转换成整数编码，这与 ASCII 页的规律相连：'A' + 1 先把 'A' 按编码 65 参与计算，得到整数 66；若把 66 保存到 char，才会按字符显示为 B。所以“同一个中间数值”可能因为最终保存类型不同而产生不同输出形式。

例如 int a = 10; double b = a; 中，不需要手动写转换。赋值过程可以追踪为：10（int） → 10.0（double）。a 本身仍是整数 10，只有赋给 b 的值按 double 保存。

把浮点结果赋给整数变量时，小数部分会向 0 截去：

int value = 12.8;int other = -12.8;  // 负数也向 0 截断，因此保存 -12cout << value << " " << other << endl;

赋值过程分别是 12.8 → 12 和 -12.8 → -12，所以输出 12 -12。向 0 截断就是删去小数部分：正数向较小方向靠近 0，负数向较大方向靠近 0；它不是四舍五入。复合赋值 a *= b 也会把计算结果转换回左边变量 a 的类型。

02 显式类型转换

程序员明确要求改变类型叫显式转换。本页主教学使用 目标类型(值)，例如 int(x)、double(a)。这种写法看起来像函数调用，但这里的 int、double 是目标类型，圆括号里是要转换的值，整段表达式产生一个新值。

还要能识别 C 风格的 (目标类型)(值)，例如 (int)(x)、(double)(a)。第一组括号写目标类型，第二组括号圈出要转换的值或表达式。两种写法都只产生本次计算使用的新值，不会修改原变量的声明类型。

double x = -98.76 / 8;int n1 = int(x);  // 主教学写法：把 x 转成 int 新值int n2 = (int)(x);  // 识读写法：两组括号分别表示目标类型和值int a = 5;int b = 2;double y1 = double(a) / b;  // 在除法前把 a 转成 doubledouble y2 = (double)(a) / b;  // 与上一行转换时机相同cout << n1 << ' ' << n2 << endl;cout << y1 << ' ' << y2 << endl;

x 约为 -12.345，所以 n1、n2 都是 -12；y1、y2 都是 2.5。本站主示例优先使用 int(x) 和 double(a)，C 风格写法用于识读。显式转换让意图更清楚，但不能恢复之前已经丢失的信息。

转换表达式不会改写源变量。例如 double value=-2.9; int whole=int(value); 执行后，value 仍是 double 类型的 -2.9，只有 whole 保存整数 -2。把两者分别输出，看到 -2.9 和 -2，就是“原变量未改变”的复核标准。

转换目标还必须装得下结果。把普通小数转成 int 时可以讨论向 0 截断，但若原值已经超出目标整数类型能表示的范围，就不能再把结果当作可靠答案。竞赛题通常会给出输入范围；做题前先核对范围，比事后猜测溢出结果更重要。

03 整数除法与转换时机

两个整数相除执行整数除法，5 / 2 得到 2。要得到 2.5，必须让除法发生前至少一个操作数变成浮点数：

int a = 5;int b = 2;double x1 = double(a) / b;  // 先转换，再做浮点除法double x2 = double(a / b);  // 先做整数除法，再转换结果cout << x1 << ' ' << x2 << endl;

把表达式拆开时，必须同时记录值和类型：

步骤 double(a) / b 或 (double)(a) / b double(a / b) 或 (double)(a / b)
读变量 a=5(int)、b=2(int) a=5(int)、b=2(int)
第一个实际运算 a → 5.0(double) 5/2 → 2(int)
第二个实际运算 5.0/2 → 2.5(double) 2 → 2.0(double)
保存 x1=2.5(double) x2=2.0(double)

x1 的转换发生在除法之前：先把 a 变成 5.0，再计算 5.0 / 2，得到 2.5；写成 (double)(a) / b 也是同一时机。x2 的转换发生在整数除法之后：先计算 5 / 2 得到 2，再把 2 转成 double，只能得到 2.0；写成 (double)(a / b) 也不能恢复小数。这就是“转换时机”。

接收变量写成 double 并不会倒回右侧重算。转换发生的时机由右侧表达式的括号和操作数类型决定。

过程演示

现在已经形成了隐式转换、目标类型(值)、(目标类型)(值) 和整数除法的规则，再把三种结果放进唯一一份完整程序。程序依次输出整数除法、除法前显式转换和浮点数向 0 截断的结果，共用同一组输入，便于比较转换发生在什么时刻。

下面的程序约定 b 不等于 0，并且 value 向 0 截断后的结果在 int 可表示范围内；不满足这两个前提时，不能把输出当作本页规则的有效验证。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int a, b;    double value;    cin >> a >> b >> value;    cout << a / b << endl;  // 两个操作数都是 int，执行整数除法    cout << fixed << setprecision(1) << double(a) / b << endl;  // 在除法前转换    cout << int(value) << endl;  // 向 0 截断    return 0;}

输入 7 2 -3.8 时：第一行先做整数除法得到 3；第二行在除法前把 a 转成 double，得到 3.5；第三行把 -3.8 向 0 截断，得到 -3。三行分别验证“运算类型”“转换时机”和“截断方向”。

其中 fixed << setprecision(1) 只控制浮点结果显示一位小数，显示时可能发生舍入；它既不改变变量的声明类型，也不是类型转换规则。真正让第二行在除法前使用浮点运算的是 double(a)。

04 混合运算与计算顺序

混合运算仍遵守括号、乘除、加减等顺序。处理面值或余量问题时，要先算已经使用的总金额，再计算剩余量：

int n = 28;int count10 = n / 10;int rest = n - count10 * 10;  // 余量要减去“数量 × 面值”int count3 = rest / 3;int count1 = rest - count3 * 3;cout << count10 << " " << count3 << " " << count1 << endl;

这里先得到 2 个 10 元，剩余 8 元，再得到 2 个 3 元和 2 个 1 元。每次减去的是“数量 × 面值”。

逐项状态为：

步骤 计算 当前结果
取 10 元 28 / 10 count10=2
算余量 28-2×10 rest=8
取 3 元 8 / 3 count3=2
再算余量 8-2×3 count1=2

这里每一步都是整数运算。若误写成 count1 = n - count10 - count3，会得到 28-2-2=24，因为减掉的是代币个数，不是已经使用的金额。

知识点速查表

表达式 结果
5 / 2 整数 2
double(5) / 2、(double)(5) / 2 浮点数 2.5
double(5 / 2)、(double)(5 / 2) 浮点数 2.0
int(3.9) 3
(int)(-3.9) -3

典型例题

**题目：**执行 int a=5; double b=2.5; a*=b; 后，a 的值是多少？

推演：

  1. 右侧计算相当于先求 a * b；
  2. 整数 5 与浮点数 2.5 运算时，5 隐式转成 5.0；
  3. 得到浮点结果 5.0 × 2.5 = 12.5；
  4. a 的类型仍是 int，复合赋值要把 12.5 转回整数；
  5. 向 0 截去小数部分，得到 12。

结论：a 最终为 12。判断复合赋值时既要看右侧怎样计算，也要看结果最后保存回什么类型。

**引导练习：**设 int sum=9, count=4; double value=-2.7;，请分别计算 double(sum) / count、(double)(sum) / count、double(sum / count)、int(value) 和 (int)(value)。提示：每一步都写出“先发生的运算”和中间类型。核对结果应为 2.25、2.25、2.0、-2、-2；若第三项写成 2.25，说明把整数除法错误地推迟到了转换之后。

**独立练习：**不看上面的过程，设 int a=-7, b=2; double value=3.9;，写出 a / b、double(a) / b、(double)(a) / b、double(a / b)、(double)(a / b)、int(value) 和 (int)(value) 的值与结果类型，并判断三个原变量是否被转换表达式改变。

**成功标准：**七个结果依次为整数 -3、浮点数 -3.5、浮点数 -3.5、浮点数 -3.0、浮点数 -3.0、整数 3、整数 3；还应说明两个“晚转换”表达式都先算出整数 -3，并确认 a、b、value 的声明类型和值没有被转换表达式改写。

容易混淆的几个问题

  • 把向 0 截断误认为四舍五入；
  • 在整数除法完成后才转换为 double；
  • 只看变量接收类型，不看右侧表达式先怎样计算；
  • 复合赋值后忘记结果要转回左值类型；
  • 计算余量时只减数量，没有乘面值。

错误写法：double average = double(sum / count);

错误原因：sum / count 先执行整数除法，小数部分已经丢失，之后转成 double 也不能恢复。

正确写法：double average = double(sum) / count;；也可以识读为 double average = (double)(sum) / count;。

**修正后复演：**令 sum=9、count=4。错误写法先得到整数 2，再变成 2.0；两种正确写法都先把 sum 变成 9.0，再计算得到 2.25。能同时说明这两个最早不同步骤和最终结果，才算定位并修正了转换时机。

**错误写法：**认为 int value = 3.9; 会得到 4。

**错误原因：**浮点数转整数是向 0 截去小数部分，不是四舍五入。

**正确写法：**明确按截断结果理解，3.9 转成 int 得到 3，-3.9 转成 int 得到 -3。

**错误认识：**执行 int whole = int(value); 后，原来的 double value 也会变成整数。

**错误原因：**转换表达式只产生一个新的整数值，再把它保存到 whole；它不会改写 value 的声明类型或原值。

**正确处理与复演：**令 value=-2.9，同时输出 value 和 whole，应分别看到 -2.9 和 -2。若原变量仍能输出小数，而新变量保存截断结果，就说明转换对象和保存位置已经分清。

本节总结

隐式转换由 C++ 根据参与运算或赋值的类型自动完成，显式转换可以写成 目标类型(值)，也要能识别 (目标类型)(值)。整数除法一旦完成，小数部分就无法靠之后的转换恢复；浮点数转整数只向 0 截去小数部分。分析表达式时先按顺序算右侧，再检查结果保存到什么类型。
