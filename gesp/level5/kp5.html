高精度运算

05
GESP 5级知识字典 · 知识点 05

用数组存储大整数，处理进位借位以及与普通整数的乘除。

检索词：进位借位大整数
05

同一份仓库记录可能提出四种问题：两批货物合计多少、发出一部分后还剩多少、相同数量装了很多箱共多少、按固定容量能装几箱并余多少。数很大时，先别急着套某段代码；本页先带你看懂共同表示，再根据题意关系、要维护的状态和扫描方向选择正确子页。

本课先记住

核心结论

高精度运算先把超大非负整数保存为十进制数位，再按题意关系、维护状态和扫描方向选择加、减、乘或除。

常用语法

字符串负责完整读入，普通数组负责逐位保存；下面只展示表示方法，不是完整运算程序。

string number;
int digit[1005];
digit[0] = number[number.size() - 1] - '0';
最小示例

507 逆序保存后，数组从下标 0 开始依次是 7、0、5；这样加、减、乘可以先处理个位。

507 -> digit[0..2] = {7, 0, 5}
关键易错点
  • 不能只看数字位数选运算
  • 加、减、乘通常从低位开始，除法从高位开始
  • 输出时要删除无效前导零，但零必须保留一个 0。

知识范围与官方定位

五级高精度运算包括大整数表示、加法、可出现负结果的减法、高精度乘普通整数、高精度乘高精度整数、高精度除普通正整数，以及阶乘中的高精度应用。本页只建立共同模型和选择路线；各运算的完整过程、程序与复杂度由四个子页分别讲解。

本页先建立共同基础并比较各方法；完整过程、C++ 写法与复杂度请进入对应子知识点学习。

共同基础

  • 常见 long long 也有固定范围，位数继续增加就不能把整个数一次放进去。高精度运算改为先用 string 完整读入，再把每个十进制数字转换成普通 int 数组中的一个元素。
  • 十进制数位序列保留了个位、十位、百位等位值。把 507 逆序保存为 [7, 0, 5] 后，下标 0 就是个位；加法、减法和乘法通常可以按下标从小到大处理。
  • 除法的商位由已经读过的高位前缀决定，所以要从最高位向最低位扫描。方向不是固定模板，要由当前运算中信息传递的方向决定。
  • 不同运算要维护不同状态：加法跟踪进位，减法跟踪借位，乘法累加数位贡献并处理进位，除法跟踪余数。这些状态在父页只用来帮助选择，具体更新规则留给子页。
  • 无论选择哪种运算，最后都要得到规范十进制结果：删除无效前导零，但结果为零时仍保留一个 0；数组容量还要覆盖可能出现的全部结果数位。
  • 选择演示 1：仓库原有 123456789012345678901 件零件，发出 987654321 件，题目要求剩余量。第一个数已经超出常见 long long 的十进制范围，所以先确定要按十进制数位保存。
  • 选择演示 2：题目动作是“原有量去掉发出量”，关系是求差，不是求总和、若干倍或平均分配，因此应选择减法。
  • 选择演示 3：计算前要比较两个数的大小，确定结果符号；逐位计算时要从低位向高位跟踪借位。这些正是高精度减法子页要解决的状态和方向。
  • 选择演示 4：因此下一步进入“高精度减法”子页，而不是在总览页展开逐位借位；本页也不计算这个大数减法的最终结果。
  • 选择演示 5：学完后可用“非负差 + 987654321 = 123456789012345678901”复核。若还原失败，先检查运算选择、大小关系和借位。
  • 本页到“会选择并会检查”为止。逐位进位、借位与符号、乘法数位贡献与阶乘、逐位商和余数的完整实现，都在对应子页中展开。

方法对比

合计：高精度加法

主要用途：题目把两个非负大数量合在一起，关系是求和；从低位向高位处理并跟踪进位，应进入“高精度加法”子页。

使用提醒：交换两个加数后总和应保持不变；不同长度也仍是加法，不能只看位数改选别的结构。

剩余：高精度减法

主要用途：题目从原有大数量中去掉一部分，关系是求差；先比较大小，再从低位向高位跟踪借位，应进入“高精度减法”子页。

使用提醒：被减数不小于减数时，用“差 + 减数 = 被减数”复核；若不成立，检查大小关系、符号和借位。

相同数量重复：高精度乘法

主要用途：每箱数量相同，求很多箱的总量，关系是相同数量重复；累加数位贡献并从低位处理进位，应进入“高精度乘法”子页。

使用提醒：错误现象是只把每箱数量加一次，结果只代表两箱；原因是把重复次数漏掉了。改选乘法后，可先用小箱数重复相加复核，例如每箱 7 件、3 箱应与 7 + 7 + 7 的 21 件一致。

平均分配：高精度除普通整数

主要用途：把超大总量按一个正的普通容量平均分配，要求份数和余数，关系是除法；从高位向低位扫描并跟踪余数，应进入“高精度除普通整数”子页。

使用提醒：错误现象是看到“有剩余”就只做一次减法，无法回答能装几箱；原因是忽略了平均分配。改选除法后，用“商 × 除数 + 余数 = 被除数”且“余数小于正除数”复核。

方向纠错：除法不能照搬低位扫描

主要用途：若除法从个位开始，当前商位缺少更高位前缀，无法正确确定；原因是把加、减、乘的信息方向机械套给了除法。

使用提醒：修正为从最高位向最低位扫描并维护余数；每处理一位，都检查当前余数小于正除数，最后再用商和余数还原被除数。

8 题

第 1 题高精度整数常把最低位放在数组哪里？

答案：A
低位在前便于从个位开始处理进位。 因此“下标较小的位置”正确，其余选项混淆了定义、条件或边界。
对应知识点：01 高精度整数的存储

第 2 题逐位加法中当前位应保存什么？

答案：D
十进制当前位是 sum%10，进位是 sum/10。 因此“总和对 10 取余”正确，其余选项混淆了定义、条件或边界。
对应知识点：02 高精度加法

第 3 题逐位相减出现负数时应怎样借位？

答案：C
十进制借一当十。 因此“当前位加 10，并向高位借 1”正确，其余选项混淆了定义、条件或边界。
对应知识点：03 高精度减法

第 4 题输出减法结果前为什么去前导零？

答案：B
高位无效零不属于规范写法，但结果 0 要保留一位。 因此“避免把 123 输出成 00123”正确，其余选项混淆了定义、条件或边界。
对应知识点：06 符号、前导零与边界

第 5 题高精度数乘普通整数时，每位计算还要加上？

答案：A
每位乘积由当前数字×乘数加进位组成。 因此“上一位产生的进位”正确，其余选项混淆了定义、条件或边界。
对应知识点：04 高精度乘法

第 6 题乘法结束后进位仍大于 0，应怎样处理？

答案：D
剩余进位可能有多位，需反复取余和整除。 因此“继续拆成十进制位”正确，其余选项混淆了定义、条件或边界。
对应知识点：04 高精度乘法

第 7 题高精度数除普通整数为何从高位向低位处理？

答案：C
当前余数与下一位组成新的被除部分。 因此“长除法要把前面的余数带到下一位”正确，其余选项混淆了定义、条件或边界。
对应知识点：05 高精度除法

第 8 题高精度除法中除数可以为 0 吗？

答案：B
除数为 0 没有定义，必须先排除。 因此“不可以”正确，其余选项混淆了定义、条件或边界。
对应知识点：05 高精度除法
