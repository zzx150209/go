计算机基础知识

01
GESP 1级知识字典 · 知识点 01

认识计算机的发展、组成、软硬件、操作系统与文件目录。

检索词：计算机组成软硬件

本课先记住

  • 核心结论： 计算机系统依靠硬件和软件共同完成信息的输入、存储、处理与输出；判断设备职责时要看信息流向，判断文件身份时要看内容和用途。
  • 常用判断： 用“CPU 负责处理、内存临时保存、外部存储长期保存”区分核心部件；用箭头方向区分输入与输出；用路径定位文件所在位置。
  • 最小示例： 键盘输入数据 → 程序装入内存并由 CPU 执行 → 屏幕输出结果；保存的 .cpp 源文件仍需编译才能得到可执行程序。
  • 关键易错点： 改扩展名不会改变文件内容，程序也不是一直直接在硬盘上运行；触摸屏等设备还可能同时承担输入和输出。

知识范围与官方定位

计算机不只是桌面上的主机和显示器。手机、自助挂号机、汽车导航和学校成绩系统也在接收、保存、处理和输出信息。要看懂它们怎样工作，可以先记住一条主线：

外部信息 → 输入 → 存储与处理 → 输出 → 外部

本页对应 GESP C++ 一级大纲中的“计算机基础知识”，重点回答六个问题：

  1. 计算机为什么从专门的计算工具发展成了通用信息处理工具？
  2. 硬件和软件怎样配合，CPU、内存和硬盘各做什么？
  3. 怎样根据信息流向判断输入设备和输出设备？
  4. 为什么计算机内部使用 0 和 1 表示信息？
  5. 操作系统与普通应用软件有什么区别？
  6. 文件、目录、路径和扩展名分别说明什么？

这是一页纯概念知识，不需要用 C++ 程序来证明。后文会用一个贯穿场景把概念落到具体过程：answer.cpp 保存在磁盘中；编译后得到可执行程序；运行时，可执行程序被装入内存，CPU 执行指令，键盘提供输入，屏幕显示输出。一级不学习硬件电路、复杂进制转换或操作系统内部算法。

01 计算机的发展与应用

从“计算数字”到“处理信息”

早期电子计算机体积大、耗电多，主要承担科学计算等专门任务。随着电子器件变小、速度提高、成本下降，计算机逐渐进入学校、家庭、医院、工厂和交通系统。它能处理的内容也从数字扩展到文字、图片、声音和网络数据。

按主要电子器件粗略划分，可以看到这样的变化：

大致阶段 主要电子器件或形态 带来的变化
早期电子计算机 电子管 机器庞大、耗电高，主要处理专门计算
晶体管计算机 晶体管 体积缩小，可靠性和速度提高
集成电路计算机 集成电路 更多元件集中到芯片中，应用范围扩大
微处理器与网络时代 大规模、超大规模集成电路 个人计算机、移动设备和网络服务普及

1946 年公开运行的 ENIAC 是著名的早期电子数字计算机。一级不要求背诵大量年份或机器型号，理解发展方向更重要：电子器件越来越小，处理速度和可靠性不断提高，计算机能承担的任务也越来越多。

判断“计算机应用”要看信息过程

医院自助挂号机的外形不像普通台式电脑，但它会完成下面的工作：

顺序 正在发生的事情 信息处理作用
1 读取证件，接收患者选择的科室 输入
2 查找科室和号源 处理
3 保存挂号结果 存储
4 显示结果并打印凭条 输出

它能按照程序自动完成一组信息处理任务，因此属于计算机应用。判断时不要只看设备有没有键盘、机箱或大屏幕，要看它是否在程序控制下接收、保存、处理或输出信息。

学校成绩系统、导航软件和工厂自动控制也遵循相同思路。它们的任务不同，处理的信息不同，但都离不开“输入—存储与处理—输出”这条主线。

02 计算机的组成

计算机系统需要硬件和软件共同工作

硬件是组成计算机的实体设备，能看见或触摸到；软件是指挥硬件完成任务的程序和相关数据。只有硬件没有软件，设备不知道要完成什么任务；只有软件没有硬件，程序也没有实际运行的地方。

计算机硬件常按五种基本作用来认识：

基本组成 主要作用 常见例子或位置
运算器 完成算术运算和逻辑判断 CPU 内部的重要部分
控制器 控制指令按要求执行 CPU 内部的重要部分
存储器 保存程序和数据 内存、硬盘、固态硬盘
输入设备 把外部信息送进计算机 键盘、鼠标、麦克风
输出设备 把处理结果送到外部 显示器、扬声器、打印机

CPU，也就是中央处理器，通常包含运算器和控制器。它负责取出并执行程序指令、完成主要运算和控制工作。CPU 很重要，但它不是整台计算机，也不负责长期保存所有文件。

CPU、内存和外部存储各有职责

“存储器”是一个大类。一级最容易混淆的是内存与硬盘、固态硬盘等外部存储设备：

对比项 内存 硬盘、固态硬盘等外部存储
主要用途 暂时放置正在运行的程序和数据 长期保存文件和程序
断电后的常见情况 内容通常丢失 已保存内容通常仍在
与运行的关系 CPU 执行程序时会频繁读取内存中的指令和数据 程序运行前通常先从这里加载到内存
能否代替 CPU 运算 不能 不能

“电脑有 16 GB 内存”和“电脑有 1 TB 固态硬盘”说的是两种不同的存储用途。内存像运行时展开材料的工作台，外部存储像长期存放材料的文件柜；这个比喻只帮助区分职责，不表示它们的内部结构真的相同。

一个程序真正怎样运行

假设磁盘中已经保存了源文件 answer.cpp，编译后得到了可执行程序。运行时会经历下面的过程：

步骤 发生的事情 主要负责者
1 answer.cpp 和编译得到的可执行程序保存在磁盘中 外部存储设备
2 操作系统把可执行程序和运行需要的数据装入内存 操作系统、内存
3 CPU 从内存中取得指令和数据 CPU、内存
4 CPU 按指令完成计算或判断，结果暂时放回内存 CPU、内存
5 结果通过显示器等设备交给用户 输出设备

源文件里保存的是人写的 C++ 代码，可执行程序才是编译后供计算机运行的程序。程序也不是一直直接在硬盘上执行：运行前通常要先装入内存，再由 CPU 取出指令并执行。

可以用三个问题检查自己有没有混淆：谁负责执行和运算？CPU。谁暂时保存正在运行的程序和数据？内存。谁适合在断电后继续保存文件？硬盘、固态硬盘等外部存储设备。

03 输入设备与输出设备

以计算机为中心看信息方向

设备的名称和外形不一定能直接说明类别。更可靠的方法是先把“计算机系统”放在中间，再画信息箭头：

外部世界 ──信息进入──> 计算机    输入外部世界 <──信息离开── 计算机    输出
设备 信息怎样流动 判断
键盘 按键内容进入计算机 输入设备
鼠标 移动和点击信息进入计算机 输入设备
麦克风 声音进入计算机 输入设备
扫描仪 纸面图像进入计算机 输入设备
显示器 图像从计算机送给用户 输出设备
扬声器 声音从计算机送给用户 输出设备
打印机 文字或图像从计算机送到纸上 输出设备

这也解释了综合测试中的判断：麦克风负责采集声音，信息方向是“外部到计算机”，所以它不是输出设备。

同一设备可能承担两种作用

触摸屏显示题目时，信息从计算机到用户，是输出；学生点击答案时，触摸位置进入计算机，是输入。同一块触摸屏可以同时具有输入和输出功能。

多功能打印机也要按具体动作判断：扫描纸张时承担输入，打印文件时承担输出。题目只描述其中一步，就按照这一步的信息流向作答。

硬盘负责存储，不要因为它既能读取又能写入，就在“计算机五大组成”的题目中机械地归为输入或输出设备。先看题目采用的是哪种分类标准，再根据设备在该过程中的主要职责判断。

04 信息表示与二进制

为什么使用 0 和 1

计算机的电子器件适合区分两种稳定状态。人们用 0 和 1 表示这两种状态，并规定怎样把它们组合起来表示数字、文字、图片和声音。二进制中的每一位只能是 0 或 1；这样的一个二进制位常称为一个“位”。

这并不表示计算机只会处理数字 0 和 1。屏幕上的汉字、照片中的颜色和扬声器播放的声音，都会按照相应规则转换成二进制数据，再由计算机保存和处理。不同类型的信息使用不同的表示规则，具体编码方法会在后续知识中学习。

相同字符不一定表示相同数值

二进制采用“逢二进一”。例如二进制 101 可以按位置拆开：

二进制 101 = 1 × 4 + 0 × 2 + 1 × 1 = 十进制 5

二进制 101 与十进制 101 看起来都由字符 1、0、1 组成，数值却不同：前者表示十进制 5，后者表示一百零一。因此，读一个数时除了看写了哪些数字，还要确认它采用什么进制。

一级只要求理解二进制由 0 和 1 组成，并能看懂这种简单的位置意义，不需要进行复杂进制转换。遇到 10201 这样的写法，可以立刻判断它不是合法的二进制数，因为其中出现了数字 2。

05 软件与操作系统

系统软件与应用软件解决的问题不同

软件让硬件按照确定的步骤完成任务。按主要用途，可以先分成两类：

类别 主要职责 常见例子
系统软件 管理计算机资源，为其他软件提供运行环境 Windows、Linux 等操作系统
应用软件 帮助用户完成某项具体任务 浏览器、文字处理软件、编程 IDE、游戏

操作系统属于系统软件。它不是输入设备、输出设备或编程语言。浏览器和 IDE 虽然功能很多，仍然是帮助用户完成具体任务的应用软件。

操作系统站在应用与硬件之间

双击浏览器图标后，并不是浏览器自己直接接管整台计算机。操作系统先找到程序文件，把运行所需内容装入内存，分配处理时间，管理窗口和设备；浏览器再完成打开网页、显示内容等具体任务。

用户操作 → 应用软件 → 操作系统 → 硬件
操作系统承担的工作 在实际使用中的表现
管理文件和目录 创建、复制、移动、重命名和删除文件
管理程序 启动程序、安排运行、结束无响应程序
管理内存 为正在运行的程序分配和回收空间
管理设备 让键盘、鼠标、显示器等能被程序使用

判断软件类别时，可以问：“它主要是在管理整台计算机的共同资源，还是在帮助用户完成某项具体任务？”前者通常属于系统软件，后者通常属于应用软件。

06 文件、目录与扩展名

文件保存内容，目录组织文件，路径说明位置

这三个概念解决的是不同问题：

概念 回答的问题 例子
文件 保存的内容是什么 answer.cpp
目录（文件夹） 文件放在哪一组中 gesp 文件夹
路径 怎样找到这个文件 D:\gesp\answer.cpp

在路径 D:\gesp\answer.cpp 中：

  • D: 表示盘符；
  • gesp 是目录名；
  • answer.cpp 是文件名；
  • .cpp 是扩展名，answer 是扩展名前的主文件名。

目录本身不是一份源代码，路径也不是文件内容。路径只是对位置的描述，就像地址帮助我们找到房间，但地址本身不是房间里的物品。

扩展名是线索，不是“变身开关”

扩展名 常见含义 里面通常保存什么
.cpp C++ 源代码文件 人能阅读和编辑的 C++ 代码文字
.exe Windows 中常见的可执行文件 编译后可由系统加载运行的程序
.txt 文本文件 普通文字
.png 图片文件 按 PNG 格式组织的图像数据

扩展名能帮助操作系统和用户判断文件类型，但改名不会自动改变文件内部的数据。把 notes.txt 改成 notes.cpp，里面仍然是原来的文字；只有内容符合 C++ 语法，编译器才可能把它当作正确源代码处理。把图片改名为 .txt，也不会让图片内容自动变成文章。

C++ 源文件与可执行程序不是同一个文件

对比项 C++ 源文件 可执行程序
常见名称 answer.cpp Windows 中常见 answer.exe
内容作用 保存程序员写的 C++ 代码 保存编译后供计算机运行的程序
主要操作 阅读、编辑、保存、编译 由操作系统加载并运行
修改后怎样生效 修改源文件后需要重新编译 运行的是最近一次成功生成的版本

在 Windows 中，可执行文件常用 .exe；在 Linux 中，可执行文件不一定有固定扩展名，所以不能把“所有可执行程序都必须以 .exe 结尾”当成通用规则。

还有一个常见现象：你改了 answer.cpp，却没有保存或重新编译，运行结果仍然和以前一样。原因是旧的可执行程序没有自动变成新版本。下一页“集成开发环境”会继续讲编辑、保存、编译和运行之间的区别。

判断计算机基础概念的统一顺序

概念题看起来很零散，其实可以按下面的顺序逐步判断：

  1. 先找信息方向。 外部信息进入计算机是输入，计算机把结果送到外部是输出。
  2. 再找当前职责。 执行和运算看 CPU，运行时临时保存看内存，长期保存文件看硬盘等外部存储。
  3. 检查软件在管什么。 管理硬件、文件和程序的是操作系统；完成浏览网页、编辑代码等具体任务的是应用软件。
  4. 确认对象和位置。 文件保存内容，目录组织文件，路径描述位置，扩展名提示常见类型。
  5. 最后检查表示规则。 二进制只能出现 0 和 1；同样的字符采用不同进制时，数值可能不同。

遇到陌生设备或新场景时，不必死记名称。把题目中的动作放回这五步，通常就能找到判断依据。

查询词 直接结论 最快自查方法

路径 描述文件或目录的位置 逐段找到盘符、目录和文件名
.cpp C++ 源代码文件 与编译后的可执行程序分开

典型例题

一名学生在 Windows 电脑上完成下面的操作：

  1. 在 IDE 中编辑 D:\gesp\answer.cpp 并保存；
  2. 编译后得到 answer.exe；
  3. 运行程序，用键盘输入数据；
  4. 程序完成处理，并把结果显示在屏幕上。

请判断每一步涉及的主要概念。

先沿过程找证据

场景线索 判断 原因
D:\gesp\answer.cpp 路径指向一个 C++ 源文件 D: 是盘符，gesp 是目录，.cpp 提示源文件类型
点击“保存” 文件内容被写入外部存储 需要在断电后继续保留
得到 answer.exe 产生 Windows 中常见的可执行文件 它与人编辑的 .cpp 源文件职责不同
运行 answer.exe 程序先装入内存，再由 CPU 执行 内存提供运行空间，CPU 负责指令和运算
键盘输入数据 输入 信息从学生进入计算机
屏幕显示结果 输出 信息从计算机送给学生
分配内存、管理文件和设备 操作系统的工作 这些是整台计算机的共同资源

再换条件验证

  • 把键盘换成麦克风，仍然是输入，因为信息方向没有变。
  • 把显示器换成扬声器，仍然是输出，因为结果仍由计算机送向外部。
  • 关闭电脑后，已经保存的 answer.cpp 通常仍在磁盘中；运行时没有另行保存的内存数据通常会丢失。
  • 只把 answer.cpp 改名为 answer.exe，不会得到真正的可执行程序，因为改名没有改变文件内部内容。

这个例子可以同时核对硬件职责、输入输出方向、操作系统作用和文件身份。判断依据来自实际过程，不依赖设备名称的死记。

引导练习（不记录进度）

观察“手机语音助手回答天气”这一过程，先按“输入 → 处理/存储 → 输出”填写三步：麦克风接收语音属于输入，程序和 CPU 完成识别与查询属于处理，扬声器播报属于输出。再判断查询结果若要下次继续使用，应保存到内存还是外部存储。

成功标准： 能为每一步写出信息方向和部件职责，并说明长期保留应使用外部存储。完成后不看本段提示，独立完成页末“整页综合测试”；提交后逐题核对答案与解析，错题必须能重新用信息流向、部件职责或文件身份说明原因。

常见错误

  1. 把计算机应用理解成“使用一台台式电脑”。 自助机、导航和自动控制也能完成信息处理。检查时找输入、存储、处理和输出，不看外壳。
  2. 把 CPU、内存和硬盘混为一谈。 CPU 负责执行和运算，内存负责运行时临时保存，硬盘等外部存储负责长期保存。用“谁处理、谁临时放、谁长期留”逐项核对。
  3. 认为程序一直直接在硬盘上运行。 可执行程序通常先从外部存储装入内存，再由 CPU 取出指令执行。
  4. 只按设备名称判断输入输出。 触摸屏、多功能打印机可能同时具有两种功能；把题目中的具体动作画成信息箭头再判断。
  5. 把 Windows、Linux 当成应用软件或编程语言。 它们是操作系统，负责管理硬件、文件和程序。
  6. 认为二进制 101 就是十进制 101。 进制不同，位置代表的数值不同；先确认采用什么进制。
  7. 认为改扩展名就能改变文件内容。 扩展名只是类型线索，改名不会完成编译，也不会把图片变成文字。
  8. 把 .cpp 源文件和可执行程序当成同一个文件。 源文件供人编辑，编译后的程序供系统加载运行；修改源文件后还要保存并重新编译。

6 题

第 1 题下面哪一项不属于计算机的输出设备？

答案：A
麦克风负责采集声音，是输入设备；其余三项都把信息输出给用户。
对应知识点：03 输入设备与输出设备

第 2 题计算机中负责执行程序指令和进行运算的核心部件通常是什么？

答案：A
中央处理器负责解释并执行程序指令，也承担主要的算术和逻辑运算。
对应知识点：02 计算机的组成

第 3 题医院自助挂号机接收证件信息、处理科室选择并打印凭条，为什么属于计算机应用？

答案：A
对应本页 01 计算机的发展与应用。判断重点是设备能自动接收、处理、保存或输出信息，而不是观察外形或颜色。
对应知识点：01 计算机的发展与应用

第 4 题用二进制表示信息时，每一位只能取哪两个值？

答案：A
二进制只有 0 和 1 两个基本数码，计算机用它们表示和处理信息。
对应知识点：04 信息表示与二进制

第 5 题下面哪个文件名最可能是 C++ 源代码文件？

答案：A
.cpp 是常见的 C++ 源代码扩展名；.exe 常表示 Windows 可执行文件。
对应知识点：06 文件、目录与扩展名

第 6 题双击浏览器图标后，负责管理程序文件、运行资源和窗口的通常是什么？

答案：A
对应本页 05 软件与操作系统。Windows、Linux 等操作系统管理硬件、文件和运行中的程序；浏览器负责具体的网页任务。
对应知识点：05 软件与操作系统
