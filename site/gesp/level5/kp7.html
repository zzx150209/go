顺序查找

07
GESP 5级知识字典 · 知识点 07

实现精确查找与左右边界查找，统计出现次数。

检索词：精确查找左右边界
07

二分查找利用有序性每次排除约一半候选范围，适合在有序序列中快速找值或找边界。

本课先记住

核心结论

二分查找依靠有序性安全排除整段候选；先看清题目要任意命中还是左右边界，再选择对应模型。

常用语法

共同模型先固定区间含义，再用安全中点比较；下面是闭区间存在性查找的循环骨架。

while (left <= right) {
    int middle = left + (right - left) / 2;
}
最小示例

在 1、3、5、7、9、11 中查找 7，先比较中点值 5，就能排除下标 0 到 2。

[0, 5] -> middle = 2, value = 5
5 < 7 -> left = 3
关键易错点
  • 无序数组不能直接二分
  • 闭区间与半开区间不能混用
  • 更新时不排除 middle 可能死循环
  • 任意命中不等于第一个或最后一个命中。

知识范围与官方定位

五级需要掌握二分查找的适用前提、区间含义、循环条件和边界更新，并能分别处理精确查找与四种常见边界：第一个 ≥、第一个 >、最后一个 ≤、最后一个 <。

本页先建立共同基础并比较各方法；完整过程、C++ 写法与复杂度请进入对应子知识点学习。

问题和范围

要解决的问题

二分查找是在有序序列中反复缩小候选范围的方法。它不是一上来就背模板，而是利用一次比较判断哪一整段已经不可能含有答案。

看同一个非递减数组 1、3、5、7、9、11：问题可以问“7 是否存在”，也可以问“第一个不小于 6 的位置”，还可以问“最后一个不大于 8 的位置”。三个问题都利用有序性，却需要选择不同的查找目标。

本页先建立这些任务共用的思考方式，并用“7 是否存在”完成一次最小实现。精确位置和四种边界的完整写法分别留在两个子知识点中。

本课范围

  • 本教学程序支持 0 ≤ n ≤ 100000；数组按非递减顺序排列，数组值与目标值都在 -1000000000 到 1000000000 之间。程序不会自动排序输入。
  • 数组使用 0 下标和 numbers[100000]。n = 100000 时最大合法下标是 99999；n = 0 时 right = n - 1 等于 -1，循环不会访问数组。
  • right - left 在循环中最大为 99999，left、right、middle 和数组值使用 int 都安全。程序只输出 YES 或 NO 加换行，最多 4 个字符。
  • 父页只讲有序性、候选区间、严格缩小和模型选择；精确查找子页负责任意命中或 -1 的闭区间细节，边界查找子页负责半开区间、四种边界与出现次数。

共同基础

  • 序列必须有序，才能根据中点大小安全排除一侧。
  • 开始前先确定搜索区间是闭区间还是半开区间，循环条件必须与它一致。
  • 中点写成 left + (right - left) / 2，可以避免 left + right 的加法溢出。
  • 每轮都必须严格缩小区间，否则循环可能卡住。

方法对比

精确查找

主要用途：寻找任意一个等于目标值的位置。

使用提醒：找到就返回；找不到返回 -1。

左边界

主要用途：寻找第一个 ≥x 或第一个 >x 的位置。

使用提醒：遇到满足条件的位置仍向左收缩。

右边界

主要用途：寻找最后一个 ≤x 或最后一个 <x 的位置。

使用提醒：遇到满足条件的位置仍向右收缩。

算法怎样形成

先在数组 1、3、5、7、9、11 中判断 7 是否存在。顺序查找从左到右比较，一次只能排除一个位置；现在要利用“越往右数值越大”这个条件，一次排除一整段。

  1. 有序性带来整段信息：第一次查看下标 2，值是 5。因为 5 < 7，而且它左边的数都不大于 5，所以目标不可能在下标 0 到 2，整个左段都可以排除。
  2. 为什么查看中间：如果总看最左端，一次仍可能只排除一个位置。查看当前区间的中点，会让中点左右两侧尽量接近；无论排除哪一边，留下的候选通常不超过原来的一半。
  3. 共同不变量：每轮开始时，若目标存在，它一定在当前候选区间内。比较中点后，只能排除已经由有序性证明不可能的部分，不能随意丢掉仍可能有答案的位置。
  4. 两种大小更新：中点值小于目标时，中点及其左侧都偏小，令 left = middle + 1；中点值大于目标时，中点及其右侧都偏大，令 right = middle - 1。两次更新都把已经检查的 middle 排除。
  5. 命中与停止：中点值等于目标时，存在性问题立即得到 true；若更新后 left > right，候选区间为空，得到 false。每轮至少排除 middle，所以区间一定严格缩小并最终停止。
  6. 无序反例：[7, 1, 3] 中查找 7，若只因中点值 1 < 7 就排除中点左侧，会把真正的 7 一起丢掉。没有有序前提，整段排除就没有依据。
  7. 先选模型：题目只问是否存在或任意一个命中位置，进入精确查找；问第一个满足条件的位置，选择左边界；问最后一个满足条件的位置，选择右边界。重复值中“任意一个”不能冒充“第一个或最后一个”。

自然语言步骤

  1. 先确认数组已经按非递减顺序排列；若没有这个前提，不能根据一次比较排除整段。
  2. 读清题目要什么：只判断存在或找任意命中，选择精确查找；找第一个满足条件，选择左边界；找最后一个满足条件，选择右边界。
  3. 选定模型后固定区间含义。本页最小程序使用闭区间 [left, right]，初始 left = 0、right = n - 1；两个端点都可能是答案。
  4. 候选区间非空时，用 middle = left + (right - left) / 2 计算中点，避免先把左右端点相加。
  5. 比较 numbers[middle] 与 target。相等就返回 true；中点值偏小就更新 left = middle + 1；偏大就更新 right = middle - 1。
  6. 每次更新都排除已经检查过的 middle。继续处理新的候选区间，直到命中，或 left > right 表示区间为空。
  7. main() 根据返回值输出 YES 或 NO。若题目要求具体位置，再进入对应子知识点学习它自己的返回值和边界规则。

执行账本

主样例的完整三轮区间变化与输出

第 1 轮[0, 5]255 < 7；有序数组中下标 0 到 2 的值都不可能等于 7left = 3，新区间 [3, 5]继续比较新区间的中点

追踪结论：三轮都与同一闭区间不变量一致：只排除已经证明不可能的一段。第三轮在相等分支立即返回，程序不会虚构第四轮搜索。

完整程序

共同模型的最小完整示例：判断目标是否存在

下面是本页唯一一份完整 C++14 程序，只演示二分家族共同的有序、取中、排除和停止机制，输出 YES 或 NO；它不覆盖四种边界的完整实现。

示例输入

6
1 3 5 7 9 11
7

示例输出

YES

样例说明：先由中点值 5 排除左段，再由中点值 9 排除右段，最后在下标 3 找到 7，因此输出 YES。

#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 100000;
int numbers[MAX_N];

bool containsTarget(int n, int target) {
  int left = 0;
  int right = n - 1;

  while (left <= right) {
      int middle = left + (right - left) / 2;

      if (numbers[middle] == target) {
          return true;
      }
      if (numbers[middle] < target) {
          left = middle + 1;
      } else {
          right = middle - 1;
      }
  }

  return false;
}

int main() {
  int n;
  cin >> n;

  for (int i = 0; i < n; i++) {
      cin >> numbers[i];
  }

  int target;
  cin >> target;

  if (containsTarget(n, target)) {
      cout << "YES\n";
  } else {
      cout << "NO\n";
  }

  return 0;
}

复杂度

二分查找阶段每轮把候选范围缩小约一半，所以查找时间是 O(log n)。完整程序还要先读入 n 个数，因此包含输入时的总时间是 O(n)；这不改变查找阶段的复杂度。

时间与空间复杂度
项目复杂度说明
查找阶段时间O(log n)每轮至少排除中点，并通常只留下原候选的一半左右。
完整程序总时间O(n)读入 n 个数组元素需要 O(n)，之后再进行 O(log n) 查找。
迭代额外空间O(1)查找过程只增加 left、right、middle 等常数个变量。
输入数组存储O(n)numbers 保存 n 个输入；常见 int 为 4 字节时，100000 个元素约占 400000 字节，实际以平台为准。

常见错误

没有有序前提就直接排除一段

为什么错：可观察的症状是目标明明存在，程序却输出 NO。例如无序数组 [7, 1, 3] 查找 7 时，中点值 1 小于 7，却不能说明左侧都更小。

怎样改：先核对题目保证输入非递减，再使用二分；本程序不自动排序。修正后用一个有序命中样例和一个有序未命中样例重新运行。

混用闭区间与半开区间

int right = n;
while (left <= right) {

为什么错：right = n 属于半开区间边界，却配上闭区间循环，可能访问 numbers[n] 越界；另一种混用还可能漏掉最后一个候选。

怎样改：本程序固定闭区间：right = n - 1，循环写 left <= right。修正后重测 n = 0，以及单元素命中和未命中。

更新后没有排除 middle

left = middle;

为什么错：可观察的症状是程序在某个单元素区间反复计算同一个 middle。例如 [3, 3] 中若仍令 left = middle，区间完全没有缩小。

怎样改：中点偏小时写 left = middle + 1，偏大时写 right = middle - 1。修正后用目标 8 查找主数组，确认程序能以 NO 停止。

把任意命中当成第一个或最后一个

为什么错：在 [1, 2, 2, 2, 5] 中，存在性查找只保证命中某个 2；若题目要第一个 2，直接返回任意中点就可能答错位置。

怎样改：先重读题目问法：任意命中进入精确查找；第一个或最后一个满足条件进入边界查找。用重复值样例复核所选模型。

把不存在位置直接当数组下标

cout << numbers[index] << '\n';

为什么错：精确位置可能用 -1 表示不存在，边界位置也可能等于 n；直接访问会越界。本页 YES/NO 程序没有这个访问动作，但进入子页后必须检查。

怎样改：访问数组前先验证 0 <= index && index < n。分别用目标小于全部和大于全部的样例，确认不存在位置不会被访问。

把额外空间 O(1) 说成整个程序只占 O(1)

为什么错：left、right、middle 确实只有常数个，但 numbers 要保存 n 个输入；n 增大时数组占用也会增大。

怎样改：分别描述“迭代查找额外空间 O(1)”和“输入数组存储 O(n)”。令 n = 100000，重新核对数组有 100000 个 int，而不是常数个元素。

练习与自检

练习一：先选对模型

数组中可能有重复值。以下三问分别应进入哪类模型：① x 是否存在；② 第一个大于等于 x 的位置；③ 最后一个小于 x 的位置？

提示：先判断题目要任意命中、第一个满足，还是最后一个满足。

练习二：只更新一轮

在主数组中查找 7。初始闭区间是 [0, 5]，middle = 2，numbers[2] = 5。写出本轮被排除的下标和新区间。

提示：5 小于 7；利用非递减顺序判断中点左侧是否还可能等于 7。

练习三：找出不停止的原因

闭区间已经缩到 [3, 3]，中点值仍小于目标。如果错误写成 left = middle，下一轮区间是什么？为什么程序会卡住？

提示：比较更新前后的 left、right 和 middle 是否发生变化。

练习四：出现次数去哪里学

题目要求统计 x 在有序数组中出现几次。仅判断 YES/NO 是否够用？接下来应进入哪个子知识点？

提示：出现次数需要找到相等区间的左右分界。

查看练习一答案

① 只问是否存在，选择精确查找；② 问第一个满足条件，选择左边界；③ 问最后一个满足条件，选择右边界。后两类都进入边界查找子页。

查看练习二答案

下标 0 到 2 的值都不大于 5，因此都不可能等于 7；令 left = middle + 1 = 3，新区间是 [3, 5]。

left = middle + 1;
查看练习三答案

middle 仍是 3，错误更新后 left 也仍是 3，所以区间还是 [3, 3]。下一轮会重复同样判断，无法停止；正确更新要排除中点。

left = middle + 1;
查看练习四答案

YES/NO 只能说明是否存在，不能给出相等元素覆盖的范围。应进入“边界查找”子知识点，学习左右边界后再计算出现次数。

第 1 题标准二分查找最关键的前提是？

答案：A
有序性使比较中点后可以排除一半范围。 因此“查找范围有序”正确，其余选项混淆了定义、条件或边界。
对应知识点：01 二分查找的前提

第 2 题闭区间二分中 a[mid] < target 时应怎样更新？

答案：D
中点及其左侧都小于目标，可排除。 因此“left = mid + 1”正确，其余选项混淆了定义、条件或边界。
对应知识点：02 精确查找

第 3 题找第一个不小于 target 的位置，a[mid] >= target 时应？

答案：C
当前中点可行，但左侧可能还有更早位置。 因此“记录并继续向左找”正确，其余选项混淆了定义、条件或边界。
对应知识点：03 第一个与最后一个位置

第 4 题有序数组中 target 的次数怎样由边界得到？

答案：B
存在时，闭区间长度等于右端减左端加一。 因此“最后位置-第一位置+1”正确，其余选项混淆了定义、条件或边界。
对应知识点：04 出现次数与插入位置

第 5 题写 mid=(left+right)/2 可能有什么问题？

答案：A
可写 left+(right-left)/2 避免加法溢出。 因此“left+right 可能溢出”正确，其余选项混淆了定义、条件或边界。
对应知识点：02 精确查找
