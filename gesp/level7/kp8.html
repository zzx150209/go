网格搜索

08
GESP 7级知识字典 · 知识点 08

检查网格边界，使用方向数组扩展，标记并统计连通区域。

检索词：方向数组连通区域

知识范围与官方定位

泛洪算法（Flood Fill）是七级大纲中的独立知识点。它把满足条件的网格格子看作顶点，把相邻关系看作边，再用 DFS 或 BFS 找出一个完整连通区域。

01 把网格看作图

每个可通行格子是一个顶点，四方向相邻或八方向相邻由题目决定。区域计数、区域大小、染色和“岛屿”问题都可转化为连通分量问题。不同字符是否连通也必须按题意判断。

具体推演： 在网格 10 / 01 中，两个 1 只在对角线上接触。若题目规定四方向，它们之间没有边，是两个区域；若规定八方向，就存在一条对角相邻边，成为一个区域。建图时改变的只是“哪些格子相邻”，搜索框架本身不变。

02 方向数组与边界

本项目二维数组示例使用 1 下标，方向数组命名为 fx、fy，下标 0 占位：

int fx[5] = {0, -1, 1, 0, 0};int fy[5] = {0, 0, 0, -1, 1};

新位置 (nx, ny) 必须先检查 1 <= nx <= n、1 <= ny <= m，再访问数组；条件顺序不能颠倒。

具体推演： 在 3 × 4 网格的 (1,1) 向上尝试时，新位置是 (0,1)。先检查得到 0 < 1，立即放弃这个方向；若先读取 grid[0][1]，就已经访问了约定范围外的格子。向右得到 (1,2)，四个边界条件都成立，才继续检查格子类型。

03 标记、染色与区域统计

进入合法格子后立即标记，再扩展相邻方向。可以使用独立 visited 数组，也可以把原网格字符改成新的颜色作为已访问标记。统计区域数量时，主循环每发现一个未访问目标格就启动一次搜索并加一；统计区域大小时，在一次搜索内每访问一个合法格就把计数加一。地图搜索还可能要求找最大区域、替换整片颜色或判断两个位置是否同属一个区域。

具体推演： 一行网格 11101 中，外层扫描到第一个 1，区域数加一；搜索依次标记前三个格子，区域大小得到 3。扫描越过 0 后又遇到未标记的最后一个 1，区域数再加一，第二个区域大小是 1。最终“区域数量 2”与“最大区域大小 3”来自不同层次的计数。

04 DFS 与 BFS 两种实现

DFS 写法短，适合规模允许递归的网格；BFS 使用队列，不依赖递归深度。两者只要相邻规则、标记时机相同，会找到同一连通区域。网格有 n*m 个格子时，时间复杂度为 O(nm)，标记空间为 O(nm)。

具体推演： 对 L 形区域 (1,1)、(1,2)、(2,1)，DFS 可能沿 (1,1)→(1,2) 深入，回溯后再访问 (2,1)；BFS 从 (1,1) 出队时会同时把后两个格子入队。两种顺序不同，但最终访问集合都是这三个格子，区域大小也都为 3。

知识点速查表

搜索一个区域：检查边界 → 检查格子类型 → 检查是否访问 → 立即标记 → 扩展相邻格。统计多个区域时，还需在外层枚举所有格子。

典型例题

基础例题

网格只有一行 111，按四方向相邻规则，三个 1 首尾连成一个区域。搜索从第一个 1 出发会依次覆盖其余两个格子，因此区域数量是 1，区域大小是 3。这两个统计量不能混淆。

典型应用例题

统计由字符 1 组成的四连通区域：

#include <bits/stdc++.h>using namespace std;
int n, m;char grid[105][105];bool visited[105][105];int fx[5] = {0, -1, 1, 0, 0};int fy[5] = {0, 0, 0, -1, 1};
void dfs(int x, int y) {    // 合法目标格第一次进入 DFS 时立即标记，保证每个格子只处理一次。    visited[x][y] = true;    // 下标 1 到 4 依次表示上、下、左、右四个方向。    for (int i = 1; i <= 4; i++) {        int nx = x + fx[i];        int ny = y + fy[i];        // 必须先确认新坐标在网格内，再读取 grid 与 visited。        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m            && grid[nx][ny] == '1' && !visited[nx][ny]) {            dfs(nx, ny);        }    }}
int main() {    cin >> n >> m;    for (int i = 1; i <= n; i++) {        for (int j = 1; j <= m; j++) cin >> grid[i][j];    }    int answer = 0;    // 外层扫描负责发现每个尚未访问的新区域。    for (int i = 1; i <= n; i++) {        for (int j = 1; j <= m; j++) {            if (grid[i][j] == '1' && !visited[i][j]) {                answer++;                dfs(i, j);            }        }    }    cout << answer << endl;    return 0;}

(2,2) 与 (3,3) 只在对角线上接触，四连通时不属于同一区域；如果题目明确使用八连通，结果才会改变。

测试类型 输入或条件 预期结果
基础 一行 111，四连通 区域数 1
边界 网格全部为 0 区域数 0
易错 10 / 01，四连通 区域数 2，对角线不连通

常见错误

错误做法 为什么错 正确方法
访问数组后才检查边界 可能先发生越界访问 先检查坐标范围，再读网格和标记
四连通问题加入对角线 会把只在角上接触的区域错误合并 严格按题意设置四方向或八方向
搜索结束后才标记 同一格子可能重复递归或入队 第一次发现合法格子时立即标记
只搜索第一个区域 会漏掉与起点不连通的区域 外层枚举全部格子
在外层循环统计区域大小 混淆区域数量与单个区域格子数 启动搜索时计区域数，搜索内部计大小
行列与 fx、fy 混用 新坐标方向错误 统一用 nx = x + fx[i]、ny = y + fy[i]

错误反例推演

网格 10 / 01 按四方向应有两个区域。若错误地加入 (1,1) 到 (2,2) 的对角方向，第一次搜索会把两个 1 都标记，程序输出区域数 1。正确的四方向数组只产生上、下、左、右四个相邻位置，因此右下角的 1 要由外层扫描启动第二次搜索，答案为 2。
