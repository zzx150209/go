01 官方核心未复习

初等数论基础

掌握整除与约数、素数与互质、同余与余数。

整除约数同余
核心要点
  • 整除：a 能被 b 整除（b|a）意味着 a = b×k 没有余数。
  • 约数：如果 b|a，b 就是 a 的约数；倍数：a 是 b 的倍数。
  • 素数（质数）：大于 1 且只有 1 和自身两个约数的数。
  • 互质：两个数的最大公约数为 1。同余：a 和 b 除以 m 余数相同。
注意事项
  • 1 不是素数，2 是最小的素数也是唯一的偶素数。
  • 判断素数只需试除到 √n，因为因数成对出现。
02 官方核心未复习

最大公约数

用欧几里得算法求最大公约数，并推导最小公倍数与分数约分。

辗转相除最小公倍数
核心要点
  • 欧几里得算法（辗转相除法）：gcd(a,b) = gcd(b, a%b)，直到 b=0。
  • 最小公倍数 lcm(a,b) = a / gcd(a,b) * b（先除后乘防止溢出）。
  • 分数约分：分子分母同除以 gcd。
  • C++17 有 std::gcd 和 std::lcm，需要 <numeric>。
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}
注意事项
  • a 和 b 顺序不影响结果，gcd(a,b)=gcd(b,a)。
  • 用 long long 防止乘法溢出。
03 官方核心未复习

素数筛法

掌握埃氏筛与线性筛，实现素数表查询。

埃氏筛线性筛
核心要点
  • 埃氏筛：从 2 开始，把每个素数的倍数标记为合数，O(n log log n)。
  • 线性筛（欧拉筛）：每个合数只被最小质因子筛一次，O(n)。
  • 筛法预处理后，O(1) 查询一个数是否为素数。
  • bool isPrime[N] 数组标记，初始全 true，0 和 1 标 false。
const int N = 1000005;
bool isPrime[N];
vector<int> primes;

void sieve(int n) {
    fill(isPrime, isPrime+n+1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            for (long long j = 1LL*i*i; j <= n; j += i)
                isPrime[j] = false;
        }
    }
}
注意事项
  • 筛法从 i*i 开始标记更小倍数已被前面筛过。
  • i*i 可能溢出 int，用 long long。
04 官方核心未复习

质因数分解

写出标准分解式，求约数个数与约数和。

分解式约数个数
核心要点
  • 任何大于 1 的整数都可以唯一分解为素数的乘积：n = p1^e1 × p2^e2 × ...。
  • 分解方法：从最小素数开始试除，记录每个素因子的指数。
  • 约数个数：(e1+1)(e2+1)...，每个质因子可取 0 到 ei 次。
  • 约数和：(1+p1+...+p1^e1)(1+p2+...+p2^e2)...。
map<int,int> factorize(int n) {
    map<int,int> factors;
    for (int i = 2; i*i <= n; i++) {
        while (n % i == 0) {
            factors[i]++;
            n /= i;
        }
    }
    if (n > 1) factors[n]++;
    return factors;
}
注意事项
  • 试除到 √n，如果最后 n>1 说明 n 本身是素数。
  • 约数个数可能很大，用 long long。
05 官方核心未复习

高精度运算

用数组存储大整数，处理进位借位以及与普通整数的乘除。

进位借位大整数
核心要点
  • 超过 long long 范围的大整数用数组（或 string）逐位存储。
  • 加法：从低位到高位逐位相加，处理进位。
  • 乘法：大数乘以一位数，逐位乘加进位；大整数相乘用双重循环。
  • 存储时通常低位在前（a[0] 存个位），方便进位。
// 大数加法（低位在前）
vector<int> add(vector<int>& a, vector<int>& b) {
    vector<int> c;
    int carry = 0;
    for (int i = 0; i < max(a.size(), b.size()) || carry; i++) {
        if (i < a.size()) carry += a[i];
        if (i < b.size()) carry += b[i];
        c.push_back(carry % 10);
        carry /= 10;
    }
    return c;
}
注意事项
  • 低位在前存储，输出时倒序打印。
  • 注意前导零问题和负数处理。
06 官方核心未复习

链表

掌握单向与双向链表的插入、删除与反转，会用数组模拟。

链表操作数组模拟
核心要点
  • 链表通过指针把节点串联，每个节点包含数据和指向下一节点的指针。
  • 插入删除只需修改指针，不需要移动元素，但查找需从头遍历。
  • 双向链表每个节点有前驱和后继指针。
  • 数组模拟链表：用数组存数据和 next 指针，避免动态分配。
struct Node {
    int val;
    Node* next;
    Node(int v) : val(v), next(nullptr) {}
};

// 在头部插入
Node* head = nullptr;
void insertFront(int v) {
    Node* p = new Node(v);
    p->next = head;
    head = p;
}

// 数组模拟链表
int val[100005], nxt[100005], cnt = 0;
注意事项
  • 动态分配的节点要手动 delete，否则内存泄漏。
  • 竞赛中推荐用数组模拟链表，更快更安全。
07 官方核心未复习

顺序查找

实现精确查找与左右边界查找，统计出现次数。

精确查找左右边界
核心要点
  • 顺序查找：从头到尾逐个比较，O(n)，适合无序或小数据。
  • 统计出现次数：遍历一遍计数。
  • 左右边界查找：找到第一个 >= x 的位置和第一个 > x 的位置。
  • 有序数组可用二分查找把 O(n) 降到 O(log n)。
int search(int a[], int n, int x) {
    for (int i = 0; i < n; i++)
        if (a[i] == x) return i;
    return -1; // 未找到
}
注意事项
  • 顺序查找简单但效率低，大数据量用二分。
  • 找到后不要忘记 break 或 return。
08 官方核心未复习

二分答案

判断单调性，求最小可行值与最大可行值。

单调判定边界取值
核心要点
  • 二分答案适用于：答案具有单调性（满足条件后更大/更小也满足）。
  • 二分范围 [l, r]，取 mid 判断 check(mid)，根据结果收缩区间。
  • 求最小可行值：check(mid) 为真时尝试更小（r=mid-1），否则 l=mid+1。
  • check 函数是核心，要正确实现判定逻辑。
bool check(int x) { /* 判断 x 是否可行 */ }

int binaryAnswer(int lo, int hi) {
    int ans = lo;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (check(mid)) {
            ans = mid;
            hi = mid - 1;  // 尝试更小
        } else {
            lo = mid + 1;
        }
    }
    return ans;
}
注意事项
  • 上下界要根据题目确定好，答案可能是浮点型（浮点二分）。
  • mid = (l+r)/2 可能溢出，用 l+(r-l)/2。
09 官方核心未复习

贪心算法

完成贪心选择、排序后构造，并用交换论证说明正确性。

贪心选择交换论证
核心要点
  • 贪心：每步选当前最优的选择，期望得到全局最优。
  • 关键是证明贪心策略正确（交换论证：换一种选择不会更好）。
  • 常见策略：按某关键字排序后依次选择，如区间调度、分数背包。
  • 贪心不一定正确，必须证明或反例验证。
// 区间调度：最多选多少个不重叠区间
struct Interval { int l, r; };
bool cmp(Interval a, Interval b) { return a.r < b.r; }

int maxIntervals(Interval v[], int n) {
    sort(v, v+n, cmp);
    int cnt = 0, lastEnd = -1e9;
    for (int i = 0; i < n; i++) {
        if (v[i].l >= lastEnd) {
            cnt++;
            lastEnd = v[i].r;
        }
    }
    return cnt;
}
注意事项
  • 贪心题先排序再决策，想清楚按什么关键字排序。
  • 如果不确定贪心是否正确，考虑动态规划。
10 官方核心未复习

分治与排序

掌握分治三步，实现归并排序与快速排序。

分治三步归并快排
核心要点
  • 分治三步：分解（把问题分成子问题）→ 解决（递归求解）→ 合并（合并结果）。
  • 归并排序：分成两半分别排序，再合并两个有序数组，O(n log n)，稳定。
  • 快速排序：选基准元素，小于放左边大于放右边，递归处理，平均 O(n log n)。
  • 分治的关键是合并步骤要高效。
// 归并排序核心
void mergeSort(int a[], int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(a, l, mid);
    mergeSort(a, mid+1, r);
    // 合并 a[l..mid] 和 a[mid+1..r]
    int i = l, j = mid+1, k = 0;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = 0; i < k; i++) a[l+i] = tmp[i];
}
注意事项
  • 归并排序需要 O(n) 额外空间存临时数组。
  • 快排在最坏情况（已排序+选端点）退化为 O(n²)。
11 官方核心未复习

递归

明确递归出口，理解调用与返回过程，完成递归枚举。

递归出口递归枚举
核心要点
  • 递归：函数直接或间接调用自己，必须有递归出口（base case）。
  • 递归三要素：出口条件、递归关系、返回值。
  • 递归过程：逐层调用 → 到达出口 → 逐层返回计算结果。
  • 经典：阶乘、斐波那契、汉诺塔、二叉树遍历（后续学）。
int factorial(int n) {
    if (n <= 1) return 1;       // 出口
    return n * factorial(n - 1); // 递归
}

// 汉诺塔
void hanoi(int n, char a, char b, char c) {
    if (n == 0) return;
    hanoi(n-1, a, c, b);
    cout << a << "->" << c << endl;
    hanoi(n-1, b, a, c);
}
注意事项
  • 没有出口或出口错误会导致栈溢出（无限递归）。
  • 递归深度太大（如 10^6）会爆栈，改用循环。
12 官方核心未复习

复杂度与数据范围

根据数据范围判断算法是否可行，选择合适复杂度。

数据范围复杂度判断
核心要点
  • 根据数据范围选择算法：n≤20 可用 O(2ⁿ) 枚举，n≤1000 可用 O(n²)，n≤10⁶ 用 O(n log n)。
  • 空间复杂度也要考虑：数组大小不能超过内存限制（通常 256MB）。
  • long long 比 int 占一倍空间，注意数组大小。
  • 常数因子也重要：O(n) 的沉重实现可能比 O(n log n) 慢。
注意事项
  • 1秒时限：O(n) 可到 10⁷，O(n²) 可到 10000，O(n³) 可到 500。
  • 内存 256MB 约可开 3×10⁷ 个 int 数组。
