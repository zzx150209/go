GESP 2级知识字典 · 知识点 08

根据编译信息与运行结果定位错误，学会输出中间变量。

检索词：编译信息中间输出

本课先记住

  • 核心结论： abs、sqrt、min、max 要核对参数范围与返回结果；rand() % n 的范围是 0 到 n - 1，srand 只设置序列起点，通常在一组取数开始前调用一次。
  • 常用语法： 先选函数，再检查参数、返回类型和随机范围：abs(x)、sqrt(x)、min(a, b) / max(a, b)、srand(seed)、rand() % n + start。
  • 最小示例： 确定随机范围时，先列出取余结果，再整体平移：abs(-6) = 6，sqrt(49.0) = 7.0，rand() % 5 + 3 的范围为 [3, 7]。
  • 关键易错点： 不要对负实数直接求 sqrt；不要把 sqrt 结果一概当成 int；% n 从 0 开始；不要在每次 rand 前用同一种子重新 srand。

知识范围与官方定位

本页对应二级大纲中的常用数学函数：掌握 abs、sqrt、max、min 的基本用途，并认识 rand、srand 以及简单随机整数范围的构造。

数学函数把常见计算封装成标准写法。使用前先明确函数需要什么参数、返回什么类型，再把结果放入后续表达式。

本页用 abs 求距离，用 sqrt 求非负数的算术平方根，用 min、max 比较两个值；再从取余范围推导 rand() 生成的整数区间，并理解 srand 只设置伪随机序列的起点。

函数是一段已经封装好的操作。调用表达式 sqrt(value) 可以拆成三部分：sqrt 是函数名，圆括号里的 value 是传入的实参，函数计算后产生一个返回值。返回值可以直接输出、参与更大的表达式，也可以先保存到类型合适的变量中；调用函数不会因为名字像数学公式就自动忽略参数范围和返回类型。

01 abs 绝对值函数

abs(x) 返回 x 的绝对值，也就是它到 0 的距离。abs(-15) 为 15，abs(8) 为 8。

在整数主教学中，参数和返回值都按整数理解：负数去掉负号，正数和 0 保持不变。绝对值不是“总把符号改成正号”，因为 abs(0) 仍是 0；做减法距离题时还要确保参与计算的整数没有超出题目给定范围。

int difference = 12 - 20;cout << abs(difference) << endl;  // 取到 0 的距离

输出 8。求两个整数的距离时，先相减再取绝对值即可。

例如输入 -9 25，如果要算两点在数轴上的距离，先求 -9-25=-34，再计算 abs(-34)=34。abs 接收的是括号内表达式已经算出的结果，不会分别处理两个数。

02 sqrt 平方根函数

sqrt(x) 计算非负数 x 的算术平方根，返回浮点类型。sqrt(49.0) 的数值为 7，但结果类型不是 int。

double side = sqrt(81.0);  // sqrt 返回浮点结果cout << side << endl;

sqrt 的实数参数必须满足 x >= 0。它返回浮点值，即使 sqrt(81.0) 数值恰好是 9，也不应据此把所有平方根结果都当作整数；例如 sqrt(2.0) 是不能用有限小数精确写完的近似值。

实数范围内不能对负数求平方根。若结果要保存到整数变量，还要考虑类型转换和可能的浮点误差，不能默认所有平方根都是整数。

03 max 与 min

max(a, b) 返回两者中的较大值，min(a, b) 返回较小值。两个参数应使用容易比较的相同类型。

int a = 8;int b = 3;int c = 6;cout << min(max(a, b), c) << endl;  // 先求 max(8,3)=8，再求 min(8,6)=6

max(a, b) 和 min(a, b) 都接收两个可比较的同类值，并返回其中一个值；它们不会自动修改 a 或 b。需要比较三个数时，可以嵌套调用，但每次仍只比较两个，例如 max(max(a, b), c)，计算顺序从最内层开始。

这里的中间结果可以写成：

  1. 先进入最内层 max(a,b)，得到 max(8,3)=8；
  2. 外层表达式变成 min(8,c)；
  3. 代入 c=6，得到 min(8,6)=6。

如果误从外层开始猜答案，就容易把三个数中的最大值 8 当作最终结果。嵌套调用和带括号的普通表达式一样，从最里面开始。

过程演示

现在已经分别形成了 abs、sqrt、min 和 max 的参数、返回值与边界，再把它们放进唯一一份完整程序。程序读取两个整数和一个非负实数，依次输出第一个整数的绝对值、两整数的较小值与较大值、实数的算术平方根。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int a, b;    double value;    cin >> a >> b >> value;    cout << abs(a) << endl;    cout << min(a, b) << " " << max(a, b) << endl;    cout << fixed << setprecision(1) << sqrt(value) << endl;  // 平方根按一位小数显示    return 0;}

输入 -7 3 81 时，abs(-7)=7；min(-7,3)=-7、max(-7,3)=3；sqrt(81)=9，按一位小数输出为 9.0。每一行都先算函数参数，再使用返回值。fixed << setprecision(1) 只负责把浮点结果显示为一位小数，不改变 sqrt 返回 double 的事实。

**跟着做：先选函数，再核对结果。**设 a=-6、b=4、value=49，请分别写出“a 到 0 的距离”“a、b 中的较大值”和 value 的算术平方根所用表达式，并计算结果。然后不用运行代码，推导 rand() % 5 + 3 的最小值和最大值。提示：先列出 % 5 的余数范围。你的四项结果应依次为 6、4、7.0，以及闭区间 [3, 7]；若随机范围从 4 开始，回看余数是否漏掉了 0。

04 rand 与 srand

rand() 产生伪随机整数。rand() % 6 的余数范围是 0 到 5，所以 rand() % 6 + 1 的范围是 1 到 6。

srand(seed) 设置伪随机序列的种子。相同种子通常产生相同序列；种子不同，序列通常不同。srand 不负责直接产生随机数，也不改变取余表达式规定的范围。

srand(7);  // 一组取数前只设置一次种子int dice = rand() % 6 + 1;  // 把 0 到 5 平移到 1 到 6cout << dice << endl;

输出的具体数值依赖实现，但一定在 1 到 6 之间。二级题目重点是范围计算，不把伪随机数当作真正不可预测的随机数。

范围推导不要跳步：rand() 返回的非负整数除以 6，余数只可能是 0、1、2、3、4、5，所以 rand() % 6 只能落在 0 到 5；每个可能值再加 1，就变为 1、2、3、4、5、6。加 1 是整体平移，不会多出 7。

构造闭区间 [left, right] 时，可以先数清区间内有多少个整数：count = right-left+1，再写成 rand() % count + left。例如 5 到 9 有 9-5+1=5 个整数，所以使用 rand()%5+5。这个公式要求 right >= left，且 count 必须大于 0；如果范围端点本身不合法，就不能直接套公式。

若要连续模拟多次掷骰子，通常只在循环开始前设置一次种子，再在循环内重复调用 rand()。如果每轮都用同一个种子重新执行 srand(7)，伪随机序列会从同一位置重新开始，反而可能反复得到同样的第一个结果。

可以把规则记成“只播种一次，多次取数”：程序开始产生这一组伪随机数前调用一次 srand(seed)，之后按需要多次调用 rand()。随机数的具体值不适合写成跨环境固定答案，应该检查范围性质，例如 rand() % 6 + 1 每次结果都满足 1 到 6。

若使用完整的标准头文件，rand、srand 来自 <cstdlib>，时间值 time(0) 来自 <ctime>；本站完整程序使用的 <bits/stdc++.h> 会在常见 G++ 环境中统一引入这些内容。用当前时间作种子通常能让不同运行时的序列起点不同，但它仍是伪随机，不适合密码或安全用途。二级只讨论范围构造与播种位置。

先按问题场景选函数，再检查参数和返回值：

典型例题

**题目：**怎样写出一个可能产生 5 到 9 的伪随机整数表达式，并说明范围？

推演：

  1. 5 到 9 一共有 9-5+1=5 个整数；
  2. rand() % 5 的余数可能是 0、1、2、3、4；
  3. 每个结果加 5 后，依次变成 5、6、7、8、9；
  4. 因而表达式可写为 rand() % 5 + 5；
  5. srand(seed) 在产生这一串数之前设置种子，不直接返回其中某个数。

结论：rand() % 5 + 5 的范围是 5 到 9。构造 [start, end] 时，先计算整数个数，再把从 0 开始的余数整体平移到 start。

容易混淆的几个问题

  • 认为 sqrt 返回 int；
  • 对负数直接调用实数平方根；
  • 嵌套 min、max 时不从内向外计算；
  • 把 % n 的范围误写为 1 到 n；
  • 认为 srand 本身会产生随机数；
  • 把伪随机结果的具体值当作跨环境固定答案。

错误写法：double answer = sqrt(-4.0);

**错误原因：**在实数范围内，负数没有算术平方根，不能把结果当作普通实数继续计算。

**正确写法：**调用 sqrt(x) 前先确认 x >= 0。

**错误写法：**用 rand() % 6 表示骰子的 1 到 6。

**错误原因：**余数范围是 0 到 5，既可能出现 0，也不会出现 6。

**正确写法：**使用 rand() % 6 + 1 得到 1 到 6。srand(seed) 只负责设置种子，通常在产生随机数前设置一次，不需要每次调用 rand() 前都重新设置。

本节总结

选择数学函数时先看任务，再检查参数范围和返回类型：abs 得到非负距离，sqrt 的实数参数应非负且结果为浮点类型，min、max 从内到外计算嵌套调用。随机整数先由 % n 得到 0 到 n-1，再整体平移；只播种一次，验证范围性质而不是固定某次结果。

关联学习

数据类型转换页面解释 sqrt 浮点结果怎样保存；多层循环可多次调用随机函数或用 min、max 维护当前结果，但应先明确每轮更新顺序。
