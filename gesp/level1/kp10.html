循环结构

10
GESP 1级知识字典 · 知识点 10

掌握三种循环与循环控制，解决累加、最值、位数、数列和枚举问题。

检索词：for-while循环控制

本章先记住

  • 核心结论： 循环让程序重复处理同一类任务；初始状态决定从哪里开始，条件决定是否继续，更新让状态逐步走向结束。
  • 常用选择： 起点和终点明确时先考虑 for；次数不定但继续条件清楚时考虑 while；必须先做一次再判断时才考虑 do-while。
  • 最小对照： 初值为 1 时，三种循环都能输出 1 到 5；初值改为 6 后，for 和 while 执行 0 次，do-while 仍先执行 1 次。
  • 关键易错点： 不能只看已经输出的结果，还要找到更新后的状态、条件第一次为假的判断，以及 break 或 continue 真正改变的去向。

前一章的分支结构让程序从多条路线中选择一条。本章继续使用条件判断，但条件现在负责决定一段任务是否还要再做一轮。循环并不是把代码“自动重复几次”，每一轮能否开始、怎样前进、何时停止，都由程序中的具体状态决定。

这是一张章节地图。四个子课负责语法、过程表和完整程序；本页负责把它们排成学习路线，并帮助你在做题时找到合适入口。

从顺序执行到重复处理

顺序结构中的语句通常只执行一次。循环到达判断位置后，会读取变量的当前值：条件成立就完成本轮任务，再准备下一轮状态；条件不成立就离开循环，继续执行后面的语句。

无论选择哪种循环，都要能回答四个问题：

  1. 初始状态： 第一次判断或第一次执行使用什么值；
  2. 继续条件： 当前状态满足什么要求才继续；
  3. 本轮任务： 条件允许后，这一轮具体处理什么；
  4. 状态更新： 哪条语句让下一轮使用新状态，并最终使条件变成 false。

for、while 和 do-while 没有改变这四项职责，只是把判断与更新放在了不同位置。break 和 continue 则在正常路径上增加了提前离开或跳过本轮的去向。

同一个任务怎样比较三种循环

先固定任务：“从 1 开始，每行输出一个整数，直到输出 5。”正常初值为 1 时，三种循环的可观察结果相同，都是 1、2、3、4、5；真正需要比较的是每一步先去哪里。

结构 控制信息放在哪里 第一轮怎样开始 一轮任务结束后 初值改为 6 时
for 初始化、条件、更新集中在循环头 初始化后先判断 1 <= 5 先更新，再回到条件 6 <= 5 为 false，执行 0 次
while 初始化在循环前，条件在循环头，更新在循环体内 先判断 1 <= 5 执行体内更新，再回到条件 6 <= 5 为 false，执行 0 次
do-while 初始化在循环前，条件在循环体末尾 不先判断，直接完成第一轮 先更新，再判断末尾条件 先处理 6，更新为 7，再由 7 <= 5 为 false 离开

初值为 1 时，三种写法都要在输出 5 后把状态更新为 6。for 和 while 接着判断 6 <= 5；do-while 在本轮末尾判断同一个条件。正常结束一定能找到这次第一次为假的判断，不能在最后一次输出后直接说“循环结束”。

四个子课怎样衔接

建议按表中顺序学习。每完成一课，都用“输出 1 到 5”重新走一遍，这样只改变控制位置，不会被新题目分散注意力。

顺序 子课与准确入口 学完后的可观察结果
1 for 循环：四个位置怎样配合 能从初始化开始，按“判断、循环体、更新”追踪到第一次失败，并据此检查起点、终点和更新方向
2 while 循环：第一次判断可能直接失败 能说明为什么初始条件为假时执行 0 次，并确认循环体中的更新会让状态接近结束
3 do-while 循环：初始条件不成立为什么仍执行一次 能指出第一轮发生在首次判断之前，并用真实状态区分 0 次与至少 1 次
4 break 与 continue：同一程序的两条特殊路径 能说清触发条件、被跳过或结束的语句、下一控制位置和最终输出

先按题目特征选择入口

不要因为三种循环能完成同一个输出，就认为它们在所有题目中都同样自然。先读题目怎样描述重复，再选择最容易核对的结构。

题目给出的线索 优先考虑 选择后立刻检查 详细入口
起点、终点、次数或固定步长明确 for 两端是否包含，更新方向是否朝终点前进 怎样确定起点、终点和更新
次数不容易预先算出，但“只要……就继续”的条件清楚 while 初始条件是否可能直接为假，所有能继续的路径是否更新状态 什么时候选择 while
每轮完成后才能知道是否继续，而且第一次任务必须发生 do-while 初值越界时先做一轮是否符合题意，末尾分号是否保留 什么时候适合 do-while
找到目标后不必继续，或某个特殊值本轮不处理 在已有循环中加入 break 或 continue 是结束整个最近循环，还是只跳过本轮；下一步到底去哪 continue 在三种循环中的下一位置

break 和 continue 不是第四种循环。先选择 for、while 或 do-while 作为正常骨架，确实需要改变正常去向时再加入控制语句。

常见任务怎样找到子课

整章综合测试还会把循环用于累计、计数、求积、最值、枚举因数与质数、数位处理和简单过程模拟。本页不再给这些任务各写一套程序，只保留状态选择与学习入口。

任务类型 需要保存的状态 最合适的复习入口
累计、计数、求积或最值 除循环变量外，还要保存“到目前为止的结果” for 怎样更新任务状态
枚举因数与质数 当前候选、判断结果以及是否找到额外因数 break 与 continue：枚举因数与质数
十进制数位处理 用工作副本逐位变化，必要时保留原输入 while 的数位处理
简单过程模拟 题目中的状态、执行顺序以及到达目标的时机 break 与 continue：简单过程模拟

状态的初值必须符合任务含义：累计和与计数通常从 0 开始，求积从 1 开始，最大值或最小值要从第一个真实数据开始。详细原因和过程放在 for 子课；做综合测试时，先确认自己保存的是循环位置还是任务结果，不要让一个变量同时承担两种职责。

怎样验证一个循环

循环的输出正确一次，还不能证明边界和停止路径都正确。至少准备下面四类检查：

检查 要记录的事实 能发现的问题
第一次执行 初始值、第一次条件的实际值、是否进入循环体 初值或判断位置错误
终点附近 终点值是否处理，更新后的下一个值是什么 < 与 <= 混淆，多一轮或少一轮
第一次失败 条件为什么第一次成为 false，离开后去哪 只会输出，不会解释停止
特殊路径 break 或 continue 是否触发，跳过了什么，下一步去哪 把结束循环和跳过本轮混为一谈

若循环可能不停止，不要故意运行。先在纸上写出连续两轮的状态：更新后没有变化，或变化方向让条件更难成为 false，就应先修正代码。实际运行时，再把预期输出与程序输出逐项对照；输出相同但停止原因不同，也要分别记录。

常见错误

  1. 看到重复就立刻写循环，没有先确定初始状态、继续条件、本轮任务和更新。
  2. 只凭“次数多或少”选择结构，没有看题目给的是固定范围、状态条件还是至少一次要求。
  3. 更新没有改变条件使用的变量，或更新方向让状态离停止边界越来越远。
  4. 过程只写成功轮次，漏掉正常结束时条件第一次为假的判断。
  5. 把 do-while 当成先判断，错误地认为初始条件为假时执行 0 次。
  6. 把 break 当成跳过本轮，或把 continue 当成结束整个循环。
  7. 只测试一个普通数据，没有覆盖零次、终点、首次失败和特殊控制路径。
