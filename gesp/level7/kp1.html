数学库常用函数

01
GESP 7级知识字典 · 知识点 01

处理角度与弧度换算，检查函数定义域，按题意处理浮点结果。

检索词：角度弧度浮点处理

知识范围与官方定位

官方七级大纲要求掌握数学库中的三角函数、对数函数、指数函数、平方根、绝对值和取整函数。本页只讨论常见 OJ 输入范围内的安全调用、定义域和返回值，不研究函数内部实现。完整程序使用 C++ 标准数学函数，页面不要求记忆某个平台的近似常数。

当题目出现角度、距离、增长倍数、数量级估算或误差要求时，应先判断所需函数，再检查单位、定义域和输出精度。数学库函数解决的是“已有数学模型怎样可靠计算”，不能代替建模本身。

01 三角函数与弧度

sin(x)、cos(x)、tan(x) 的参数是弧度。角度 degree 要先换算：

double radian = degree * acos(-1.0) / 180.0;double answer = sin(radian);

acos(-1.0) 得到圆周率 π。以 90° 为例，换算后是 π/2，正弦约为 1。asin、acos 的输入必须在 [-1, 1] 内，返回的也是弧度。

具体推演： 输入 degree = 30 时，先算 radian = 30 × π / 180 = π/6，再调用 sin(π/6)，得到约 0.5。如果误写成 sin(30)，函数会把 30 当成弧度，结果约为 -0.988，并不是 30° 的正弦值。结论是：只要题目给的是角度，就必须先换成弧度。

02 对数函数与指数函数

log(x) 表示以 e 为底的自然对数，log10(x) 表示以 10 为底的常用对数，log2(x) 表示以 2 为底的对数；三者都要求 x > 0。exp(x) 表示 e 的 x 次幂，pow(a, b) 表示 a 的 b 次幂。调用对数函数前必须先判断定义域，较大的 x 传给 exp 还可能溢出。

例如 log(1.0) 为 0，log10(1000.0) 为 3，log2(8.0) 为 3；而 log(0.0) 在实数范围内没有定义。不能先调用函数再检查结果。

具体推演： 若一个数量每轮翻倍，从 1 增长到 32，需要的轮数可以用 log2(32) = 5 判断，因为 2⁵ = 32。调用顺序是先检查 32 > 0，再调用 log2，最后按题意取用结果；若输入改为 0，定义域检查失败，应直接报告无定义，而不是继续计算。

03 平方根、绝对值、幂与取整

函数 含义 关键条件
sqrt(x) 非负平方根 x >= 0
fabs(x) 浮点数绝对值 返回非负值
pow(a, b) a 的 b 次幂 注意范围与浮点结果
ceil(x) 不小于 x 的最小整数值 向正无穷方向
floor(x) 不大于 x 的最大整数值 向负无穷方向

因此 ceil(-2.3) == -2，floor(-2.3) == -3。两者都不是“简单删除小数部分”。

具体推演： 对 x = -2.3，数轴上不小于它的整数有 -2、-1、0……，其中最小的是 -2，所以 ceil(x) = -2；不大于它的整数有 ……-4、-3，其中最大的是 -3，所以 floor(x) = -3。同一数据同时推演两种方向，就不会把它们误解成“去掉小数”。

04 浮点结果与允许误差

double 保存近似值，数学上的 0 可能算成极小数。判断两个浮点结果是否足够接近时，可写：

const double EPS = 1e-9;if (fabs(calculated - expected) < EPS) {    cout << "equal" << endl;}

fixed << setprecision(6) 只控制显示为小数点后 6 位，不会提高计算精度。

具体推演： 假设计算得到 calculated = 0.30000000000000004，期望值是 0.3，两者直接用 == 可能判为不等；差值绝对值约为 4 × 10⁻¹⁷，小于 1e-9，因此允许误差判断得到“足够接近”。随后用 setprecision(2) 输出为 0.30，只是改变显示结果，内存中的近似值并未变成精确的 0.3。

知识点速查表

先检查单位和定义域，再调用函数；最后按题目误差要求比较或输出。sqrt 允许零，log 不允许零；三角函数使用弧度；ceil 与 floor 在负数处最容易混淆。

典型例题

基础例题

计算 sin(30°)、log10(1000) 和 ceil(-2.3)：

  1. 30° 先换成 π/6，所以 sin(π/6) 约为 0.5；
  2. 10³ = 1000，所以 log10(1000) = 3；
  3. 不小于 -2.3 的最小整数是 -2，所以 ceil(-2.3) = -2。

这类题先判断单位和定义域，再代入函数，不需要编写复杂程序。

典型应用例题

读入角度与实数，输出正弦、平方根或未定义：

#include <bits/stdc++.h>using namespace std;
int main() {    double degree = 0.0;    double x = 0.0;    cin >> degree >> x;    // 标准三角函数接收弧度，先把输入的角度转换为弧度。    double radian = degree * acos(-1.0) / 180.0;    // fixed 与 setprecision 只控制输出格式，不改变 double 的计算精度。    cout << fixed << setprecision(6) << sin(radian) << endl;    // sqrt 的实数定义域要求 x >= 0，必须在调用前完成判断。    if (x >= 0.0) {        cout << sqrt(x) << endl;    } else {        cout << "undefined" << endl;    }    return 0;}

输入 90 4 时输出约为 1.000000 和 2.000000。程序只做常数次计算，时间和额外空间复杂度均为 O(1)。

调用过程

输入 90 4 时，程序依次完成：

步骤 当前数据 处理结果
读取输入 degree=90，x=4 等待检查与换算
角度转弧度 90 × π / 180 radian=π/2
调用三角函数 sin(π/2) 约为 1
检查平方根定义域 4 >= 0 可以调用 sqrt(4)
格式化输出 保留 6 位小数 1.000000、2.000000

如果输入为 0 -1，正弦仍可计算，但 -1 不满足平方根的实数定义域，第二行应输出 undefined。

建议测试案例

测试类型 输入或条件 预期结果
基础 90 4 正弦为 1.000000，平方根为 2.000000
边界 0 0 正弦与平方根都为 0.000000
易错 180 -1 角度先转弧度；平方根输出 undefined

常见错误

错误做法 为什么错 正确方法
sin(90) 直接把角度传入 标准三角函数把 90 当作弧度 先计算 90 × π / 180
认为 x >= 0 就能调用 log(x) 对数要求参数严格大于 0 调用前检查 x > 0
用 calculated == expected 比较计算结果 浮点运算可能产生微小舍入误差 比较 fabs(calculated-expected) < EPS
认为 ceil(-2.3)=-3 ceil 朝正无穷方向取整 区分 ceil(-2.3)=-2 与 floor(-2.3)=-3
认为 setprecision 提升计算精度 它只改变显示格式 用 double 计算，再按题意格式化输出

错误反例推演

把 90° 直接写成 sin(90) 时，程序计算的是 90 弧度，输出约 0.894，而正确过程是先算 90 × π / 180 = π/2，再得到 sin(π/2) = 1。同一个输入产生明显不同结果，说明“角度未转弧度”不是格式问题，而是传给函数的数据含义已经错了。
