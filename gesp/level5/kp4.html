质因数分解

04
GESP 5级知识字典 · 知识点 04

写出标准分解式，求约数个数与约数和。

检索词：分解式约数个数

一个整数可以有许多乘法拆法，但继续拆到质数并合并相同质因数后，会得到唯一的标准形式。本课从 360 的具体拆分出发，推导升序试除、重复相除和最后剩余因子的处理规则。得到各质因数的指数后，还能直接计算约数个数，并理解约数和与完全平方数等基础应用。

本课先记住

核心结论

每个大于 1 的正整数，都能唯一分解为素数幂的乘积（不计排列顺序）。

360 = 23 × 32 × 5

常用语法

用 while 除尽同一质因数。

while (n % p == 0) {
    n = n / p;
    count++;
}

p 是当前试除因子；count 提前设为 0，用来累计它的指数。

最小示例

12 = 22 × 3

指数是 2 和 1。

约数个数：
(2 + 1) × (1 + 1) = 6

关键易错点

  • 同一质因数要连续除尽。
  • 循环后别漏掉剩余的大质因数。
  • 约数个数是“指数加一”后相乘。

01 唯一分解定理

先看 360：它可以写成 36×10，也可以写成 8×45。把这些合数继续拆开并合并相同质因数，都会整理成 360=2³×3²×5。

唯一分解定理准确地说：每个大于 1 的整数都能写成 n=p₁^a₁×p₂^a₂×…×pₖ^aₖ，其中 p₁<p₂<…<pₖ 是互不相同的质数，a₁、a₂、…、aₖ 是正整数；这样的质数和指数唯一。“唯一”忽略乘法因子的书写顺序，但不允许把 4、9 等合数留作底数。

1 不在定理“大于 1”的范围内。1 没有质因数，后面会把它作为单独边界处理。

具体样例与推演

场景：有人沿着 360=36×10 分解，另一个人沿着 360=8×45 分解，他们最后会不会得到不同答案？

  1. 沿 36×10 拆：36=2²×3²，10=2×5，合并后是 2³×3²×5。
  2. 沿 8×45 拆：8=2³，45=3²×5，合并后仍是 2³×3²×5。
  3. 两条路径的先后顺序不同，但只要继续拆到质数、合并相同质数并按升序整理，质数底数和指数就完全相同。

适用结论：算术基本定理保证：每个大于 1 的整数都能写成质数幂的乘积，而且除因子排列顺序外，这种写法唯一。

错误反例：把 360=8×45 当作最终的标准质因数分解。

为什么错：8 和 45 都是合数，仍可继续拆；没有落到“质数底数+指数”的标准形式，就不能直接读取约数公式。

怎样改：继续拆成 8=2³、45=3²×5，再按质数升序写成 2³×3²×5。

02 试除分解

怎样让程序真正得到这些质因数？从最小候选 factor=2 开始，若 factor 能整除 remaining，就用 while 连续相除并累计 exponent；除不动后再检查下一个候选。只除一次会漏掉 360 中另外两个因子 2。

循环开始检查 factor 时，所有比 factor 小的质因数都已经从 remaining 中除尽。因此，如果 factor 此时还能整除 remaining，factor 就不可能是合数：否则它还含有一个更小的质因数，与“更小质因数已经除尽”矛盾。按升序试除，所以记录到的质因数也天然升序。

只需在 factor<=remaining/factor 时继续。对正数来说，这与 factor×factor<=remaining 等价，却不需要先做可能越界的乘法。循环退出后若 remaining>1，它也不可能是合数；因为合数一定有一个不大于自身平方根的因子，而这样的因子已经全部检查过。

具体样例与推演

场景：按 C1 的真实变量变化完整分解 S1：remaining=360。

  1. 初始时还没有输出任何质因数，满足不变量：原数 360=已经记录的质数幂乘积×remaining。
  2. factor=2，连续执行三次整除：360→180→90→45，exponent=3；记录 2³ 后，不变量成为 360=2³×45。
  3. factor=3，连续执行两次整除：45→15→5，exponent=2；记录 3² 后，不变量成为 360=2³×3²×5。
  4. 检查 factor=4 时，4<=5/4 为假，循环停止。remaining=5>1，把它作为最后质因数记录，得到 2³×3²×5。

适用结论：候选因子从 2 递增；每次进入 factor 前，更小的质因数都已从 remaining 中除尽。用 while 除尽当前因子后，不变量继续成立，因此不会漏掉重复质因数。

错误反例：把 while(remaining%factor==0) 写成只执行一次的 if。

为什么错：例如 72 含有三个 2；if 只把 72 变成 36，指数误记为 1，分解式与约数个数都会一起出错。

怎样改：保留 while，并在每次相除时把 exponent 增加 1；循环结束后再统一记录 factor^exponent。

03 标准分解式

本教学程序读取一个正整数 n，范围为 1≤n≤10¹²。n>1 时，第一行按质因数升序输出 p^e，各项之间恰好一个空格且行尾没有空格；第二行输出正约数个数。n=1 时固定输出第一行 NONE、第二行 1。

remaining 保存尚未分解的部分；factor 是当前候选因子；exponent 记录同一质因数连续出现的次数；divisorCount 累乘约数个数；firstFactor 只判断输出前是否需要补一个空格。它们的含义都不会在循环中互换。

每次完整除尽一个质因数后才输出 factor^exponent。这里输出的字符 ^ 只是分解式记号；在 C++ 表达式中 ^ 表示按位异或，不能拿来计算乘方。

具体样例与推演

场景：把数学分解 360=2³×3²×5 翻译成 D1 规定的机器可判定输出。

  1. 程序变量 remaining 保存尚未分解的部分，factor 是当前候选因子，exponent 统计它连续出现的次数，divisorCount 累乘 exponent+1。
  2. 输出底数和指数时使用普通字符，例如 2^3；字符 ^ 在这里由字符串输出，不能把 C++ 表达式 2^3 当作乘方计算。
  3. firstFactor 初始为 true；从第二项开始先输出一个空格，所以行内恰好单空格且末尾无多余空格。S1 的第一行必须精确为 2^3 3^2 5^1。
  4. n=1 没有质因数，按 D1 单独输出 NONE，再在第二行输出约数个数 1。

适用结论：标准分解输出必须同时满足数学正确和格式正确：质数升序、显式正指数、项间一个空格、无尾随空格，并且永远恰好输出两行。

错误反例：直接写 cout << factor << "^" << exponent << " ";，每项后都追加空格。

为什么错：最后一个质因数后会留下尾随空格；人工看不明显，严格比较输出时会判错。

怎样改：用 firstFactor 控制分隔符：只有已经输出过一项时，才在下一项前输出一个空格。

04 约数个数

若 n=p₁^a₁×p₂^a₂×…×pₖ^aₖ，那么每个正约数都能唯一写成 p₁^b₁×p₂^b₂×…×pₖ^bₖ，其中 0≤bᵢ≤aᵢ。对质因数 pᵢ，指数有 aᵢ+1 种选择；各项独立选择，所以正约数个数 τ(n)=(a₁+1)(a₂+1)…(aₖ+1)。

360=2³×3²×5¹，因此 divisorCount 从 1 开始，依次乘 4、3、2，得到 24。因为一个正整数的不同正约数都位于 1 到 n 之间，所以 divisorCount≤n≤10¹²，long long 足够保存。

约数和只作公式扩展，不加入本页程序输出：σ(n)=(1+p₁+…+p₁^a₁)(1+p₂+…+p₂^a₂)…。因此 σ(360)=(1+2+4+8)(1+3+9)(1+5)=1170。对 2≤n≤10¹²，有 σ(n)<n(1+ln n)<2.9×10¹³，正数部分和与部分乘积也不会超过最终结果；本页不使用浮点 pow 或等比数列闭式写程序。

具体样例与推演

场景：由 360=2³×3²×5¹ 推出正约数个数，并把约数和只作为公式扩展。

  1. 一个正约数可从原数中选择 2 的指数 0、1、2、3，共 4 种；3 的指数有 3 种；5 的指数有 2 种。
  2. 三类指数彼此独立，乘法原理给出 τ(360)=(3+1)(2+1)(1+1)=24；这正是 C1 的第二行。
  3. 若只在纸上求约数和，每个质因数对应一个等比和：σ(360)=(1+2+2²+2³)(1+3+3²)(1+5)=15×13×6=1170。
  4. D1 只要求“标准分解式+约数个数”两行，所以 1170 只能用于推理和练习核对，C1 不得输出第三行。

适用结论：指数决定每个质因数可以选几次；约数个数把选择数相乘，约数和把各质因数的幂次和相乘。两条公式都来自独立选择。

错误反例：把指数相加得到 3+2+1=6 个约数，并让 C1 再输出约数和 1170。

为什么错：指数相加没有枚举各质因数选择的所有组合；增加第三行还会违反 D1 的严格两行输出合同。

怎样改：对每个指数加 1 后相乘得到 24；约数和只留在公式扩展中，程序仍恰好输出两行。

05 分解后的应用

n=1 没有质因数，可以把它理解为“没有任何质因数可选”的空情况，因此 τ(1)=σ(1)=1；程序用 NONE 明确表示空分解，避免用空白行让学生猜测。

一个正整数是完全平方数，当且仅当标准分解式中的每个质因数指数都是偶数。例如 900=2²×3²×5²，所以 900 是完全平方数。比较质因数集合与指数还可以继续研究整除、最大公约数和最小公倍数，但这些完整实现留到后续课程。

一次试除最坏要检查到原数的平方根，时间复杂度是 O(√n)，只使用固定数量的变量，额外空间是 O(1)。remaining 变小后经常能提前结束，但当输入本身是大质数时仍要检查到平方根，所以最坏界不变。

具体样例与推演

场景：用边界输入说明剩余质因数、完全平方数判断和复杂度边界。

  1. n=1 没有质因数，却有一个正约数 1，所以必须走单独分支输出 NONE 和 1。
  2. n=14 时先除去 2，remaining=7；下一候选 3 已满足 3>7/3，循环停止，但 7 仍必须作为指数 1 的最后质因数记录。
  3. n=49 时 factor=7 恰好满足 7<=49/7，while 连除两次得到 7²；这检验了平方根边界不能写成严格小于。
  4. n=900 分解为 2²×3²×5²，所有指数为偶数，所以它是完全平方数。
  5. 试除最多走到当前 remaining 的平方根，最坏时间 O(√n)，只使用固定数量的整数和布尔变量，辅助空间 O(1)。

适用结论：循环条件 factor<=remaining/factor 避免 factor*factor 溢出；循环后若 remaining>1，它一定是最后一个质因数，不能漏记。

错误反例：循环结束就直接换行，不检查 remaining>1，并把条件写成 factor*factor<remaining。

为什么错：对 14 会漏掉 7，对 49 可能错过恰在平方根处的 7；若 factor*factor 超出整数范围，还可能因溢出让循环条件失真。

怎样改：使用 factor<=remaining/factor，并在循环后用 if(remaining>1) 记录 remaining^1，同时更新约数个数。

典型例题

基础例题：把 360 标准分解并统计约数

题意：输入一个正整数 n（1≤n≤10^12）。n>1 时，第一行输出升序的 p^e，各项之间一个空格且行尾无空格；第二行输出正约数个数。n=1 时输出 NONE 和 1。

示例输入：

360

示例输出：

2^3 3^2 5^1
24

说明：这一个样例同时用于形成算法、验证程序和追踪执行。360 中的 2 连除三次、3 连除两次，退出循环后剩余 5；指数 3、2、1 让约数个数成为 4×3×2=24。约数和 1170 只由前面的公式另行推导，不属于本程序的两行输出。

#include <bits/stdc++.h> // 引入输入输出所需的标准库声明
using namespace std; // 允许直接使用 cin 和 cout

int main() { // 程序从这里开始分解一个正整数
    long long remaining; // remaining 保存尚未完成分解的部分
    cin >> remaining; // 读入需要质因数分解的正整数

    if (remaining == 1) { // 1 没有质因数，单独输出约定结果
        cout << "NONE\n1\n";
        return 0;
    }

    long long divisorCount = 1; // 约数个数公式从乘法单位元 1 开始累乘
    bool firstFactor = true; // true 表示还没有输出任何质因数项

    for (long long factor = 2; factor <= remaining / factor; factor++) { // 只试除到当前剩余数的平方根
        if (remaining % factor == 0) { // factor 能整除时，它是当前最小质因数
            int exponent = 0; // exponent 记录该质因数连续出现的次数
            while (remaining % factor == 0) { // 连续除尽同一个质因数，不能只除一次
                remaining /= factor; // 从剩余部分中去掉一个 factor
                exponent++; // 质因数 factor 的指数增加 1
            } // 当前质因数已经除尽

            if (!firstFactor) { // 从第二项开始，先输出一个分隔空格
                cout << " ";
            }
            cout << factor << "^" << exponent; // 输出标准分解式中的一项
            firstFactor = false; // 后续质因数项需要先输出空格
            divisorCount *= exponent + 1; // 该质因数的指数有 0 到 exponent 共 exponent+1 种选择
        } // 结束当前候选因子的整除判断
    } // 所有不超过当前平方根的候选因子已经试除

    if (remaining > 1) { // 循环后仍大于 1 的剩余数就是最后一个质因数
        if (!firstFactor) { // 前面已有质因数项时，先输出分隔空格
            cout << " ";
        }
        cout << remaining << "^1"; // 最后剩余质因数只出现一次
        divisorCount *= 2; // 指数 1 对应在约数中选 0 次或 1 次两种情况
    } // 结束最后剩余质因数的处理

    cout << "\n" << divisorCount << "\n"; // 换行后输出全部正约数的个数
    return 0; // 向运行环境返回 0，表示质因数分解正常完成
} // 结束 main 函数，分解和计数均已完成

典型应用：分层练习与自检

题意：依次完成：①分解 72 并数约数；②不省略任何除法手推 360；③修复 14 的剩余因子和 49 的平方边界；④只用公式求 σ(360)；⑤判断 900 是否为完全平方数；⑥解释 n=1 的两行输出。

示例输入：

72；360；14；49；360；900；1

示例输出：

72：2^3 3^2，12；360：2^3 3^2 5^1，24；14：2^1 7^1，4；49：7^2，3；σ(360)=1170；900：YES，27；1：NONE 和 1

解题说明：答案：72=2³×3²，τ=4×3=12。360 必须写全 360→180→90→45、45→15→5，再得到 τ=4×3×2=24。14 除去 2 后补记 7；49 让 factor=7 在等号边界进入循环。σ(360)=15×13×6=1170，但主程序不输出它。900=2²×3²×5²，指数全为偶数且 τ=27。1 没有质因数，空选择只有一种，因此输出 NONE 和 1。若这些答案都能独立解释，可进入“素数筛法”学习多次分解的预处理。

常见错误

  • 同一质因数只除一次：症状是 72 不能得到 2^3×3^2；改用 while 连续相除并重跑 72。
  • 遗漏最后剩余质因数：症状是 14 只记录 2；循环后检查 remaining>1 并重跑 14。
  • 平方根边界漏掉等号：症状是 49 被误记为 49^1；使用 factor<=remaining/factor 并重跑 49。
  • 约数个数把指数相加：症状是 360 得到 6 而不是 24；对每个指数加 1 后相乘。
  • 输出项后总加空格：症状是 72 第一行末尾多一个空格；用 firstFactor 只在第二项起输出前导空格。
  • 把 n=1 输出为空行：空白含义不明确；固定输出 NONE 和 1。

用 if 代替 while，只除一次

错误代码：

if (remaining % factor == 0) {
    remaining /= factor;
    exponent++;
}

错误原因：输入 72 时，2 只被除去一次，remaining 仍含因子 2，程序不能得到 2^3×3^2。根因是没有把同一质因数完全除尽。

正确写法：

while (remaining % factor == 0) {
    remaining /= factor;
    exponent++;
}

遗漏最后剩余质因数

错误代码：

for (long long factor = 2; factor <= remaining / factor; factor++) {
    // 分解循环
}
cout << divisorCount;

错误原因：输入 14 时先除去 2，remaining=7 后循环结束；若直接输出，只会留下 2^1，约数个数也会从 4 错成 2。

正确写法：

if (remaining > 1) {
    cout << remaining << "^1";
    divisorCount *= 2;
}

平方根边界漏掉等号

错误代码：

factor < remaining / factor

错误原因：输入 49 时 factor=7 正好位于平方根位置，严格小于会跳过 7，并把合数 49 错记为 49^1。

正确写法：

factor <= remaining / factor

把指数相加当作约数个数

错误代码：

divisorCount += exponent;

错误原因：360 的指数和是 6，但实际有 (3+1)(2+1)(1+1)=24 个正约数。根因是把彼此独立的指数选择错误地相加。

正确写法：

divisorCount *= exponent + 1;

把 C++ 的 ^ 当成乘方

错误代码：

long long value = factor ^ exponent;

错误原因：在 C++ 中 ^ 是按位异或，例如 2^3 的计算结果是 1，不是 8。本程序只需要把 ^ 当字符输出。

正确写法：

cout << factor << "^" << exponent;

每个质因数后都输出空格

错误代码：

cout << factor << "^" << exponent << " ";

错误原因：输入 72 时第一行会在 3^2 后多一个空格，无法与精确输出匹配。根因是没有区分第一项与后续项。

正确写法：

if (!firstFactor) {
    cout << " ";
}
cout << factor << "^" << exponent;
firstFactor = false;

让 n=1 留下含义不明的空行

错误代码：

long long divisorCount = 1;
cout << "\n" << divisorCount << "\n";

错误原因：输入 1 时第一行为空，学生无法判断是漏输出还是“没有质因数”。本页接口要求显式输出 NONE。

正确写法：

if (remaining == 1) {
    cout << "NONE\n1\n";
    return 0;
}

用乘法写平方根条件

错误代码：

factor * factor <= remaining

错误原因：在本页 n≤10^12 时乘积仍安全，但把这段习惯直接复用到 long long 大范围时，factor*factor 可能溢出并让循环判断失真。

正确写法：

factor <= remaining / factor

知识范围与官方定位

对应五级大纲“唯一分解定理”：理解标准质因数分解，能用试除法求分解并进行基础应用。

本页只使用一级至五级已经学习的语法和能力；小知识点按页内编号连续查询，不设置前置完成门槛。

是什么
唯一分解定理把每个大于 1 的整数写成一组确定的“质数底数 + 正指数”。排列因子的顺序可以不同，按质数升序整理后的标准式唯一。
解决什么问题
标准质因数分解能输出整数的组成，并由各指数直接计算约数个数；约数和与完全平方数判断可由同一组指数继续推出。
什么时候使用
题目要求分解一个正整数、统计约数、分析质因数指数，或判断完全平方数时使用。本页只处理一次 1≤n≤10¹² 的输入。
核心思想
升序检查候选因子，把能整除 remaining 的因子用 while 完全除尽并记录指数。更小质因数已被除尽，因此当前能整除的 factor 是质数；越过当前平方根后，剩余的大于 1 的数也是质数。
C++ 实现方法
先处理 n=1；再用 factor<=remaining/factor 控制外层循环，用 exponent 记录连续相除次数，用 firstFactor 保证项间一个空格且行尾无空格，最后检查 remaining>1 并把 divisorCount 乘 2。

第 1 题大于 1 的正整数质因数分解具有什么性质？

答案：A
唯一分解定理保证质因数及其指数唯一。 因此“忽略因数顺序后唯一”正确，其余选项混淆了定义、条件或边界。
对应知识点：01 唯一分解定理

第 2 题试除分解时同一个质因数 p 应怎样处理？

答案：D
连续相除才能得到 p 的完整指数。 因此“连续相除直到不能再除”正确，其余选项混淆了定义、条件或边界。
对应知识点：02 试除分解

第 3 题72 的标准质因数分解是？

答案：C
72=8*9=2^3*3^2，标准式只写质数。 因此“2^3 * 3^2”正确，其余选项混淆了定义、条件或边界。
对应知识点：03 标准分解式

第 4 题n=p^a*q^b 时，正约数个数是？

答案：B
每个质因数的指数可从 0 取到原指数，选择数相乘。 因此“(a+1)(b+1)”正确，其余选项混淆了定义、条件或边界。
对应知识点：04 约数个数

第 5 题若试除结束后 n 仍大于 1，这个剩余数应怎样处理？

答案：A
小质因数都已除尽后，剩余大于 1 的部分必为质数。 因此“作为一个指数为 1 的质因数”正确，其余选项混淆了定义、条件或边界。
