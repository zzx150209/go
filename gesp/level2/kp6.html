循环嵌套

06
GESP 2级知识字典 · 知识点 06

用双重循环处理行列、图形与枚举问题，控制内层跳转。

检索词：行列问题内层跳转

本课先记住

  • 核心结论： 嵌套分支先走外层再决定是否进入内层；else 与最近的未配对 if 结合；else if 只执行第一条成立分支，switch 从匹配 case 开始并由 break 停止。
  • 常用语法： 用大括号标清层次，并把更严格的 else if 条件放在前面：if (...) { ... } else if (...) { ... } else { ... }；固定值分支写成 case value: ...; break;。
  • 最小示例： 分数判断先经过外层有效范围，再进入从严格到宽松的等级分支；score = 90 时，score >= 90 为真，输出 A，后续条件不再检查。
  • 关键易错点： 省略大括号容易误判悬空 else；宽条件放在严格条件前会挡住后者；switch 漏写 break 会继续落入后续 case。

知识范围与官方定位

本页对应二级大纲中的多层分支结构：掌握 if、if-else 和 switch 的嵌套或组合，能够追踪执行路径，并正确处理条件顺序、边界和 break。

多层分支用于“先判断一层，再根据结果继续细分”的问题。读代码时先确定外层路径，再进入对应内层，不能把所有条件同时执行。

本页从外层条件开始逐层追踪嵌套 if，理解 else 与最近未配对 if 的关系；再比较 else if 条件顺序和 switch 固定值分支，最后用 59、60、89、90 以及非法分数检查所有边界。

分支是根据条件只选择某条执行路径；多层分支是在已经选择的路径中继续判断。它与一串彼此独立的 if 不同：独立 if 可能有多项同时执行，if ... else if ... else 只进入第一个成立分支，嵌套 if 则要求先进入外层路径，内层判断才有机会执行。

01 嵌套 if 与配对规则

当第二个判断只在第一个条件成立后才有意义，可以把 if 放进另一个 if：

if (score >= 60) {  // 外层决定能否进入及格后的细分    if (score >= 90) {        cout << "pass and excellent" << endl;    } else {  // 已及格但未达到 90        cout << "pass" << endl;    }} else {  // 外层为假时，内层完全不执行    cout << "not pass" << endl;}

这段语法可以拆成“外层条件、外层真分支、内层条件、内层两条路径、外层假分支”。缩进帮助阅读，但真正决定范围的是大括号。二级主代码始终保留大括号，避免仅靠缩进猜测 else 属于哪一层。

大括号明确了层次。没有大括号时，else 与前面最近且尚未配对的 if 配对，容易看错，因此二级主代码应保留完整大括号。

对输入 95、75、50 分别追踪：

score 外层 score>=60 内层 score>=90 输出
95 真，进入内层 真 pass and excellent
75 真，进入内层 假 pass
50 假，不进入内层 不检查 not pass

输入 50 时，内层条件不是“假”，而是根本没有执行到。嵌套分支必须先取得外层路径，才能判断下一层。

过程演示

已经形成嵌套结构后，再看唯一完整程序。外层先把输入分成“非法”和“合法”两条路径；只有进入合法路径，内层才继续把成绩分成 A、B、C。追踪时要区分“条件为假”和“根本没有执行到”。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int score;    cin >> score;    if (score < 0 || score > 100) {  // 外层先排除非法范围        cout << "invalid" << endl;    } else {        if (score >= 90) {  // 合法后从最严格条件开始            cout << "A" << endl;        } else if (score >= 60) {            cout << "B" << endl;        } else {            cout << "C" << endl;        }    }    return 0;}
输入 外层非法判断 内层 score>=90 内层 score>=60 输出 未执行分支
-1 真 不检查 不检查 invalid A、B、C
59 假，进入合法路径 假 假 C 无
60 假，进入合法路径 假 真 B C
89 假，进入合法路径 假 真 B C
90 假，进入合法路径 真 不检查 A B、C
101 真 不检查 不检查 invalid A、B、C

例如输入 90，先得到外层非法判断为假，进入合法路径后，内层 score>=90 才为真并输出 A。这正是“先选择外层，再执行内层”，不是一条平铺的四分支链。

02 多条件与 else if

一组互斥区间常用 if ... else if ... else。程序从上到下检查，遇到第一个为真的条件后执行对应分支，其余分支跳过。

if (score >= 90) {  // 从最严格条件开始    cout << "A";} else if (score >= 80) {    cout << "B";} else if (score >= 60) {    cout << "C";} else {  // 接住前面条件都不满足的剩余区间    cout << "D";}

条件要从更严格到更宽松排列。若先写 score >= 60，90 分也会提前进入该分支。

输入 score = 75 时，程序按顺序追踪如下：

检查条件 结果 下一步
score >= 90 假 继续检查下一项
score >= 80 假 继续检查下一项
score >= 60 真 输出 C，停止检查

第三个条件成立后，后面的 else 不再执行。else if 链只会进入第一个满足条件的分支。

03 switch、case 与 break

当一个整数或字符要与若干固定值比较时，可以使用 switch：

switch (month) {  // 从匹配的固定 case 位置开始执行    case 2:        cout << "February";        break;  // 离开 switch，防止继续贯穿    case 4:        cout << "April";        break;    default:  // 没有 case 匹配时进入        cout << "other";}

switch (month) 中圆括号里的内容叫选择表达式，它通常得到整数或字符值；case 2、case 4 是互不重复的固定常量入口；default 是没有匹配项时的可选入口。case 只决定“从哪里开始”，不会自动决定“在哪里停止”，所以通常需要 break。

匹配某个 case 后从该位置继续执行，直到遇到 break 或离开 switch。遗漏 break 会继续执行后面的 case，叫作贯穿。题目可能专门考查贯穿，但日常代码若不需要贯穿，应写清 break。

if 与 switch 组合

当一个范围条件成立后，还要比较若干固定值，可以先用 if，再在它内部使用 switch：

if (type == 2) {  // 外层决定内层 switch 是否执行    switch (month) {        case 6:            cout << "summer";            break;        case 12:            cout << "winter";            break;        default:            cout << "other month";    }} else {    cout << "other type";}

输入 2 6 时，先检查 type==2 为真，才进入 switch；month 匹配 case 6，输出 summer，随后 break 只结束 switch。输入 1 6 时外层条件为假，整个 switch 都不执行，输出 other type。if 和 switch 的大括号都不能省略，否则层次和作用范围会难以辨认。

反过来，也可以先由 switch 选中固定类别，再在某个 case 内用 if 判断范围：

switch (type) {  // 外层先选择固定类别    case 1:        if (score >= 60) {  // case 内再判断范围            cout << "pass";        } else {            cout << "not pass";        }        break;  // 离开外层 switch    default:        cout << "other type";}

两个 switch 也可以嵌套。下面先选组别，再在组别 1 内选择代码：

switch (group) {    case 1:        switch (code) {  // 只有外层选中组别 1 才进入            case 2:                cout << "A";                break;  // 只结束最近的内层 switch            default:                cout << "B";                break;        }        break;  // 再结束外层 switch    default:        cout << "other";        break;}

输入 group=1、code=2 时，内层 break 只离开内层 switch，随后仍会执行外层 case 1 末尾的第二个 break。两层 break 各管最近的一层，不能用一个内层 break 同时结束两层选择。

无论是哪一种组合，都先执行外层选择，再看是否能到达内层。break 在上例中结束的是它所在的 switch，不会像 return 那样直接结束整个程序。

04 条件顺序与边界

边界值要逐一代入。例如“0 到 100 分”通常包含 0 和 100；区间 80—89 可写 score >= 80 && score < 90。多个条件组合时先确认每个比较，再看 && 或 ||。

处理年份、票价、分段收费等问题时，先在纸上列出互不重叠的区间，再按顺序写分支。这样能避免一个值同时符合多段或没有任何分支接住。

例如规则是“90 分及以上优秀，60—89 分及格，其余不及格”，把 59、60、89、90 逐个代入：

分数 >=90 >=60 结果
59 假 假 不及格
60 假 真 及格
89 假 真 及格
90 真 不再检查 优秀

如果第二个条件误写成 score>60，60 会掉进“不及格”；若优秀条件误写成 score>90，90 会被分到“及格”。边界题必须实际代入等号两侧检查。

典型例题

**题目：**一个 switch 在 case 1 输出 A 后没有 break，紧接的 case 2 输出 B 后才 break。输入 1 时输出什么？

推演：

  1. switch 的值为 1，从 case 1 开始执行；
  2. 先输出 A；
  3. 当前分支末尾没有 break，所以不会重新匹配，而是直接继续向下执行；
  4. 到达 case 2 的语句并输出 B；
  5. 随后遇到 break，离开 switch。

**结论：**连续输出 AB。case 负责确定开始位置，break 才负责在需要的位置停止。

**引导练习：**把合法成绩分成“90—100 为 A、60—89 为 B、0—59 为 C”，范围外输出 invalid。请先在纸上写外层合法性条件，再写内层两个条件，并用 -1、59、60、89、90、101 逐个走路径。提示：外层只负责合法/非法，内层从严格条件向宽条件检查。核对输出依次应为 invalid、C、B、B、A、invalid，而且 -1 和 101 都不应执行任何内层条件。

容易混淆的几个问题

  • 忽略外层条件，直接进入内层分支；
  • 不写大括号，误判 else 的配对对象；
  • 把宽条件放在严格条件之前；
  • 忘记 switch 中的 break；
  • 用 = 代替 ==，或遗漏边界等号。

**错误写法：**先写 if (score >= 60)，后写 else if (score >= 90)。

**错误原因：**90 分先满足较宽的 score >= 60，后面的优秀分支永远没有机会执行。

**正确写法：**先判断 score >= 90，再判断 score >= 60，最后用 else 接住不及格情况。

错误写法：if (score = 90)

**错误原因：**单个 = 是赋值，不是判断相等；它还会修改 score。

**正确写法：**相等比较使用 if (score == 90)。若判断分数段，使用 score >= 90。

**修正后复演：**假设输入原本是 50。错误写法 score = 90 会先把变量改成 90，条件又因非零而成立；改成 score == 90 后，50 与 90 比较为假，score 仍保持 50。检查“变量值没有被条件修改”就是修正成功的标准。

switch 中也要逐个检查 case 后是否需要 break；只有题目明确要求贯穿时才故意省略。

本节总结

多层分支先走外层，再决定是否进入内层；没有走到的条件属于未执行分支。else if 从上到下只进入第一个成立分支，因此严格条件应放在宽松条件之前。switch 从匹配的 case 开始，通常用 break 停止；所有结构都要用边界值逐一验证。

8 题
第 1 题下面程序统计字符 grade 满足的条件个数。grade 为 E 时输出什么？
#include <bits/stdc++.h>
using namespace std;

int main() {
    char grade = 'E';
    int count = 0;
    if (grade >= 'B') {
        count++;
    }
    if (grade >= 'C') {
        count++;
    }
    if (grade >= 'D') {
        count++;
    }
    if (grade >= 'F') {
        count++;
    }
    if (count == 1) {
        cout << 'A';
    } else if (count == 2) {
        cout << 'B';
    } else if (count == 3) {
        cout << 'C';
    } else {
        cout << 'D';
    }
    return 0;
}

正确答案：C

E 同时满足前三个比较条件，但不满足 grade >= F，所以 count 为 3，进入第三个分支并输出 C。

第 2 题程序读入两个温度值 p、q，并根据 p > q 是否成立输出其中较高者。核心步骤最适合采用哪种结构？

正确答案：C

比较结果有真、假两种情况，程序要据此选择输出 p 或 q，因此核心步骤应使用分支结构。

第 3 题输入 2 后，下面程序输出什么？
#include <bits/stdc++.h>
using namespace std;

int main() {
    int month;
    cin >> month;
    switch (month) {
        case 2:
            cout << "Feb ";
        case 4:
            cout << "Apr ";
            break;
        default:
            break;
    }
    return 0;
}

正确答案：C

case 2 后没有 break，输出 Feb 后会继续贯穿到 case 4，再输出 Apr，随后遇到 break。

第 4 题x 等于 1 时，下面程序输出什么？
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x = 1;
    switch (x) {
        case 1:
            cout << 'A';
        case 2:
            cout << 'B';
            break;
        default:
            cout << 'C';
    }
    return 0;
}

正确答案：B

case 1 没有 break，会继续执行 case 2，依次输出 A、B；case 2 的 break 随后结束 switch。

第 5 题要先判断“是否及格”，及格后再判断“是否优秀”，最适合使用哪种写法？

正确答案：A

第二个判断只在第一个条件成立时才有意义，因此可以把“是否优秀”的 if 放在“是否及格”的 if 内部。

第 6 题按顺序判断成绩等级时，为什么通常要先判断 score >= 90，再判断 score >= 60？

正确答案：A

在 if…else if 结构中，遇到第一个为真的条件后就跳过后续分支。若先写 score>=60，90 分以上也会提前进入及格分支。

第 7 题程序按“score >= 90 输出优秀；否则 score >= 60 输出及格；否则输出不及格”判断。输入 59、60、90 时，输出依次是什么？

正确答案：A

59 不满足 60 分边界，输出不及格；60 恰好满足 score>=60，输出及格；90 先满足最严格的 score>=90，输出优秀。

第 8 题程序先判断 type == 2，成立后才进入 switch(month)。输入 type=1、month=6 时会怎样？

正确答案：A

嵌套或组合分支要先取得外层路径。type==2 为假时，整个 switch 都不会执行；month 的值不会绕过外层条件，应进入外层 else。
