复杂度估算

09
GESP 4级知识字典 · 知识点 09

估算操作次数，理解时间复杂度与空间复杂度的含义。

检索词：时间复杂度空间复杂度

复杂度关注输入规模增大时，程序所需时间和额外空间怎样增长。写程序前估算复杂度，可以判断它在题目数据范围和时间限制下是否可能运行完，而不是猜某台电脑上的具体秒数。

本课先记住

核心结论

先数主要操作，再保留增长最快的数量级；并列步骤相加，嵌套步骤按真实次数相乘。

常用语法

一层遍历：O(n) // 主要操作次数与 n 同数量级
两层各遍历 n 次：O(n²) // 内层总次数为 n 乘 n
三个固定变量：O(1) 空间 // 变量数量不随 n 增长

最小示例

for (int i = 1; i <= n; i++) { // 循环体恰好成功执行 n 次
    operations++; // 每轮记录一次主要操作
} // i=n+1 时条件首次失败并结束

关键易错点

  • 看到两个循环就一律判断 O(n²)
  • 把代码行数当成实际执行次数
  • 分析空间时漏掉随 n 增长的辅助数组

这节课要会什么

本课建立三个核心：从真实执行记录数出主要操作；比较 O(1)、O(n)、O(n²)、O(n³)、O(2ⁿ) 的增长；把时间工作量与额外存储量分开估算。

从这个场景开始

两段程序在 n=10 时都很快，不代表 n=100000 时仍一样。复杂度不猜某台电脑要几秒，而是观察 n 变大后，主要操作次数按什么速度增长。

知识范围与官方定位

四级需要根据主要操作次数估算时间复杂度，识别 O(1)、O(n)、O(n²)、O(n³)、O(2ⁿ) 等增长，并估算辅助空间。

算法是怎样形成的

  1. 先观察本页完成程序，输入规模只有 n。单层循环每成功进入一次就把 singleCount 加 1；n=3 时，i=1、2、3 共进入 3 次。
  2. 把 n 改成任意正整数，单层循环仍恰好进入 n 次，所以主要操作次数是 n；n 扩大 10 倍，次数也扩大 10 倍，记为 O(n)。
  3. 双层循环中，每个固定的外层 i 都让 j 从 1 走到 n，因此一次外层带来 n 次计数；外层本身又有 n 轮，总次数是 n×n。
  4. n=3 时可以数到 9 次；n 扩大 10 倍时，n² 扩大 100 倍，因此双层部分记为 O(n²)。这一步来自真实次数，不是因为代码看起来有两层大括号。
  5. 若分析整个程序，两个部分先后执行，次数相加为 n+n²；n 越大，n² 增长更快，所以整体时间复杂度由 n² 主导。
  6. 最后检查存储：程序只有 n、i、j 和两个计数器，变量个数不随 n 增加，额外空间是 O(1)。换成长为 n 的辅助数组才会变成 O(n)。
  7. 若每个阶段都产生两个继续展开的分支，阶段 0、1、2、3 的分支数依次可能是 1、2、4、8；到第 n 层达到 2ⁿ 量级，这就是指数增长的形成来源。
  8. 一般分析时沿用同一方法：确定规模，选择主要操作，数真实次数，再保留增长最快的数量级；并列步骤相加，嵌套次数按边界相乘。

01 操作次数与时间复杂度

先选择最能代表工作量的主要操作，再写出它随输入规模 n 的次数。

复杂度保留增长最快的项，并省略常数倍。例如 3n+5 记为 O(n)，2n²+n 记为 O(n²)。

  • n=10 时，3n+5=35；n=100 时变成 305，增长主要由 n 决定
  • 2n²+n 在 n=10 时是 210，在 n=100 时是 20100，平方项越来越占主导
  • 因此分别记为 O(n) 与 O(n²)，不是在计算精确秒数

02 常数与单层循环

固定次数的赋值、比较或计算通常是 O(1)。

从 1 到 n 的单层循环通常执行 n 次，记为 O(n)。两个先后执行的 O(n) 循环相加仍是 O(n)，不是 O(n²)。

  • 无论 n 是 10 还是 100000，只取 values[1] 都是固定一次访问，属于 O(1)
  • 循环 i=1..n 执行 n 次，属于 O(n)
  • 两个先后循环各 n 次，总数 2n，省略常数后仍是 O(n)

03 多层循环与增长数量级

两层都各执行 n 次时，总次数为 n×n，属于 O(n²)；三层都为 n 次时是 n³。若内层边界是 j≤i，总次数则是 1+2+…+n，同样属于 O(n²)，必须看边界而非只看层数。

若每个阶段都产生两个继续展开的分支，分支数可从 1 变成 2、4、8，直到 2ⁿ，属于指数增长。这里学习识别增长形状，不提前展开递归算法。

for (int i = 1; i <= n; i++) { // 第一层执行 n 轮
    for (int j = 1; j <= n; j++) { // 每个 i 都让第二层执行 n 轮
        for (int k = 1; k <= n; k++) { // 每组 i、j 都让第三层执行 n 轮
            operations++; // 主要操作总计执行 n 乘 n 乘 n 次
        } // 结束当前 k 循环
    } // 结束当前 j 循环
} // 完成三层嵌套，时间复杂度为 O(n³)

04 空间复杂度

空间复杂度关注算法额外使用的存储。固定几个变量是 O(1)，长度为 n 的辅助数组是 O(n)，n×n 辅助矩阵是 O(n²)。

输入本身是否计入要看题目口径；比较算法时通常重点看额外空间。

  • 只增加 sum、index 两个整数，n 增大时变量数不变，辅助空间 O(1)
  • 新建 helper[1..n]，元素数量随 n 成正比，辅助空间 O(n)
  • 新建 helper[1..n][1..n]，元素数量为 n²，辅助空间 O(n²)

05 补充识别：对数增长

如果循环变量每次乘 2，达到 n 只需约 log₂n 次，常记为 O(log n)。它与“每层分成两个分支”的 O(2ⁿ) 方向相反：前者数翻倍多少次到 n，后者每增加一层让工作量翻倍。

这是识别性补充；本页核心仍是官方列出的常数、线性、平方、立方和指数增长。

  • 每轮把 value 扩大 2 倍，不是只增加 1
  • n=16 时 2⁴=16，所以循环 4 次
  • n 扩大一倍通常只多执行一次，增长慢于 O(n)
int value = 1; // 从 1 开始记录倍增值
int count = 0; // 记录实际循环次数
while (value < n) { // 尚未达到 n 时继续倍增
    value = value * 2; // 每轮把 value 扩大为原来的两倍
    count++; // 记录完成一次倍增
} // value 第一次达到或超过 n 时结束
// n=16 时 value 依次变为 2、4、8、16，共执行 4 次

典型例题

比较单层循环和双层循环

教学程序约定 1≤n≤1000，统计一个单层循环和一个 n×n 双层循环各执行多少次。

完成程序

#include <bits/stdc++.h> // 引入本程序需要的标准库
using namespace std; // 允许直接使用 cin、cout、string 等标准库名称

int main() { // 主函数是程序的入口
    int n; // 定义输入规模
    cin >> n; // 读入用于统计循环次数的 n

    int singleCount = 0; // 记录单层循环体执行次数
    for (int i = 1; i <= n; i++) { // 单层循环一共执行 n 轮
        singleCount = singleCount + 1; // 每轮把计数增加 1
    } // 结束 O(n) 的单层循环

    int doubleCount = 0; // 记录双层循环最内层执行次数
    for (int i = 1; i <= n; i++) { // 外层循环执行 n 轮
        for (int j = 1; j <= n; j++) { // 每轮外层都执行 n 轮内层循环
            doubleCount = doubleCount + 1; // 统计一次最内层操作
        } // 结束当前外层轮次对应的内层循环
    } // 结束 O(n²) 的双层循环

    cout << singleCount << ' ' << doubleCount << '\n'; // 输出 n 与 n×n 两种实际次数
    return 0; // 返回 0，表示程序正常结束
} // 结束 main 函数
示例输入
3
示例输出
3 9

解题与执行过程

  1. 单层循环执行 n 次；n = 3 时 singleCount 从 0 变到 3，属于 O(n)。
  2. 双层循环的外层和内层都执行 n 次，总次数是 n×n；n = 3 时 doubleCount 为 9，属于 O(n²)。
  3. 如果 n 扩大 10 倍，线性次数约扩大 10 倍，平方次数约扩大 100 倍。
  4. 程序只使用固定数量的计数变量，没有随 n 增长的辅助数组，额外空间是 O(1)。

迁移

常见错误

只看代码长度

错误写法：代码行数少就判断运行一定快。原因：短代码也可能执行大量循环。正确写法：选择主要操作并统计它随输入规模的次数。

看到两个循环就判 O(n²)

错误写法：两个先后执行的 n 次循环直接相乘。原因：先后执行应相加。正确写法：先判断循环是嵌套还是并列，再核对各自边界。

忽略嵌套循环的乘法关系

错误写法：两层都执行 n 次却记为 O(n)。原因：内层会被外层重复完整执行。正确写法：把相关层次数相乘得到 n×n。

保留所有低阶项和常数

错误写法：把 3n + 5 记成 O(3n + 5)。原因：复杂度描述增长数量级。正确写法：省略常数倍和低阶项，记为 O(n)。

把数组元素值当成空间规模

错误写法：数组中数字很大就判断空间复杂度更高。原因：空间取决于元素数量和类型。正确写法：按额外变量、数组或矩阵的数量级估算。
