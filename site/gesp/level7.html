01 官方核心未复习

数学库常用函数

处理角度与弧度换算，检查函数定义域，按题意处理浮点结果。

角度弧度浮点处理
核心要点
  • 三角函数 sin/cos/tan 使用弧度，角度转弧度：rad = deg * PI / 180。
  • asin/acos/atan 返回弧度，注意定义域：asin(x) 要求 |x|≤1。
  • pow(a,b) 求幂，sqrt(x) 求平方根，log(x) 自然对数，log10(x) 常用对数。
  • 浮点数比较不要用 ==，用 fabs(a-b) < 1e-9。
#include <cmath>
const double PI = acos(-1.0);
double deg = 90;
double rad = deg * PI / 180;
cout << sin(rad);  // 1.0

double a = 0.1 + 0.2;
if (fabs(a - 0.3) < 1e-9) cout << "equal";
注意事项
  • PI 用 acos(-1.0) 获取比手写 3.14159... 更精确。
  • 浮点误差累积，比较时设一个 epsilon（如 1e-9）。
02 官方核心未复习

复杂动态规划

增加状态维度，按阶段推进状态，按区间长度完成转移。

状态维度阶段推进
核心要点
  • DP 三步：定义状态、推导转移方程、确定初始值和遍历顺序。
  • 状态维度增加：如同时记录是否选过、是否处于某种状态。
  • 区间 DP：按区间长度从小到大枚举，dp[i][j] 表示区间 [i,j] 的最优解。
  • 枚举断点 k 把区间分成 [i,k] 和 [k+1,j]。
// 区间DP：石子合并（简述）
int dp[305][305], sum[305];
for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j],
                dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1]);
        }
    }
}
注意事项
  • 区间 DP 必须按区间长度从小到大枚举。
  • 注意初始化：dp[i][i] = 0，其他设为无穷大。
03 官方核心未复习

二维动态规划

处理网格最值、最长公共子序列与编辑距离。

网格最值编辑距离
核心要点
  • 网格 DP：dp[i][j] 表示从起点到 (i,j) 的最优值，从左/上转移。
  • 最长公共子序列（LCS）：dp[i][j] 表示 A 前 i 个和 B 前 j 个的 LCS。
  • 编辑距离：插入、删除、替换三种操作的最小编辑次数。
  • 转移方程根据题目具体分析。
// LCS
int dp[1005][1005];
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j])
            dp[i][j] = dp[i-1][j-1] + 1;
        else
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
// dp[n][m] 就是 LCS 长度
注意事项
  • 网格 DP 注意第一行第一列的初始化。
  • LCS 不要求连续，子串才要求连续。
04 官方核心未复习

线性动态规划

掌握最大连续和、最长上升子序列与背包空间优化。

最大连续和空间优化
核心要点
  • 最大连续子段和：dp[i] 表示以 i 结尾的最大连续和，dp[i]=max(a[i], dp[i-1]+a[i])。
  • 最长上升子序列（LIS）：O(n²) DP，O(n log n) 用二分优化。
  • 01 背包：dp[j] 表示容量 j 时的最大价值，倒序枚举容量。
  • 完全背包：正序枚举容量，每个物品可选多次。
// 最大连续子段和
int dp[100005], ans = -INF;
dp[1] = a[1];
for (int i = 2; i <= n; i++) {
    dp[i] = max(a[i], dp[i-1] + a[i]);
    ans = max(ans, dp[i]);
}

// 01背包
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w[i]; j--)
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
注意事项
  • 01 背包必须倒序枚举容量，正序就变成完全背包了。
  • LIS 二分优化用 lower_bound 找替换位置。
05 官方核心未复习

图的基本概念

识别图的组成，计算顶点的度，判断路径、环与连通性。

顶点与边连通性
核心要点
  • 图由顶点集 V 和边集 E 组成，记为 G=(V,E)。
  • 无向图边没有方向；有向图边有方向（弧）。
  • 度：无向图中与该顶点相连的边数；有向图分入度和出度。
  • 路径：顶点序列；环：起点和终点相同的路径；连通：任意两点间有路径。
注意事项
  • n 个顶点的无向完全图有 n(n-1)/2 条边。
  • 树是无环连通图，n 个顶点 n-1 条边。
06 官方核心未复习

图的存储

掌握邻接矩阵、邻接表与链式前向星。

邻接矩阵邻接表
核心要点
  • 邻接矩阵：g[i][j] 表示 i 到 j 是否有边，适合稠密图，O(n²) 空间。
  • 邻接表：vector<int> adj[n+1]，每个顶点存邻居列表，适合稀疏图。
  • 邻接表方便遍历所有出边，矩阵方便 O(1) 查询两点是否相邻。
  • 带权图邻接表存 pair<int,int>（邻接点, 权值）。
// 邻接表
vector<int> adj[100005];
void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);  // 无向图
}

// 带权邻接表
vector<pair<int,int>> adj[100005];
adj[u].push_back({v, w});
注意事项
  • 顶点编号从 0 或 1 开始，保持统一。
  • 链式前向星用数组模拟邻接表，竞赛常用。

图的遍历

实现 DFS 与 BFS 遍历，处理非连通图。

DFS遍历非连通图
核心要点
  • DFS 遍历图：从起点出发，递归访问未访问的邻居。
  • BFS 遍历图：用队列逐层扩展。
  • 非连通图需要枚举所有起点，visited 数组标记。
  • 遍历顺序不同但都能访问所有可达结点。
vector<int> adj[100005];
bool vis[100005];

void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u])
        if (!vis[v]) dfs(v);
}

int components = 0;
for (int i = 1; i <= n; i++) {
    if (!vis[i]) {
        dfs(i);
        components++;
    }
}
注意事项
  • 有向图的连通性要分强连通和弱连通。
  • 遍历顺序影响具体结果，但不影响连通性判定。
08 官方核心未复习

网格搜索

检查网格边界，使用方向数组扩展，标记并统计连通区域。

方向数组连通区域
核心要点
  • 把网格看成图，每个格子是一个结点，相邻格子是边。
  • 方向数组 dx[] = {-1,1,0,0}, dy[] = {0,0,-1,1} 表示上下左右。
  • 检查边界：坐标不能越出 0~n-1 和 0~m-1。
  • 统计连通区域：DFS/BFS flood fill 算法。
int grid[105][105], n, m;
int dx[] = {-1, 1, 0, 0};
int dy[] = {0, 0, -1, 1};

void floodFill(int x, int y, int oldColor, int newColor) {
    if (x < 0 || x >= n || y < 0 || y >= m) return;
    if (grid[x][y] != oldColor) return;
    grid[x][y] = newColor;
    for (int d = 0; d < 4; d++)
        floodFill(x+dx[d], y+dy[d], oldColor, newColor);
}
注意事项
  • 网格 BFS 求最短步数比 DFS 更可靠。
  • 注意障碍物和边界的判断顺序。
09 官方核心未复习

哈希表与集合

统计元素出现次数，判断存在性，比较有序与无序关联容器。

键值统计关联容器
核心要点
  • unordered_map<key,value>：键值对存储，平均 O(1) 查找插入。
  • unordered_set：只存键不存值，O(1) 判断存在性。
  • map/set：有序（红黑树），O(log n) 查找，按键排序。
  • 统计频率：用 map<int,int> 或 unordered_map<int,int>。
#include <unordered_map>
unordered_map<string, int> cnt;
cnt["apple"]++;
cnt["banana"]++;
cout << cnt["apple"];  // 1

unordered_set<int> seen;
seen.insert(5);
if (seen.count(5)) cout << "exists";

// 遍历
for (auto& [key, val] : cnt)
    cout << key << ":" << val;
注意事项
  • unordered_map 最坏 O(n)（哈希冲突），map 稳定 O(log n)。
  • 自定义类型作为 key 需要定义哈希函数或比较函数。

综合应用

把图论、动态规划与数据结构组合起来解决问题。

算法组合建模
核心要点
  • 综合题通常需要组合多个数据结构和算法。
  • 解题步骤：建模（把问题转化为图/数组/区间）→ 选算法 → 写代码。
  • 先写暴力解法确保正确，再想优化。
  • 注意数据范围，选择合适复杂度的算法。
注意事项
  • 不要一上来就写最复杂的算法，先确保思路正确。
  • 复杂题分步测试，每完成一部分就验证。
