树的基础知识

理解结点、边、根、子树、深度与度的概念。

结点关系树的术语
核心要点
  • 树是 n 个结点的有限集合，有且仅有一个根结点，其余结点分成若干子树。
  • 结点的度：子树个数；树的度：最大结点度。
  • 深度：从根到该结点的层数；高度：结点到最远叶结点的路径长度。
  • 叶结点：度为 0 的结点；父结点/子结点/兄弟结点按层次关系命名。
注意事项
  • 树中 n 个结点有 n-1 条边。
  • 根结点没有父结点，叶结点没有子结点。
02 官方核心未复习

树的构造与遍历

根据输入构造树，掌握先序、中序、后序遍历。

构造树三种遍历
核心要点
  • 先序遍历：根 → 左 → 右；中序：左 → 根 → 右；后序：左 → 右 → 根。
  • 根据输入构造二叉树：常见格式有括号表示法、层序数组。
  • 遍历用递归实现最简洁，也可以用栈模拟迭代版本。
  • 已知先序+中序可以唯一确定二叉树，后序+中序也可以。
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val;
    preorder(root->left);
    preorder(root->right);
}

void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val;
    inorder(root->right);
}
注意事项
  • 先序+后序不能唯一确定一棵二叉树。
  • 空指针要判断，递归函数首先 if(!root) return。
03 官方核心未复习

层序遍历

用队列按层访问结点，处理按层统计问题。

队列实现按层访问
核心要点
  • 层序遍历按从上到下、从左到右顺序访问，用队列实现。
  • 根入队，每次出队一个结点并访问，把它的左右孩子入队。
  • 层序遍历可用来按层统计结点数、求树的宽度。
  • 每次处理一层时记录当前队列大小，可以逐层处理。
#include <queue>
void levelOrder(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* node = q.front();
        q.pop();
        cout << node->val;
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
注意事项
  • 层序遍历必用队列，不是栈。
  • 求深度可以在每层处理时计数。
04 官方核心未复习

遍历序列还原

根据两种遍历序列还原二叉树，并推断第三种序列。

序列还原结构推断
核心要点
  • 先序第一个元素是根，中序中根左边是左子树、右边是右子树。
  • 递归地对左右子树重复此过程，即可还原整棵树。
  • 同理，后序最后一个元素是根。
  • 还原后可以推出第三种遍历序列。
// 先序+中序还原（简述）
TreeNode* build(int preL, int preR, int inL, int inR,
                vector<int>& pre, vector<int>& in) {
    if (preL > preR) return nullptr;
    int rootVal = pre[preL];
    int k = inL;
    while (in[k] != rootVal) k++;
    int leftSize = k - inL;
    TreeNode* node = new TreeNode(rootVal);
    node->left = build(preL+1, preL+leftSize, inL, k-1, pre, in);
    node->right = build(preL+leftSize+1, preR, k+1, inR, pre, in);
    return node;
}
注意事项
  • 注意计算左右子树大小的偏移量，这是最容易出错的地方。
  • 元素必须互不相同，否则中序中找不到唯一位置。
05 官方核心未复习

特殊二叉树

掌握二叉搜索树、完全二叉树与满二叉树的性质。

二叉搜索树完全二叉树
核心要点
  • 二叉搜索树（BST）：左子树所有结点 < 根 < 右子树所有结点。
  • BST 的中序遍历是升序序列。
  • 完全二叉树：除最后一层外全满，最后一层靠左排列。
  • 满二叉树：所有层都满，结点数 2^h - 1。
注意事项
  • 完全二叉树用数组存储：i 的左孩子是 2i，右孩子是 2i+1。
  • BST 查找时间平均 O(log n)，最坏 O(n)（链状）。
06 官方核心未复习

哈夫曼编码

构造哈夫曼树，计算带权路径长度并生成编码。

哈夫曼树带权路径
核心要点
  • 哈夫曼树：带权路径长度（WPL）最小的二叉树。
  • 构造：每次选两个权值最小的结点合并，新结点权值为两者之和。
  • 哈夫曼编码：左分支 0 右分支 1，频率高的字符编码短。
  • WPL = Σ(字符频率 × 编码长度)，也等于所有非叶结点权值之和。
// 用优先队列构造哈夫曼树（简述）
priority_queue<int, vector<int>, greater<int>> pq;
for (int w : weights) pq.push(w);
int wpl = 0;
while (pq.size() > 1) {
    int a = pq.top(); pq.pop();
    int b = pq.top(); pq.pop();
    wpl += a + b;
    pq.push(a + b);
}
注意事项
  • 哈夫曼树不唯一（等权结点合并顺序不同），但 WPL 唯一。
  • 哈夫曼编码是前缀编码，不会一个编码是另一个的前缀。

格雷码

理解格雷码的生成规则与相邻码字只差一位的性质。

生成规则相邻码字
核心要点
  • 格雷码：相邻两个数的二进制表示只有一位不同。
  • n 位格雷码有 2^n 个编码。
  • 构造方法：n 位格雷码 = (n-1)位格雷码正序 + (n-1)位格雷码逆序，前面补 0/1。
  • 二进制转格雷码：g = b ^ (b >> 1)。
// 二进制转格雷码
int binaryToGray(int b) {
    return b ^ (b >> 1);
}

// 生成 n 位格雷码序列（简述）
vector<int> gray(int n) {
    if (n == 1) return {0, 1};
    vector<int> v = gray(n-1), r;
    for (int x : v) r.push_back(x);
    for (int i = v.size()-1; i >= 0; i--)
        r.push_back((1 << (n-1)) | v[i]);
    return r;
}
注意事项
  • 格雷码首尾两个编码也只差一位（循环格雷码）。
  • 常用于电机控制和错误校正。
08 官方核心未复习

路径枚举与回溯

在迷宫中枚举路径，处理状态标记与撤销。

状态标记回溯撤销
核心要点
  • 回溯：按决策树深度优先搜索，走不通就回退，撤销选择继续试。
  • 在迷宫中：标记访问过的格子，DFS 搜索，递归返回后取消标记。
  • 回溯三步：做选择 → 递归 → 撤销选择。
  • 适用于：全排列、子集、迷宫路径、N 皇后等。
int maze[15][15];
bool visited[15][15];
int dx[] = {0, 1, 0, -1};
int dy[] = {1, 0, -1, 0};

void dfs(int x, int y, int n, int m) {
    if (x < 0 || x >= n || y < 0 || y >= m) return;
    if (maze[x][y] == 1 || visited[x][y]) return;
    visited[x][y] = true;
    // 到达终点处理
    for (int d = 0; d < 4; d++)
        dfs(x+dx[d], y+dy[d], n, m);
    visited[x][y] = false;  // 撤销
}
注意事项
  • 回溯必须撤销选择（恢复现场），否则其他路径会误判。
  • 方向数组简化四方向扩展。

深度优先搜索

用递归实现 DFS，处理连通性与路径问题。

递归搜索连通性
核心要点
  • DFS：一条路走到黑，走不通就回溯，用递归或栈实现。
  • 连通性问题：从一个点出发 DFS，能到达的所有点在同一连通分量。
  • 路径问题：记录当前路径，到达目标时处理。
  • visited 数组防止重复访问。
vector<int> adj[100005];
bool vis[100005];

void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) dfs(v);
    }
}

// 统计连通分量数
int cnt = 0;
for (int i = 1; i <= n; i++) {
    if (!vis[i]) { dfs(i); cnt++; }
}
注意事项
  • DFS 递归深度不能太大，可能爆栈。
  • 无向图 DFS 不需要记录父结点来避免走回去。

广度优先搜索

用队列实现 BFS，求最短步数与层次信息。

队列搜索最短步数
核心要点
  • BFS：按层扩展，用队列实现，第一次到达目标时步数最少。
  • 求最短路径（边权为 1）：BFS 天然保证最短。
  • BFS 用 dist 数组记录距离，初始 -1 表示未访问。
  • 每层处理完后步数加一。
int dist[100005];
memset(dist, -1, sizeof(dist));
queue<int> q;
dist[start] = 0;
q.push(start);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
注意事项
  • BFS 求最短路只适用于边权相同（或为1）的图。
  • 网格 BFS 同样用队列和方向数组。
