程序设计语言

02
GESP 2级知识字典 · 知识点 02

区分机器语言、汇编语言与高级语言，了解编译与运行过程。

检索词：语言分类编译过程

本课先记住

  • 核心结论： 机器语言由 CPU 直接执行，汇编语言用助记符但仍需汇编，高级语言更接近人的表达；C++ 源代码必须经过翻译和链接才能运行。
  • 常用语法： C++ 程序按 源代码 → 编译 → 目标文件 → 链接 → 可执行程序 → 运行 的固定阶段形成可执行结果。
  • 最小示例： int c = a + b; 仍只是高级语言源代码，CPU 不能直接执行 .cpp 文件；它还要经过目标文件和可执行程序阶段。
  • 关键易错点： 编译错误、链接错误、运行错误和逻辑错误发生在不同阶段；程序能运行不等于答案正确。

知识范围与官方定位

本页对应二级大纲中的程序设计语言分类与特点：认识机器语言、汇编语言和高级语言，知道常见高级语言，并理解 C++ 源程序通常需要经过编译和链接才能运行。

程序设计语言是人向计算机表达处理步骤的工具。不同层次的语言写法不同，但最终都要让计算机得到能够执行的机器指令。

本页用同一个“计算两个整数之和”任务比较机器语言、汇编语言和高级语言，再沿着“源代码、编译、链接、运行”追踪 C++ 程序从文字文件变成可执行程序的过程，并区分编译失败、链接失败、运行失败和答案错误。

程序设计语言是一套有明确词汇、语法和含义的表达规则，程序员用它写出处理步骤。这里的“语言”不只是若干英文单词：语法规定怎样写才合法，语义说明一条语句表示什么操作，翻译工具再把这些操作转换成计算机能够执行或处理的形式。

01 三类程序设计语言

机器语言由计算机能够直接执行的机器指令组成，常以二进制形式表示。它与具体硬件关系密切，难以阅读和编写。

汇编语言用助记符表示机器指令，比机器语言容易阅读，但仍与处理器密切相关，必须由汇编器翻译。

高级语言更接近人类表达和数学描述，通常更容易编写、阅读和维护。C++、Python、Java 都属于高级语言。高级语言源程序不能直接交给 CPU 执行，也需要翻译。

可以用同一个“计算两个整数之和”任务比较三类语言：

语言层次 人看到的表达 计算机怎样处理
机器语言 一串与处理器对应的 0 和 1 CPU 可以直接执行对应指令
汇编语言 用助记符表示“取数、相加、保存” 汇编器翻译成机器指令
高级语言 C++ 中可写成 c = a + b; 编译器等翻译工具处理

三种写法表达的是同一件事，但抽象程度不同。高级语言更方便人阅读，不等于 CPU 能直接理解；机器语言能直接执行，也不等于适合人手工编写大型程序。

“翻译工具”也要与语言层次对应：汇编器把汇编语言翻译成机器相关代码；编译器通常先把整份源程序翻译并检查，再生成后续可执行成果；解释器通常边读取边执行相应内容。实际语言可以有不同实现方式，二级只需掌握 C++ 通常先编译、Python 常见实现通常通过解释环境运行，不能据此断言一种高级语言永远只有一种执行方式。

02 常见高级语言与 C++

C++ 是通用的高级程序设计语言，可以编写控制台程序、桌面软件、游戏和系统软件等。GESP C++ 认证以 C++ 为工具训练程序设计思维。

C++ 编译后的程序通常运行效率高，因此常用于算法竞赛和对效率有要求的软件。它既支持按照步骤组织程序的过程式编程，也支持把数据和操作组织在一起的面向对象编程。二级只需要认识这些特点，不在本页展开类和对象的语法。

常见名称可以这样辨认：

语言 都属于什么层次 常见运行准备方式 本页只需记住
C 高级语言 通常先编译、链接 接近系统开发，语法与 C++ 有联系但不是同一种语言
C++ 高级语言 通常先编译、链接 效率高，支持过程式和面向对象等方式
Python 高级语言 常见实现通过解释环境执行 写法较接近人的表达，不等于 CPU 直接执行源文件
Java 高级语言 常先编译成字节码，再由运行环境执行 说明高级语言的执行准备方式并非只有一种

“高级语言”是按表达抽象层次分类，不是按新旧、难易或运行速度排名。C++ 和 Python 都是高级语言，却不必采用完全相同的翻译和运行过程。

下面的局部语句表达“把两个整数相加并保存结果”。这里只比较语言表达层次，不把完整程序作为本课的新核心：

int c = a + b;  // 读取 a、b 的当前整数值，相加后把结果保存到 c

.cpp 文件保存的是源代码，不是 CPU 可以直接执行的机器指令。代码简单并不改变它需要翻译的事实。

03 源程序的翻译与运行

使用编译型语言时，可以把过程简化为：

源代码 → 编译 → 目标代码 → 链接 → 可执行程序 → 运行

  1. 编辑：编写并保存源代码；
  2. 编译：检查语法，把源代码翻译为目标代码；
  3. 链接：把目标代码和需要的库连接成可执行程序；
  4. 运行：操作系统加载程序，CPU 执行机器指令。

若把 C++ 的常见过程再展开一步，可以看到每一阶段的输入和输出：

阶段 读入什么 主要工作 产生或交给下一步什么
编辑 人的题意和设计 写出 .cpp 源文件 源代码
预处理 #include 等指令和源代码 展开头文件等预处理内容 预处理后的源代码
编译 预处理后的代码 检查语法、类型与名称并翻译 目标代码
链接 目标代码和所需库 找到各部分定义并组合 可执行程序
运行 可执行程序和输入 操作系统加载，CPU 执行 输出或运行时现象

预处理和编译在日常工具中常被一个“编译”按钮一起完成，但它们的职责不同。知道这个顺序能帮助定位错误：找不到头文件常发生在预处理附近，漏分号通常在编译阶段报告，缺少某个已声明功能的定义可能在链接阶段报告。

编译报错通常说明语法、名称或类型等问题；程序能够运行但答案错误，属于逻辑错误；运行时出现除以 0 等问题，属于运行阶段错误。编译成功不等于答案一定正确。

把一份 C++ 文件想成沿着流水线前进：

源代码 → 编译器 → 目标代码 → 链接器 → 可执行程序 → 操作系统加载 → CPU 运行

现象 停在哪一步 具体例子
漏写分号，提示语法错误 编译失败 还没有生成可执行程序
使用了找不到定义的功能 链接失败 已经编译，但不能组成完整程序
程序启动后做了不允许的运算 运行失败 例如整数除数实际变成 0
程序输出错误答案 已运行，逻辑错误 把 a + b 误写为 a - b

“保存成功”只说明源文件写入磁盘；“编译成功”只说明能生成后续程序；“运行成功”也只说明程序走到了结束。是否得到正确答案，还要用具体输入检查输出。

知识点速查表

语言 表达特点 是否需翻译
机器语言 机器指令，与硬件密切相关 CPU 直接执行
汇编语言 助记符，与硬件关系较强 需要汇编
高级语言 更接近人的表达 需要编译或解释

典型例题

**题目：**判断“Python 与 C++ 都属于高级语言，所以 CPU 可以直接执行它们的源文件”是否正确。

推演：

  1. Python 和 C++ 的确都比机器语言更接近人的表达，因此前半句正确；
  2. CPU 直接执行的是机器指令，不直接认识 .cpp 等高级语言源文件；
  3. C++ 源代码通常还要经过编译和链接，形成可执行程序后再运行；
  4. 因而“属于高级语言”不能推出“CPU 直接执行源文件”。

**结论：**整句话错误。前半句正确，后半句错误；语言越方便人阅读，越不能省略必要的翻译过程。

**引导练习：**下面四个现象分别最先对应哪个阶段：① .cpp 文件漏写分号；② 已声明的函数始终找不到定义；③ 程序启动后除数变成 0；④ 程序顺利结束却把加法写成减法。请先按“编译—链接—运行—逻辑检查”的顺序逐项配对。提示：先问可执行程序是否已经生成，再问程序是否已经开始运行。核对结果依次是编译失败、链接失败、运行失败、逻辑错误；还要能说明第④项不能由“运行结束”证明答案正确。

容易混淆的几个问题

  • 认为汇编语言就是机器语言，因而不需要翻译；
  • 把编辑、保存和编译混为一谈；
  • 认为扩展名为 .cpp 的文件就是可执行程序；
  • 认为程序能运行就说明逻辑和输出一定正确。

错误判断：“C++ 是高级语言，所以 CPU 可以直接执行 .cpp 源文件。”

错误原因：“高级”表示更接近人的表达，不表示更接近 CPU 指令。C++ 源代码还要经过编译和链接。

**正确结论：**C++ 的典型过程是“源代码 → 编译 → 目标代码 → 链接 → 可执行程序 → 运行”。

错误判断：“高级语言一定比机器语言运行得慢。”

**错误原因：**源代码是否容易阅读和程序最终运行效率不是同一件事。高级语言经过翻译后也会变成机器指令，实际效率还与编译器和程序写法有关。

**正确结论：**二级应掌握三类语言的表达特点和翻译方式，不用“高级”或“低级”两个词直接判断所有程序的运行速度。

本节总结

机器语言能由 CPU 直接执行，汇编语言需要汇编，高级语言需要编译或解释。对 C++ 来说，保存 .cpp 文件不等于得到可执行程序；编译、链接、运行分别可能失败，即使程序顺利结束，也还要核对输出是否符合题意。
