知识范围与官方定位

官方七级大纲要求掌握图的遍历。深度优先遍历（DFS）沿一条分支尽量深入，广度优先遍历（BFS）按与起点的边数分层扩展。两者都必须使用访问标记避免在环中重复处理。

01 遍历目标与访问标记

遍历是从起点出发，系统访问所有可达顶点。顶点第一次被发现时就应标记，后续遇到它直接跳过。无向图的一条边存了两个方向，如果没有标记，程序会在两个端点之间往返。

具体推演： 无向边只有 1—2 时，从 1 出发先标记 1，再发现并标记 2；处理 2 时又看到邻点 1，因为 visited[1]=true，所以直接跳过。若没有访问标记，程序会沿 1→2→1→2…… 不断往返。

02 深度优先遍历 DFS

DFS 访问顶点后，依次递归访问尚未访问的相邻点：

进入 dfs(u) 后先执行 visited[u] = true，再枚举 graph[u] 中的相邻点；只有 visited[v] 为假时才递归。DFS 适合连通性、连通分量和需要沿路径深入的路径搜索。若只需判断能否到达目标，发现目标后可以结束当前搜索；若要记录一条具体路径，还需保存每个顶点从哪个前驱到达。

具体推演： 图有边 1—2、1—3、2—4，邻点按编号递增。DFS 从 1 先进入 2，再进入 4；4 没有新邻点后回溯到 2、再回到 1，最后访问 3。首次访问顺序是 1,2,4,3，递归路径的“进入—回溯”解释了为什么不是按层访问。

03 广度优先遍历 BFS

BFS 使用队列。起点入队时距离为 0；每次取出队首，把未访问邻点的距离设为当前距离加 1，并立即标记、入队。无权图中第一次到达顶点时的距离，就是起点到它的最少边数。

执行顺序是：起点入队并标记；反复取出队首；把每个未访问邻点标记，令它的距离等于当前距离加 1，再入队。标记必须发生在入队时。

具体推演： 对同一张图，从 1 开始时队列 [1]、dist[1]=0；取出 1 后把 2、3 入队，队列变为 [2,3]，距离都为 1；取出 2 后发现 4，队列变为 [3,4]，dist[4]=2。第一次到达 4 经过两条边，因此最少边数为 2。

04 非连通图与连通分量

从一个起点只能访问同一连通分量。要遍历整张非连通图，应从 1 到 n 检查每个未访问顶点，每启动一次 DFS 或 BFS，连通分量数加 1。

具体推演： n=5，边为 1—2、2—3、4—5。外层遇到顶点 1 时计数变为 1，一次遍历标记 1、2、3；继续检查到 4 时仍未访问，计数变为 2，第二次遍历标记 4、5。最终所有顶点都被处理，连通分量数为 2。

知识点速查表

方法 核心结构 常见用途
DFS 递归或栈 深入搜索、连通性、连通分量
BFS 队列 分层遍历、无权图最少边数

两种方法在邻接表上完整遍历时，时间复杂度均为 O(n+m)，访问标记和队列/递归空间为 O(n)。

典型例题

基础例题

无向图有边 1—2、1—3。若邻接点按 2,3 的顺序保存，从 1 开始 DFS 会访问 1,2,3；BFS 也会先访问 1，再发现同一层的 2 和 3。这个例子中顺序可能相同，但原因不同：DFS 沿分支深入，BFS 按距离分层。

典型应用例题

统计无向图连通分量：

#include <bits/stdc++.h>using namespace std;
vector<int> graph[1005];bool visited[1005];
void dfs(int u) {    // 顶点第一次进入 DFS 时立即标记，避免在无向边或环上重复递归。    visited[u] = true;    for (int i = 0; i < graph[u].size(); i++) {        int v = graph[u][i];        // 只沿尚未访问的邻点继续深入。        if (!visited[v]) {            dfs(v);        }    }}
int main() {    int n, m;    cin >> n >> m;    // 无向图的每条边要存入两个方向。    for (int i = 1; i <= m; i++) {        int u, v;        cin >> u >> v;        graph[u].push_back(v);        graph[v].push_back(u);    }    int answer = 0;    // 每遇到一个未访问顶点，就发现了一个新的连通分量。    for (int u = 1; u <= n; u++) {        if (!visited[u]) {            answer++;            dfs(u);        }    }    cout << answer << endl;    return 0;}

输入 5 3，边为 1 2、2 3、4 5 时输出 2。一次 DFS 会标记一个完整分量，因此不会重复计数。时间复杂度为 O(n+m)，空间复杂度为 O(n+m)。

DFS 与 BFS 过程追踪

对边 1—2、1—3、2—4，从顶点 1 出发：

方法 当前操作 待处理状态 已标记顶点
DFS 进入 1，再递归到 2 递归路径 1 → 2 1,2
DFS 从 2 递归到 4 递归路径 1 → 2 → 4 1,2,4
DFS 回到 1，再访问 3 递归路径 1 → 3 1,2,3,4
BFS 1 入队并出队，发现 2、3 队列变化：[1] → [2,3] 1,2,3
BFS 2 出队，发现 4 队列变化：[2,3] → [3,4] 1,2,3,4
BFS 3、4 依次出队 [3,4] → [4] → [] 1,2,3,4

BFS 在顶点入队时立即标记，因此即使另一个顶点也连接到 4，顶点 4 也不会重复入队。

建议测试案例

测试类型 输入或条件 预期结果
基础 5 个顶点，边为 1 2、2 3、4 5 连通分量数为 2
边界 n = 1, m = 0 连通分量数为 1
易错 三角形 1—2—3—1 每个顶点只访问一次，不发生无限递归

常见错误

错误做法 为什么错 正确方法
BFS 出队时才标记 同一顶点可能被多个前驱重复入队 顶点入队时立即标记
DFS 不检查访问标记就递归 在无向边或环上会反复递归 只递归访问尚未标记的邻点
只从顶点 1 出发就结束 非连通图中会漏掉其他分量 枚举所有未访问顶点并启动新遍历
在带权图上直接用 BFS 求最小权值和 BFS 只保证无权图的最少边数 使用与边权条件匹配的算法
把 DFS 首次找到的路径称为最短路 DFS 不按边数分层 无权图最少边数使用 BFS
认为 DFS 访问顺序固定 顺序受邻接表排列影响 只依赖“全部可达点会被访问”等稳定性质

错误反例推演

在菱形图 1—2、1—3、2—4、3—4 中，若 BFS 等到出队才标记顶点，处理 2 时会把 4 入队，处理 3 时又会把尚未出队、仍未标记的 4 再入队，队列出现两个 4。改为发现 4 时立即标记，第二次遇到它就会跳过，既避免重复处理，也保留第一次到达的最少边数。

关联学习

泛洪算法本质上是在网格图上执行 DFS 或 BFS；区别只是相邻点由方向数组现场计算，而不是预先存入邻接表。

9 题

第 1 题在可能含环的图上执行 DFS，访问标记的主要作用是什么？

答案：A
对应本页 01：图中可能通过不同路径再次到达同一顶点，环还可能造成无限递归。访问标记让已经处理的顶点被跳过，从而保证每个顶点只需进入一次。

第 2 题DFS 枚举到顶点 u 的相邻顶点 v 时，什么时候应该递归调用 dfs(v)？

答案：A
对应本页 02：只有 v 尚未访问，递归才会发现新的顶点。已访问顶点应直接跳过，否则在无向边或环上会来回递归并产生重复处理。

第 3 题统计无向图连通分量时，应在什么情况下把答案加 1 并启动一次 DFS？

答案：A
对应本页 04：一次 DFS 会访问起点所在的整个连通分量。外层循环再次遇到未访问顶点，说明它不属于此前任何分量，因此发现了一个新分量，应计数一次并从它继续 DFS。

第 4 题无向图中，1 邻接 2、3，2 还邻接 4。从 1 开始 DFS，相邻点按编号从小到大处理，首次访问顺序是什么？

答案：A
对应本页 02：从 1 先进入较小邻点 2，再从 2 深入到尚未访问的 4；4 没有新邻点后回溯到 1，最后访问 3，所以顺序为 1，2，4，3。

第 5 题BFS 使用队列的哪项性质，使较早发现的顶点先被处理？

答案：A
对应本页 03：队列按先进先出工作：先发现并入队的顶点先出队，因而 BFS 会先处理距离起点较近的一层，再处理更远的一层。

第 6 题BFS 发现尚未访问的相邻顶点 v 时，为什么应在 v 入队时立即标记？

答案：A
对应本页 03：如果等到出队才标记，同一层的多个顶点可能都发现 v 并把它重复入队。入队时立即标记，能保证 v 只入队一次，同时首次得到的层数或距离保持最短。

第 7 题在每条边代价都相同的无权图中，从起点执行 BFS，第一次到达顶点 v 时得到的 distance[v] 表示什么？

答案：A
对应本页 03：BFS 按经过 0 条边、1 条边、2 条边的层次依次扩展。顶点第一次被发现时，不可能还存在边数更少而尚未处理的路线，所以 distance[v] 是最少边数。

第 8 题无向图中，1 邻接 2、3，2 和 3 都邻接 4。从 1 开始 BFS，相邻点按编号从小到大入队，首次出队顺序是什么？

答案：A
对应本页 03：处理 1 时依次把 2、3 入队；2 出队时发现 4 并立即标记、入队，此时 3 仍在 4 前面；3 不会重复加入 4，最终顺序是 1，2，3，4。

第 9 题无权图中要求从起点到终点经过的最少边数，应优先选择哪种遍历？

答案：A
对应本页 03：BFS 按距离层次扩展，第一次到达终点时经过的边数最少。DFS 先深入一条路线，首次到达的路线不保证边数最少。
