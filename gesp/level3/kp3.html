位运算

03
GESP 3级知识字典 · 知识点 03

掌握与、或、异或、取反和移位，安全地进行位操作。

检索词：按位运算移位

本课先记住

  • 核心结论： 位运算先把整数补成相同位宽，再逐位计算；读取或修改第 k 位时，先用 1u << k 生成只选中目标位的掩码。
  • 常用语法： a & b、a | b、a ^ b、~a、a << k、a >> k；读、设、清、翻分别使用 ((value >> k) & 1u)、value | mask、value & (~mask)、value ^ mask。
  • 最小示例： 6=0110₂、3=0011₂，所以 6 & 3=0010₂=2。
  • 关键易错点： 不混淆 & 与 &&；最右位编号为 0；~ 必须结合位宽；移动量必须小于类型位宽；混合表达式主动加括号。

知识范围与使用边界

想象一个整数保存着一排开关：每一位是 0 或 1。我们既可能只想查看某个开关，也可能只改变一个开关而不影响其他位置。位运算就是直接处理这些二进制位的工具。

本课只收束三个核心：先在固定位宽下计算按位与 &、按位或 |、异或 ^ 和按位非 ~；再追踪非负无符号数的左移 << 与右移 >>；最后用 1u << k 读取、设置、清除或翻转第 k 位。后面的位段拆合与异或恢复只是这三个核心的直接应用，不进入 Mastery 三核心。

这里的“位宽”是统一规定用多少位二进制观察一个数。例如只观察低 8 位时，十进制 45 写成 00101101。本课示例使用非负整数和 unsigned int；在常见 32 位 GCC/OJ 环境中，unsigned int 通常表示 0 到 2³² - 1，实际位宽仍由平台决定。无符号常量 1u 中的 u 表示无符号类型，不会改变数字 1 的大小。

类型名 unsigned int 表示无符号整数类型，字面量 1u 表示无符号整数 1。

位编号从最右侧开始，最右位是第 0 位，向左依次是第 1、2、3 位。生成 1u << k 前必须保证 k 小于 unsigned int 的位宽。本课不讨论负数移位，也不把可能丢失高位的左移当作无条件乘法技巧。

01 六种位运算

核心一：固定位宽下逐位计算

&、|、^ 都有左右两个整数。先把两数补成相同位宽，再让同一列的两位配对。~ 只有一个整数，会把约定位宽内的每一位翻转。

1101& 1010------  1000

只有最左一列同时为 1，所以结果是 1000₂=8。

按位或竖式

1101| 1010------  1111

每一列至少出现一个 1，所以结果是 1111₂=15。

异或竖式

1101^ 1010------  0111

后三列的两位不同，所以结果是 0111₂=7。

按位非竖式

~ 1101------  0010

纸面结果 0010₂=2 的前提是“只观察低 4 位”。在 C++ 中可以把这个前提写成 ((~13u) & 15u)：15u 的低 4 位全是 1，因此最后只保留低 4 位。不能脱离位宽直接把 ~13u 写成 2。

前三项双目运算可以压缩复算为：13&10=1000₂=8、13|10=1111₂=15、13^10=0111₂=7。

位运算和逻辑运算含义不同。6 & 3 计算 0110 & 0011=0010，结果为 2；6 && 3 只判断两个数是否都非 0，结果为真。现象相似时仍要先看清符号。

核心二：安全左移与右移

左移把所有位向左移动，右侧补 0；本课的非负无符号数右移时，左侧补 0，移出右端的低位被丢弃。

unsigned int value = 5u; // 本例只处理小范围非负无符号数unsigned int doubled = (value << 1); // 先确认移动量小于位宽且高位不会丢失

完成移位判断的成功标准是：先画出固定位宽，再标出移动方向和补入的 0，最后检查是否有需要保留的位被移出。

02 判断第 k 位

核心三：用掩码读取目标位

为了只选择第 k 位，可以准备一个“只有目标位置为 1、其他位置都是 0”的二进制数，这个数叫掩码。表达式 1u << k 会把最低位的 1 移到第 k 位。

安全读取第 k 位

unsigned int value = 45u; // 低8位是00101101unsigned int k = 4u; // 从右侧第0位开始编号，并保证k小于类型位宽unsigned int bit = ((value >> k) & 1u); // 目标位移到最右后只保留最低位

45u >> 4 的低 8 位是 00000010，再与 00000001 做按位与，得到 0，所以 45 的第 4 位为 0。括号说明先移位，再只保留最低位。

判断奇偶是读取第 0 位的特例。(value & 1u) == 0u 表示最低位为 0，也就是非负偶数；最低位为 1 时是奇数。

03 设置、清除与翻转第 k 位

同一个掩码还可以设置、清除或翻转目标位：

unsigned int value = 45u; // 当前要读取或修改的非负整数unsigned int k = 4u; // 目标位编号，并保证k小于unsigned int位宽unsigned int mask = (1u << k); // 只在第k位放置1unsigned int setValue = (value | mask); // 设置目标位unsigned int clearValue = (value & (~mask)); // 清除目标位unsigned int flipValue = (value ^ mask); // 翻转目标位

不要用减法代替清除。如果目标位原本就是 0，减去 1u << k 会改变其他位或得到错误数值；value & (~mask) 无论目标位原来是 0 还是 1，都只会把该位清零。

完成掩码操作的成功标准是：能先写出 mask 的位模式，再说明每个表达式只改变目标位，并用十进制结果反向核对。

04 位段拆分与合并

这一节是三核心后的兼容应用，用于承接既有第 5 题，不进入 Mastery。上一课已经见过十六进制字面量：0xABu 的低 8 位是 10101011。0x0Fu=00001111₂ 可以保留低四位，右移四位可以把高四位移到最右。

unsigned int value = 0xABu; // 低8位是10101011unsigned int low = (value & 0x0Fu); // 保留低四位1011，得到11unsigned int high = ((value >> 4) & 0x0Fu); // 高四位1010移到最右，得到10unsigned int combined = ((high << 4) | low); // 放回高四位并接回低四位

因此 0xABu 拆分为高四位 10、低四位 11，再合并会回到原值。既有第 5 题使用 10101100₂，同理得到高四位 10、低四位 12。

bool odd = ((value & 1u) != 0u); // 先读取最低位，再判断是否为1unsigned int bit = ((value >> k) & 1u); // 先移动目标位，再保留最低位unsigned int cleared = (value & (~mask)); // 先取反掩码，再清除目标位

不要写含义模糊的 value & mask == 0u。括号既控制顺序，也把“先做哪一步”直接告诉读者。

典型例题

前面的真值、移位和掩码追踪已经完成后，再把四个表达式放进一份完整程序。输入保证 value 是非负 unsigned int，k 小于 unsigned int 的位宽；本程序不处理非法移动量。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    unsigned int value; // 保存要读取或修改的非负整数    unsigned int k; // 保存从右侧第0位开始的目标位编号    cin >> value >> k; // 题目保证k小于unsigned int位宽
    unsigned int mask = (1u << k); // 生成只选中第k位的掩码    unsigned int bit = ((value >> k) & 1u); // 读取目标位    unsigned int setValue = (value | mask); // 把目标位设置为1    unsigned int clearValue = (value & (~mask)); // 把目标位清除为0    unsigned int flipValue = (value ^ mask); // 翻转目标位
    cout << bit << ' ' << setValue << ' ' << clearValue << ' ' << flipValue << '\n'; // 按读、设、清、翻输出    return 0;}

三组运行结果如下：

输入 读、设、清、翻输出 检查目的
45 4 0 61 45 61 目标位原来为0
45 3 1 45 37 37 目标位原来为1
0 0 0 1 0 1 零值与最低位边界
5u << 1 10，即 00000101 → 00001010 左移方向与补0
10u >> 1 5 非负无符号数右移

横向滑动查看完整表格

完成这道典型例题的成功标准是：能在运行程序前独立写出四个表达式和预期结果，运行后四项都与手算一致，并能解释为什么其他位置没有被修改。

常见错误

  1. 现象： 把 6 & 3 算成真假值。原因： 混淆了 & 与 &&。修正： 补齐为 0110 & 0011 后逐列计算。复验： 结果是 0010₂=2。
  2. 现象： 把最右位称为第 1 位。原因： 忘记本课从 0 编号。修正： 在位串下先写 7…2、1、0。复验： 45=00101101₂ 的第 4 位是 0。
  3. 现象： 直接写 ~13u=2。原因： 忽略了 C++ 会翻转类型中的所有位。修正： 明确只观察低4位并计算 ((~13u)&15u)。复验： 低4位为 0010₂=2。
  4. 现象： 把任意 x<<k 都当作乘 2^k。原因： 没检查移动量和高位丢失。修正： 先确认 k 小于位宽并画出移动后的固定位宽。复验： 5u<<1=10 的低8位没有高位丢失。
  5. 现象： 用 value-(1u<<k) 清除目标位。原因： 假定目标位原本一定为1。修正： 使用 value&(~mask)。复验： 45 的第4位原本为0，清除后仍是45。
  6. 现象： 写 value & mask == 0u。原因： 混合表达式没有明确分组。修正： 写成 ((value & mask)==0u)。复验： 先得到掩码结果，再与0比较。

判断目标位时先完成按位运算

× 错误写法value & mask == 0u
✓ 正确写法((value & mask) == 0u)

原因：混合表达式省略括号后难以确认先做按位与还是相等判断，容易读错或写错。

检查方法：内层括号得到掩码结果，外层比较它是否为0。

本课小结

本课只掌握三个核心：固定位宽下按真值逐位计算 & | ^ ~；在非负 unsigned 范围内安全追踪 << >>；用 1u << k 掩码读取、设置、清除和翻转一位。位段拆合与异或恢复只是承接既有题目的兼容应用。
