GESP 2级知识字典 · 知识点 07

使用绝对值、平方根、最大最小值与随机数，注意取值范围。

检索词：绝对值平方根最大最小值

本课先记住

  • 核心结论： 外层控制组或行，内层完成每组的重复动作；每轮外层开始都要重置内层状态，总次数按各轮实际次数求和，并补上内外层最后一次失败判断；break 和 continue 只影响最近一层。
  • 常用语法： 双层循环先认清每层变量、初值、条件和更新：外层 for (int i = 1; i <= rows; i++) 控制行，内层 for (int j = 1; j <= columns; j++) 完成每行。
  • 最小示例： 固定两行、每行三次时共有六次输出；每行到 j = 4 时内层判断为假，最后到 i = 3 时外层判断为假。
  • 关键易错点： 不要把内层初值放到外层之外；内层次数变化时不能直接相乘；不要把内层 break 当成结束所有循环；while 中的 continue 不能跳过必要更新。

知识范围与官方定位

本页对应二级大纲中的多层循环结构：掌握 for、while、do-while 的嵌套形式，能够计算执行次数、输出图形或数列，并理解内层 break、continue 的影响。

循环嵌套就是在一个循环体中再放循环。外层通常控制“做几组”，内层控制“每组做几次”；总次数必须按每一轮内层实际次数求和。

本页先用矩形输出理解“外层一轮，内层完整执行一遍”，再追踪内层变量重新初始化、最后一次失败判断，以及 break、continue 只影响最近一层循环的规则；最后把行列、字符周期和数位处理放回同一套过程表中检查。

循环嵌套是把一个完整循环写在另一个循环的循环体里。外层每进入一轮，内层都要从自己的初始化开始，经历判断、执行、更新，直到内层结束，控制权才回到外层。判断代码属于哪一层时看大括号范围，不能只看变量名或缩进。

01 嵌套循环的基本形式

最常见的是双重 for。下面外层控制 3 行，内层在第 i 行输出 i 个数字：

for (int i = 1; i <= 3; i++) {  // 外层控制行号    for (int j = 1; j <= i; j++) {  // 第 i 行输出 i 次        cout << j;    }    cout << endl;}

输出为 1、12、123 三行。内层每完成一次，外层才进入下一轮；进入新的外层轮次时，内层循环变量重新初始化。

观察下面这个固定执行 2 行、每行 3 次的双层循环，最容易看清“外层一次，内层完整执行一次”：

i j 当前是第几行、第几列
1 1 第 1 行第 1 列
1 2 第 1 行第 2 列
1 3 第 1 行第 3 列
2 1 第 2 行第 1 列
2 2 第 2 行第 2 列
2 3 第 2 行第 3 列

当 i=1 时，j 要从 1 完整走到 3；之后外层才令 i=2，内层的 j 又从 1 开始。

for 和 while 也可以混合嵌套。下面外层 for 控制两行，内层 while 每行输出三个星号：

for (int i = 1; i <= 2; i++) {    int j = 1;  // 每行开始时重置内层变量    while (j <= 3) {        cout << '*';        j++;  // 内层循环的更新    }    cout << endl;}

while 嵌套时，每进入一轮外层循环，也要重新设置内层循环的初值。若把 int j = 1; 放到外层循环之前，第一行结束后 j 已经变成 4，第二行将不会进入内层循环。

两层都使用 while 时，初始化和更新不会集中写在循环头里，更要逐项检查：

int row = 1;while (row <= 2) {    int column = 1;  // 每行重新初始化列变量    while (column <= 3) {        cout << '*';        column++;  // 更新内层变量    }    cout << endl;    row++;  // 更新外层变量}

这段代码中有两次初始化和两次更新：row 只在整个结构开始前初始化一次，column 却在每轮外层开始时重新初始化；漏掉任意一层的更新都可能造成该层无法结束。

do-while 嵌套同样遵守“外层一轮，内层完整执行”的规则，而且每层循环体都至少执行一次：

int i = 1;do {    int j = 1;  // 每轮外层开始时重置内层变量    do {        cout << j;        j++;    } while (j <= 3);  // 内层末尾判断    cout << endl;    i++;} while (i <= 2);  // 外层末尾判断

程序输出两行 123。读嵌套 do-while 时要分别找到内层和外层末尾的条件，不能把两个 while 误认为同一层。

过程演示

已经看过双重 for、混合嵌套、双重 while 和双重 do-while 的基本形式，再把最常用的双重 for 放进唯一完整程序。程序输入行数、列数和一个字符，输出对应矩形；外层每轮开始时，内层变量 column 都重新从 1 开始。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int rows, columns;    char mark;    cin >> rows >> columns >> mark;    for (int row = 1; row <= rows; row++) {  // 外层控制行        for (int column = 1; column <= columns; column++) {  // 每行都从第 1 列开始            cout << mark;        }        cout << endl;    }    return 0;}

输入 2 3 # 时，内层判断的完整轨迹是：第 1 行令 column 依次为 1、2、3 并输出三个 #，随后 column=4 的最后一次判断为假；第 2 行重新初始化 column=1，再次到 column=4 为假。外层完成第 2 行后，row=3 的最后一次判断为假，程序结束。

**跟着做：先画轨迹表，再预测输出。**把输入改成 2 3 @，不要先运行程序。先写出第 1 行的三组 (row, column)，再写出第 2 行，并补上内层 column=4 与外层 row=3 的失败判断。提示：进入第 2 行时，column 会重新从 1 开始。你的表中应有 6 次输出，程序结果应是两行 @@@；实际运行后，若少了一行，就检查内层变量是否在每轮外层开始时重新建立。

02 循环次数与行列角色

若外层每轮内层次数相同，总次数可以相乘；若内层次数依赖 i，要逐轮相加。例如第 1 到第 4 行分别执行 1、2、3、4 次，总次数是 1+2+3+4=10。

更通用的计算写法是：总次数 = 每一轮外层对应的内层次数之和。当每轮内层都执行 m 次、外层执行 n 次时，这个和才可以简写成 n × m。例如 3 行每行 4 次是 4+4+4=12；三角形四行则是 1+2+3+4=10，不能误算成 4×4。

网格题常用 i 表示行、j 表示列。本站主教学默认使用 1 下标：行列都从 1 到 N 时，主对角线满足 i==j，副对角线满足 i+j==N+1。例如 N=3 时，副对角线坐标依次是 (1,3)、(2,2)、(3,1)，三组坐标的和都是 4。

官方题若明确从 0 开始，则行列范围改为 0 到 N-1，副对角线公式相应变为 i+j==N-1。这属于题目明确给定的坐标约定，不应反过来改变本站网格主教学的 1 下标写法。

03 break 与 continue

break 只结束它所在的最近一层循环。内层遇到 break 后，外层仍可进入下一轮。continue 跳过当前这一轮剩余语句，进入该层循环的下一轮。

for (int i = 1; i <= 3; i++) {    for (int j = 1; j <= 5; j++) {        if (j == 3) {            break;  // 只结束最近的内层循环        }        cout << j;    }    cout << endl;}

每行输出 12，共三行。break 没有直接结束外层循环。

continue 逐轮追踪可以看下面的内层循环：

for (int j = 1; j <= 5; j++) {    if (j == 3) {        continue;  // 跳过本轮 cout，随后仍执行 for 的更新    }    cout << j;}cout << endl;

break 和 continue 都作用于它们所在的最近一层循环：break 直接离开该层；continue 只跳过该层当前轮剩余语句。在 for 中执行 continue 后仍会先执行更新部分，再回到条件判断；在 while 中若把必要的更新写在 continue 后面，则更新可能被跳过，必须特别检查是否会形成死循环。

j j==3 本轮动作
1 假 输出 1
2 假 输出 2
3 真 跳过 cout，进入下一轮
4 假 输出 4
5 假 输出 5

最终输出 1245。continue 不会结束循环，也不会把 j 永远停在 3；在 for 中会先执行更新部分 j++，再开始下一次条件判断。

官方真题少见写法 if (i % 5) break; 把非零整数直接当作真。它等价于更直白的 if (i % 5 != 0) break;。二级主教学优先写完整比较，读官方题时再把余数代入 0 或非 0 判断。

04 嵌套循环中的字符与数位

取余可以生成周期。例如 j % 3 依次产生 0、1、2，可配合字符编码输出 X、Y、Z 的重复序列。写成直白形式更适合二级阅读：

for (int row = 1; row <= 2; row++) {    for (int j = 0; j < 6; j++) {        char letter = 'X' + j % 3;  // 余数 0、1、2 映射为 X、Y、Z        cout << letter;    }    cout << endl;}

外层循环执行 2 行，内层每行按余数 0、1、2、0、1、2 输出 XYZXYZ。字符周期由内层产生，换行由外层每轮末尾产生。

数位处理中，n % 10 取得个位，n /= 10 去掉个位。若外层处理多个整数，内层 while 可以逐位处理每个数；每个数开始前要重新设置计数或备份变量。例如依次处理 12 和 305 时，12 的数位轨迹是 12→1→0，305 的轨迹必须从 305 重新开始，不能沿用前一个数结束后的 0。

05 综合循环应用

九九乘法表：内层上界跟随行号

for (int i = 1; i <= 9; i++) {    for (int j = 1; j <= i; j++) {  // 第 i 行输出 i 项        cout << j << "*" << i << "=" << i * j << " ";    }    cout << endl;}

第 1 到第 9 行分别输出 1、2、3、……、9 项，总项数是 1+2+...+9=45，不是 9×9。每次外层进入新行，内层 j 都重新从 1 开始。

多组数据：每组重新统计

for (int group = 1; group <= t; group++) {    int n;    cin >> n;    int count = 0;  // 每组开始时重新统计    for (int i = 1; i <= n; i++) {        int value;        cin >> value;        if (value % 2 == 0) {            count++;        }    }    cout << count << endl;}

count 必须定义在外层循环体内，因此每组开始都会重新变成 0。若把它移到外层循环之前而又不手动清零，第二组输出会包含第一组已经统计的偶数，得到的是累计结果而不是“本组结果”。

判断回文数时，逐位反转会不断修改 n，所以要先保存原值：

下面的局部示例约定 n 是非负整数，并且反转后的值仍在 int 可表示范围内；真实题目必须先查看输入范围。

int original = n;  // 保存原数，n 作为工作副本int reversed = 0;while (n > 0) {    reversed = reversed * 10 + n % 10;    n /= 10;}if (original == reversed) {    cout << "yes";} else {    cout << "no";}

枚举多个数并判断是否符合条件时，外层负责枚举候选，内层负责检查。内层一旦找到反例，可直接 break，不要继续做无用检查。

例如要依次判断 121、123 是否为回文数，外层负责读入两个候选，内层分别反转。121 的中间反转值是 1→12→121，比较后为回文；123 的中间反转值是 3→32→321，比较后不是回文。每次进入内层前都要重新设置 original 和 reversed=0。

典型例题

**题目：**输入 3 和 4，输出 3 行、每行 4 个星号。

**推演：**外层循环控制 3 行；每一轮外层开始后，内层 j 都从 1 重新走到 4，共输出 4 个星号；内层结束后再换行。三轮内层次数是 4+4+4=12。

for (int i = 1; i <= rows; i++) {  // 外层控制行    for (int j = 1; j <= columns; j++) {  // 内层控制列        cout << '*';    }    cout << endl;}

输入：

3 4

输出：

************

**结论：**输出是 3×4 的星号矩形，共 12 个星号。固定内层次数时总次数可以相乘；若内层上界依赖 i，则应逐轮相加。

另一个常见追踪是：外层 i 从 1 到 4，内层 j 从 1 到 i，连续输出 j。四轮分别输出 1、12、123、1234，连接后得到 1121231234。

容易混淆的几个问题

  • 直接把外层次数和内层上界相乘，忽略内层次数会变化；
  • 忘记内层变量每轮重新初始化；
  • 认为内层 break 会结束所有循环；
  • continue 前后的累计顺序判断错误；
  • 反转数字后忘记原变量已变为 0。

**错误写法：**把 int j = 1; 放在外层 while 之前，第一行结束后不再把 j 设回 1。

**错误原因：**第一轮结束时 j 已经超过上界，后续外层轮次不会再次进入内层循环。

**正确写法：**每次进入新的外层轮次时，在内层循环之前重新设置 j = 1。

**错误写法：**内层循环条件误写成 j <= rows，输出矩形时把行数当成列数。

**错误原因：**外层变量和内层上界角色混乱。外层控制行，内层应按列数执行。

**正确写法：**外层使用 i <= rows，内层使用 j <= columns；再用 1×1、单行和单列检查边界。

本节总结

外层决定有多少组或多少行，内层决定每组做多少次；每轮外层开始时都要重新建立内层初值。计算次数要逐轮记录，过程表必须包含内层和外层的最后一次失败判断。break 只结束最近一层循环，continue 只跳过当前层当前轮的剩余语句。
