字符串处理

06
GESP 3级知识字典 · 知识点 06

按位置访问字符，查找与截取连续子串，完成连接与替换。

检索词：字符访问子串截取

本课先记住

  • 核心结论： 一个字符也没有、长度为 0 的字符串，叫作空串。原字符串中连续的一段字符，叫作子串。字符数组中有效文本最后一个字符后面的 \0 用来告诉程序字符串在哪里结束，因此它叫作结束标记。
  • 常用语法： 用 getline(cin, s) 读取包含空格的一整行；用 s.length() 得到字符个数；合法下标是 0 到 s.length() - 1；用 find、substr 和 replace 处理连续文本。
  • 最小示例： string s = "aB2"; 中，s[0] 是 'a'。把小写字母逐个改成大写后得到 "AB2"，原来的大写字母和数字保持不变。
  • 关键易错点： 空串不能访问 s[0]；find 返回 0 也表示在开头找到，失败才返回 string::npos；字符数组容量为 N 时最多保存 N - 1 个普通字符，最后要留给 \0。

知识范围与使用边界

字符串用来保存和处理文本。本课先区分一个字符、一串字符和固定容量字符数组，再学习输入、长度、下标、拼接、查找和替换。

核心概念

本课只解决三个核心问题：核心一：文本表示与安全输入，先判断数据是一个字符、一段文本还是固定容量字符数组，再选择不会丢失空格的输入方式；核心二：按下标遍历、修改与比较，只访问合法位置并解释每轮怎样改变文本；核心三：连接、截取、查找、替换与分割，根据位置、数量和修改后的新长度检查边界。八个知识章节完整保留，但都服务于这三个核心。

学完本课，你需要会：

  • 使用 char 保存一个字符，使用 string 保存一段文本；
  • 根据文本是否包含空格选择 cin >> 或 getline；
  • 使用长度和下标遍历字符串，并在访问前检查边界；
  • 使用 +、find、substr 和 replace 处理文本；
  • 为字符数组保留 \0 结束标记，避免写出缓冲区。

本课不使用指针、函数、递归、文件、异常处理或更高等级的字符串算法。

char letter = 'A'; // 用 letter 保存单个英文字母字符；当前值由 'A' 得到char digit = '7'; // 用 digit 保存字符形式的数字 7，而不是整数 7；当前值由 '7' 得到

string 保存一串字符，字符串使用双引号：

string word = "Apple"; // 用 word 保存不含空格的单词文本；当前值由 "Apple" 得到string sentence = "I like C++"; // 用 sentence 保存可能包含空格的一整行文本；当前值由 "I like C++" 得到

'A' 是一个字符，"A" 是长度为 1 的字符串。比较当前位置的单个字符时写 text[i] == 'A'；查找一段文本时写 text.find("cat")。

字符数组也能保存文本，但它的容量在声明时已经固定：

char word[10] = "go"; // 字符串字面量依次写入 'g'、'o'、'\0'，其余位置补 0

数组中依次保存 'g'、'o' 和 \0。\0 是数值为 0 的结束标记，不是可显示的字符 '0'。

在 C++ 中，sizeof(char) 规定为 1 字节，所以 char word[10] 一共占 10 字节。用 "go" 初始化后，前 3 个位置依次是 'g'、'o'、'\0'，其余位置也会被初始化为 0。这里要分清三个量：数组容量是 10，文本长度是 2，为文本和结束标记实际用到的位置数是 3。

对这个完整字符数组，sizeof(word) 得到固定容量 10；strlen(word) 需要 <cstring>，它从开头数到第一个 \0，结果是文本长度 2。若使用 string text = "go";，应写 text.size() 或 text.length() 得到 2，不能用 sizeof(text) 当作字符个数，因为 string 对象还要保存自己的管理信息。

容量为 10 的字符数组若要保存以 \0 结尾的普通文本，最多只能放 9 个可显示字符。word[9] 是最后一个存储位置，不能在已经放满 10 个可显示字符后再把 \0 写到 word[10]，因为下标 10 已经越界。

表示方式 保存内容 示例 主要边界
char 一个字符 char c = 'x'; 使用单引号
string 可变长度文本 string s = "cat"; 空串不能访问首尾字符
char s[105] 固定容量字符序列 char s[105] = {}; 最后要为 \0 留一个位置

02 字符串输入

字符串输入

cin >> text 读到空格、制表符或换行时停止，适合读取一个不含空格的单词：

string word; // 用 word 保存不含空格的单词文本；值将在紧接着的输入或判断分支中确定cin >> word; // 依次读入 word（不含空格的单词文本）

getline(cin, text) 会读取一整行，空格也是文本的一部分：

string sentence; // 用 sentence 保存可能包含空格的一整行文本；值将在紧接着的输入或判断分支中确定getline(cin, sentence); // 读取一整行文本（包括中间的空格）并保存到 sentence

如果前面刚使用 cin >> n 读过数据，输入流中通常还留着一个换行符。在题目保证数字后立即换行时，可以先忽略这个换行，再读取下一整行：

int n; // 用 n 保存数字输入，用来演示 getline 前的换行处理；值将在紧接着的输入或判断分支中确定cin >> n; // 依次读入 n（数字输入，用来演示 getline 前的换行处理）cin.ignore(); // 忽略数字后留下的一个换行符，避免 getline 立即读到空行
string sentence; // 用 sentence 保存可能包含空格的一整行文本；值将在紧接着的输入或判断分支中确定getline(cin, sentence); // 读取一整行文本（包括中间的空格）并保存到 sentence

这里 ignore() 只处理紧跟在数字后的一个字符，因此这段写法依赖“数字后立即换行”的输入格式。若题目输入格式不同，要按题意处理分隔字符。

03 长度、空串与下标

字符串长度、空串和下标

size() 和 length() 都返回字符串中的字符个数。本站示例统一使用 length()；官方题中看到 size() 时，要知道它们在这里作用相同。

empty() 用来判断字符串是否为空：

if (text.empty()) { // empty() 为 true 表示长度为 0，此时没有任何字符可访问    cout << "Empty"; // 输出提示 Empty，表示当前判断分支的结果} else { // 条件“text.empty()”不成立时，改走这一条处理路径    cout << text[0]; // 字符串非空，输出下标 0 的首字符} // 条件“text.empty()”不成立时的替代动作到此完成

如果要读取首个字符，也要先保护空串：

string s; // 用 s 保存本例正在遍历或修改的字符串；值将在紧接着的输入或判断分支中确定getline(cin, s); // 读取一整行文本（包括中间的空格）并保存到 s
if (!s.empty()) { // 只有字符串非空时才能安全访问下标 0    char first = s[0]; // 用 first 保存字符串的第一个字符；当前值由 s[0] 得到    cout << first; // 输出非空字符串的首字符} // 空串不会访问 s[0]；非空时 first 已保存首字符

字符串位置和长度使用 string::size_type 保存。这是 string 专门提供的非负整数类型，length() 的返回值也是这个类型。先了解它，再用它遍历字符串，就不会把普通 int 和字符串长度混在一起比较。

长度为 5 的字符串，有效下标是 0、1、2、3、4。不存在下标 5。访问首项 text[0] 或末项 text[text.length() - 1] 前，必须先确认字符串不是空串。

核心二：按下标遍历、修改与比较

04 字符串遍历

字符串遍历

下面的片段读取一整行，并统计字符 'a' 出现的次数。它复用本课的合法下标循环，但不是另一份完整程序：

string text;getline(cin, text);int count = 0;for (string::size_type i = 0; i < text.length(); i++) {    if (text[i] == 'a') {        count++;    }}

空格和标点也各占一个位置。空串的长度为 0，循环第一次判断就不成立，因此不会访问 text[0]。

char lower = tolower(ch); // 用 lower 保存把当前字符转换成小写后的结果；当前值由 tolower(ch) 得到char upper = toupper(ch); // 用 upper 保存把当前字符转换成大写后的结果；当前值由 toupper(ch) 得到

例如，字符串已经保存在 s 中时，可以用下面的局部片段统一改成小写：

for (string::size_type i = 0; i < s.size(); i++) { // 从下标 0 开始逐个处理有效字符    s[i] = tolower(s[i]); // 接住转换后的字符，再写回原来的位置}

如果只想判断而不转换，可以写 if (islower(ch)) 或 if (isupper(ch))。它们回答的是“这个字符是不是英文小写/大写字母”，不是比较两个字符串。

06 通过下标修改字符

字符串下标不仅可以读取字符，也可以直接修改合法位置上的字符。下面的完整程序把一行文本中的小写英文字母改成大写：

完整程序：逐字符转成大写

#include <bits/stdc++.h> // 引入输入输出和 string，供本例按下标修改字符using namespace std; // 后续直接使用 cin、cout 和 string，避免重复书写 std 前缀
int main() { // 程序从这里开始，把字符串中的小写字母改成大写    string s; // 用 s 保存本例正在遍历或修改的字符串；值将在紧接着的输入或判断分支中确定    getline(cin, s); // 读取一整行文本（包括中间的空格）并保存到 s
    // 从下标 0 到最后一个有效位置，逐个检查并修改小写英文字母。    for (string::size_type i = 0; i < s.size(); i++) { // 让下标覆盖每个有效字符：继续条件是 i < s.size()，每轮结束执行 i++        if (s[i] >= 'a' && s[i] <= 'z') {  // 当前字符是小写字母，把它改成对应大写字母            s[i] = s[i] - 'a' + 'A'; // 保持字母序号不变，把当前小写字母映射到对应大写字母        } // 小写字母已经转成对应大写，其他字符保持原样    } // s[i] 是否需要转成大写已处理，i++ 后继续下一字符
    cout << s << '\n'; // 输出修改后的完整字符串并换行    return 0; // 修改后的大写文本已输出，向运行环境返回成功状态 0} // 通过下标原地修改字符串的完整过程结束

表达式 s[i] - 'a' 得到当前小写字母与 'a' 的编码距离，再加上 'A' 就得到对应的大写字母。这个转换依据英文字母编码连续排列的特点；字符编码基础可回看二级 ASCII 编码课程。

长度为 s.size() 的字符串，最后一个合法下标是 s.size() - 1。s[s.size()] 已经越过最后一个字符，不能读取也不能修改。空串没有任何合法下标，所以访问前仍要先检查 s.empty()。

两端交换完成字符串反转

字符串反转和数组反转使用同一过程：左下标从 0 开始，右下标从最后一个字符开始，每轮交换一对字符后同时向中间移动。

int left = 0; // 左下标从字符串首字符开始int right = (int)s.length() - 1; // 先把长度转成 int 再减 1，空串时得到 -1 而不会访问字符while (left < right) { // 左右下标尚未相遇时，继续交换一对字符    char temporary = s[left]; // 暂存左侧字符，避免下一行覆盖后丢失    s[left] = s[right]; // 把右侧字符写到当前左侧位置    s[right] = temporary; // 把原左侧字符写到当前右侧位置    left++; // 左下标向中间移动一格    right--; // 右下标向中间移动一格} // 左右下标相遇或交错时，整个字符串已经反转

对 "abcd"，第一次交换下标 0 和 3 得到 "dbca"，第二次交换下标 1 和 2 得到 "dcba"，然后 left = 2、right = 1，条件不成立并停止。空串或长度为 1 的字符串一开始就不满足 left < right，不会访问不存在的位置。

简单密码转换：每个小写字母后移一位

简单密码题通常会明确给出字符映射规则。下面只处理常见 GCC/OJ 的 ASCII 小写英文字母：a 变成 b，……，y 变成 z，z 回到 a。输入若含空格、数字或大写字母，必须另按题意决定是否保留，不能擅自套用这段规则。

for (string::size_type i = 0; i < s.size(); i++) { // 从左到右处理每个待加密字符    if (s[i] == 'z') { // z 已在小写字母末尾，后移一位要回到 a        s[i] = 'a'; // 按首尾相接规则把 z 替换成 a    } else if (s[i] >= 'a' && s[i] <= 'y') { // a 到 y 都有紧邻的下一个小写字母        s[i] = s[i] + 1; // 利用 ASCII 连续编码，把当前字符后移一位    } // 其他字符不满足两个分支，因此保持原样} // 所有字符处理完后，s 保存完整密码转换结果

例如 "az by" 依次变为 "ba cz"：a → b、z → a、空格保持、b → c、y → z。这类题的关键不是背代码，而是先把“哪些字符会变、怎样变、边界字符怎样回绕”写成完整规则。

片段 s[1] = 'd'; 会让 abc 修改为 adc：下标 1 是第二个字符，赋值只改变这个位置，原来的 a 和 c 保持不变。

07 字符串比较与字典序

字符串比较与字典序

两个字符串可以使用 ==、!=、<、>、<=、>= 比较。== 和 != 判断整段文本是否相同；大小关系按字典序比较，也就是从左到右找到第一对不同字符，再比较它们的字符编码。若前面的字符都相同，较短的字符串排在前面。

string firstName = "Xiao"; // 用 firstName 保存名字的前半部分；当前值由 "Xiao" 得到string lastName = "Dengzi"; // 用 lastName 保存名字的后半部分；当前值由 "Dengzi" 得到string fullName = firstName + " " + lastName; // 用 fullName 保存加入空格后拼接成的完整名字；当前值由 firstName + " " + lastName 得到

结果是 "Xiao Dengzi"。中间的空格也要明确写入，不能假定程序会自动添加。

字符串截取 substr()

substr(position, count) 从下标 position 开始，截取至多 count 个字符。

substr() 截取位置示意

string text = "ABCDE123"; // 原字符串共 8 个字符，下面将从下标 2 开始截取string part = text.substr(2, 3); // 从下标 2 开始连续截取 3 个字符，part 得到 "CDE"

下标 2 对应字符 'C'，向后取 3 个字符，part 得到 "CDE"。本课只在已经确认起点不超过字符串长度时使用 substr，不讨论非法起点引发的异常。

典型例题

字符串查找 find()

find(target) 查找目标字符串第一次出现的位置。找到时返回起始下标，找不到时返回特殊标记 string::npos。

前面已经用 string::size_type 保存长度和下标。find 还会在失败时返回同一类型的特殊标记 string::npos，所以查找位置也继续使用这个类型。

string text = "red blue red"; // 原文本中 red 出现两次，find 默认只返回第一次的位置string::size_type position = text.find("red"); // 查找 red 第一次出现的位置；找不到时保存 string::npos

这里第一次出现的位置是 0。位置 0 仍然表示查找成功，所以不能把 find 的结果直接当成真假值。

字符串替换 replace()

replace(position, count, newText) 从 position 开始，替换 count 个字符。使用前必须先确认已经找到目标：

if (position != string::npos) { // position 不是 npos，说明 find 确实找到了目标词    text.replace(position, 3, "green"); // 从找到的位置开始删去 3 个字符，再写入 green} // 找到时已完成首次替换；未找到时不进入分支，原文本保持不变

替换后 text 变成 "green blue red"。新文本可能比旧文本更长或更短，后续访问必须根据替换后的新长度判断。

下面的局部片段把查找、截取、替换和拼接连在一起，并且只替换第一次出现的目标词：

查找并替换片段

string oldWord = "cat"; // oldWord 是待查找的旧词string newWord = "dog"; // newWord 是替换后写入的新词string::size_type position = text.find(oldWord); // 保存第一次出现的位置if (position != string::npos) { // 只有确实找到时才能使用这个位置    string piece = text.substr(position, oldWord.length()); // 截取被替换的旧片段    text.replace(position, oldWord.length(), newWord); // 在原位置写入新词    string result = "Result: " + text; // 用修改后的文本完成拼接}

字符串分割

C++14 的 string 没有 split() 成员函数。字符串分割是按一个分隔字符把原字符串拆成若干片段。

例如把 club.code.org 按 . 分割。开始时 part 为空；依次读到 c、l、u、b 后，part 变成 club。读到第一个 . 时输出 club 并清空 part；随后同样得到并输出 code；循环结束时 part 里还剩 org，最后再输出一次。

当前读到的字符 part 的变化 输出
c、l、u、b 逐个累积为 club 暂不输出
. 输出后清空 club
c、o、d、e 逐个累积为 code 暂不输出
. 输出后清空 code
o、r、g 逐个累积为 org 循环后输出 org

下面的局部片段会保留空片段：

string part = ""; // part 保存当前正在累积的片段for (string::size_type i = 0; i < s.size(); i++) { // 从左到右检查每个字符    if (s[i] == '.') { // 遇到分隔符时，一个片段结束        cout << part << '\n'; // 空片段也会输出一个空行        part = ""; // 清空后开始收集下一段    } else {        part = part + s[i]; // 普通字符接到当前片段末尾    }}cout << part << '\n'; // 循环后别漏掉最后一个片段

因此开头分隔符、末尾分隔符或连续分隔符都会输出空行。例如 .a 的第一段为空，a. 的最后一段为空，a..b 的中间一段为空。空片段应不应该保留，必须按照题目要求决定，不能自己悄悄丢掉或保留。

字符数组与结束标记

字符数组容量固定，而且文本末尾必须保留 \0。char text[105] 的下标是 0 到 104，因此最多安全保存 104 个普通字符。

cin.getline(text, CAPACITY) 会读取一整行，最多写入 CAPACITY - 1 个普通字符，并在后面补上 \0。下面的局部片段统计数字字符：

const int CAPACITY = 105; // 最后一个位置留给结束标记char text[CAPACITY] = {}; // 先把字符数组全部初始化为 0cin.getline(text, CAPACITY); // 最多读入 CAPACITY - 1 个普通字符int digitCount = 0; // 从还没有统计到数字开始for (int i = 0; text[i] != '\0'; i++) { // 遇到结束标记时停止    if (text[i] >= '0' && text[i] <= '9') {        digitCount++; // 当前字符是数字，计数增加 1    }}

循环遇到 \0 时停止，因此不会把结束标记当成普通文本。若输入可能超过 104 个字符，题目必须另外说明如何处理过长输入；程序不能把字符写到数组外面。

官方真题少见写法：append 的三个参数

官方题中可能出现：

s.append(other, 0, 2); // 取 other 从下标 0 开始的 2 个字符，追加到 s 末尾

先用本课已经学过的操作写成直白等价形式：

string piece = other.substr(0, 2); // 用 piece 保存从原字符串截取出的局部文本；当前值由 other.substr(0, 2) 得到s = s + piece; // 把截取出的 piece 接到 s 末尾，形成新的字符串内容

它的作用是取出 other 从下标 0 开始的两个字符，再追加到 s 末尾。原写法把“从哪个字符串取、从哪里开始、取几个字符”压进一次 append 调用中，是官方真题少见写法。

容易误读的地方是把第二个参数 0 当成“追加 0 个字符”，或把第三个参数 2 当成结束下标。实际上 0 是起始下标，2 是字符个数。日常编程和本站主示例优先使用上面的两句直白写法。

常见错误

  1. 混用字符和字符串。单个字符写 'a'，一段文本写 "a" 或 "cat"。
  2. 用 cin >> text 读取带空格句子。它在第一个空白处停止，整行文本应使用 getline。
  3. 前一次 cin >> 后直接 getline。输入流中的换行可能被立即读走，要按输入格式先处理分隔字符。
  4. 空串仍访问首尾字符。访问 text[0] 或 text[text.length() - 1] 前先检查 empty()。
  5. 把 find 返回的 0 当成失败。0 是第一个合法下标，失败标记是 string::npos。
  6. 未确认查找成功就调用 replace。必须先判断位置不等于 string::npos。
  7. 替换后仍使用旧长度。替换可能改变字符个数，后续访问要按新长度判断。
  8. 访问 s[s.size()]。字符串最后一个合法下标是 s.size() - 1，空串则没有合法下标。
  9. 把字典序误认为长度比较。字符串从左到右比较第一对不同字符，只有一方是另一方前缀时才由长度决定先后。
  10. 把 char text[105] 当作能保存 105 个普通字符。必须为末尾的 \0 留一个位置。
  11. 以为 string 自带 split()。C++14 的 string 没有这个成员函数；本课按分隔字符遍历、累积并在合适的位置输出片段。
  12. 调用 tolower() 或 toupper() 后不保存返回值。这两个函数返回转换后的字符，要写成 ch = tolower(ch) 或 s[i] = toupper(s[i])。
  13. 没有判断空串就访问 s[0]。先写 if (!s.empty())，确认存在首个字符后再访问。
  14. 分割时没有阅读题意就丢弃或保留空片段。开头、末尾和连续分隔字符都可能产生空片段，输出规则由题目决定。
