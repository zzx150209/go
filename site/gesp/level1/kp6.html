基本数据类型

06
GESP 1级知识字典 · 知识点 06

认识整型、浮点、字符和布尔类型的范围与选择方法。

检索词：int-doublechar-bool

本课先记住

  • 核心结论： 数据类型决定一个值怎样被解释、通常能保存多大以及参与运算时遵守什么规则；选择类型要同时检查输入范围和中间结果。
  • 常用语法： 整数常用 int、较大整数用 long long，小数常用 double，单个字符用 char，真假状态用 bool。
  • 最小示例： int age = 12; double score = 92.5; char grade = 'A'; bool passed = true;
  • 关键易错点： 数值范围不等于有效精度；整数除法会舍去小数部分，普通 char 的符号范围还可能随平台而不同。

知识范围与官方定位

变量像一个有名字的盒子，数据类型决定这个盒子准备保存什么、通常能保存多大，以及计算机怎样解释里面的数据。

例如，年龄 12、平均分 92.5、等级字符 'A' 和“记录是否完成”这四项数据看起来都很短，却不能用同一种规则理解：

数据 它回答的问题 合适的类型
12 有多少、是几 整数类型
92.5 带小数的测量或计算结果 浮点类型
'A' 是哪个单个字符 char
true 某件事是否成立 bool

选类型时，先别急着背类型名。按顺序问自己：

  1. 数据是整数、小数、单个字符，还是“真／假”状态？
  2. 如果是整数，输入值和计算过程中的最大结果有多大？
  3. 如果是小数，需要多大的数值范围和多少位可靠有效数字？
  4. 题目中的写法是否真的与选定类型匹配？

本页覆盖一级大纲中的整数、浮点、字符、布尔类型，并保留现有自测需要的最小类型转换知识。表中的字节数和范围以常见 GCC/OJ 环境为参考；C++ 在不同编译器和平台上的具体实现可能不同。

01 整数类型

整数类型保存没有小数部分的数，例如人数、次数、编号和总和。一级只学习 int 和 long long：普通整数优先用 int，较大整数或较大中间结果用 long long。

常见大小和范围

类型 常见字节数 常见有符号范围 初学时怎样看
int 4 字节 -2,147,483,648 到 2,147,483,647 普通整数的首选
long long 8 字节 -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 较大整数和较大中间结果

表中的字节数和范围以常见 GCC/OJ 环境为参考；选择时仍要以题目数据范围为准。一级竞赛代码需要保存较大整数时，直接检查是否应使用 long long，不扩展其他整数类型成员。

普通整数为什么优先用 int

int 能覆盖大多数一级题目的年龄、分数、计数和较小计算结果，写法也最直白：

int age = 12; // 年龄是普通整数，12 远在 int 的常见范围内int studentCount = 45; // 当前学生人数也适合用 int 保存

什么时候需要 long long

要同时检查输入值和计算结果。例如 100,000 个数，每个数最大是 100,000：

最大总和 = 100000 × 100000 = 10000000000

每个输入都能放进 int，但总和 10,000,000,000 已经超过 int 的常见上限，所以保存总和的变量应使用 long long。

long long total = 100000LL * 100000; // 先按 long long 做乘法，再保存 10000000000

LL 后缀说明这个整数常量按 long long 处理。不能只把左边改成 long long，却让右边先按范围较小的整数类型算完；中间结果溢出后，再放进更大的盒子也救不回来。

怎样验证整数类型是否合适

  1. 找出题目允许的最大绝对值。
  2. 写出加、减、乘过程中可能出现的最大中间结果。
  3. 与类型范围比较，不要只看最后答案。
  4. 用最大值附近的数据手算一次。

例如结果最多 1,000,000，int 足够；结果可能到 5,000,000,000，就应考虑 long long。即使使用 long long，范围也不是无限的，继续乘很大的数仍会溢出。

02 浮点类型与有效精度

浮点类型用来保存带小数的数据，例如温度、平均分、长度和计算得到的比值。一级主要认识 float 和 double。

范围和精度是两件事

类型 常见字节数 常见最大绝对值（约） 可靠有效数字（约）
float 4 字节 3.4 × 10³⁸ 6—7 位
double 8 字节 1.7 × 10³⁰⁸ 15—16 位

“最大绝对值”回答的是数能有多大；“有效数字”回答的是能可靠保留多少位有意义的数字。范围很大，不代表每一位都精确。

浮点数也能表示负数和 0。表格只用最大绝对值帮助比较数量级，没有列出所有接近 0 的表示形式。

什么是有效数字

有效数字从第一个非零数字开始计算，是整个数中可靠的总位数，不是“小数点后有几位”。

数 有效数字 为什么
123.456 6 位 从 1 数到 6
0.00123456 6 位 前导 0 只负责定位小数点，不计入
120.030 6 位 从第一个非零数字 1 开始，中间和末尾表示精度的 0 都计入

因此，“float 约有 6—7 位有效数字”不能理解成“永远保留小数点后 6—7 位”。把超过可靠位数的值保存进去时，末尾可能发生舍入：

float roughValue = 12345678.0f; // 8 位整数超过 float 常见可靠精度，末尾可能舍入double preciseValue = 12345678.0; // double 通常能可靠保留这 8 位数字

小数常量 3.14 默认按 double 看待；写成 3.14f 才明确表示 float 常量。一级小数计算通常优先使用 double，除非题目明确要求其他类型。

为什么小数有时不是完全精确

计算机内部用二进制保存数据，很多十进制小数不能用有限位二进制准确写完。于是 0.1、0.2 这样的值在内部通常只是非常接近原数。

这属于浮点表示的精度限制，并不是 double “算错了”。还要分清：

  • 保存精度：变量内部能可靠保留多少位有效数字；
  • 输出格式：屏幕上要求显示几位小数。

把结果显示成两位小数，并不会让内部存储自动变成“精确到两位”；反过来，屏幕只显示两位，也不代表变量内部只有两位。

怎样验证浮点类型是否合适

  1. 先确认结果确实可能有小数。
  2. 检查最大数量级是否在范围内。
  3. 再判断需要多少位可靠有效数字。
  4. 用普通小数和带前导零的小数各检查一次。
  5. 最后按题目要求核对输出位数，不把显示格式当成内部精度。

03 char 字符类型

char 保存一个字符，常见大小是 1 字节。字符常量必须用单引号：

char grade = 'A'; // grade 保存单个等级字符 Achar digit = '3'; // digit 保存字符 3，不是整数 3

下面三种写法表示的对象不同：

写法 含义 类型
'3' 单个字符 3 char
3 整数三 整数类型
"3" 由双引号包围的文本 不是普通 char

所以自测中问“字符常量 '3' 的类型”，应先看单引号，答案是 char，不能因为里面长得像数字就选 int。

字符在计算机内部也有编号。常见 ASCII 编码中，'0' 到 '9'、'A' 到 'Z'、'a' 到 'z' 各自连续，'0' 常见编号为 48，'A' 为 65。本页只用它说明“字符和整数不是同一个值”；字符编码和字符转换会在后续内容中系统学习。

普通 char 默认按有符号还是无符号解释，由编译器和平台决定。一级阶段把它用于普通单字符，不要依赖它保存负数，也不要把“1 字节”误解成“固定能保存 -128 到 127”。

04 bool 与逻辑值

bool 只表示两种逻辑状态：

bool recordReady = true; // 记录已经准备好，状态成立bool answerCorrect = false; // 记录答案尚不正确，状态不成立

true 和 false 必须小写。它们不是放在引号中的文字，也不是四种不同状态中的两个编号。

在常见 GCC/OJ 环境中，bool 通常占 1 字节；这不表示它有 256 种逻辑状态，它的逻辑值仍只有 false 和 true。普通 cout 输出时，false 通常显示 0，true 通常显示 1。

条件判断中，0 会被当作假，非 0 会被当作真。但写程序时应优先使用含义明确的状态名和比较条件，不要让读者猜一个数字代表什么。

需要记录的事情 是否适合 bool 原因
是否提交完成 是 只有完成／未完成两种状态
答案是否正确 是 只有正确／错误两种状态
学生得了多少分 否 分数有很多可能值
菜单选了第几项 否 编号不只两种

只有当问题本身只需要回答“是／否”时，才适合选择 bool。

05 类型转换

有时已有数据的类型与当前需要的结果不同，程序会发生类型转换。本页只讲现有一级自测需要的三条规则，完整运算规则在下一页继续学习。

浮点数转整数：向 0 截去小数部分

double value = -3.8; // 原变量保存小数 -3.8int whole = int(value); // 转成 int 后向 0 截断，whole 得到 -3
原值 转换 结果
3.14 int(3.14) 3
3.8 int(3.8) 3
-3.8 int(-3.8) -3

这不是四舍五入。转换得到的是一个新的整数值，原来的 value 仍保存 -3.8。

整数除法和浮点除法

当 a = 7、b = 2 时：

表达式 先发生什么 结果
a / b 两边都是整数，先做整数除法 3
a * 1.0 / b 1.0 让运算中出现浮点数 3.5
0.0 + a / b 先算 a / b = 3，再加 0.0 3.0
(0.0 + a) / b 括号内先得到浮点数 7.0，再除以 2 3.5

判断结果时，要看小数在整数除法之前还是之后参与运算。整数除法已经算完后再出现 0.0，丢掉的小数部分不会回来。

取余只用于整数

% 的两个操作数都必须是整数：

int remainder = 7 % 2; // 7 除以 2 余 1，两个操作数都是整数

7 % 2.5、3.14 % 2 和 8.0 % 3.0 都不符合 C++ 的取余规则。需要处理浮点运算时，不能直接套用整数取余写法。

怎样选择类型

如果数据是…… 先选择 还要检查
普通整数 int 输入和中间结果是否超过约 21 亿
较大整数 long long 结果是否仍在约 ±9.22 × 10¹⁸ 内
带小数的数据 double 范围、有效数字和题目输出要求
单个字符 char 是否确实只有一个字符、是否用了单引号
是／否状态 bool 问题是否真的只有两种状态

实际选择时按三步走：先按数据含义分类，再检查范围或精度，最后用边界数据验证。

典型例题

一个学习平台要保存一条统计记录：当前活跃学生数、历史提交总次数、平均分、等级字符，以及这条记录是否已经准备好。五项数据属于同一条记录，但含义和范围不同。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    int activeStudents; // 当前活跃人数是普通范围内的整数    long long totalSubmissions; // 历史提交总次数可能超过 int 上限    double averageScore; // 平均分可能带小数，优先使用 double    char level; // 等级只需要保存一个字符
    cin >> activeStudents >> totalSubmissions >> averageScore >> level;    bool recordReady = true; // 四项数据读入后，把“记录已准备”保存为真
    cout << "active students: " << activeStudents << endl;    cout << "total submissions: " << totalSubmissions << endl;    cout << "average score: " << averageScore << endl;    cout << "level: " << level << endl;    cout << "record ready: " << recordReady << endl;    return 0;}

输入：

45 8000000000 92.5 A

输出：

active students: 45total submissions: 8000000000average score: 92.5level: Arecord ready: 1

执行过程：

步骤 读入或形成的数据 为什么使用这个类型
1 activeStudents = 45 45 是普通整数，int 足够
2 totalSubmissions = 8000000000 80 亿超过 int 常见上限，使用 long long
3 averageScore = 92.5 平均分带小数，使用 double
4 level = 'A' 等级只有一个字符，使用 char
5 recordReady = true 只记录是否准备好，使用 bool
6 依次输出五项 普通输出中 true 显示为 1

这段程序展示了同一条记录中怎样根据数据含义和范围选择类型。把第二项错误地改成 int，输入 8,000,000,000 就可能超出范围；把第三项改成 int，92.5 的小数部分无法按原值保存。

引导练习（不记录进度）

为 2000000000、3000000000、0.000123456789 选择类型。先判断数据是整数还是小数，再检查常见范围或有效数字：第一项可用 int，第二项超过常见 int 上限应使用 long long，第三项需要保留较多有效数字时优先使用 double。

成功标准： 每项选择都同时写出“数据含义”和“范围或精度”依据。完成后不看本段答案，独立完成页末“整页综合测试”；提交后逐题核对解析，并能用边界值重新说明错题为什么不适合原类型。

常见错误

  1. 只看最后答案，不看中间结果。 右边先溢出后，再赋给 long long 已经太晚；要让较大类型在计算开始前参与。
  2. 把浮点范围和精度混为一谈。 能表示很大的数，不等于每一位都可靠。
  3. 把有效数字理解成小数位数。 123.456 与 0.00123456 都有 6 位有效数字。
  4. 字符引号写错。 单个字符写 'A'；"A" 不是普通 char。
  5. 把 bool 当成普通小整数。 它应表达“是否成立”，不能保存分数或多项菜单编号。
  6. 认为浮点转整数会四舍五入。 int(3.8) 得 3，int(-3.8) 得 -3，都是向 0 截断。
  7. 看到表达式里有 0.0 就断定结果一定是 3.5。 若整数除法已经先完成，丢掉的小数部分不会被后面的浮点数补回来。
  8. 把 % 用在小数上。 取余运算的两个操作数都必须是整数。

5 题

第 1 题字符常量 '3' 的数据类型是什么？

答案：C
单引号包围一个字符，得到 char 类型的字符常量。
对应知识点：03 常量

第 2 题当 a = 7、b = 2 时，下面哪个表达式的结果不是 3.5？

答案：A
A 中 a / b 先做整数除法得到 3，再与 0.0 相加得到 3.0。其余选项先把运算转为浮点除法。
对应知识点：02 浮点类型与有效精度

第 3 题下面哪个表达式符合 C++ 的取余规则？

答案：A
取余运算符 % 的两个操作数都必须是整数，只有 7 % 2 符合规则。
对应知识点：01 整数类型

第 4 题int(3.14) 的结果是什么？

答案：A
转换为 int 时会截去小数部分，因此得到 3。
对应知识点：05 类型转换

第 5 题要保存 true 或 false，最直接的数据类型是什么？

答案：A
bool 用于保存逻辑值 true 或 false，输出时通常显示为 1 或 0。
对应知识点：04 bool 与逻辑值
