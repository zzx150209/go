数据类型转换

04
GESP 2级知识字典 · 知识点 04

掌握隐式转换与强制转换，注意整数除法与精度丢失。

检索词：隐式转换强制转换

先观察一个现象：cout << ('C' + 2); 会输出整数 69，把同一个计算结果保存到 char 后却会输出字符 E。两个结果为什么不同？这正是本页要解决的问题。

本课先记住

  • 核心结论： ASCII 中空格为 32、'0' 为 48、'A' 为 65、'a' 为 97，数字、大写字母和小写字母各自连续；字符参与运算时先按编码值计算。
  • 常用语法： 转换前先检查字符范围，再明确结果要保存成整数还是字符：int code = static_cast<int>(ch);、char ch = static_cast<char>(code);；数字字符判断写成 ch >= '0' && ch <= '9'。
  • 最小示例： 数字字符和字母转换都建立在各自连续的编码范围上：'7' - '0' == 7，char upper = lower - 'a' + 'A';。
  • 关键易错点： 不要把字符 '7' 当成整数 7；不要写 '0' <= ch <= '9'；字符相减的结果是整数，不会自动按字符显示。

知识范围与官方定位

本页要认识 ASCII 编码的基本原理、常用字符编码和连续区间，并能在字符与整数编码之间转换。

本页只建立三个新核心：

  1. 记住空格、'0'、'A'、'a' 对应的编号，用连续区间推导其他编码；
  2. 在字符与编码之间双向转换，并追踪当前值、类型和输出形式；
  3. 先判断范围，再完成数字字符和 ASCII 英文字母大小写的基础转换。

开始前，只需要已经认识 char、int、cin/cout、比较、&& 和 if/else。完整的类型转换规则会在下一页系统学习。

计算机用整数编码保存字符。二级不要求背完整 ASCII 表，但要记住常用字符的编号、连续区间和字符参与运算时的结果。

本页先记住空格、'0'、'A'、'a' 四个常用 ASCII 字符的编号，再利用数字、大写字母、小写字母各自连续排列的规律，完成字符与编码、数字字符与整数、大小写字母之间的基础转换。

数字字符与整数的转换、ASCII 英文字母的大小写转换，是利用连续区间完成的两个小任务。完成它们，才算真正把编码规律用起来。

过程演示

分析字符运算时，依次记录四件事：当前值、当前类型、执行的操作、最终怎样输出。先看开头问题的最小过程：

cout << ('C' + 2) << endl;char letter = 'C' + 2;cout << letter << endl;
代码 运算后的值与类型 输出时的类型 屏幕结果
'C' + 2 69，int int 69
char letter = 'C' + 2 把整数 69 保存为 char char E

计算的中间值相同，显示不同，是因为输出时的类型不同。下面再解释 69 是怎样得到的。

01 ASCII 编码与常用字符

先记住下面四个常用字符的编号：

字符 ASCII 编码 用途
空格 32 认识空白字符的编码
'0' 48 推导数字字符
'A' 65 推导大写英文字母
'a' 97 推导小写英文字母

先区分三个概念：字符是 'A' 这样的符号；编码是计算机为字符规定的整数编号，例如 65；字形是屏幕或纸上画出的具体样子。ASCII 规定字符与整数怎样对应，不规定字体怎样画字母。

补充了解：为什么说 ASCII 是 7 位？

标准 ASCII 使用 7 个二进制位，编码范围是 0 到 127。C++ 规定 sizeof(char) 等于 1 Byte；在本项目常用的 G++ / OJ 环境中，一个 Byte 是 8 bit，因此一个 char 能保存本页使用的 ASCII 编码。ASCII 的 7 位范围和本环境中 char 占 1 Byte是两件相关但不同的事。

数字字符 '0' 到 '9' 连续排列，大写字母 'A' 到 'Z' 连续排列，小写字母 'a' 到 'z' 也连续排列。遇到同一段中的其他字符，可以从已经记住的字符开始往后数：

  • '3' 在 '0' 后面 3 格，所以编码是 48 + 3 = 51；
  • 'C' 在 'A' 后面 2 格，所以编码是 65 + 2 = 67。

不需要背完整 ASCII 表，但不能跨不同区间随意推算。

字符常量用单引号，如 'A'；双引号 "A" 表示字符串，不是单个 char。

字符 '1' 与整数 1 看起来相似，含义却不同：'1' 是编码为 49 的字符，1 是数值一。cout << '1' 和 cout << 1 都能在屏幕上显示 1，但 '1' + 1 得到整数 50，1 + 1 得到整数 2。判断类型不能只看屏幕上的符号。

02 字符编码与整数运算

char 参与加减运算时，会先提升为整数再计算。'C' 的编码是 67，所以 'C' + 2 得到 int 类型的 69。只有把这个结果保存或转换成 char，才会按编码 69 显示字符 E。

本页使用两个固定工具：

static_cast<int>(ch)    // 得到字符 ch 对应的整数编码static_cast<char>(code) // 得到整数 code 对应的字符

static_cast<目标类型>(值) 会产生本次使用的新结果，不会永久改变原变量的声明类型。先会用这两个固定写法即可；隐式转换、显式转换和更多类型组合留到数据类型转换页面学习。

cin >> ch 默认跳过空格、换行和制表符等空白，所以不能用下面的完整程序把键盘输入的空格直接读入第一项 ch。如果只想验证空格编码，可以在代码中保存字符常量：

char space = ' ';cout << static_cast<int>(space) << endl; // 输出 32

ASCII 中 0 到 31 是控制代码，127 是 DEL；32 到 126 通常作为可打印范围，其中 32 是显示为空白的空格。

下面唯一一份完整程序约定第一项是非空白可打印 ASCII 字符，第二项是 32 到 126 的编码。程序本身不检查输入范围；只有输入满足约定时，转换结果才是本课准备观察的字符。

完成程序

#include <bits/stdc++.h>using namespace std;
int main() {    char ch;    int code;    cin >> ch >> code;    cout << static_cast<int>(ch) << endl;  // 字符转成整数编码    cout << static_cast<char>(code) << endl;  // 编码转成可显示字符    return 0;}

输入样例：

A 66

输出样例：

65B

执行过程如下：

输入值与类型 操作 新结果与类型 屏幕输出
ch='A'，char static_cast<int>(ch) 65，int 65
code=66，int static_cast<char>(code) 'B'，char B

两次转换都只产生新的表达式结果：ch 仍是 char，code 仍是 int。如果第二项输入 32，第二行会输出一个空格，看起来像一行空白；本程序不把控制代码作为需要观察字形的输入。

**引导练习：**先尝试自己写出输入 0 57 时的两行输出，再逐格核对“当前值—类型—操作—新类型—输出”。

完成后展开核对

第一项 ch='0' 是 char，转换成 int 后得到 48，第一行输出 48。第二项 code=57 是 int，转换成 char 后得到 '9'，第二行输出 9；两个原变量的声明类型都没有改变。

03 数字字符的判断与转换

先观察：'8' - '0' 得到整数 8；':' - '0' 也能算出整数 10，但 ':' 并不是数字字符。能算出差值，不等于输入合法，所以第一步必须判断字符是否落在连续的数字区间：

if (ch >= '0' && ch <= '9') {  // 两个边界必须同时满足    cout << "digit" << endl;} else {    cout << "not digit" << endl;}

确认范围后，利用与 '0' 的距离完成双向转换：

目标 具体计算 中间整数 最终结果
字符 '7' 转数值 '7' - '0' 55 - 48 = 7 整数 7
整数 7 转字符 '0' + 7 48 + 7 = 55 保存到 char 后为 '7'

整数转数字字符前，必须保证整数在 0 到 9 之间。若 x=12，'0' + x 得到编码 60，对应的不是字符 '12'；一个 char 也不能同时保存两个字符。

不能写 '0' <= ch <= '9'。C++ 会先计算 '0' <= ch，得到 0 或 1，再把这个结果与 '9' 比较，并不是数学中的连续不等式。正确写法是 ch >= '0' && ch <= '9'。

04 英文字母大小写转换

在 ASCII 中，对应的英文字母大小写编码相差 'a' - 'A'，结果是 32。这个规律只用于 ASCII 英文字母：如果不判断范围就给 '?' 加 32，会得到字符 '_'，这不是大小写转换。因此，转换前必须先检查字符属于哪一段。

if (ch >= 'A' && ch <= 'Z') {    ch = ch + ('a' - 'A');} else if (ch >= 'a' && ch <= 'z') {    ch = ch - ('a' - 'A');}cout << ch << endl;

输入 b 时：

  1. 大写区间判断为假，小写区间判断为真；
  2. 'b' 的编码 98 减去 32，得到整数 66；
  3. 66 保存回 char ch，对应字符 'B'；
  4. cout << ch 输出 B。

输入 ? 时，两个范围判断都不成立，程序不会加减 32，仍输出 ?。范围判断不是装饰，它防止数字和标点被错误移动到其他编码位置。

知识点速查表

目标 前提 写法
查看字符编码 ch 是本页讨论的 ASCII 字符 static_cast<int>(ch)
编码转字符 code 已确认在目标 ASCII 范围 static_cast<char>(code)
判断数字字符 无 ch >= '0' && ch <= '9'
数字字符转整数 已确认 '0' 到 '9' ch - '0'
0—9 转数字字符 x 在 0 到 9 '0' + x，再保存到 char
大写转小写 已确认 'A' 到 'Z' upper + ('a' - 'A')
小写转大写 已确认 'a' 到 'z' lower - ('a' - 'A')

典型例题

**题目：**比较 char ch='4'; ch=ch+2; cout<<ch; 与 cout<<('4'+2); 的输出。

推演：

  1. '4' 的编码是 52，加 2 后中间结果都是 int 类型的 54；
  2. 第一段把 54 保存回 char ch，编码 54 对应字符 '6'，所以输出 6；
  3. 第二段直接输出整数表达式，没有转回 char，所以输出数值 54。

**结论：**两段计算的中间整数相同，最终显示不同，是因为保存或输出时的类型不同。

**引导练习：**字符 ch='8' 的编码是 56。请分别计算 ch-'0'、ch+1 直接交给 cout、以及 char next=ch+1; cout<<next; 的结果。提示：先写出中间整数，再看输出时是 int 还是 char。核对结果依次是整数 8、整数 57、字符 9；若把第二项也写成字符 9，说明漏看了表达式结果类型。

容易混淆的几个问题

  • **把字符 '7' 当成整数 7：**计算会相差 48。先确认范围，再用 '7' - '0' 得到数值 7；回看 03 数字字符。
  • **只算编码，不追踪类型：**整数 54 可能输出 54，保存为 char 后却会输出 6。每一步都写清结果类型；回看 02 字符编码与整数运算。
  • **写连续不等式 '0' <= c <= '9'：**左边比较会先变成 0 或 1。立即改成 c >= '0' && c <= '9'；回看 03 数字字符。
  • **不检查范围就转 char 或直接加减 32：**可能把标点变成另一个无关字符。先检查目标编码、数字或字母区间；回看 03 数字字符 和 04 大小写转换。
  • **写 char c = "A";：**双引号表示字符串，不能保存到单个 char。立即改成单引号 char c = 'A';；回看 01 ASCII 编码与常用字符。

**修正后复演：**依次代入 '/'、'0'、'9'、':'。只有 '0' 和 '9' 同时满足上下边界，前后的标点都应进入 else；这四个结果正好检查两个等号和两个区间外边界。

输出编码时也要明确类型：cout << c; 输出字符本身，cout << static_cast<int>(c); 才输出对应整数编码。

本节总结

ASCII 用整数给字符编号。记住空格、'0'、'A'、'a' 对应的编号，再利用数字、大写字母和小写字母各自连续的规律，就能推导常用编码。字符参与算术时先得到整数结果；之后是显示整数还是字符，要看结果最终以 int 还是 char 保存和输出。数字与大小写转换都必须先检查范围。

进入综合测试前

达到下面三项，才算真正学会：

  1. 不查完整表，能从一个已知字符的编号推导另一个数字字符或英文字母的编码；算错时回看 01 ASCII 编码与常用字符；
  2. 能解释 A → 65、66 → B 的每一步值和类型；混淆输出时回看 02 字符编码与整数运算；
  3. 能先判断范围，并分别完成一次数字字符双向转换和一次 ASCII 英文字母大小写转换；数字边界回看 03 数字字符，字母边界回看 04 大小写转换。

三个核心自检

  1. 不查表，从 'A'=65 推导 'G' 的编码；
  2. 写出完整程序输入 B 97 时的两行输出，并说出两次转换后的类型；
  3. 先写范围判断，再分别完成：字符 '8' 转整数、整数 3 转字符、字符 'd' 转大写；同时说明为什么标点 '?' 不应加减 32。
三题都完成后展开核对
  1. 'G' 在 'A' 后 6 格，编码是 65 + 6 = 71。
  2. 第一行是 66，结果类型为 int；第二行是 a，结果类型为 char。
  3. '8' - '0' 得整数 8；'0' + 3 的整数结果保存为 char 后得到 '3'；'d' 在 'a' 到 'z' 内，减去 32 后得到 'D'。'?' 不在两个英文字母区间内，直接加减 32 只会把它变成无关标点。
