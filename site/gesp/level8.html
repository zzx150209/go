01 官方核心未复习

计数原理

掌握加法原理与乘法原理，区分分类与分步。

加法原理乘法原理
核心要点
  • 加法原理：完成一件事有多种互斥方案，方案数相加。
  • 乘法原理：完成一件事分多个步骤，每步方法数相乘。
  • 区分分类与分步：分类是'或'的关系，分步是'且'的关系。
  • 容斥原理：|A∪B| = |A| + |B| - |A∩B|。
注意事项
  • 先分类再分步，确保不重不漏。
  • 题目有'至少''至多'时考虑容斥。
02 官方核心未复习

排列与组合

计算排列数与阶乘，理解组合数的意义与性质。

排列数组合数
核心要点
  • 排列 P(n,k) = n! / (n-k)!，从 n 个中选 k 个排列。
  • 组合 C(n,k) = n! / (k!(n-k)!)，从 n 个中选 k 个不排序。
  • 组合性质：C(n,k) = C(n,n-k)，C(n,k) = C(n-1,k-1) + C(n-1,k)。
  • 阶乘增长极快，n=20 就超过 int，n=100 需高精度或模运算。
// 用递推公式求组合数（杨辉三角）
long long C[105][105];
for (int i = 0; i <= n; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++)
        C[i][j] = C[i-1][j-1] + C[i-1][j];
}
注意事项
  • n 不大时用递推，n 大时用乘法逆元求组合数。
  • C(n,0)=1, C(n,n)=1, C(n,1)=n。
03 官方核心未复习

杨辉三角

处理边界条件，用递推与预处理求组合数。

边界条件组合数递推
核心要点
  • 杨辉三角第 i 行第 j 列等于 C(i,j)。
  • 递推公式：C[i][j] = C[i-1][j-1] + C[i-1][j]。
  • 边界：C[i][0] = C[i][i] = 1。
  • 预处理后 O(1) 查询组合数。
const int MOD = 1e9 + 7;
long long C[1005][1005];
for (int i = 0; i <= 1000; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++)
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
}
注意事项
  • 模运算要在每次加法后取模，防止溢出。
  • 空间优化：每行只依赖上一行，可用一维数组倒序更新。
04 官方核心未复习

倍增

用二进制拆分与倍增预处理实现快速查询。

二进制拆分倍增查询
核心要点
  • 倍增：把区间长度按 2 的幂次分解，预处理跳 2^k 步的结果。
  • 经典应用：快速求 LCA（最近公共祖先）、ST 表求区间最值。
  • 预处理 O(n log n)，查询 O(log n)。
  • 二进制拆分：任何数都可表示为若干 2 的幂之和。
// ST表求区间最大值（简述）
int st[18][100005];
for (int i = 1; i <= n; i++) st[0][i] = a[i];
for (int k = 1; (1<<k) <= n; k++)
    for (int i = 1; i + (1<<k) - 1 <= n; i++)
        st[k][i] = max(st[k-1][i], st[k-1][i+(1<<(k-1))]);

int queryMax(int l, int r) {
    int k = log2(r - l + 1);
    return max(st[k][l], st[k][r-(1<<k)+1]);
}
注意事项
  • ST 表适用于静态数组（不修改）的区间查询。
  • log2 用 __lg() 或循环计算，精度问题注意。
05 官方核心未复习

数列与代数

对表达式化简，处理等差数列与等比数列。

数列求和表达式化简
核心要点
  • 等差数列：a_n = a_1 + (n-1)d，和 S_n = n(a_1+a_n)/2。
  • 等比数列：a_n = a_1 * q^(n-1)，和 S_n = a_1(1-q^n)/(1-q)（q≠1）。
  • 常见求和公式：Σi = n(n+1)/2，Σi² = n(n+1)(2n+1)/6。
  • 代数化简：先化简表达式再计算，避免大数中间结果。
注意事项
  • 等比数列求和 q=1 时单独处理，就是 n*a1。
  • 取模除法要用乘法逆元。
06 官方核心未复习

几何计算

计算面积与周长、坐标距离，注意退化图形。

坐标距离退化图形
核心要点
  • 两点距离：√((x2-x1)² + (y2-y1)²)，不开方用平方距离比较。
  • 三角形面积：叉积公式 |(B-A)×(C-A)| / 2。
  • 多边形面积： shoelace 公式，按顶点顺序累加叉积。
  • 注意退化情况：三点共线面积为 0，点在边上。
struct Point { double x, y; };
double dist(Point a, Point b) {
    return sqrt((a.x-b.x)*(a.x-b.x) + (a.y-b.y)*(a.y-b.y));
}
double cross(Point a, Point b, Point c) {
    return (b.x-a.x)*(c.y-a.y) - (b.y-a.y)*(c.x-a.x);
}
double triangleArea(Point a, Point b, Point c) {
    return fabs(cross(a,b,c)) / 2.0;
}
注意事项
  • 浮点计算注意精度，用 epsilon 判断相等。
  • 叉积正负表示方向（左转/右转）。
07 官方核心未复习

图算法选择

根据顶点、边、方向与权值选择合适的图算法。

图建模算法选择
核心要点
  • 根据问题选算法：连通性→DFS/BFS，最短路→Dijkstra/SPFA/Floyd。
  • 最小生成树→Prim（稠密图）或 Kruskal（稀疏图）。
  • 边权正负决定算法：有负权用 SPFA，无负权用 Dijkstra。
  • 顶点数小（n≤500）可用 Floyd O(n³)，顶点多用邻接表优化。
注意事项
  • 先分析数据范围再选算法，不要套模板不思考。
  • 建图时注意有向/无向、是否有权重。
08 官方核心未复习

最小生成树

理解生成树与最小生成树，实现 Prim 与 Kruskal。

PrimKruskal
核心要点
  • 生成树：连通所有顶点且无环，n 个顶点 n-1 条边。
  • 最小生成树（MST）：所有生成树中边权之和最小的。
  • Kruskal：把边按权排序，依次加入不形成环的边（并查集）。
  • Prim：从一个点出发，每次选距离树最近的点加入。
// Kruskal
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end(), cmp);
    init(n);
    int total = 0, cnt = 0;
    for (auto& e : edges) {
        if (find(e.u) != find(e.v)) {
            unite(e.u, e.v);
            total += e.w;
            if (++cnt == n-1) break;
        }
    }
    return total;
}
注意事项
  • Kruskal 适合稀疏图，Prim 适合稠密图。
  • MST 不唯一但权值和唯一。
09 官方核心未复习

单源最短路

理解松弛操作，实现 Dijkstra 与负权处理。

松弛操作Dijkstra
核心要点
  • Dijkstra：边权非负，用优先队列每次取最近点松弛，O((n+m)log n)。
  • 松弛操作：若 dist[u]+w(u,v) < dist[v]，则更新 dist[v]。
  • 有负权边用 Bellman-Ford 或 SPFA。
  • 多源最短路用 Floyd O(n³)，或把所有源点加入队列。
// Dijkstra
vector<pair<int,int>> adj[MAXN];
int dist[MAXN];
void dijkstra(int s) {
    fill(dist, dist+MAXN, INF);
    dist[s] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}
注意事项
  • Dijkstra 不能处理负权边，会死循环或结果错误。
  • 优先队列里的旧条目用 if(d > dist[u]) continue 跳过。
10 官方核心未复习

复杂度分析

分析常见算法复杂度，按数据范围选择算法。

复杂度范围判断
核心要点
  • 常见图算法复杂度：Dijkstra O((n+m)log n)，Floyd O(n³)，Kruskal O(m log m)。
  • 根据 n 和 m 选算法：n≤500 可用 Floyd，m 大用 Kruskal。
  • 优化常数：邻接表比矩阵快，优先队列比朴素实现快。
  • 空间复杂度也要考虑：邻接矩阵 O(n²)，邻接表 O(n+m)。
注意事项
  • 时间紧时先写正确的暴力版，再想优化。
  • 注意递归 DFS 的栈空间限制。
11 官方核心未复习

空间优化

优化数组空间与图存储，使用滚动数组。

滚动数组图存储
核心要点
  • 滚动数组：DP 只依赖前一行/前一层时，用两个数组交替。
  • 01 背包的一维数组本身就是空间优化（O(W)）。
  • 图存储：链式前向星比邻接表数组更紧凑。
  • 不必要的数组及时释放或用局部变量。
// 滚动数组优化 DP
int dp[2][MAXN];
for (int i = 1; i <= n; i++) {
    int cur = i % 2, prev = 1 - cur;
    for (int j = 1; j <= m; j++) {
        dp[cur][j] = max(dp[prev][j], dp[cur][j-1]) + a[i][j];
    }
}
注意事项
  • 滚动数组时注意当前行和上一行的交替关系。
  • 内存不够时考虑用 short 或 char 代替 int。
12 官方核心未复习

算法优化

在暴力与剪枝、预处理与数学优化之间做出选择。

暴力剪枝预处理
核心要点
  • 暴力→剪枝：提前排除不可能的情况，如 DFS 中当前解已劣于最优解则剪枝。
  • 预处理→离线：把需要多次查询的量预处理出来。
  • 数学优化：用公式或数论结论替代暴力枚举。
  • 位运算优化：用位操作替代计数/标记。
注意事项
  • 优化前先确认瓶颈在哪里，不要盲目优化。
  • 常数优化：用快读、减少模运算次数、循环展开。
