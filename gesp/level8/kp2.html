知识范围与官方定位

官方八级要求掌握排列、组合、阶乘、排列数与组合数，并能用 DFS 完成基础排列、组合枚举。本页只处理互不相同元素；含重复元素的去重排列不作为本页核心。

01 排列与组合的区别

从若干元素中选出一些元素，若交换顺序会产生新方案，就是排列；若只关心选了哪些元素，交换顺序仍是同一方案，就是组合。

从 5 人中选班长和副班长，职位有顺序，是排列；从 5 人中选 2 人参赛，不分角色，是组合。先问“交换两个人后是否算新方案”，通常就能判断。

02 阶乘与全排列

n! = n × (n-1) × ... × 2 × 1，并规定 0! = 1。n 个互不相同元素的全排列有 n! 种。例如 1、2、3 的全排列共有 3! = 6 种。

阶乘增长非常快：10! = 3628800。枚举全排列时不仅要考虑计算时间，还要考虑输出本身已经有 n! 组。

03 部分排列

从 n 个不同元素中选 m 个并安排顺序，排列数为：

A(n,m) = n × (n-1) × ... × (n-m+1) = n! / (n-m)!

从 5 人中选班长和副班长，班长有 5 种选择，副班长剩 4 种，共 5 × 4 = 20 种。

04 DFS 生成排列

DFS 逐个填写位置，used[value] 表示数字是否已在当前排列中。递归返回后必须撤销标记，才能尝试其他方案。下面输出 1..n 的全排列，约定 1 <= n <= 9。

#include <bits/stdc++.h>using namespace std;
int n;int path[10];bool used[10];
void generatePermutation(int position) {    if (position > n) {        for (int i = 1; i <= n; i++) {            cout << path[i] << (i == n ? '\n' : ' ');        }        return;    }
    // 当前层选择还没有出现在排列中的数字。    for (int value = 1; value <= n; value++) {        if (used[value]) {            continue;        }        path[position] = value;        used[value] = true;        generatePermutation(position + 1);        // 回到当前层后恢复现场，继续尝试其他数字。        used[value] = false;    }}
int main() {    cin >> n;    generatePermutation(1);    return 0;}

时间复杂度为 O(n × n!)，数组和递归栈使用 O(n) 额外空间。

05 组合数与基本性质

C(n,m) 表示从 n 个不同元素中选 m 个且不考虑顺序的方案数：

C(n,m) = n! / (m!(n-m)!)

边界为 C(n,0)=C(n,n)=1，对称性为 C(n,m)=C(n,n-m)。直接使用阶乘公式时，中间乘积可能先溢出，较大范围应使用下一页的递推预处理。

06 DFS 生成组合

组合枚举让所选数字严格递增。参数 start 表示本层允许选择的最小数字，因此会生成 1,3，不会再生成顺序不同但集合相同的 3,1。

#include <bits/stdc++.h>using namespace std;
int n, m;int selected[25];
void choose(int position, int start) {    if (position > m) {        for (int i = 1; i <= m; i++) {            cout << selected[i] << (i == m ? '\n' : ' ');        }        return;    }
    int remaining = m - position + 1;    int largestStart = n - remaining + 1;    // 只从 start 往后选，保证组合递增且不重复。    for (int value = start; value <= largestStart; value++) {        selected[position] = value;        choose(position + 1, value + 1);    }}
int main() {    cin >> n >> m;    choose(1, 1);    return 0;}

程序约定 1 <= m <= n <= 20 且输出规模可接受。时间复杂度为 O(C(n,m) × m)，额外空间为 O(m)。

位置填写追踪。 从 A、B、C 中选 2 个按顺序站到第 1、2 个位置：第 1 个位置有 3 种选择；选定后，第 2 个位置只剩 2 种，共 3×2=6 种。AB 与 BA 是不同方案，所以这是排列。

选与不选追踪。 从 A、B、C 中选 2 人组队，可按是否选择 A 分类：选择 A 时，还需从 B、C 中选 1 人，共 2 种；不选 A 时，只能选择 B、C，共 1 种，因此 C(3,2)=2+1=3。这正对应组合数递推中的两部分。

边界要单独核对：n=1 时全排列只有 1 种；m=0 时“一个也不选”仍是一种合法组合；m=n 时只能全部选中。若 m>n，题目输入本身不合法，不能继续套公式或进入 DFS。

逐段具体推演（对应 01—06）。

01 判断模型。 从甲、乙、丙中选两人：若担任班长和副班长，甲乙 与 乙甲 职位不同，所以是排列；若只是组成两人小组，交换后成员没变，所以是组合。

02 全排列。 3 人排队时，第 1 位有 3 种选择；假设先放甲，第 2 位只剩 2 种，第 3 位被唯一确定，因此共 3×2×1=6。n=1 时只有排列 1，所以 1!=1，递归应输出一次。

03 部分排列。 5 人选班长和副班长：班长 5 种，副班长不能重复，只剩 4 种，中间结果是 5×4=20。只填两个职位，不再乘剩余的 3、2、1。

04 排列 DFS。 n=3 时先选 1，状态变为 path=[1]、used[1]=true；再选 2、3 后输出 123。返回上一层时先弹出 3 并令 used[3]=false，才可能继续得到 132。

05 组合数。 从 5 人选 2 人，先按排列得到 5×4=20；每组如 {甲,乙} 被 甲乙、乙甲 算两次，所以 20÷2=10。C(5,0)=1 表示一人也不选这一种方案。

06 组合 DFS。 从 {1,2,3,4} 选 2 个：先选 1 后只尝试 2、3、4，得到 12、13、14；先选 2 后只尝试 3、4，得到 23、24；最后是 34，共 6 个，不会再生成 21。

知识点速查表

全排列 是 n!

典型例题

从 6 人中选 3 人，分别担任队长、记录员和联络员。三个职位不同，交换人员会产生新方案，因此是部分排列：A(6,3)=6×5×4=120。若只是组成 3 人小组，则是组合：C(6,3)=20。

常见错误

回溯恢复反例。 第一次输出 123 后若只弹出 3，却忘记把 used[3] 改回 false，后面的分支会一直认为 3 已被占用，132、213 等答案都会丢失。正确顺序是“递归返回 → 弹出本次选择 → 恢复访问标记”。

  • 只看到“选人”就使用组合；应先检查角色和顺序。
  • 忘记 0! = 1 或 C(n,0)=1；这些是公式和递推边界。
  • 排列 DFS 返回后没有恢复 used；会遗漏后续方案。
  • 组合 DFS 每层都从 1 开始；会产生重复选择和重复组合。
  • 忽略 n!、C(n,m) 的输出规模与整数溢出。

  • 杨辉三角：不用阶乘也能递推组合数。

10 题

第 1 题3 名同学站成一排，共有多少种不同站法？

答案：B
第一个位置有 3 人可选，第二个位置剩 2 人，第三个位置剩 1 人。根据乘法原理，排列数是 3 × 2 × 1 = 3! = 6。
对应知识点：02

第 2 题从 5 人中选 2 人分别担任班长和副班长，共有多少种安排？

答案：C
两个职位不同，交换人选会得到不同方案。班长有 5 种选择，副班长剩 4 种，因此共有 5 × 4 = 20 种。
对应知识点：03

第 3 题DFS 生成 1 到 n 的全排列时，used[x] 通常表示什么？

答案：A
当前排列中每个数字只能使用一次。used[x] 记录数字 x 是否已经被选择，递归返回时再恢复为未选择，以便尝试其他位置。
对应知识点：04

第 4 题4 个互不相同元素的全排列数量是多少？

答案：D
全排列数量为 4!。逐步计算 4 × 3 × 2 × 1 = 24，因此答案是 24。
对应知识点：02

第 5 题从 5 人中选 2 人参加比赛，不区分先后顺序，共有多少种选法？

答案：B
先按顺序选择会得到 5 × 4 = 20 种，但每组两人会因交换顺序被计算 2 次，所以组合数为 20 ÷ 2 = 10。
对应知识点：05

第 6 题DFS 枚举组合时，让下一次只从当前数字之后开始选择，主要作用是什么？

答案：B
组合不区分选择顺序。下一层从当前数字之后开始，使所选数字严格递增，例如只产生 1,3 而不再产生 3,1，从而避免重复。
对应知识点：06

第 7 题C(6, 0) 的值是多少？

答案：B
从 6 个元素中选择 0 个，只有“一个也不选”这一种方案，因此 C(6, 0) = 1。这也是组合数递推的边界。
对应知识点：05

第 8 题下面哪一项正确体现了组合数的对称性？

答案：B
选择 k 个元素后，剩下的 n-k 个元素也随之唯一确定，所以“选 k 个”和“确定不选的 n-k 个”方案一一对应，即 C(n,k)=C(n,n-k)。
对应知识点：05

第 9 题从 8 名同学中选出 3 人组成不分职位的小组，应优先使用哪类计数？

答案：B
小组内没有不同职位，交换三人的选择顺序不会产生新方案，因此顺序不影响结果，应使用组合数 C(8,3) 而不是排列数。
对应知识点：01

第 10 题只有 1 个互不相同的元素时，它的全排列数量和唯一排列分别是什么？

答案：B
唯一元素只能放在唯一位置，因此 1!=1，唯一排列就是 1。DFS 放入这个元素后达到递归终点，应恰好输出一次。对应页内知识点 02。
对应知识点：02

只保留本页最近一次完整提交结果；重新测试不会改变“已复习”状态。
