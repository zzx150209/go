简单动态规划

按状态定义、初值、转移、顺序和答案五步建立一维动态规划。

  • 01动态规划基础
  • 02线性动态规划

01 状态定义

动态规划保存已经求出的子问题答案，避免重复计算。第一步必须写清 dp[i] 的唯一含义，例如“走到第 i 级台阶的方案数”。状态含义决定后面的所有公式。

02 初值与转移

爬楼梯每次走 1 或 2 级时，dp[1]=1、dp[2]=2。到第 i 级的最后一步来自 i-1 或 i-2，两类方案互不重复，所以 dp[i]=dp[i-1]+dp[i-2]。

03 顺序与答案

因为当前状态依赖更小下标，必须从小到大计算。题目问第 n 级，答案就是 dp[n]，不能凭数组习惯改成 dp[n-1]。

#include <bits/stdc++.h>using namespace std;int main() {    int n;    cin >> n;    int dp[46] = {};    // 初始化最小的两个状态，避免转移时访问不存在的下标    dp[1] = 1;    if (n >= 2) {  // n 至少为 2 时，第二个初值才会成为有效状态        dp[2] = 2;    }    for (int i = 3; i <= n; i++) {  // 从小到大计算每一级的方案数        dp[i] = dp[i - 1] + dp[i - 2];  // 最后一步分别来自前一级或前两级    }    cout << dp[n] << '\n';    return 0;}

限定 1 <= n <= 45 时答案在 int 范围内。时间与空间复杂度均为 O(n)。

测试案例

类型 输入 应得到的结果

边界 n=2 走 1+1 或直接走 2，共 2 种
基础 n=5 状态依次为 1、2、3、5、8，答案 8
特殊 较大的 n=45 应在 int 范围内得到正确结果，并检查数组空间和溢出边界

常见错误

状态定义与答案下标不一致

原因：题目目标是第 n 级，答案位置应与定义一致。

检查方法：公式写完后重新读一遍 dp[i] 表示什么。

先套转移再补初值

原因：最小状态没有更小的合法来源，会访问负下标或未定义状态。

检查方法：把初始化、转移起点和数组下标放在一起检查。

整页综合测试

5 题

第 1 题动态规划第一步最应写清什么？

答案：A
状态含义决定初值、转移和答案位置；含义不清时，后续公式即使形式相似也容易出错。
对应知识点：01

第 2 题爬楼梯每次走 1 或 2 级，dp[i] 表示到第 i 级方案数，转移是什么？

答案：B
最后一步来自 i-1 或 i-2，两类方案互不重复，因此方案数相加。
对应知识点：02

第 3 题同一状态定义下，dp[1]、dp[2] 应是多少？

答案：C
到第 1 级只有一种走法，到第 2 级有 1+1 和 2 两种走法，所以是 1、2。
对应知识点：02

第 4 题转移读取 dp[i-1] 和 dp[i-2] 时，应按什么顺序计算？

答案：A
从小到大才能保证计算当前状态前，依赖的两个较小下标已经得到正确结果。
对应知识点：03

第 5 题最大连续和入门中，dp[i] 表示“以第 i 个数结尾的最大和”，答案应怎样取得？

答案：B
最优连续段可能在任意位置结束，因此要在所有“以 i 结尾”的状态中取最大值。
对应知识点：04
