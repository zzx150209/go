结构体

05
GESP 4级知识字典 · 知识点 05

定义结构体类型与对象，访问成员，使用结构体数组。

检索词：成员访问结构体数组

结构体把同一个对象的不同类型数据组合在一起。例如管理学生、图书或比赛记录时，可以把姓名、编号和成绩等相关数据放进一个整体。

本课先记住

核心结论

结构体先定义“一个对象有哪些字段”，再创建对象；对象用点访问成员，结构体指针用箭头访问成员。

常用语法

struct Student { // 开始定义学生这种新类型
    string name; // 声明姓名成员
    int score; // 声明分数成员
}; // 结束类型定义，分号不可省略

最小示例

Student student = {"Alice", 90}; // 按成员声明顺序创建并初始化对象
cout << student.score; // 用点运算符读取该对象的 score 成员

关键易错点

  • 定义结构体后忘记创建对象
  • 对象使用 -> 或指针使用 .
  • 大括号初始化顺序与成员声明顺序不一致

这节课要会什么

本课建立三个核心：把同一对象的相关字段组织成类型；沿“对象/下标—成员”准确访问数据；理解结构体对象、数组、指针和函数参数在内存中的关系。

从这个场景开始

一份学生档案不能只放一个整数：它还要记录姓名、年龄和成绩。结构体像一个贴好字段标签的档案袋，把属于同一对象的不同数据装在一起。

知识范围与官方定位

四级需要掌握结构体类型和对象的定义、成员访问、结构体数组、结构体指针、嵌套结构以及结构体参数的基本使用。

01 定义类型与对象

`struct Student { ... };` 定义的是一种新类型，说明每名学生对象包含哪些成员；它像统一的档案格式，本身还不是某名学生的数据。右大括号后的分号属于类型定义，不能省略。

写 `Student student;` 才创建具体对象。两个 Student 对象会分别拥有自己的 name 和 score，修改一个对象的成员不会自动改变另一个对象。

一个结构体对象要为所有成员保存数据，但 `sizeof(Student)` 不保证等于各成员 sizeof 的简单相加：编译器可能为对齐加入填充，不同平台、编译器和标准库实现也可能不同。需要真实字节数时在目标环境使用 sizeof 实测，不背固定结论。

struct Student { // 定义一种包含姓名与分数的新类型
    string name; // 每个 Student 对象各自拥有一个姓名成员
    int score; // 每个 Student 对象各自拥有一个分数成员
}; // 完成类型定义，末尾必须写分号

Student student; // 根据 Student 类型创建一个具体对象
关键提醒：结构体定义末尾的分号不能遗漏；结构体大小受成员类型、对齐和环境影响，不能只把成员字节数机械相加。

02 成员访问与初始化

结构体对象使用点运算符访问成员：先确定左边是哪一个对象，再在这个对象内部选择右边的字段。`student.score` 与另一个对象的 `other.score` 是不同存储位置。

大括号初始化按成员声明顺序逐项对应。`Student student = {"Xiao Ming", 92}` 先给 name，再给 score；若顺序与类型不匹配会报错或表达错误含义。

本课使用按声明顺序的大括号初始化，不使用更高标准才提供的指定成员初始化。初始化后仍可用点运算符单独读取或修改成员。

Student student = {"Xiao Ming", 92}; // 按 name、score 的声明顺序初始化对象
cout << student.name << ' '; // 先读取并输出姓名成员
cout << student.score << '\n'; // 再读取并输出同一对象的分数成员

03 结构体数组

同一类对象可以放入结构体数组。`students[i].score` 分两步理解：先用合法下标 i 选中第 i 个 Student 对象，再用点运算符读取它的 score。

若按 1 下标保存 n 名学生，数组容量必须至少为 n+1，students[0] 留作占位；若按 0 下标，合法范围是 0 到 n-1。下面片段明确采用 1 下标。

找最高分时保存学生下标 best，而不只保存一个分数，这样姓名、分数等成员始终来自同一对象。相同最高分时不更新，可保留最先出现的学生。

  • 输入 Alice 88、Bob 95、Carol 91，best 初始指向 Alice
  • 读到 Bob 95 后 best 改为 Bob 的下标，Carol 91 不更新
  • 最后通过同一个 best 同时取姓名和成绩，输出 Bob 95
int best = 1; // 采用 1 下标，并把第 1 名学生设为初始候选
for (int i = 2; i <= n; i++) { // 从第 2 名遍历到第 n 名学生
    if (students[i].score > students[best].score) { // 比较当前学生与候选人的分数
        best = i; // 只在严格更高时更新，平分保留先出现者
    } // 结束是否更新最高分下标的判断
} // 结束全部学生遍历
cout << students[best].name << ' '; // 用 best 读取最高分学生姓名
cout << students[best].score << '\n'; // 用同一 best 读取对应分数

04 结构体指针与复合成员

指向结构体对象的指针用箭头运算符访问成员，`pointer->score` 等价于 `(*pointer).score`。箭头左侧必须是指向有效结构体对象的指针。

结构体成员还可以是另一个结构体，这叫结构体嵌套。`pointer->birthday.month` 从左向右分层定位：先沿指针找到 Student，再取其中的 Date 对象，最后取 month。

  • 先由 pointer->birthday 找到 student 内部的 Date 对象
  • 再用 .month 找到月份成员，读出 5
  • pointer 必须先指向仍然有效的 Student 对象
struct Date { // 定义表示日期的内层结构体类型
    int month; // 保存月份成员
    int day; // 保存日期成员
}; // 结束 Date 类型定义

struct Student { // 定义包含嵌套日期的学生类型
    string name; // 保存学生姓名
    Date birthday; // 用一个完整 Date 对象保存生日
}; // 结束 Student 类型定义

Student student = {"Xiao Ming", {5, 20}}; // 按层次初始化姓名和生日
Student* pointer = &student; // 让结构体指针指向仍然存在的 student 对象
cout << pointer->birthday.month << '\n'; // 先经箭头找到 birthday，再读取其中的 month

05 结构体作为函数参数

值传递会创建整个结构体的副本，函数内修改副本不影响原对象；引用参数直接操作原对象；指针参数通过地址访问对象并可以用 nullptr 表示缺少对象。

只读结构体时使用 `const Student&`，既避免复制，又禁止函数误改成员。需要加分时才使用 `Student&`，函数名和接口共同告诉调用者“原档案会改变”。

结构体若含数组或嵌套结构，这些成员仍属于整个对象。传值时复制的是整个对象内容，传引用时不创建完整副本。

void addPoint(Student& student) { // 用引用接收并准备修改原学生对象
    student.score = student.score + 1; // 直接把原对象的分数增加 1
} // 函数结束后，调用处学生对象保留新分数

典型例题

找出最高分学生

固定输入 3 名学生；姓名不含空格，分数在 int 范围内，程序输出最高分学生。

完成程序

#include <bits/stdc++.h> // 引入本程序需要的标准库
using namespace std; // 允许直接使用 cin、cout、string 等标准库名称

struct Student { // 定义描述一名学生的结构体类型
    string name; // 保存学生姓名
    int score; // 保存学生分数
}; // 结束 Student 类型定义，末尾分号不可省略

int main() { // 主函数是程序的入口
    Student students[3]; // 创建包含 3 名学生的结构体数组
    for (int i = 0; i < 3; i++) { // 依次访问每个合法数组元素
        cin >> students[i].name >> students[i].score; // 读入并保存同一学生的姓名和分数
    } // 结束学生信息输入循环

    int best = 0; // 用下标 0 的学生作为当前最高分候选
    for (int i = 1; i < 3; i++) { // 从第二名学生开始比较分数
        if (students[i].score > students[best].score) { // 判断当前学生是否超过候选学生
            best = i; // 保存新的最高分学生下标
        } // 结束是否更新候选人的判断
    } // 结束最高分学生查找循环

    cout << students[best].name << ' ' << students[best].score << '\n'; // 用同一下标输出姓名和分数
    return 0; // 返回 0，表示程序正常结束
} // 结束 main 函数
示例输入
Alice 88
Bob 95
Carol 91
示例输出
Bob 95

解题与执行过程

  1. 输入阶段依次创建并填写 3 个 Student 对象，结构体数组保持每名学生的 name 与 score 对应。
  2. best 初始为 0，表示当前候选对象是 Alice 88。
  3. 访问 students[i].score 比较成员；读到 Bob 95 时把 best 改为 1，Carol 91 不再更新。
  4. 最后通过同一个下标 best 访问姓名和分数，输出 Bob 95。

常见错误

结构体定义末尾漏分号

错误写法：struct Student { ... }。原因：结构体类型定义结束后必须有分号。正确写法：struct Student { ... };。

混用点和箭头

错误写法：对象 student 写成 student->score，或指针 pointer 写成 pointer.score。原因：左侧类型不同。正确写法：对象用 student.score，指针用 pointer->score。

结构体数组越界

错误写法：Student students[3] 却访问 students[3]。原因：合法下标只有 0、1、2。正确写法：先检查对象下标，再访问成员。

把类型名当成对象名

错误写法：定义 Student 类型后直接写 Student.score。原因：类型本身不是具体对象。正确写法：先创建 Student student，再使用 student.score。

比较后丢失对象对应关系

错误写法：只保存最高分数，最后无法确定对应姓名。原因：相关成员没有一起定位。正确写法：保存结构体对象下标，再通过该下标访问所有成员。
