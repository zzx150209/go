01 根据关系构造树

根据父子关系建树时，先确定唯一根，再把每个孩子连接到唯一父结点。根据边关系建树时还要结合题意判断边是否有方向；若是无向输入，遍历时需要记住父结点或访问状态，避免沿原边返回。

下面的二叉树将用于比较四种遍历：

1      /   \     2     3    / \   / \   4   5 6   7

02 三种递归遍历

“前、中、后”描述根相对左右子树的访问位置：前序是根、左、右；中序是左、根、右；后序是左、右、根。递归函数必须先判断空指针，再访问结点。

#include <bits/stdc++.h>using namespace std;
struct Node {    int value;    Node* left;    Node* right;};
void preorder(Node* root) {    if (root == nullptr) {  // 当前子树为空，没有结点需要访问        return;    }    // 前序遍历先访问根，再依次处理左、右子树    cout << root->value << ' ';    preorder(root->left);    preorder(root->right);}
int countNodes(Node* root) {    if (root == nullptr) {  // 空树的结点数为 0        return 0;    }    // 当前根计 1，再加上左右子树的结点数    return 1 + countNodes(root->left) + countNodes(root->right);}
int main() {    Node n4{4, nullptr, nullptr};    Node n5{5, nullptr, nullptr};    Node n2{2, &n4, &n5};    Node n3{3, nullptr, nullptr};    Node n1{1, &n2, &n3};    preorder(&n1);    cout << '\n' << countNodes(&n1) << '\n';    return 0;}

输出第一行为 1 2 4 5 3，第二行为 5。每个结点只处理一次，时间复杂度 O(n)；递归额外空间与树高有关。

测试案例

类型 输入树 应得到的关键结果
基础 根 1，左孩子 2，右孩子 3 前序 1 2 3，中序 2 1 3，后序 2 3 1
边界 空树 四种遍历都不输出，结点数和叶结点数都是 0
特殊 单结点树 8 四种遍历都只输出 8；它既是根也是叶结点
特殊 7 个结点的完全二叉树 层序为 1 2 3 4 5 6 7，可检查同层从左到右

常见错误

先访问结点再判断空指针

× 错误写法cout << root->value; if (root == nullptr) return;
✓ 正确写法函数开头先判断 root == nullptr，再读取成员

原因：root 为空时已经先发生非法访问。

检查方法：把空树出口写成每个树递归函数的第一段。

只背前中后名称，不看根的位置

× 错误写法把中序也写成先输出根，再遍历左右子树
✓ 正确写法先写出规则，再把访问根的语句放到相应位置

原因：前、中、后表示根分别在左右子树之前、中间或之后访问。

检查方法：用只有三个结点的小树手算一次最容易发现顺序错误。
