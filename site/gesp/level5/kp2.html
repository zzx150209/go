最大公约数

02
GESP 5级知识字典 · 知识点 02

用欧几里得算法求最大公约数，并推导最小公倍数与分数约分。

检索词：辗转相除最小公倍数
02

两个数很小时，我们还能从较小的数开始逐个试除；可输入接近 10^9 时，这样检查会很慢。欧几里得算法抓住“用余数替换后，公共约数不会改变”这一点，让第二个数不断变小，最后直接得到最大公约数。本课会把这个理由、循环过程和三个常见应用连成一条完整路线。

知识范围与官方定位

对应 GESP 五级“欧几里得算法”：会用辗转相除法求最大公约数，并能在明确的整数范围与零边界下计算最小公倍数、完成分数约分和多个数的最大公约数。

本页只使用一级至五级已经学习的语法和能力；小知识点按页内编号连续查询，不设置前置完成门槛。

是什么
这是一节独立算法课：先证明余数替换为什么不改变答案，再把替换写成能处理负数和 0 的循环。
解决什么问题
学完后，你能求两个整数的非负 gcd 与 lcm，并把同一个 gcd 用到规范约分和多个数的公共因数计算。
什么时候使用
看到最大等长切分、分数约分、同时分组或多个整数的共同尺度时，可以先判断问题是否需要 gcd；遇到周期同时发生时还常会继续用 lcm。
核心思想
若 a=q×b+r，那么 (a,b) 与 (b,r) 的公共正约数集合双向相同；余数又严格小于正的 b，所以可以反复缩小直到第二个数为 0。
C++ 实现方法
先把输入归一为非负数；循环中先保存 remainder=a%b，再更新 a、b；求 lcm 时先保护零，再按 a/greatest*b 先除后乘。本课数据保证结果可放入 long long。

01 最大公约数与欧几里得算法

先看固定例子 48 和 18。除法关系是 48=18×2+12，也就是余数 12 来自“48 减去 18 的 2 倍”。

若正整数 d 同时整除 48 和 18，那么 d 也整除 48-18×2=12；所以原来每一个公共约数，也都是 18 和 12 的公共约数。反过来，若 d 同时整除 18 和 12，那么 d 也整除 18×2+12=48；所以 18 和 12 的每一个公共约数，也都是 48 和 18 的公共约数。两个方向都成立，公共正约数集合完全相同，最大者当然也相同。一般地，当 a=q×b+r 时，gcd(a,b)=gcd(b,r)，其中 r=a%b。

这条关系可以重复使用：(48,18) 变成 (18,12)，再变成 (12,6)，最后变成 (6,0)。当 b>0 时，余数满足 0<=r<b，因此新的第二个数严格变小，不会无限循环；当 b==0 时停止，当前 a 就是最大公约数。

循环每轮必须按固定顺序做三件事：先计算并保存 remainder=a%b，再令 a=b，最后令 b=remainder。临时量 remainder 保住了旧 a 和旧 b 算出的余数，避免前一次赋值把旧值覆盖。while (b != 0) 还保证只有除数非零时才执行 %。

本课输入允许负数和 0，所以 main 先把 a、b 归一为非负数。约定 gcd(0,b)=|b|、gcd(a,0)=|a|，教学程序把 gcd(0,0) 定义为 0；题目若另有定义，应以题面为准。数据范围排除了 LLONG_MIN，因此取相反数安全。

当两数都为正时，欧几里得算法的时间复杂度是 O(log(min(|a|,|b|)))；含零边界直接结束，是 O(1)。若要统一写法，可记为 O(log(min(|a|,|b|)+1))。程序只使用几个 long long 变量，额外空间复杂度是 O(1)。

具体样例与推演

场景：从“枚举公共约数”出发，用 48 和 18 亲手形成余数替换规则，再按程序顺序走到停止。

  1. 自然想法是从 18 开始向下试除 48 和 18；数字接近 10^9 时，逐个尝试可能很慢，我们需要一次可靠的缩小。
  2. 写出 48=18×2+12。若 d 同时整除 48 和 18，则 d 也整除 48-18×2=12，所以原来的公共约数不会丢。
  3. 反过来，若 d 同时整除 18 和 12，则 d 也整除 18×2+12=48，所以替换后没有增加假的公共约数。
  4. 两个方向合起来，gcd(48,18)=gcd(18,12)。一般地，a=q×b+r 时都有 gcd(a,b)=gcd(b,r)。
  5. 程序从 (48,18) 开始：b!=0，先保存 remainder=48%18=12，再更新为 (18,12)。
  6. 第二轮保存 18%12=6，更新为 (12,6)；第三轮保存 12%6=0，更新为 (6,0)。
  7. 此时 b==0，循环停止，返回 a=6。只要 b>0，新余数就在 0 到 b-1 之间，第二个数严格变小，因此过程一定结束。
  8. 输入先取绝对值，零边界按 gcd(0,b)=|b|、gcd(a,0)=|a|、教学约定 gcd(0,0)=0 处理。两数为正时是 O(log(min(|a|,|b|)))，含零直接 O(1)，额外空间 O(1)。

适用结论：先证明替换前后公共正约数双向相同，再使用“判断 b、保存余数、更新 a、更新 b”的循环。固定样例必须走出 12、6、0 三个真实余数，最终 gcd=6。

错误反例：错误写法：先执行 a=b，再计算 b=a%b。观察到的现象是 48、18 第一轮就把 b 错算为 0。

为什么错：根因是旧 a 被覆盖，第二句实际计算 18%18；另外，不检查 b 是否为 0 就取模还会造成除零错误。

怎样改：修正为先保存 remainder=a%b，再依次更新 a、b，并把取模放在 while (b != 0) 内。重跑 48 18 时余数必须是 12、6、0；重跑 24 0 时不得进入循环，答案必须是 24。

02 最小公倍数

对两个正整数，最大公约数记为 g。a×b 中的公共部分被重复计算了一次，所以有 gcd(a,b)×lcm(a,b)=a×b，进而得到 lcm(a,b)=a/g×b。

程序必须先处理零：只要 a 或 b 为 0，就把最小公倍数定义为 0。只有两数都非零时，g 才至少为 1，除法 a/g 才能安全执行；这也避免了 gcd(0,0)=0 时发生除零。

两数都非零时要先算 a/g，再乘 b。先除后乘能减小中间结果，却不代表任何范围都绝不会溢出。本课归一化后的 a、b 都不超过 10^9，因此最小公倍数不超过 10^18，可以放进 long long；换一道题必须重新核对范围。

具体样例与推演

场景：复用刚得到的 gcd 计算 lcm，同时把 0、运算顺序和 long long 范围放进同一条安全路径。

  1. 正整数 48 和 18 的公共部分是 gcd=6；在 48×18 中，这部分重复了一次，所以先从 48 中除掉 6，再乘 18。
  2. 零保护必须在除法之前：若 a==0 或 b==0，直接令 least=0。这样 0 0 不会出现 a/greatest 中除数为 0。
  3. 本例两数都非零，零保护判断为 false；先算 48/6=8，再算 8×18=144，得到 least=144。
  4. 先除后乘能减小中间量，但不能替代范围证明。本课 |a|、|b|<=10^9，非零 lcm 最大不超过 10^18，处在 long long 范围内。
  5. 独立自检：gcd(12,18)=6，先算 12/6=2，再算 2×18=36，所以 lcm(12,18)=36。

适用结论：可靠顺序是“非负归一化 → 求 greatest → 任一数为 0 就令 least=0 → 否则算 a/greatest*b”。本例完整答案为 6 144。

错误反例：错误写法：直接计算 a*b/greatest，或在 0 0 时仍执行 a/greatest*b。现象可能是大数结果变负、变乱，或发生除零。

为什么错：根因有两个：乘法先产生过大的中间值；双零时 greatest=0，不能作为除数。即使先除后乘，超出题目范围时仍可能溢出。

怎样改：修正为先用 if (a != 0 && b != 0) 保护零，再用 long long 按 a/greatest*b 计算，并证明范围。重跑 0 0 应输出 0 0；重跑 1000000000 999999999 应输出 gcd=1、lcm=999999999000000000。

03 约分与多个数的最大公约数

分数 p/q 的前提是 q!=0。先把分母整理为正数：若 q<0，就把 p、q 同时变号，让负号只留在分子；再令 g=gcd(|p|,|q|)，把分子和分母都除以 g。因为除的是最大公约数，得到的两个数互质，分数已经最简。

若 p=0 且 q!=0，规范结果直接写成 0/1。例如 0/-15 先整理符号后仍应归一为 0/1，而不是保留 0/15。

多个数的最大公约数可以从左到右合并。先求 current=gcd(a,b)，再求 gcd(current,c)，继续处理后面的数；每一步都把“已经处理过的数的最大公约数”与下一个数合并，结果保持非负。例：gcd(24,36)=12，再算 gcd(12,60)=12，所以三个数的最大公约数是 12。

具体样例与推演

场景：先完成 84/126 的引导约分，再把同一个 gcd 函数用于 24、36、60，最后独立检查符号与零。

  1. 引导练习第一步：84%126=84，状态由 (84,126) 变为 (126,84)；第二步余数 42，变为 (84,42)；第三步余数 0，停在 (42,0)。
  2. 因此 gcd(84,126)=42，分子分母同除 42 得到 2/3；再检查 gcd(2,3)=1，确认已经最简。
  3. 规范分数还要满足分母非零并且最终为正。若原分母为负，分子分母同时变号，把负号留在分子；若分子为 0，则把结果统一写成 0/1。
  4. 多个数从左到右合并：先算 current=gcd(24,36)=12，再算 gcd(current,60)=12，因此 gcd(24,36,60)=12。每次返回非负数，下一次可以继续直接使用。
  5. 独立练习答案：gcd(24,36,60)=12；lcm(12,18)=36；gcd(-48,18)=6 且 lcm(-48,18)=144；gcd(0,24)=24 且 lcm(0,24)=0；教学约定下 gcd(0,0)=0、lcm(0,0)=0。

适用结论：成功标准：能写出 84/126 的三个余数并得到 2/3；能说明分母必须非零且最终为正、0/q 归一为 0/1；能按左到右顺序得到三个数 gcd=12，并正确处理负数和零。

错误反例：错误做法：84/126 只同除 2 得到 42/63 就停止，或把 -6/-9 约成 -2/-3 后保留负分母。观察到的现象是分数仍可继续约分，或同一个值出现多种符号写法。

为什么错：根因是没有除以最大公约数，也没有执行“分母最终为正”的规范；只找到一个共同因子并不能保证最简。

怎样改：修正为先确认分母非零，整理符号，再同除 gcd(|p|,|q|)；分子为 0 时写成 0/1。重跑 84/126 必须得到 2/3，-6/-9 必须得到 2/3，0/-15 必须得到 0/1。

典型例题

基础例题：最大公约数与最小公倍数

题意：输入两个整数 a、b（-10^9<=a,b<=10^9），输出非负的最大公约数和最小公倍数。本程序约定 gcd(0,0)=0，任一输入为 0 时 lcm=0。

示例输入：

48 18

示例输出：

6 144

说明：归一化后仍是 48 和 18。三轮余数依次为 12、6、0，停止状态是 (6,0)，所以 greatest=6。两数都非零，通过零保护后先算 48/6=8，再算 8×18=144，最终输出 6 144。

#include <bits/stdc++.h>
using namespace std;

long long gcdValue(long long a, long long b) {
    while (b != 0) {
        long long remainder = a % b;
        a = b;
        b = remainder;
    }
    return a;
}

int main() {
    long long a, b;
    cin >> a >> b;

    if (a < 0) {
        a = -a;
    }
    if (b < 0) {
        b = -b;
    }

    long long greatest = gcdValue(a, b);
    long long least = 0;
    if (a != 0 && b != 0) {
        least = a / greatest * b;
    }

    cout << greatest << " " << least << "\n";
    return 0;
}

典型应用：引导练习——一边辗转相除，一边约分

题意：不用写新程序，补完 gcd(84,126) 的每轮状态，再把 84/126 约成最简分数。

示例输入：

84 126

示例输出：

gcd=42，84/126=2/3

解题说明：84%126=84，状态变为 (126,84)；126%84=42，变为 (84,42)；84%42=0，停在 (42,0)。因此 gcd=42，分子分母同时除以 42，得到 2/3。自检：2 和 3 已互质，分母为正。

执行追踪：48 18 从读入到输出的七步执行账本

常见错误

  • 覆盖旧值后才求余数：现象：48 和 18 第一轮就错误得到余数 0。原因：先执行 a=b 后，a%b 已变成 18%18。修正：先保存 remainder=a%b，再更新 a、b。重跑标准：三轮余数必须依次为 12、6、0，答案为 6。
  • 没有在取模和求 lcm 前保护零：现象：输入 24 0 或 0 0 时可能除零或崩溃。原因：对 b==0 仍执行 %，或用 greatest==0 做除数。修正：循环只在 b!=0 时取模，lcm 在任一数为 0 时直接取 0。重跑标准：24 0 输出 24 0，0 0 输出 0 0。
  • 先乘后除或忽略整数范围：现象：大输入得到负数或错误结果。原因：a*b 可能在除以 gcd 之前溢出。修正：使用 long long，先算 a/greatest 再乘 b，并按题目范围证明最终值安全。重跑标准：1000000000 999999999 输出 1 999999999000000000。
  • 只除任意共同因子就停止约分：现象：84/126 写成 42/63 后仍可继续约分。原因：除的是 2，不是最大公约数 42。修正：分子分母同除 gcd(|p|,|q|)，并整理分母符号与零分子。重跑标准：84/126 得到 2/3，0/-15 得到 0/1。

覆盖旧 a 后才求余数

错误代码：

a = b;
b = a % b;

错误原因：现象：48 和 18 第一轮就得到 b=0。原因：第二行实际算的是 18%18，旧 a 已丢失。修正：余数必须先存入临时量。重跑标准：余数依次为 12、6、0，gcd 为 6。

正确写法：

long long remainder = a % b;
a = b;
b = remainder;

b 为 0 时仍执行取模

错误代码：

long long remainder = a % b;

错误原因：现象：输入 24 0 时出现除零错误。原因：% 的右操作数不能为 0。修正：先用循环条件拦住 b==0。重跑标准：24 0 不进入循环，gcd 为 24。

正确写法：

while (b != 0) {
    long long remainder = a % b;
    a = b;
    b = remainder;
}

lcm 没有零保护或先乘后除

错误代码：

long long least = a * b / greatest;

错误原因：现象：0 0 会除零，大数还可能先溢出。原因：没有先处理零，而且 a*b 先产生更大的中间值。修正：先保护零，非零时再先除后乘；但换题仍要核对范围。重跑标准：0 0 输出 0 0，1000000000 999999999 的 lcm 为 999999999000000000。

正确写法：

long long least = 0;
if (a != 0 && b != 0) {
    least = a / greatest * b;
}

只除一个共同因子就停止

错误代码：

84 / 2 = 42，126 / 2 = 63

错误原因：现象：得到 42/63 后仍能同时除以 21。原因：2 只是共同因子，不是最大公约数。修正：同除 gcd(84,126)=42，并整理符号与零分子。重跑标准：84/126 得到 2/3，0/-15 得到 0/1。

正确写法：

84 / 42 = 2，126 / 42 = 3

第 3 题正整数 a、b 的最小公倍数可怎样安全计算？
