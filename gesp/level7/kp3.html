二维动态规划

03
GESP 7级知识字典 · 知识点 03

处理网格最值、最长公共子序列与编辑距离。

检索词：网格最值编辑距离

知识范围与官方定位

官方七级大纲要求掌握二维动态规划。二维状态常用两个位置共同描述子问题：可以是网格的行列，也可以是两个序列各自的前缀长度。重点仍是状态含义、边界、转移和计算顺序。

什么时候使用二维 DP？ 当答案同时由两个位置决定，例如网格中的行与列、两个字符串各自的前缀长度，单个下标无法区分所有子问题时，可以设计 dp[i][j]。两维各表示什么必须先写清楚，再判断上、左、左上等依赖是否已经算好。

01 二维状态与依赖方向

dp[i][j] 只是存储形式，必须补全含义。例如“从 (1,1) 到 (i,j) 的路径数”或“两个序列前 i、j 项的最长公共子序列长度”。填表顺序应保证转移所依赖的位置已经求出。

具体推演： 在 2 × 3 网格中，dp[2][3] 若定义为“到达第 2 行第 3 列的路径数”，两个下标分别固定了行和列；它依赖已经算好的 dp[1][3] 与 dp[2][2]。若只写成一维 dp[3] 却没有说明当前保存的是哪一行，就无法判断读取的是上一行旧值还是当前行新值。

02 网格路径计数

若只能向右或向下移动，到达 (i,j) 的最后一步来自 (i-1,j) 或 (i,j-1)：

dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

使用 1 下标时，可以令 dp[1][1] = 1，再按行、列递增计算。边界外状态不能被读取。

具体推演： 无障碍 2 × 3 网格先得到第一行 1,1,1、第一列 1,1；随后 dp[2][2] = 1 + 1 = 2，dp[2][3] = dp[1][3] + dp[2][2] = 1 + 2 = 3。中间值说明每个状态恰好汇总“从上来”和“从左来”两类互不重复的路径。

03 障碍与网格最优值

遇到障碍格时，路径数应直接设为 0，表示不可达。求最大路径和时从合法来源取 max，求最小路径时从合法来源取 min；若权值可能为负，不能用 0 代表不可达。路径数量使用相加，最大路径和或最小路径使用比较，不能混用转移与初值。

具体推演： 在 2 × 3 网格中若 (1,2) 是障碍，第一行路径数变为 1,0,0；第二行依次为 1、1、1。到 (2,3) 的唯一合法路线是先向下再一直向右。若仍让障碍格沿用普通转移，dp[1][2] 会错误变成 1，后面就会凭空多出一条穿过障碍的路线。

04 最长公共子序列 LCS

设 dp[i][j] 表示字符串 a 的前 i 个字符与 b 的前 j 个字符的 LCS 长度：

  • a[i - 1] == b[j - 1]：dp[i][j] = dp[i - 1][j - 1] + 1；
  • 不相等：dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])。

字符串使用 0 下标，所以长度为 i、j 的前缀末尾分别是 a[i - 1]、b[j - 1]。子序列可以不连续，但相对顺序不能改变。空前缀边界 dp[0][j] 与 dp[i][0] 都为 0。

具体推演： 对 a = "abc"、b = "ac"，先匹配 a 得到长度 1；字符 b 在第二个字符串当前前缀中没有匹配，长度仍为 1；最后两个 c 相等，从左上状态加一得到 2。最终公共子序列是 "ac"，它在 a 中不连续，却保持了先 a 后 c 的相对顺序。

05 编辑距离入门

编辑距离表示把字符串 a 的前 i 个字符变成字符串 b 的前 j 个字符，最少需要多少次单字符操作。允许的三种操作是插入、删除、替换。

设 dp[i][j] 为两个前缀间的最少编辑次数。空串变成长度为 j 的前缀需要插入 j 次，所以 dp[0][j] = j；长度为 i 的前缀变成空串需要删除 i 次，所以 dp[i][0] = i。若 a[i - 1] == b[j - 1]，末尾不用操作，从 dp[i - 1][j - 1] 转移；否则在插入、删除、替换三个来源的最小值上加 1。

具体推演： 把 "cat" 变成 "cut" 时，首字符 c 与末字符 t 都可保留，只需把中间的 a 替换成 u，总代价为 1。若只允许插入和删除，就要先删 a 再插 u，代价为 2；同时比较三种操作后取最小值，才能得到正确编辑距离 1。

典型例题

基础例题

在没有障碍的 2 × 2 网格中，从左上角出发，只能向右或向下走到右下角。令 dp[i][j] 表示到达 (i,j) 的路径数，则状态表为：

位置 路径数 来源
(1,1) 1 起点
(1,2) 1 只能从左边来
(2,1) 1 只能从上边来
(2,2) 2 1 + 1

典型应用例题

计算两个字符串的 LCS 长度：

#include <bits/stdc++.h>using namespace std;
int main() {    string a, b;    cin >> a >> b;    int n = a.size();    int m = b.size();    int dp[205][205] = {};    // dp[i][j] 表示 a 的前 i 个字符与 b 的前 j 个字符的 LCS 长度。    for (int i = 1; i <= n; i++) {        for (int j = 1; j <= m; j++) {            // 两个前缀的末尾字符下标分别是 i-1 和 j-1。            if (a[i - 1] == b[j - 1]) {                dp[i][j] = dp[i - 1][j - 1] + 1;            } else {                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);            }        }    }    // 两个完整字符串对应状态 dp[n][m]。    cout << dp[n][m] << endl;    return 0;}

输入 abcde ace，输出 3。时间复杂度为 O(nm)，空间复杂度为 O(nm)。

状态追踪

以 a = "ab"、b = "ac" 为例，空前缀所在的第 0 行和第 0 列都是 0：

dp[i][j] 比较的字符 转移 结果
dp[1][1] a 与 a dp[0][0] + 1 1
dp[1][2] a 与 c max(dp[0][2], dp[1][1]) 1
dp[2][1] b 与 a max(dp[1][1], dp[2][0]) 1
dp[2][2] b 与 c max(dp[1][2], dp[2][1]) 1

两个完整字符串的 LCS 长度是 dp[2][2] = 1，可以选择公共子序列 "a"。

常见错误

错误做法 为什么错 正确方法
不解释两个下标分别代表什么 状态与转移无法核对 先写出 dp[i][j] 的完整含义
访问 i-1、j-1 却不设空前缀边界 第一个字符处会越界或使用错误初值 明确初始化第 0 行和第 0 列
把子序列当成必须连续的子串 LCS 允许跳过字符 只保持相对顺序，不要求连续
障碍格仍沿用普通转移 不存在的路径会被继续传递 障碍状态直接设为 0
字符串写成 a[i]、b[j] 前缀长度与字符串下标错一位 比较 a[i - 1] 与 b[j - 1]
编辑距离只考虑替换 漏掉插入和删除可能更优的情况 比较插入、删除、替换三个来源

错误反例推演

在 2 × 3 网格中把 (1,2) 设为障碍。错误写法仍执行普通转移，会得到第一行 1,1,1、最终 dp[2][3] = 3；正确写法先把障碍状态设为 0，状态表变为第一行 1,0,0、第二行 1,1,1，答案只有 1。多出的两条路线都穿过了不可走格，说明障碍必须在转移前截断。
