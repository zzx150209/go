GESP 7级知识字典 · 知识点 04

掌握最大连续和、最长上升子序列与背包空间优化。

检索词：最大连续和空间优化

知识范围与官方定位

官方七级大纲要求掌握动态规划最优解优化。本页从“为什么可以从子问题最优解得到当前最优解”出发，整理最长上升子序列、候选最值比较和空间压缩。优化必须保持原状态含义与依赖关系，不能只追求数组更小。

当题目要求连续区间或子序列的最优值时，先写出能说明答案的基础状态；当基础写法已经正确、但重复枚举候选或保存了不再需要的旧阶段时，再考虑时间或空间优化。优化的判断依据是依赖关系，不是代码看起来更短。

01 最优状态与最大连续和

若一个问题的最优解能由若干更小问题的最优解组合得到，就具有最优子结构。状态转移要枚举所有合法前驱，再取 min 或 max。求最小值时初值应足够大，求最大值时则应结合题意设为合法下界。

最大连续和是典型的一维最值状态。设 dp[i] 表示必须以第 i 个数结尾的最大连续子段和，则 dp[i] = max(a[i], dp[i - 1] + a[i])：要么从当前数重新开始，要么接到前一段后面。最终答案是所有 dp[i] 的最大值；全负序列不能强行选择不存在的空子段 0。

具体推演： 对序列 -2, 3, -1，dp[1] = -2；到 3 时比较“单独从 3 开始”和“接在 -2 后得到 1”，选择 3；到 -1 时比较 -1 与 3 + (-1) = 2，选择 2。三个结尾状态为 -2,3,2，最终答案取最大值 3。

02 最长上升子序列 LIS

设 dp[i] 表示以第 i 个数结尾的最长严格上升子序列长度。初值为 1；枚举 j < i，若 a[j] < a[i]，可以转移：

dp[i] = max(dp[i], dp[j] + 1)

最终答案是所有 dp[i] 的最大值，而不一定是 dp[n]。严格上升使用 <，若题目说“不下降”才使用 <=。

具体推演： 对序列 3,1,2，初值都是 1。3 不能接到任何更早元素后；1 也不能接在 3 后；处理 2 时，1 < 2，所以由 dp[2] + 1 得到 dp[3] = 2。最终状态为 1,1,2，最长严格上升子序列是 1,2。

03 01 背包与候选最值优化

01 背包 的二维状态压成一维后，每件物品最多选一次，因此容量必须从大到小倒序更新。正序会读到本轮刚写入的新状态，造成同一物品被重复选择。

当多个状态反复枚举同一批候选值时，还可以思考是否能维护前缀最值或其他汇总量。但必须先写出正确的基础转移，证明汇总量正好覆盖相同候选集合，不能因为变量更少就认为更优。网格最值也遵循同一原则：从可达的上方、左方等合法来源中取 max 或 min。

具体推演： 背包容量为 4，当前只有一件重量 2、价值 3 的物品。倒序先算容量 4，读取旧的 dp[2] = 0，得到 3；再算容量 2，得到 3，最终同一物品只用一次。若正序先把 dp[2] 改成 3，再算 dp[4] 就会读到这个本轮新值并得到 6，等于把唯一物品选了两次。

04 空间优化与更新方向

如果当前阶段只依赖上一阶段，可以使用滚动数组；若压成一维数组，更新方向必须避免覆盖仍要读取的旧状态。依赖“上一行左侧旧值”的问题往往需要倒序，依赖“当前行左侧新值”的问题往往需要正序，最终以原转移为准。

具体推演： 网格路径压成一维后，处理第二行时 dp[j] 原本保存上方路径数，dp[j - 1] 已更新为当前行左方路径数，因此要从左到右。若上一行是 1,1,1，第二行依次更新为 1,2,3；反向更新会在计算右侧时读不到当前行已经得到的左方状态，结果不再对应原二维转移。

知识点速查表

先确认状态含义不变，再比较时间和空间。LIS 的状态以位置结尾；候选最值必须全部合法；滚动数组需要区分上一阶段与当前阶段；一维更新方向由依赖关系决定。

典型例题

基础例题

序列 -2 3 -1 4 -5 的最大连续子段和可以逐项计算：

i a[i] dp[i] = max(a[i], dp[i-1] + a[i]) 当前答案
1 -2 -2 -2
2 3 3 3
3 -1 2 3
4 4 6 6
5 -5 1 6

最优连续子段是 3 -1 4，答案为 6。状态强调“必须以当前位置结尾”，最终答案再取所有状态的最大值。

典型应用例题

求长度为 n 的序列的 LIS 长度：

#include <bits/stdc++.h>using namespace std;
int main() {    int n;    int a[1005] = {};    int dp[1005] = {};    cin >> n;    for (int i = 1; i <= n; i++) {        cin >> a[i];        // dp[i] 初始为 1：只选择 a[i] 自身也是合法上升子序列。        dp[i] = 1;    }    int answer = 0;    // 按结尾位置从左到右计算，当前状态只读取更早的 j。    for (int i = 1; i <= n; i++) {        for (int j = 1; j < i; j++) {            if (a[j] < a[i]) {                // 把 a[i] 接到以 j 结尾的严格上升子序列后面。                dp[i] = max(dp[i], dp[j] + 1);            }        }        // 最优结尾不一定是 n，所以每个 dp[i] 都要参与答案比较。        answer = max(answer, dp[i]);    }    cout << answer << endl;    return 0;}

输入 6 和 3 1 2 5 4 6，输出 4。时间复杂度为 O(n^2)，空间复杂度为 O(n)。

状态追踪

以容量为 4、只有一件重量 2、价值 3 的 01 背包为例：

写法 更新顺序 容量 2 更新后 容量 4 更新后
优化前：二维 dp[item][capacity] 从上一行读取 选一次得到 3 仍只能选一次，得到 3
优化后：一维 dp[capacity] 倒序 4 → 2 得到 3 先更新容量 4，读取的仍是上一轮 dp[2] = 0，得到 3
错误的一维正序 2 → 4 先得到 3 又读取本轮的新 dp[2] = 3，错误得到 6

空间优化后状态含义不变；倒序的作用是阻止同一件物品在同一轮被重复使用。

常见错误

错误做法 为什么错 正确方法
把 dp[i] 写成前 i 个数的统一答案，却使用“以 i 结尾”的转移 状态含义和转移不一致 明确 dp[i] 是否必须以第 i 个数结尾
LIS 只输出 dp[n] 最优子序列不一定在最后一个位置结束 取所有 dp[i] 的最大值
严格上升使用 <= 相等元素会被错误接入 严格上升用 <，不下降才用 <=
最大连续和把答案初始化为 0 全负序列会错误选择空子段 用第一个合法状态初始化答案
01 背包一维状态正序更新 同一物品会在一轮中被重复使用 容量从大到小倒序更新
没有分析依赖就改变更新方向 可能覆盖后面仍要读取的旧状态 先画清依赖，再决定正序或倒序

错误反例推演

全负序列 -5,-2,-8 若把最大连续和答案初始化为 0，每个合法非空子段都小于 0，程序最终会保留 0；但题目要求非空子段，真实候选中最大的是只选 -2。把答案改为第一个合法状态 -5，再依次比较，才会更新到正确结果 -2。
