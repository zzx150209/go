算法的概念与描述

04
GESP 3级知识字典 · 知识点 04

判断步骤是否明确且能结束，按接近代码的步骤推断输出。

检索词：步骤明确结果推断

本课先记住

  • 核心结论： 解决一个问题时，按顺序完成的一步步操作，合起来叫作算法。合格的算法必须说清输入、输出和每一步，并且能够在有限步后结束。
  • 常用语法： 本课不新增 C++ 语法，继续使用已经学过的 cin、赋值、if 和 cout。像代码一样把步骤写出来，但不要求完全符合 C++ 格式，这种写法叫作伪代码。
  • 最小示例： 输入 3 8 5，先令 maximum=3，再比较后得到 maximum=3→8→8，最后输出 8。
  • 关键易错点：
    • 只写“求出最大值”没有给出可执行步骤。
    • 四种描述中的输入、顺序、条件方向和输出必须一致。
    • 一次样例追踪能帮助发现错误，但不能单独证明所有输入都正确。

知识范围与使用边界

本课只解决一个问题：怎样把“要完成什么”整理成计算机能够照着执行的一组步骤。我们会用“输入三个整数，输出其中的最大值”贯穿自然语言、流程图、伪代码、执行追踪和 C++ 程序。变量、输入输出、赋值和 if 都已经学过；流程图的起止、输入输出、处理、判断图形也已经在二级学过，这里只复用，不重新讲一遍符号课。

本课聚焦三个核心：用五个特征检查步骤；核对四种描述是否表达同一过程；用具体输入追踪条件、路径、动作和状态。后续课程会再学习更多解决问题的方法，本课不提前展开，也不把一次样例追踪说成对所有输入的完整证明。

01 什么是算法

核心一：用五个特征检查步骤

算法的五个基本特征

题目说：“输入三个整数，输出其中的最大值。”如果只回答“求出最大值”，计算机仍然不知道先做什么、后做什么。可以真正执行的步骤应当写成：先把第一个数作为当前最大值，再依次比较第二个数和第三个数，遇到更大的数就更新，最后输出当前最大值。

这两句话的差别不在长短，而在于后者能够逐步执行。检查一段描述时，可以使用下面五个基本特征。

特征 准确含义 对当前任务的检查问题
输入 可以有零个或多个外部给定的数据 是否明确读入 a、b、c？
输出 至少产生一个与问题有关的结果 是否明确输出 maximum？
有穷性 对每组合法输入，都能在有限步后停止 两次比较后是否一定到达输出和结束？
确定性 每一步含义清楚，相同状态下执行方式唯一 “更大时更新”是否写明比较对象和更新值？
可行性 每一步都能用有限次基本操作完成 是否给出读入、赋值、比较和输出，而不是直接写“得到答案”？

“适当比较三个数，得到答案”不是合格描述。“适当”没有明确规则，“得到答案”也不是可以直接执行的基本操作。把它改成“令 maximum=a；若 b>maximum 就令 maximum=b；若 c>maximum 就令 maximum=c；输出 maximum”，五项检查才都有可以核对的内容。

02 分析问题的输入、输出和处理步骤

核心二：四种描述保持同一执行含义

先冻结这道题的单一事实：输入是三个整数 a、b、c，状态变量是 maximum，两个条件依次是 b>maximum 和 c>maximum，输出是最终的 maximum。表达方式可以改变，这四项不能悄悄改变。

第一次判断检查 b 比当前最大值更大是否成立，第二次判断再用同样规则检查 c；两次判断读取的是按顺序更新后的同一个状态。

自然语言描述算法

  1. 输入三个整数 a、b、c。
  2. 把 a 保存为当前最大值 maximum。
  3. 如果 b 比当前最大值更大，就把 maximum 更新为 b。
  4. 如果 c 大于当前最大值，就把 maximum 更新为 c。
  5. 输出 maximum，结束。

流程图描述算法

流程图把上面五步放到带箭头的执行路径中。每个判断都有“是”和“否”两条出口：为“是”时更新，为“否”时不更新；两条路径随后汇合到下一步。输入输出框在标准手绘流程图中使用平行四边形，处理步骤使用矩形，判断使用菱形。

输入 a, b, cmaximum ← a如果 b > maximum，那么 maximum ← b如果 c > maximum，那么 maximum ← c输出 maximum
#include <bits/stdc++.h>using namespace std;
int main() {    int a, b, c;    cin >> a >> b >> c;
    // 用第一个真实输入初始化，全为负数时也不会凭空得到 0    int maximum = a;
    if (b > maximum) {        maximum = b;    }    // 这里读取的是比较 b 之后的当前 maximum    if (c > maximum) {        maximum = c;    }
    cout << maximum << '\n';    return 0;}

教学程序支持三个处于 C++ int 可表示范围内的整数。程序只做赋值和比较，不做可能溢出的加减乘除。下面五组结果分别覆盖两次更新、两次不更新、相等边界和全负数边界：

输入 maximum 变化 精确输出
3 8 5 maximum=3→8→8 8
9 3 7 maximum=9→9→9 9
3 5 9 maximum=3→5→9 9
4 4 4 maximum=4→4→4 4
-4 -9 -2 maximum=-4→-4→-2 -2

完成这道典型例题的成功标准是：四种描述都保留相同的三个输入、两次比较顺序、真假方向和最终输出；五组输入都得到表中的精确结果。

典型应用：判断是否达到及格线

错误描述：“输入分数；如果分数达到 60，就输出 Pass；结束。”当输入 59 时，这段描述没有给出任何输出，因此没有覆盖题目中的全部合法输入。修正后应明确：条件成立输出 Pass，否则输出 Fail，两条路径最后都结束。

原因：当三个输入都小于 0 时，没有任何数能更新 maximum，程序会输出并不存在于输入中的 0。

检查方法：维护最值时，优先用第一个真实候选值初始化。

常见错误

  1. 把任务目标当作可执行步骤。 现象：描述只有“求出最大值”。原因：没有初始化、比较和更新动作。修正：写出 maximum=a，再依次比较 b 和 c。复验：逐步指出每句话由哪条语句执行。
  2. 四种描述的条件方向不一致。 现象：流程图在“是”出口更新，伪代码却在条件为假时更新。原因：互译时只看关键词，没有核对真假路径。修正：统一为“新数大于当前最大值时更新”。复验：代入 3 8 5，确认第一次走“是”、第二次走“否”。
  3. 追踪时读取旧状态。 现象：比较 c 时仍使用初始值 3。原因：漏记比较 b 后的更新。修正：每一步先记录更新后状态，再进入下一步。复验：表中必须出现 maximum=3→8→8。
  4. 最大值凭空初始化为 0。 现象：输入 -4 -9 -2 却输出 0。原因：0 不是三个候选值之一。修正：使用 maximum=a。复验：全负数样例应精确输出 -2。
  5. 把一个样例当成全部证明。 现象：只测 3 8 5 正确就停止检查。原因：其他路径和边界还没有执行。修正：补测两次都假、两次都真、相等和全负数。复验：五组代表输入全部得到登记输出。
