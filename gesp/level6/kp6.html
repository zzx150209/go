01 队列分层扩展

BFS 从起点开始处理距离 0、1、2…… 的状态。先把起点入队；循环取出队首，依次检查相邻状态，并把新状态加入队尾。先进先出让距离较小的状态先处理。

#include <bits/stdc++.h>using namespace std;
int n, m, dist[105][105];char grid[105][105];int fx[5] = {0, -1, 1, 0, 0};int fy[5] = {0, 0, 0, -1, 1};
int main() {    cin >> n >> m;    for (int x = 1; x <= n; x++) {  // 读入网格并把所有格子设为未访问        for (int y = 1; y <= m; y++) {            cin >> grid[x][y];            dist[x][y] = -1;        }    }    queue<pair<int, int>> q;    if (grid[1][1] == '.') {  // 起点可走时，把它作为第 0 层加入队列        dist[1][1] = 0;        q.push({1, 1});    }    while (!q.empty()) {  // 按发现顺序逐个扩展队首格子        int x = q.front().first, y = q.front().second;        q.pop();        for (int d = 1; d <= 4; d++) {  // 检查当前格子的四个相邻位置            int nx = x + fx[d], ny = y + fy[d];            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;  // 越界位置不能进入            if (grid[nx][ny] == '#' || dist[nx][ny] != -1) continue;  // 跳过障碍和已发现格子            // 第一次发现邻点时就确定最短距离并立即标记            dist[nx][ny] = dist[x][y] + 1;            q.push({nx, ny});        }    }    cout << dist[n][m] << '\n';    return 0;}

测试案例

类型 网格情况 应得到的关键结果
基础 2×2 全部可走 从左上到右下最短为 2 步
边界 1×1，起点就是终点 距离为 0，不需要移动
特殊 终点被障碍完全围住 搜索结束仍为 -1，表示无路可达
特殊 存在多条可行路径 返回最少步数，不统计路径总数

常见错误

等到出队才标记

原因：等待出队期间仍显示未访问，可能被重复加入。

检查方法：把这三步写成固定顺序。

把 BFS 当成任意代价下的最短路

原因：普通 BFS 的分层只表示步数，只有每一步代价相同时，先到达才保证总代价最小。

检查方法：题目若给不同费用，本页结论不能直接套用。

整页综合测试

5 题

第 1 题BFS 使用队列的主要原因是什么？

答案：A
队列让先发现的状态先处理，因此距离较小的一层会在下一层之前完成扩展。
对应知识点：01

第 2 题每步代价相同的网格中，BFS 首次到达某格意味着什么？

答案：B
BFS 按距离从小到大扩展，所以第一次到达时记录的就是从起点出发的最少步数。
对应知识点：01

第 3 题发现未访问邻点时，正确顺序是什么？

答案：B
入队时立即写入距离或标记，可防止同一状态在等待出队期间被重复加入。
对应知识点：02

第 4 题dist 全部初始化为 -1，起点设为 0；结束后终点仍为 -1 表示什么？

答案：A
搜索结束仍为 -1 表示终点从未被发现，因此不存在从起点到终点的可达路径。
对应知识点：02

第 5 题3×3 空网格从 (1,1) 到 (3,3)，每次上下左右一步，最少几步？

答案：C
行坐标要增加 2、列坐标也要增加 2，总共至少 4 步，并且确实存在 4 步路径。
对应知识点：03
